# Math problem workspace

This directory belongs to one mathematical problem or research task. Keep the
work reproducible: save the statement, derivation, source URLs, programs, and
the commands used to check the result.

Start with `AGENTS.md`, then use the files under `prompts/` for role-specific
guidance. Define completion in `GOAL.md`, track work in `TASKS.md`, and keep
provisional calculations in the scratch with `note_scratch`. Cognee holds
both: the durable memory the whole project reads, and the scratch only the
roles doing provisional work can reach.
