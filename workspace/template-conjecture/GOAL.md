# Goal

_Replace this with the objective for this conjecture. A workspace launched by
`./conjecture` should supply its own; this is what a run reads if nobody did._

The working assumption is that this problem will not be solved. It has resisted
specialists for years, so the deliverable is **a genuine partial result stated
exactly**, not a claim of the whole. Claiming the conjecture on an argument that
has not survived attack is the one outright failure available here.

## What counts as a result

- A statement in `code/lean/Lib/` that the kernel accepts, and what it rests on.
  A `conditional` verdict over cited literature is a real result.
- A restriction under which the conjecture holds, with its hypotheses written as
  binders rather than described.
- A counterexample, with the space it was found in recorded.
- A route closed, with the obstruction that closed it named exactly. This is a
  result and belongs in the record as one.

## What does not count

- A number no statement refers to.
- A summary of the literature with nothing formalised.
- A restatement of the conjecture as itself.
