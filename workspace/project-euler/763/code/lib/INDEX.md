# Index — code/lib

What each file in this folder is for. Keep it current: describe a file when you create it, and refresh this index after adding, renaming, or deleting files.

| File | Purpose |
| --- | --- |
| `amoeba.py` | Reusable 3D (parameterized-d) PE763 routines: children(p,d), lvl(p) (canonical level, sum(p)), dividable_count(S,d)=f_of, forward_level(level,d) canonical one-step frozenset BFS, reachable_sets/D, next_level_bits/decode_bits/encode_bits (bitmask), config_features/feature_record (level-histogram/bbox/M), triangle_parent(top) (returns p if top=={p+e1,p+e2,p+e3}), and top_caps(S) (canonical collapse cap-finder: list of empty parents p at level M-1 whose full forward child-triangle equals S's top level — consolidated from check_recurrence.py, probe_topcap.py, probe_a2_fails.py; identical computation, only probe_a2_fails's 3-tuple packaging moved into a local wrapper). Correctness by brute oracles reproducing D(2)=3, D(10)=44499 and claim-B checks. |
| `amoeba2d.py` | Reusable 2D amoeba (PE763 d=2) routines. CANONICAL shared copy of the A007902 auxiliary recurrence `G(k,m)` (memoized, returns 0 for k<1) and `a(n)` (offset 1, a(1)=1, a(n)=G(n,0)); plus int-bitmask encode/decode and next_level_bits2_compact (one BFS step, per-level compact grid width). G correctness established by reproducing OEIS A007902 a(1..33) exactly (incl. a(22)=13686805) and by matching the 2D BFS oracle code/amoeba2d/d2d.py on a(1..14); the BFS steps by frozenset oracle agreement for N=0..12 (code/amoeba/d2_check.py). |
| `datafiles.py` | Shared helpers for reading the run's data/level_N.txt feature dumps. `sorted_key(path)` returns int(N) from a level_<N>.txt path, robust to relative or absolute globs and multi-digit N. Consolidated from program-local copies in code/pattern/aggregate_triangle.py, distinct_hist_from_data.py, fit_qk.py and full_triangle_dump.py. The first three had GENUINELY diverged: aggregate_triangle and fit_qk used split('level_'), distinct_hist_from_data used split('_') (the latter only parses relative paths); full_triangle_dump was an identical split('level_') copy. The kept split('level_') form is a strict superset — identical to the split('_') form on every relative input it handles, and correct on absolute paths too — so importing it is semantics-preserving everywhere. Correctness: trivial path-parse, exercised by the calling programs' own data aggregation. |
| `holonomic.py` | Shared PE763 holonomic-fit routine. `fit(m, d, D=None)` builds the exact-rational linear system for a P-recursive recurrence sum_j p_j(N)D[N+j]=0 (p_j degree d, order m) and returns the nullspace of polynomial coefficient sets fitted over the sequence D (default D(0..14)). Consolidates four identical copies formerly in code/pattern/holonomic2.py, holonomic3.py, holonomic_diag.py, holonomic_fit.py — they had not diverged, so no definition was chosen over another. Returns a list of sympy vectors (independent solutions). Correctness: reproduces the nullspace each predecessor program computed over the same (m,d) sweep. |
| `valuations.py` | Shared integer 2/3-valuation helper for the per-histogram multiplicity study. `f23(v)` returns (v2, v3, rest) with v=2^v2·3^v3·rest, rest coprime to 6. Consolidated verbatim from four identical local copies in code/pattern/check_3exp.py, check_b_multiset.py, multiset_to_b.py and tabulate_3exp.py (they had NOT diverged), which now import it. Correctness established by the four probes agreeing with the authoritative whole-range checks verify_mult_structure.py / verify_mult_closedform.py over the N=2..12 dump. |
