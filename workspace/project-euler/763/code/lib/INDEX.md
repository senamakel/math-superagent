# Index — code/lib

What each file in this folder is for. Keep it current: describe a file when you create it, and refresh this index after adding, renaming, or deleting files.

| File | Purpose |
| --- | --- |
| `amoeba.py` | Reusable 3D (and parameterized-d) PE763 routines shared by every oracle and data dump. Functions: `children(p, d)` — canonical forward d-neighbours of a point; `forward_level(level, d)` — canonical one-step forward BFS over frozenset-of-tuples configs in d dims; `reachable_sets(N, d=3)` — CANONICAL naive level-by-level BFS driver returning all distinct frozensets reachable after exactly N divisions (consolidated from the three former copies in code/brute.py and code/amoeba/brute.py (identical 3D) and code/amoeba2d/d2d.py (divergent 2D; resolved by the d parameter, not by choosing — the 3D copies agreed, the 2D reduces at d=2)); `D(N, d=3)` = len(reachable_sets); `next_level_bits(level, W)` — one-step BFS over fixed-width bitmask configs; `next_level_fs(level)` — 3D one-step frozenset step (= forward_level(level,3)); `decode_bits`/`encode_bits` — bitmask <-> frozenset; `config_features`/`feature_record` — structural features (level histogram, bbox, max level M). Correctness established by brute oracles reproducing D(2)=3 and D(10)=44499. |
| `amoeba2d.py` | Reusable 2D amoeba (PE763 d=2) routines. CANONICAL shared copy of the A007902 auxiliary recurrence `G(k,m)` (memoized, returns 0 for k<1) and `a(n)` (offset 1, a(1)=1, a(n)=G(n,0)); plus int-bitmask encode/decode and next_level_bits2_compact (one BFS step, per-level compact grid width). G correctness established by reproducing OEIS A007902 a(1..33) exactly (incl. a(22)=13686805) and by matching the 2D BFS oracle code/amoeba2d/d2d.py on a(1..14); the BFS steps by frozenset oracle agreement for N=0..12 (code/amoeba/d2_check.py). |
| `holonomic.py` | Shared PE763 holonomic-fit routine. `fit(m, d, D=None)` builds the exact-rational linear system for a P-recursive recurrence sum_j p_j(N)D[N+j]=0 (p_j degree d, order m) and returns the nullspace of polynomial coefficient sets fitted over the sequence D (default D(0..14)). Consolidates four identical copies formerly in code/pattern/holonomic2.py, holonomic3.py, holonomic_diag.py, holonomic_fit.py — they had not diverged, so no definition was chosen over another. Returns a list of sympy vectors (independent solutions). Correctness: reproduces the nullspace each predecessor program computed over the same (m,d) sweep. |
