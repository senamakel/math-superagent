| `amoeba.py` | Reusable 3D (parameterized-d) PE763 routines shared by every oracle and data dump: children(p,d), lvl(p)=sum of coords (canonical level, consolidated from identical sum(p) copies across inventor/ programs; none had diverged, so no definition was chosen over another), dividable_count(S,d=3) = #dividable cells (a cell with none of its children in S) — the underlying definition of f(C); f_of(C) is the canonical alias = dividable_count(C,3), the single home of the name `f_of` imported by all six inventor probe programs (check_recurrence, decomp_probe, definitive_check, diagnose_B, diagnose_B2, structure_probe). Formerly five of those six kept an identical local f_of wrapper and definitive_check kept its own local implementation; all six are now consolidated to import f_of from here, and they were semantically identical (each = sum(1 for p in S if all(c not in S for c in children(p,3)))), so no definition had to be chosen over another. forward_level(level,d) canonical one-step frozenset BFS, reachable_sets/D, next_level_bits/decode_bits/encode_bits (bitmask), config_features/feature_record (level-histogram, bbox, max level M). Correctness by brute oracles reproducing D(2)=3, D(10)=44499 and by the claim-B checks (D(N+1)=sum_C f(C)). |
| `amoeba2d.py` | Reusable 2D amoeba (PE763 d=2) routines. CANONICAL shared copy of the A007902 auxiliary recurrence `G(k,m)` (memoized, returns 0 for k<1) and `a(n)` (offset 1, a(1)=1, a(n)=G(n,0)); plus int-bitmask encode/decode and next_level_bits2_compact (one BFS step, per-level compact grid width). G correctness established by reproducing OEIS A007902 a(1..33) exactly (incl. a(22)=13686805) and by matching the 2D BFS oracle code/amoeba2d/d2d.py on a(1..14); the BFS steps by frozenset oracle agreement for N=0..12 (code/amoeba/d2_check.py). |
| `holonomic.py` | Shared PE763 holonomic-fit routine. `fit(m, d, D=None)` builds the exact-rational linear system for a P-recursive recurrence sum_j p_j(N)D[N+j]=0 (p_j degree d, order m) and returns the nullspace of polynomial coefficient sets fitted over the sequence D (default D(0..14)). Consolidates four identical copies formerly in code/pattern/holonomic2.py, holonomic3.py, holonomic_diag.py, holonomic_fit.py — they had not diverged, so no definition was chosen over another. Returns a list of sympy vectors (independent solutions). Correctness: reproduces the nullspace each predecessor program computed over the same (m,d) sweep. |
