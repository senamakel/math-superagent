| `amoeba.py` | Reusable 3D (parameterized-d) PE763 routines shared by every oracle and data dump: children(p,d), lvl(p)=sum of coords (canonical level, consolidated from identical `sum(p)` copies in all of the inventor/ programs that used it — check_recurrence, probe_failures, probe_live, structure_probe, probe_a2_fails, probe_parent_present, decomp_probe, diagnose_B, diagnose_B2, probe_refined_collapse; none had diverged, so no definition was chosen over another), forward_level(level,d) canonical one-step frozenset BFS, reachable_sets/D, next_level_bits/decode_bits/encode_bits (bitmask), config_features/feature_record (level-histogram, bbox, max level M). | `amoeba2d.py` | Reusable 2D amoeba (PE763 d=2) routines. CANONICAL shared copy of the A007902 auxiliary recurrence `G(k,m)` (memoized, returns 0 for k<1) and `a(n)` (offset 1, a(1)=1, a(n)=G(n,0)); plus int-bitmask encode/decode and next_level_bits2_compact (one BFS step, per-level compact grid width). G correctness established by reproducing OEIS A007902 a(1..33) exactly (incl. a(22)=13686805) and by matching the 2D BFS oracle code/amoeba2d/d2d.py on a(1..14); the BFS steps by frozenset oracle agreement for N=0..12 (code/amoeba/d2_check.py). |
| `holonomic.py` | Shared PE763 holonomic-fit routine. `fit(m, d, D=None)` builds the exact-rational linear system for a P-recursive recurrence sum_j p_j(N)D[N+j]=0 (p_j degree d, order m) and returns the nullspace of polynomial coefficient sets fitted over the sequence D (default D(0..14)). Consolidates four identical copies formerly in code/pattern/holonomic2.py, holonomic3.py, holonomic_diag.py, holonomic_fit.py — they had not diverged, so no definition was chosen over another. Returns a list of sympy vectors (independent solutions). Correctness: reproduces the nullspace each predecessor program computed over the same (m,d) sweep. |
