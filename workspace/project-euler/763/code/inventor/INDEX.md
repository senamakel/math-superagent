# Index — code/inventor

What each file in this folder is for. Keep it current: describe a file when you create it, and refresh this index after adding, renaming, or deleting files.

| File | Purpose |
| --- | --- |
| `_run_all.py` | Utility runner that executes the three inventor verification programs (check_recurrence.py, probe_topcap.py, probe_reachable.py) via subprocess with cwd=/workspace and prints their stdout/stderr. Convenience driver, not a result carrier. |
| `_run_fig3.py` | Scratch runner, now a stub: records that the Eriksson Fig.3 internal-consistency check was done by hand (no shell tool available) and documented in check_eriksson_fig3.py. No computation. |
| `check_a12_lean_large.py` | Lean A1/A2/B claim probe for the large N=13..14 frontiers: bitmask BFS with transient per-config decode, checks A1 (exactly 3 top cells), A2_tri (top-3 = child triangle of one parent at M-1), A2_empty (parent absent), and B (sum f(C) vs D(N+1)). Omits the expensive per-config A3 collapse iteration that makes definitive_check.py exceed the 600s budget on the 5.9M N=14 frontier. Correctness: reproduces A1/A2/B for N<=12 exactly matching definitive_check.py (A1bad=0, A2tri=0, B match True only at N=1,2). |
| `check_eriksson_fig3.py` | Independent hand-arithmetic consistency check of the OCR'd Eriksson Fig.3 folded-polyominoid table (from research/L0.0/pebbling_ejc_survey.full.md): confirms column n=2 = Catalan C_{k+1} (1,2,5,14,42,132,429) and row k=2 = n(3n-1)/2 (1,5,12,22,35,51). Verifies internal consistency only, NOT that these are the true folded-polyominoid counts. Canonical copy relocated from code/ root (root check_eriksson_fig3.py is byte-identical and marked superseded). |
| `check_recurrence.py` | Tool_builder target verifying CLAIM A (deterministic reverse cap-collapse: every reachable 3D config has exactly 3 cells on its max level, forming the full child-triangle of one empty parent) and CLAIM B (D(N+1) = sum over conf(N) of f(C)=#dividable cells). Imports the canonical forward_level(level,3) and f_of for claim B and the canonical top_caps for the cap-finder, all from lib/amoeba (top_caps was a formerly duplicated local copy). Exact, N<=7 oracle. |
| `decomp_probe.py` | Full structural decomposition of 3D amoeba reachable configs, N=2..12, for a compressed counting DP: per config records max level M, f(C)=#dividable cells, and level histogram; tabulates D(N) by M, by f, joint (M,f), and histogram distribution. Uses memory-compact bitmask BFS (next_level_bits, width N+1) to reach N=12 under the 2 GiB cap, decoding transiently. Also checks A1/A2/A3. Outputs scratchpad/structure_probe.txt. Imports lvl/children/decode_bits/next_level_bits/f_of from lib.amoeba (f_of formerly a local wrapper, now a direct import). |
| `definitive_check.py` | Definitive claim check + decomposition for the 3D amoeba to N=14: runs the memory-compact bitmask forward BFS and checks per config A1 (max level holds exactly 3 cells), A2_tri (those 3 = {p+e1,p+e2,p+e3} for a single parent p at M-1), A2_empty (stronger: that parent p is empty), A3 (naive deterministic empty-parent top-cap collapse to origin in N steps), B (D(N+1)==sum f(C)). Also tabulates for N=2..12 the D(N) decomposition by M, by f, joint (M,f), and histograms. Imports next_level_bits/decode_bits/children/f_of/lvl from lib/amoeba — f_of was formerly a GENUINE local implementation here (the one divergent copy), now consolidated to import the canonical alias, and lvl was a local `sum(p)` copy now replaced by the canonical import; both changes are semantics-preserving. Exact; oracle to N=14 under the 2 GiB cap. Writes /workspace/scratchpad/structure_probe.txt. |
| `diagnose_B.py` | Diagnoses why CLAIM B fails (D(N+1) < sum_C f(C)): the forward map (C,p)->child is not injective, so sum f(C) overcounts distinct children. Counts, per reachable child C', the number of empty preimage-parent cells p whose full child triangle sits inside C', and reports the preimage-multiplicity distribution and collision count for N=0..7. Imports lvl/children/forward_level/f_of from lib.amoeba (f_of formerly a local wrapper, now a direct import). |
| `diagnose_B2.py` | Second, cleaner diagnosis of the CLAIM B collision: for each reachable child C' enumerates all empty preimage-parent points p whose full child triangle lies inside C', tabulates the preimage-multiplicity distribution, and prints sum_C f(C), D(N+1), collisions=sum f(C)-D(N+1), and sigma(mult*count). Definitively shows the multiply-reachable children that break the D(N+1)=sum f(C) identity. Imports lvl/children/forward_level/f_of from lib.amoeba (f_of formerly a local wrapper, now a direct import). Companion to diagnose_B.py. |
| `probe_a2_fails.py` | Pinpoints which reachable configs fail A2/A3 using the same top_caps definition as check_recurrence.py. Local top_caps is gone — imports the canonical top_caps from lib/amoeba wrapped in a local top_caps_packed returning (M, sorted(top), caps) to preserve its original 3-tuple return. Prints, for N=1..5, the top set and all near-miss cap parents of each config whose top-3 is not a unique single cap. Uses lib/amoeba; N<=6 oracle. |
| `probe_failures.py` | Probe of why the top-cap collapse (A2/A3) fails for N>=4: for each reachable config dumps cells by level, every empty parent p at level M-1 whose child triangle sits in the top level, and whether the top 3 are a single full triangle. Uses lvl/children/forward_level from lib.amoeba. Bounded N<=6 oracle. |
| `probe_live.py` | Dumps the actual top-level structure of reachable configs at N=3,4,5: cells grouped by level, the top level, and candidate parents (empty cells at M-1 whose children lie in the top). Shows exactly how A2 fails. Uses lvl/children/forward_level from lib.amoeba. |
| `probe_parent_present.py` | Resolves the A2 failure: for configs where top-3 is not the triangle of an EMPTY parent, checks whether it IS the triangle of a parent p present in the config (p got re-created afterwards). Was one of 4 local triangle_parent copies; now imports the canonical triangle_parent from lib/amoeba (its local copy differed only in taking 3 separate args a,b,c; semantics identical to the canonical iterable form). Reports not-triangle vs parent-present vs parent-absent counts for N=0..7. Uses lvl/children/forward_level also from lib.amoeba. |
| `probe_reachable.py` | Forward-BFS 3D config probe: verifies reverse-merge reachability (Eriksson voidance characterization) and voidance-set structure for small N. |
| `probe_refined_collapse.py` | Tests the REFINED collapse (A3) relevant to a compressed DP: whether, with top-3 always the full child triangle {p+e1,p+e2,p+e3} of a single parent p (which may be present or empty in the config), iterating S := (S - children) |
| `probe_reverse_moves.py` | For the N=4 configs where the naive top-cap collapse fails, lists ALL legitimate reverse moves (empty points p with children(p) all in the config, with their levels), to show whether the true reverse structure is a clean top-cap collapse or a lower-level balancing move (voidance/folded-polyominoid picture). Uses lvl/children/forward_level from lib.amoeba; bounded N<=4 oracle. No f_of use. |
| `probe_topcap.py` | Empirical probe of the 3D FE763 top-cap collapse structure on forward-BFS configs N<=6: T1 max level holds exactly 3 cells, T2 those 3 form the full child-triangle of a unique empty parent, T3 deterministic cap-collapse reaches origin. One-step BFS imported as canonical forward_level(level,3) and the cap-finder as canonical top_caps (former duplicated local copy), both from lib/amoeba. NOTE: retains its own local `level(p)=sum(p)` helper (identical semantics to lib.amoeba.lvl but named `level`, which doubles as its loop variable, so it was NOT renamed to the imported lvl). |
| `research_structure.py` | Structural analysis of the PE763 growth rule: computes D(N) by exact BFS in d=2 and d=3 (importing canonical forward_level(level,d) from lib/amoeba) and verifies the reverse-merge characterization — every reachable config reduces to {origin} by replacing the d children of a common absent parent (Eriksson voidance picture). Prints d=2 D(0..14), d=3 D(0..12), and reverse-merge-vs-forward frontier agreement for d=2 N<=6. |
| `structure_probe.py` | The real tool-builder deliverable for the inventor proposal: re-runs exact forward BFS (frozenset, memory-capped) to N=14 and checks per reachable config A1 (max level holds exactly 3 cells), A2 (top 3 = complete forward triangle of one empty parent at M-1), A3 (deterministic cap-merge reaches origin in N steps), B (D(N+1)=sum f(C)). Also tabulates counts by max level M, by f(C)=#dividable cells, the joint (M,f) table, and most-frequent level histograms for N=2..12. Imports forward_level/children/config_features/lvl/f_of from lib.amoeba (f_of formerly a local wrapper, now a direct import). Exact, exponential oracle bounded by the 2 GiB cap at N=14. Writes scratchpad/structure_probe.txt. |
| `test_c1.py` | Tests conjecture C1 (reachable amoeba config == origin-connected set) by enumerating origin-connected sets (positive directed animals) by size and comparing to D_2D(N) and 3D D(N). RESULT: C1 is FALSE (2D counts match A005773 directed animals, not the amoeba sequence). Verified by an independent subset-based checker (code/out/verify_c1_subsets.py). Canonical copy relocated from code/ root. |
| `trace_collapse.py` | Traces the refined collapse on the N=4 configs where it FAILS, to understand why: for each failing config prints the full collapse trace (max level M, top cells, parent chosen each step) so one can see whether it loops, diverges, or reaches a non-origin fixed point (with a 40-step loop guard). Was one of 4 local triangle_parent copies; now imports the canonical triangle_parent from lib/amoeba (identical to its local iterable-form copy). Uses lvl/children/forward_level also from lib.amoeba. Bounded N<=4 oracle. |
| `verify_topcap_full.py` | Full verification of the top-cap structural claims A1 (exactly 3 cells on max level M), A2 (those 3 = triangle of one empty parent at M-1), A3 (cap-collapse reaches origin in exactly N steps, first step landing in conf(N-1)), and B (D(N+1)==sum dividable_count) over EXACT reachable config sets N=1..14, regenerated by the fixed-width bitmask BFS (lib.amoeba.next_level_bits) since data/level_*.txt only carry feature records not coordinates. Prints per-claim bad counts per N; writes output to code/out/verify_topcap_full.txt. |
