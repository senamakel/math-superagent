## Formula

- D-finite with recurrence: n*a(n) +(3-2n)*a(n-1) +3(3-n)*a(n-2)=0. - _R. J. Mathar_, Dec 20 2011
- 0 = a(n)*(+9*a(n+1) + 15*a(n+2) - 12*a(n+3)) + a(n+1)*(-3*a(n+1) + 10*a(n+2) - 5*a(n+3)) + a(n+2)*(+a(n+2) + a(n+3)) if n>0. - _Michael Somos_, Jan 31 2014
- a(n) ~ 3^(n+1/2) / (6*sqrt(Pi)*n^(3/2)). - _Vaclav Kotesovec_, Feb 12 2014
- G.f.: 1 + x^2/(1 - x - x^2/(1 - x - x^2/(1 - x - x^2/(1 - ...)))), a continued fraction. - _Ilya Gutkovskiy_, Sep 23 2017
