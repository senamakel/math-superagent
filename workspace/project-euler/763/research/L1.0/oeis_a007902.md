# A007902 — pebbling configurations

Source: https://oeis.org/A007902

## Correction to first read

The first read wrongly dismissed A007902 as "not D(N)" — that compared it to
the **3D** D(N). Matched against the run's **2D amoeba sequence** D_2D it is
a real identification.

## The sequence

1,1,2,4,9,20,46,105,243,561,1301,3014,6995,16227,37668,87426,202961,471150,
1093819,2539348,5895408,13686805,... — "Number of pebbling configurations
with n pebbles" (graph pebbling; cf. A007901). Asymptotic a(n) ~ c*d^n,
d≈2.3216421, c≈0.1226871 (Knessl 2006). OEIS gives a memoized recurrence over
pebbling states G(k,m); **no closed form**.

## The match

Run's 2D values (code/out/d2_values.txt; two independent BFS routes, N=0..20):
1,1,2,4,9,20,46,105,243,561,1301,3014,6995,16227,37668,87426,202961,471150,
1093819,2539348,5895408.

This equals **D_2D(N) = A007902(N+1)** exactly on every overlapping term. So
the 2D analogue of the PE763 amoeba is a catalogued OEIS sequence. Match is
observational (term-by-term); a bijective proof (2D amoeba configs <-> pebbling
configs) is not in this source.

Consistency: A007902's ratio d≈2.32 matches the 2D frontier growth, far below
3D D(N)'s ~x3.4, confirming it is the 2D genus. The 3D D(N)=1,1,3,9,30,... is
NOT A007902 (differs at n=2).

## Bearing on the run

Limited direct relevance: the target is 3D D(10000), and even the 2D amoeba
has no closed form in this source (only asymptotic + memoized recurrence). It
does not hand over a closed form for 3D D(N). But it is the run's strongest
structural identification — the 2D amoeba is "pebbling configurations" — a
named object to study, and the 3D genus is its higher-dimensional cousin.
Retain so the 2D analogue is called by its OEIS name.
