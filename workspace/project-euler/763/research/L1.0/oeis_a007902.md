count D_2D(N)=A007902(N+1), verified on every available term (run's 2D BFS

Khodulev, CGMO AMM 102 (1995), Knessl).

**Exact recurrence (Alois P. Heinz / CGMO eqs 2.1-2.3) — the two-index G(k,m):**
```
G(k,0) = 2G(k-1,0) + G(k,1) + δ(k,2)
G(k,1) = G(k-3,0) + 2G(k-2,1) + G(k-1,2) + G(k-4,1)
G(k,m) = G(k-m-2,m-1) + 2G(k-m-1,m) + G(k-m,m+1),  m≥2
a(n) = (n==1 ? 1 : G(n,0))
```
Exact, holds over the whole index domain (G(k,m)=0 when k<1). This is a
memoised DP, **not** a closed-form evaluation — no one-index closed form exists
for A007902. Hypotheses hold (2D pebbling game = this run's d=2 amoeba model).
