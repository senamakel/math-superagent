# Index — prompts

What each file in this folder is for. Keep it current: describe a file when you create it, and refresh this index after adding, renaming, or deleting files.

| File | Purpose |
| --- | --- |
| `goals.md` | Goals guidance: translate goals into observable completion criteria before delegating. |
| `inventor.md` | Inventor guidance: propose a change of representation when an approach stalls. |
| `librarian.md` | Librarian guidance: build the `research/` library, descriptive names, one index line per document. |
| `orchestrator.md` | Orchestrator guidance: sequence understand → research → derive → implement → verify; reject plans that search the answer space. |
| `organizer.md` | Workspace-organizer guidance: keep every `INDEX.md` accurate, describe files on creation, keep toolkits/ and research/ in step. |
| `pattern_finder.md` | Pattern-recognition guidance: work from computed data, exact recurrence search, conjecture vs proof. |
| `reflection.md` | Reflection guidance: judge the attempt, distinguish unsolved from solved, give actionable lessons. |
| `research.md` | Research guidance: prefer original papers, return exact URLs, never fetch a published contest answer. |
| `scholar.md` | Scholar guidance: how to write a `research/<name>.md` summary from a source and keep it under ~1000 tokens. |
| `tool_builder.md` | Tool-builder guidance: state method+complexity before running, reproduce examples first, build `toolkits/`. |
