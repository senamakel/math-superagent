# Index — code

What each file in this folder is for. Keep it current: describe a file when you create it, and refresh this index after adding, renaming, or deleting files.

| File | Purpose |
| --- | --- |
| `audit_results.py` | Independent auditor for results_full_bothsides.txt. Touches no solver code. Parses the 90 (d,b,a,|a|) data rows and runs 7 checks: d non-square in [2,99]; |a|,|b| <= 1e13; a == nint(pi - b*sqrt(d)); sign(a)==-sign(b) or a==0; the master identity in |a| (b>0: nint(b*sqrt(d)-pi); b<0: nint(pi+|b|*sqrt(d))); local minimality in b over {b-10..b+10}; and exact re-sum of |a| equals the S reported in the file. Also reports the d=2 oracle residual. |
| `brute.py` | Naive BQA brute force: for d, x, n scans all b in [-n,n] and takes the nearest a to minimise abs(a+b*sqrt(d)-x). Reproduces worked examples 1-3. Float arithmetic; not scalable. |
| `brute_n7.py` | Independent brute force at n=10^7 (mpmath dps=40): scans all b in [-floor(n/sqrt(d)),floor(n/sqrt(d))] for the 16 chosen d, sets a=nint(pi-b*sqrt(d)) clamped to [-n,n], and minimises the resulting error. Writes results_brute_n7.txt and prints a comparison against the n=1e13 solver file (expected to differ). Not scalable. |
| `check_rel.py` | Investigated whether abs(I_d) equals round(sqrt(d)*b_d). Hypothesis **disproved** (see memory.md); kept as a record of a failed approach. |
| `compute_I.py` | Computes I_d and b_d for all non-square d in [2,99] at n=10^4 by scanning b in [0,n]. Small-scale data generation; also prints the abs(I_d) sequence. |
| `crosscheck_two_routes.py` | Final mechanical reconciliation of the two full-scale PE591 result files (results_full_bothsides.txt and results_ostrowski_n13.txt): parses both, asserts exactly 90 numeric rows, asserts (b,a) identical on every d, asserts |a|,|b| <= 1e13 on every row, sums the |a| column of each independently with exact ints, and checks both equal 526007984625966. Purely file-to-file, exact integer arithmetic. |
| `out/brute_n7_run.log` | Captured stdout of the brute_n7.py run: per-d (d, b, a, absolute-a, err) rows plus a comparison against results_full_bothsides.txt whose per-d MISMATCHes are expected (brute at n=1e7, solver file at n=1e13). |
| `out/results_brute_n7.txt` | Per-d output of brute_n7.py at n=1e7 for the 16 chosen d: rows (d, b, a, absolute-a, err). Independent brute-force reference for the mid-scale check. |
| `out/results_full.txt` | Output of solution.py (positive-b-only) for PE591 at n=1e13: rows d, b, a, abs(a), and S=sum(abs(a))=498809825393729. **Candidate result, superseded by results_full_bothsides.txt (the problem allows b of either sign).** |
| `out/results_full_bothsides.txt` | Output of solution_bothsides.py (both signs of b) for PE591 at n=1e13: rows d, b, a, abs(a), and S=526007984625966. Corrected answer consistent with the problem statement (b sign is free); supersedes results_full.txt. Current authoritative result file. |
| `out/results_ostrowski_n13.txt` | Output of the fully-independent solver solution_ostrowski.py at n=10^13: 90 rows 'd b a |a|' for every non-square d in [2,99], then 'S 526007984625966'. Complete and reproducible from the source; S independently re-summed from the file rows. |
| `out/results_solver_n7.txt` | Row data (d, b, a, absolute-a) of solution_bothsides.solve_d_both at n=1e7 for the 16 d. Apples-to-apples independent-check values matching brute_n7 at n=1e7 (not the n=1e13 numbers). |

| `probe_semi.py` | Explores which candidate irrational (pi/sqrt2, pi*sqrt2, 2pi*sqrt2, pi, 2pi) the d=2 record b's match as semiconvergent or convergent denominators. |
| `probe_structure.py` | Fast float scan: whether d=2 record b's match convergent denominators of pi/sqrt2, pi*sqrt2, etc. Probe; superseded by the Cabanillas candidate-set method. |
| `solution.py` | PE591 solver that considers only positive b (b in [0,L]): Cabanillas (arXiv:1904.01874) Prop 9/10 candidate-set method, a_d = nint(pi - b_d*sqrt(d)). Writes results_full.txt. **One-sided; superseded by solution_bothsides.py.** |
| `solution_bothsides.py` | Corrected PE591 solver considering BOTH signs of b (matching the problem, where b's sign is free): runs the Cabanillas candidate method for beta={pi} (b positive) and 1-beta (b negative), takes the global min, a = nint(pi - b*sqrt(d)). Reproduces worked examples 1-4; writes results_full_bothsides.txt. Current authoritative solver. |
| `solution_ostrowski.py` | PE591 fully-independent solver written fresh from Cabanillas' Algorithm 3(ii) + Prop 9/10 (irrational-alpha Case 2) in research/cabanillas_prop9_10_exact_statement.md. Computes the continued fraction of sqrt(d) with EXACT integer arithmetic via the periodic (P,Q,a) recurrence (so all q_k exact ints); alpha=sqrt(d)-floor(sqrt(d)); numeration digits b_k of beta={pi} and 1-beta via Algorithm 3(ii) at mpmath dps=220; generates Prop 9+10 candidates, keeps n<=L=floor(1e13/sqrt(d)); min distance per side sets the sign of b, a=nint(pi - b*sqrt(d)). Includes brute_scan validation (all 90 d at n=1e6, 16 d at n=1e7) and the full n=1e13 driver writing results_ostrowski_n13.txt, S=526007984625966. Row-by-row (b,a) identical to solution_bothsides.py. |
| `struct_probe.py` | Probe verifying the d=2 given oracle b,a satisfy the BQA relation and scanning small-scale record b's for d=2; early structural investigation. |
| `verify_cabanillas.py` | Standalone small-scale verification of Cabanillas Prop 9/10 candidate structure for a few alpha,beta pairs against brute force. Superseded as a toolkit by toolkits/ostrowski_verify.py and toolkits/verify_cabanillas_exact.py. |
| `verify_n7_rerun.py` | Independent re-run check: calls solution_bothsides.solve_d_both(d, 10**7) for the 16 d in results_brute_n7.txt and compares (b,a) exactly against brute-force results at the same n=10^7. Corrects the apples-to-apples comparison that brute_n7.py's built-in report misses (its internal comparison is against the n=1e13 file, which is expected to differ). All 16 d PASS. |
