# Blueprint — the statement graph

Derived from `research/backward/` and the claim library, and rewritten whenever either moves. Do not edit this file; the next write re-derives it.

`research/BACKWARD.md` lists the decompositions and `research/CLAIMS.md` lists what is established. This file is the graph between them: which proposition rests on which, what that makes each one's standing, and — the section to read first — which lemmas can be picked up right now without reading the rest of the argument.

A node is **ready** when everything it rests on is settled. A node is **blocked** when something it rests on is not. That distinction is the whole point: the open-gap list in `BACKWARD.md` makes every unproved lemma look equally attackable, and most of them are not.
