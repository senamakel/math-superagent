# Backward — what would suffice to prove the goal

Derived from the files under `research/backward/`, and rewritten whenever one of them is written. Do not edit this file; the next write re-derives it. One skeleton is one decomposition of the goal: open `research/backward/<name>.md` to work on it.

This is not the approach ledger. An approach is a *route* — a reformulation that might get there. A skeleton is a *decomposition* — the goal itself, broken into propositions that can each be attacked on their own. `research/APPROACHES.md` answers what else could get us there; this file answers what would be enough.

Every open gap below is a task. A gap with a `next` a tool_builder or a theorem_prover could start on today is worth more than three lemmas nobody can begin.

## The open gaps — each one is a task

Prove any of these and the skeleton it belongs to moves. Pick the one with a first step.

- [[eu700-eulercoin-sum]] `G-verify-recurrence` — gcd(A,M)=1, and on the actual (A,M) and on several small test moduli the recurrence iterated from its base produces exactly the forward-scan record lows, terminates at value 0, and reproduces the statement's a_1 = 1504170715041707, a_3 = 8912517754604 and partial sum 1513083232796311.
  - next: tool_builder writes code/verify_recurrence.py — print math.gcd(A,M); run the recurrence; for a direct forward scan up to n ~ 10^6 (and on a few small (A,M)) assert the recurrence's record lows coincide; assert the first two Eulercoins and their sum match the statement.
  - _no thread — nothing is attacking this_
- [[eu700-eulercoin-sum]] `G-run-full` — Iterating the recurrence to termination on the actual (A,M) yields a finite list of Eulercoin values whose sum V is the answer, computed in exact integer arithmetic.
  - next: tool_builder writes code/solution.py that iterates the recurrence in exact Python ints, stops when the newly produced value is 0, and prints the Eulercoin list and their sum; check the first terms against code/verify_recurrence.py and the worked example before trusting the full-size result.
  - _no thread — nothing is attacking this_
- [[eu700-eulercoin-sum]] `G-independent-check` — The value V from G-run-full equals the sum obtained by an independent derivation — the Eulercoin values expressed as continued-fraction convergent / remainder quantities of A/M (best-approximant-of-second-kind identification, Cornell Thm 4.14/4.15), or summed via the floor_sum route (eu700-floor-sum-tool) — at full size.
  - next: tool_builder writes code/check_cf.py (or check_floor_sum.py) that computes the record-low values from the continued-fraction convergents of A/M via an independent library route, sums them, and asserts equality with V from code/solution.py.
  - _no thread — nothing is attacking this_
