# PE700 Eulercoin values: piecewise-arithmetic (AP-run) structure

## Question
The Eulercoins are the record lows of c_n = A·n mod M, A=1504170715041707,
M=4503599627370517. The run already computed all 102 of them and V =
1517926517777556. Is there further exploitable structure in the value/index
sequences themselves?

## Findings (all exact over the 102 computed terms)

1. **Not a CC linear recurrence.** `find_linear_recurrence` (max order 6)
   reports no constant-coefficient linear recurrence fits all 102 values.
   `oeis_lookup` reports no catalogue match. So no closed form is available by
   lookup; the regularity must come from the structure of the problem.

2. **The values split into 17 runs of constant consecutive difference.**
   Run lengths (in terms): 2,2,3,4,3,2,3,3,2,39,2,3,4,35,4,2,5.
   The two long runs dominate:
   - coins #16–53 (indices 15..53), 39 terms, value step d=-409165,
     index step +283827021
   - coins #60–94 (indices 59..93), 35 terms, value step d=-137,
     index step +924571768317
   The same 17 boundary positions partition the index sequence.

3. **Self-consistency with c_n = A·n mod M.** For every run, the index step D
   and value step d satisfy A·D ≡ d (mod M) — exact for all 17 runs
   (`code/out/ap_relation.py`). This is a necessary relation, and it holds.

4. **The AP decomposition recomputes V independently.**
   Summing per run by the exact AP formula L·a0 + d·L·(L-1)//2 over the
   NON-overlapping coin set gives V = 1517926517777556, exactly equal to the
   direct sum of all 102 values and to the documented answer
   (`code/out/ap_verify2.py`, `ap_fix.py`). Care: adjacent constant-difference
   runs share a boundary coin; the overlapping segsum double-counts it
   (off by 11680905034494 = the shared boundary sum), so count terms
   non-overlapping.

## Status
This is a *conjecture* over the terms supplied (102 terms is all the problem
has). It survived a deliberate check: recomputing V through the decomposition
matches the independently verified answer. Because the sequence is generated by
the verified index recurrence n_{k+2}=ceil(c_{n_k}/c_{n_{k+1}})·n_{k+1}-n_k,
and A·D ≡ d holds, the AP structure is the manifest linear effect of that
Euclidean recurrence — each run is one Euclidean step, the large-magnitude D
steps appearing where ceil() jumps.

Origin: piecewise arithmetic is exactly what continued-fraction / Euclidean
record-low recurrence structure produces. No OEIS closed form exists.
