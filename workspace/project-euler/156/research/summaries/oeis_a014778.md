# A014778 — fixed points of f(n,1)=n (PE156's d=1 solution set)

**Source:** https://oeis.org/A014778 (OEIS entry; entry text on disk as `research/sources/oeis-A014778-main.full.md`; the 84-line b-file content in `research/summaries/oeis-A014778-full.md`). Terms below as filed by the lookup.

**Definition.** Numbers k equal to the number of 1's in the decimal digits of all numbers ≤ k — exactly PE156's `f(n,1) = n` for d=1 (the problem counts 0..n; the sequence counts 1..k; 0 contributes no 1, so 0-based and 1-based solutions agree for d=1).

## What it establishes for this run

- **Finiteness** (comment by Joseph L. Pe, Nov 2002): the number of 1's used in positive integers ≤ k is ≥ A(k) = (1/10)·(number of digits in 1..k) = (1/10)·Σ_{i=1..k}(1+⌊log10 i⌋), and A(k)/k → ∞, so f(n,1)=n can hold only finitely often. This is the d=1 instance of the general superlinear growth that Khovanova–Marton's Prop 9.1 makes precise (n ≤ d·10^10).
- **84 terms total**, last = 1111111110 (from the b-file, `research/summaries/oeis-A014778-full.md`).
- **Structure** (David Wasserman, Jun 2007): six runs of ten consecutive numbers, ten pairs of consecutive numbers, four isolated numbers.
- **Cross-references**: the per-digit family A101639, A101640, A101641, A130427, A130428, A130429, A130430, A130431; counts in A130432; f(n,1) itself is A094798; base-generalization counts A165617. The run's per-digit catalogue note `research/notes/oeis-catalogue-pe156.md` tabulates these.
