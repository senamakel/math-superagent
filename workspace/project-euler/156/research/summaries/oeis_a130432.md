# A130432 — per-digit counts of PE156 fixed points

**Source:** https://oeis.org/A130432 (OEIS entry, filed by lookup this cycle).

**Definition.** For digit n from 1 to 9, a(n) = the number of numbers m such that m equals the number of n's in the decimal digits of all numbers ≤ m. I.e. a(d) = |{m : f(m,d)=m}|, the per-digit fixed-point counts this run must reproduce (counting n=0 as a solution, which the run does — 0 ≤ m and f(0,d)=0 for every d).

**Terms.** 84, 14, 36, 48, 5, 72, 49, 344, 9 (for d = 1..9).

## What it establishes for this run

- The OEIS lookup confirmed this sequence matches the run's computed per-digit counts: `code/solution.py` reported count=84,14,36,48,5,72,49,344,9 for d=1..9 (with s(d) values and last terms in `code/out/solution-run.log`), and `code/brute/independ_check.py` re-confirmed them. So the run's solver found exactly the right number of solutions per digit — an independent catalogue check on search completeness.
- The counts are > 1 for every digit, confirming the per-digit solution sets are nontrivial; the sums s(d) (computed by the run, not taken from A216398) are the actual answer input.
- Counts are divisible by d (84=1·84, 14=2·7, 36=3·12, 48=4·12, 5=5·1, 72=6·12, 49=7·7, 344=8·43, 9=9·1), consistent with Khovanova–Marton's periodicity observation (solutions repeat modulo 10^10 in each [r·10^10, (r+1)·10^10), r < d), noted in `research/notes/khovanova-marton-archive-labeling.md`.
