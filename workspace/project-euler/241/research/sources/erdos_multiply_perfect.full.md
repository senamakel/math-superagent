## Summary

Denote by P(x) the number of integers n≤x satisfying σ(n)≡*0*(mod n), and by P*2*(x) the number of integers n ≤ x satisfying σ(n)=*2*n. The author proves that P(x)<x*3/4+ɛ*and P*2*(x)<x*(1*−c)/*2*for a certain c>*0*.
