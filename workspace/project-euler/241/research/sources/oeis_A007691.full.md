A007691

Multiply-perfect numbers: n divides sigma(n).
(Formerly M4182)

205

1, 6, 28, 120, 496, 672, 8128, 30240, 32760, 523776, 2178540, 23569920, 33550336, 45532800, 142990848, 459818240, 1379454720, 1476304896, 8589869056, 14182439040, 31998395520, 43861478400, 51001180160, 66433720320, 137438691328, 153003540480, 403031236608

( [list][4]; [graph][5]; [refs][6]; [listen][7]; [history][8]; [text][9]; [internal format][10])

OFFSET

1,2

COMMENTS

sigma(n)/n is in [A054030][11].

Also numbers such that the sum of the reciprocals of the divisors is an integer. - [Harvey P. Dale][12], Jul 24 2001

Luca's solution of problem 11090, which proves that for k>1 there are an infinite number of n such that n divides sigma_k(n), does not apply to this sequence. However, it is conjectured that this sequence is also infinite. - [T. D. Noe][13], Nov 04 2007

Numbers k such that sigma(k) is divisible by all divisors of k, subsequence of [A166070][14]. - [Jaroslav Krizek][15], Oct 06 2009

[A017666][16] (a(n)) = 1. - [Reinhard Zumkeller][17], Apr 06 2012

Bach, Miller, & Shallit show that this sequence can be recognized in polynomial time with arbitrarily small error by a probabilistic Turing machine; that is, this sequence is in BPP. - [Charles R Greathouse IV][18], Jun 21 2013

Conjecture: If n is such that 2^n-1 is in [A066175][19] then a(n) is a triangular number. - [Ivan N. Ianakiev][20], Aug 26 2013

Conjecture: Every multiply-perfect number is practical ( [A005153][21]). I've verified this conjecture for the first 5261 terms with abundancy > 2 using Achim Flammenkamp's data. The even perfect numbers are easily shown to be practical, but every practical number > 1 is even, so a weak form says every even multiply-perfect number is practical. - [Jaycob Coleman][22], Oct 15 2013

Numbers such that [A054024][23] (n) = 0. - [Michel Marcus][24], Nov 16 2013

Numbers n such that k(n) = [A229110][25] (n) = antisigma(n) mod n = [A024816][26] (n) mod n = [A000217][27] (n) mod n = (n(n+1)/2) mod n = [A142150][28] (n). k(n) = n/2 for even n; k(n) = 0 for odd n (for number 1 and eventually odd multiply-perfect numbers n > 1). - [Jaroslav Krizek][15], May 28 2014

The only terms m > 1 of this sequence that are not in [A145551][29] are m for which sigma(m)/m is not a divisor of m. Conjecture: after 1, [A323653][30] lists all such m (and no other numbers). - [Antti Karttunen][31], Mar 19 2021

EXAMPLE

120 is OK because divisors of 120 are {1,2,3,4,5,6,8,10,12,15,20,24,30,40,60,120}, the sum of which is 360=120*3.

MATHEMATICA

Do[If[Mod[DivisorSigma[1, n], n] == 0, Print[n]], {n, 2, 2*10^11}]

(* Alternative: *)

Transpose[Select[Table[{n, DivisorSigma[-1, n]}, {n, 100000}], IntegerQ[ #[[2]] ]& ] ][[1]]

(* Alternative: *)

Select[Range[10^6], IntegerQ@ DivisorSigma[-1, #] &] (* [Michael De Vlieger][48], Mar 19 2021 *)

from sympy import divisor_sigma as sigma

def ok(n): return sigma(n, 1)%n == 0
