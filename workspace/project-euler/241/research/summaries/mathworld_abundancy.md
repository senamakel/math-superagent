# Abundancy

---

[image: DOWNLOAD Mathematica Notebook] [Download Wolfram Notebook][1]

The abundancy of a number [image: n] is defined as the [ratio][2][image: sigma(n)/n], where [image: sigma(n)] is the [divisor function][3]. For [image: n=1], 2, ..., the first few values are 1, 3/2, 4/3, 7/4, 6/5, 2, 8/7, 15/8, 13/9, 9/5, 12/11, 7/3, 14/13, ... (OEIS [A017665][4] and [A017666][5]).

A positive integer [image: n] for which [image: sigma(n)/n] is an integer is called a [multiperfect number][6]. The first few are 1, 6, 28, 120, 496, 672, 8128, ... (OEIS [A007691][7]), corresponding to the abundancies 1, 2, 2, 3, 2, 3, 2, 4, 4, ... (OEIS [A054030][8]).
