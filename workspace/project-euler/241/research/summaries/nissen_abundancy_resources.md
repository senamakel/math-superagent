# Nissen — Abundancy: Some Resources (terminology hub)

Source: http://upforthecount.com/math/abundance.html — `[[nissen_abundancy_resources.full]]`
(Walter Nissen, upforthecount.com. Cited by A159907, A088912, A055153, A141643, A141645,
A159271, A160678 — the canonical "resources" link for abundancy studies.)

## What it is

A terminology and resource hub for **abundancy** = sigma(n)/n. Its key content is a
compilation of the (many, inconsistent) names different authors have given the same ratio:
abundancy index, index, abundancy ratio, multiplicity, k-ply, abundance, index of perfection,
k-fold, kinship, **perfection quotient** (the Project Euler 241 term for p(n)), relative
abundance, rho, relative sum of divisors function, characteristic ratio, etc.

## What it establishes for this problem

- **Fixes the naming.** The problem's "perfection quotient p(n) = sigma(n)/n" is the same
  object as the abundancy index I(n)/S(n) of the number-theory literature (Laatsch,
  Weiner, Holdener–Stanton). This connects the problem statement's vocabulary to every
  library source, so a search for "abundancy" or "perfection quotient" or "abundancy index"
  all hit the same mathematics.
- Historical anchor: Euler's *De numeris amicabilibus* (Opera postuma) already treats the
  ratio; Nissen argues for a single consistent name ("abundancy") for the function.
- A link hub to the primary hemiperfect resources (Michon/Marcus data pages hpn11..hpn17,
  Wikipedia hemiperfect entry) — all of which the library now holds.

## Does not settle

Pure terminology/pointer page: no theorems, no bounds, no enumeration. Its value to the run
is (a) the name equivalence just noted, and (b) as the standard pointer page that OEIS
entries cite — having it on disk means a later search that hits "abundancy resources" reads
the actual primary source instead of guessing its content.
