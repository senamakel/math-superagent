# A160678 — numbers n with abundancy sigma(n)/n = 13/2

Source: https://oeis.org/A160678 — `[[oeis_A160678.full]]`

## Definition

n in A160678 iff sigma(n)/n = 13/2. The sequence is conjectured to be finite
(COMMENTS); Michel Marcus has a table of 307 known terms.

## What it lets this run do (load-bearing)

a(1) = ~1.71e44 is **independently confirmed here** to be the smallest number
with abundancy 13/2. This is exactly a(6) from A088912 (the k=6 case of the
statement's k+1/2 = 13/2). Since 1.71e44 >> 10^18, **no n <= 10^18 has
abundancy 13/2 (k=6)**, so the search over n <= 10^18 reduces to the five
targets 3/2, 5/2, 7/2, 9/2, 11/2 (k = 1..5). This is the second, independent
confirmation of the reachability bound `a088912-abundancy-threshold`
(previously sourced only from A088912; now corroborated by A160678's own
first term, whose factorization A160678 spells out).

a(1) factorization given by OEIS: 2^23 3^9 5^2 7^5 11^5 13^2 17 19^3 31 37 43
61^2 97 181 241, and sigma(a(1)) is exhibited factor by factor to verify the
13/2 ratio.

## Does not settle

exceed it anyway). No new enumeration method; confirms only the reachability
cutoff.
