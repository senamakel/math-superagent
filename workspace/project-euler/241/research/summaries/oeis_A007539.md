# OEIS A007539 — first n-fold perfect number

Source: https://oeis.org/A007539 — `[[oeis_A007539.full]]`

## Definition

a(n) = smallest k with σ(k)/k = n (an n-fold perfect / n-multiperfect number):
1, 6, 120, 30240, 14182439040, 154345556085770649600,
141310897947438348259849402738485523264343544818565120000, ...

## What is load-bearing for THIS run

- **A007539 is the integer-abundancy twin of A088912.** A088912 gives the
  *smallest m with σ(m)/m = k + 1/2*; A007539 gives smallest m with σ(m)/m = k.
  The interleaving is formalised by OEIS A317681 (a(2n)=A007539(n),
  a(2n+1)=A088912(n), n>0) — see `research/summaries/oeis_A317681.md`.
- The ordering a(1)=1 < … < a(8) is consistent with, but does not prove, the
  run's reachability claim `a088912-abundancy-threshold` (a(1..5) < 1e18,
  a(6) ≈ 1.7e44). No half-integer-abundancy member of this run's answer set is
  affected: the set is A159907 ∩ [1,1e18], independent of A007539.
- Footnotes (RH bounds a(n) > exp(exp(n/e^γ)), smallest-multiperfect tables)
  are adjacent theory only; no member of the PE241 qualifying set has integer
  abundancy, so A007539 never intersects the answer set.

## Verdict

**Background, not load-bearing.** Confirms the multiply-perfect side of the
abundancy landscape the run already covers via A007691 / wiki / Numericana;
provides no bound or enumeration method for the half-integer case and no value
in the answer set. Does not contradict anything on disk.
