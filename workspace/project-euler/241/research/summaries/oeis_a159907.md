# A159907 — Numbers m with half-integral abundancy index (the PE241 qualifying set)

**Source:** https://oeis.org/A159907 — `[[oeis_a159907.full]]`.

## What the entry establishes

A159907 = { n : 2σ(n) ∈ n·odd } = { n : 2·σ(n)/n is an odd integer } = the
**hemiperfect numbers** (Michel Marcus, Nov 2017). Equivalently the condition
σ(n)/n = (2k+1)/2. (OEIS's linked "formula" line is `2·σ(m) in m·A005408` where
A005408 = odd numbers, and `antisigma(m) = m/2`.)

- **All terms n in A159907 are even.** Proof on the page: for odd n, σ(n) is odd, so
  2σ(n)=(odd)·n would be odd·odd = odd but LHS 2σ(n) is even — contradiction. Also odd
  n and higher powers of 2 beyond 2 can never qualify.
- **Characterization via antisigma (Nathaniel Johnston).** Since
  (σ(n)+antisigma(n))/n = (n+1)/2 for all n, and all members are even: for even n,
  σ(n)/n is a half-integer **iff** antisigma(n)/n is an integer. Thus, absent an odd
  multiply-perfect number, the hemiperfects from 24 on sit inside A242484 (antisigma
  divisible sequence). The Krizek conjecture on the page is equivalent to: no odd
  multiply-perfect numbers > 1.

This is the canonical identification that the whole PE241 solve is literally this
sequence's terms ≤ 10^18 (claims `hemiperfect-22-below-1e18`), and the evenness lemma
behind claim `a159907-sequence-even`.
