# A067698 — numbers with σ(n) ≥ e^γ n log log n (Robin-related)

Source: https://oeis.org/A067698 — `[[oeis_a067698.full]]`

## What it establishes

- **Definition:** n is in A067698 iff σ(n) ≥ e^γ · n · log log n, γ = Euler–Mascheroni.
- **Robin's theorem:** 5040 is the last element iff the Riemann hypothesis is true; the sequence is infinite if RH is false. Gronwall: limsup σ(n)/(n log log n) = e^γ.
- If RH is false, the next element (a(28)) is > 10^(10^13.11); Briggs gives a conditional lower bound 10^(10^10).
- The sequence (2,3,4,5,6,8,9,10,12,16,18,20,24,30,36,48,60,72,84,120,180,240,360,720,840,2520,5040) is the short list stated to have the property (a known finite result, {1..5040} checked).

## Does not help this problem (and why)

This is about **Robin's inequality and the Riemann hypothesis**, not about half-integer abundancy or enumerating hemiperfects. The only connection to the run is that Robin's theorem supplies the *lower bound* on a(6) cited inside A088912 (a(6) > 5e16), which is already captured. The abundancy values σ(n)/n of these numbers are not half-integers relevant to k+1/2 (e.g. 5040 = 12·420 has σ(5040)/5040 not of the form (odd)/2).
