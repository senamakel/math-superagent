# A242484 — numbers n with antisigma(n) ≡ 0 (mod n)

Source: https://oeis.org/A242484 — `[[oeis_A088912.full]]` holds the OEIS family detail.

## What it establishes

- **Definition:** n is in A242484 iff antisigma(n) = Σ_{k<n, k∤n} k = n(n+1)/2 − σ(n) is ≡ 0 (mod n).
- **Terms:** 1,2,24,4320,4680,26208,8910720,17428320,20427264,91963648,197064960,8583644160,10200236032,21857648640,...
- **Link to hemiperfects:** (σ(n)+antisigma(n))/n = (n+1)/2 for all n. If n is even, σ(n)/n is half-integer iff antisigma(n)/n is an integer. Since all hemiperfects are even (A159907), every hemiperfect > 2 is in A242484, and this holds iff there is no odd multiply-perfect number (conjecture). So A242484 ⊇ A159907 (from n=24 on).

## Does not help / marginal (why)

This is a *consequence* of the evenness fact the run already has (A159907, Property 2.2). It gives no new bound and no enumeration method for the sum ≤ 10^18. The identity σ+antisigma = n(n+1)/2 is a useful crosscheck used in the A159907 characterization but changes nothing about the DFS. Record as a corroborating but non-operative row.
