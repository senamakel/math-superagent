# A242484 — Numbers n with antisigma(n) ≡ 0 (mod n)

**Source:** https://oeis.org/A242484 — `[[oeis_a242484.full]]`.

## What the entry establishes

A242484 = { n : antisigma(n) ≡ 0 (mod n) }, antisigma(n) = sum of non-divisors < n =
n(n+1)/2 − σ(n).

- **If there is no odd multiply-perfect number (A007691), then a(n) = A159907(n−1) for
  n ≥ 2** — i.e. after 1, A242484 coincides with the hemiperfect sequence. This is the
  same characterization proved on the A159907 entry (claim `a242484-equivalence`):
  for even n, σ(n)/n half-integer ⟺ antisigma(n)/n integer, and the only way they
  differ is an odd multiply-perfect number.
- Terms shown match A159907[2..] (24, 4320, 4680, ..., exactly the hemiperfects), with
  n=1 extra.
