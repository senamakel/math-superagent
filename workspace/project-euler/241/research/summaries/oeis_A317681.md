# OEIS A317681 — smallest m with σ(m) = n·m/2

Source: https://oeis.org/A317681 — `[[oeis_A317681.full]]`

## Definition

a(n) = smallest m with σ(m) = (n/2)·m, n ≥ 2:
2:1, 3:2, 4:6, 5:24, 6:120, 7:4320, 8:30240, 9:8910720, 10:14182439040,
11:17116004505600, 12:154345556085770649600, 13:170974031122008628879954060917200710847692800,
14:141310897947438348259849402738485523264343544818565120000, ...

**Interleaving formula**: a(2n) = A007539(n), a(2n+1) = A088912(n) for n>0.
So the odd-indexed subsequence is exactly the run's A088912 reachability table
(smallest n of half-integer abundancy k+1/2 for k=1..6).

## Load-bearing consequences

1. **Confirms `a088912-abundancy-threshold` by an independent OEIS entry.**
   A317681 a(13) = the A088912 a(6) value ≈ 1.71e44 — the same 13/2 smallest
   member already confirmed by A160678 (`a160678-reachability-13over2`). Three
   independent OEIS pages (A088912, A160678, A317681) now agree the smallest
   abundancy-13/2 number is 170974031122008628879954060917200710847692800
   ≫ 1e18, so k=6 contributes zero to the PE241 sum. This is corroboration, not
   a new bound (still asserted, not proved by any source).
2. **Sourced statement of a deep open problem:** "For k ≥ 4 it is not known
   whether there are finitely or infinitely many numbers with abundancy k/2."
   Confirms the 22-answer-set below 1e18 is an empirical computational fact,
   not a theorem — the completeness burden rests on the tree-search method
   (Alekseyev `alekseyev-tree-search-complete`, Flammenkamp
   `flammenkamps-tree-search-method`), exactly as the oracle note states.
3. "1 is the only abundancy-1 number and 2 the only abundancy-3/2 number"
   (solitary) — the 3/2 branch of the DFS returns {2}, matching the oracle.

## Verdict

**Useful corroboration, no new method.** Adds a second/third sourced agreement
on the reachability cutoff and an explicit statement that abundancy-k/2 sets
for k ≥ 4 are not known finite (so PE241's answer-set count 22 is not a
theorem about the whole sequence — only about ≤ 1e18).

No claim-block needed: everything stated here is already carried by
