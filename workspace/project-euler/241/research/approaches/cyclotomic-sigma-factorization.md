# Cyclotomic factorization of σ(p^e): constrain primes via their residue classes modulo cyclotomic polynomials

```approach
idea: Factor σ(p^e) = (p^(e+1)-1)/(p-1) = ∏_{d|e+1, d>1} Φ_d(p) where Φ_d is the d-th cyclotomic polynomial. The half-integer abundancy condition ∏ σ(p^e)/p^e = k+1/2 becomes a product of cyclotomic values divided by prime powers, and each Φ_d(p) imposes a congruence constraint on p modulo the roots of Φ_d — effectively restricting which primes can appear for a given exponent pattern
mechanism: For each prime power p^e dividing n, σ(p^e)/p^e = (p^(e+1)-1)/(p^e(p-1)) = ∏_{d|e+1, d>1} Φ_d(p)/p^e. The full abundancy σ(n)/n = ∏_{p^e||n} ∏_{d|e+1, d>1} Φ_d(p)/p^e. For a fixed target T = (2k+1)/2, cross-multiplying gives a Diophantine equation: 2·∏ σ(p^e) = (2k+1)·∏ p^e. The key structural fact is that Φ_d(p) for d>1 grows roughly like p^φ(d), so for a fixed exponent signature the product of cyclotomic factors gives a polynomial in the primes. This turns the problem from "search over all prime assignments" into "find integer solutions to a family of polynomial Diophantine equations parameterized by exponent signatures." The cyclotomic factors are irreducible over Q for each d, so each Φ_d(p) forces p into a specific residue class modulo d (for d prime, p ≡ 1 mod d if Φ_d(p) contributes a new prime factor). This is a genuinely different encoding: the search is now over exponent multisets (there are few of them) followed by solving polynomial constraints on the primes, rather than a tree-search over prime powers. The bound 10^18 restricts the exponent signatures severely (r ≤ 15, max exponent ≤ 59), and for each signature the cyclotomic product gives an explicit algebraic equation.
status: proposed
first-step: Build the table of all feasible exponent signatures (multisets of exponents, one per distinct odd prime) such that the minimal n = 2^a · ∏ p_i^{e_i} (with p_i the i-th odd prime) ≤ 10^18. For each signature, write the cyclotomic product equation 2·∏_{i} ∏_{d|e_i+1, d>1} Φ_d(p_i) = (2k+1)·∏ p_i^{e_i} and determine what constraints the Φ_d factors place on the p_i. Then for the small set of viable signatures, solve the resulting polynomial Diophantine system for odd primes p_i.
precedent: none checked — the cyclotomic factorization of the divisor-sum is standard (it underlies the study of multiperfect numbers, e.g. Broughan–Zhou, "Odd multiperfect numbers of abundancy 4", J. Number Theory 2008), but applying it as a standalone constraint-solver for hemiperfect enumeration below a bound (rather than as a lemma inside a tree-search) has not been checked against the literature
```
