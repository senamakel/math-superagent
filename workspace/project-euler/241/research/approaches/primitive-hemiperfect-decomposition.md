# Primitive hemiperfect decomposition: enumerate base cases, derive all others via restricted multipliers

```approach
idea: Define a hemiperfect number n (with σ(n)/n = k+1/2) as primitive for its abundancy class if no proper divisor of n has the same abundancy k+1/2. Prove that every hemiperfect n is a multiple m·p of a primitive hemiperfect p with the same k, and that the multiplier m is forced to be 1 or to have a specific prime-factor structure (since multiplying by m must preserve the half-integer abundancy exactly). Enumerate primitive hemiperfects first (far fewer than the full set), then generate all valid multiples below 10^18
mechanism: If σ(n)/n = σ(p)/p = k+1/2 and p|n with p < n, then writing n = p·m with gcd(p,m)=1 gives σ(n)/n = σ(p)/p · σ(m)/m = (k+1/2)·σ(m)/m. For n to have the same abundancy, we need σ(m)/m = 1, which forces m = 1. If gcd(p,m) > 1, the multiplicativity breaks: σ(p^a·m')/σ(p^a) is not simply σ(m'). The primitive concept becomes: n is primitive for abundancy T if no n/p (p prime) has abundancy T. This is analogous to primitive non-deficient numbers. The structural claim is that the primitive hemiperfects below 10^18 are very few (likely the squarefree-core ones or those with a single odd prime power beyond the 2-adic part), and that every non-primitive hemiperfect is obtained by "inflating" a primitive one with extra prime powers that cancel their abundancy contribution — a much more constrained search than the general DFS. The multiplier must satisfy σ(m)/m = 1 for the coprime part (forcing m=1) and a precise p-adic correction for the non-coprime part, restricting it to specific forms like p^a → p^{a+2} or similar "abundancy-preserving" exponent jumps.
status: proposed
first-step: Compute the set of primitive hemiperfects below 10^7 by brute force: for each qualifying n, check if any n/p (p prime divisor) also has the same half-integer abundancy. Catalog the pattern: which odd prime powers appear in primitive vs. non-primitive hemiperfects, and what multiplier relationships connect them. Use this to formulate the exact "inflation" rule and bound the multiplier's size. Then enumerate all primitive hemiperfects ≤ 10^18 by a restricted search, and inflate each to fill out the full set.
precedent: none checked — the concept of "primitive" for fixed abundancy classes appears in the study of weird numbers and primitive non-deficient numbers (Erdős, 1941; Iannucci, 2005), but its application to hemiperfect enumeration with a formal inflation lemma has not been checked
```
