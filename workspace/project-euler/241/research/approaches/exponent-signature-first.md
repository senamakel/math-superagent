# Exponent-signature enumeration with prime-assignment search

```approach
idea: Enumerate exponent signatures (multisets of exponents sorted nonincreasing) feasible for n ≤ 10^18, then for each signature determine if any assignment of distinct primes in nondecreasing order achieves a half-integer abundancy
mechanism: Every n = ∏ p_i^{e_i} has an exponent signature E = (e_1 ≥ e_2 ≥ ... ≥ e_r). The product constraint ∏ p_i^{e_i} ≤ 10^18 and the prime ordering (p_1 < p_2 < ... < p_r, with e_i nonincreasing) mean the minimum n for a given signature E is achieved by assigning the smallest primes in order: 2^{e_1}·3^{e_2}·5^{e_3}·... . The number of signatures with this minimum ≤ 10^18 is small — e_1 ≤ 59 and the product constraint limits r and the exponent values. Crucially, for a fixed signature E and a fixed target T = r/2, the function f(p_1,...,p_r) = ∏ σ(p_i^{e_i})/p_i^{e_i} is strictly decreasing in each p_i. This monotonicity means that for a given signature, there is at most a narrow range of prime assignments that can achieve T — and often none at all. The search flips the usual order: first fix HOW MANY of each prime power (the signature), then determine WHICH primes can realize the target. The signature enumeration is a bounded integer partition problem (product of p_min^e ≤ 10^18); the prime assignment is a monotonically constrained search over r-tuples of distinct primes. This is structurally different from the denominator-cancellation DFS which interleaves prime choice and exponent choice, building n multiplicatively from small primes up. Here the global shape is chosen first, and the primes are fit to it second. For small r (≤ 10 or so) and small exponents, the prime-assignment step can be solved by greedy/binary-search along each dimension, exploiting strict monotonicity.
precedent: 
  - Goto & Shibata, Math. Comp. 2004 §3 "General algorithm" — the three-step signature-first search for harmonic numbers (list ω(n); for each, list exponent types; for each type, list prime possibilities); same sorting/monotonicity lemma (§3.3: 1 < S(q^e) < S(q^f) < S(p^e) < S(p^f) < 2; Lemma 4.2: H(p^e q^f) > H(p^f q^e)). https://www.ams.org/journals/mcom/2004-73-245/S0025-5718-03-01554-0/S0025-5718-03-01554-0.pdf — research/sources/goto_shibata_harmonic_mean.full.md
  - Cohen & Sorli, "Odd harmonic numbers exceed 10^24", Math. Comp. 2010 — harmonic-number tree/component/exponent enumeration of the same shape (harmonic seeds). https://doi.org/10.1090/s0025-5718-10-02337-9
  - Sorting lemma standard across independent literatures: CA/SA theory (Alaoglu–Erdős 1944; Caveney–Nicolas–Sondow, Ramanujan J. 2012) — nonincreasing exponents on smallest primes maximize σ/n; maxab.py re-derives it. http://www.jstor.org/stable/2690424 (Alaoglu–Erdős); https://doi.org/10.1007/s11139-012-9371-0
verdict: grounded — the method is a real published technique (Goto–Shibata), but NOT genuinely new: it is the harmonic-number enumeration transplanted to hemiperfect abundancy, and for that family the published standard is the interleaved tree-search (Flammenkamp; Alekseyev arXiv:2601.17832) that the run's denominator-cancellation DFS already implements. It offers no advantage over the run's current method. The exact count of feasible signatures at 10^18 is not in the literature and was not computed here (unverified; finiteness standard via e1 ≤ log2(10^18) ≈ 59 and the product constraint).
status: grounded (not refuted; known technique, not novel for this target family)
first-step: [no longer needed — the run's DFS is the standard method for the hemiperfect target; signature-first duplicates the harmonic-number technique without benefit]. If pursued anyway, no published numeric count of feasible signatures exists at 10^18.
```
