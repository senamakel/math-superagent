# OEIS A001950 — Upper Wythoff sequence — verdict

Source: https://oeis.org/A001950

## What this sequence is

A001950(n) = ⌊n·φ²⌋, φ = (1+√5)/2, the *upper Wythoff sequence*. There are
several recorded closed forms: a(n) = n + ⌊nφ⌋ = n + A000201(n), and
a(n) = ⌊n·φ²⌋ = ⌊n(3+√5)/2⌋. Also: indices at which blocks (1,0) occur in the
infinite Fibonacci word (Benoit Cloitre's comment). A090909 is the same
sequence (a(n)=⌊φ²n⌋, Gary Detlefs).

## What it establishes for PE1006

in O(log) blocks rather than one step per k. The closed form ⌊j·φ²⌋ is exact
for all j (Beatty sequence of irrational φ², no floating point needed —
the term is computable exactly as a Beatty integer).
