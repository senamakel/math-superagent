# OEIS A330064 — Beatty for cosh x — v erdict (see also A276575 verdict)

Source: https://oeis.org/A330064

## What it is

A330064(n) = ⌊n·cosh x⌋ where x ≈ 1.61749989 is the unique solution of
1/x + sech(x) = 1. It is the Beatty conjugate of ⌊n·x⌋ (A330063). The
constant cosh x ≈ 2.6179… is *not* φ² = 2.618… — close, but off in the fourth
decimal.

## What it establishes for PE1006

**Nothing, and it is a substitution trap.** Its early terms 2,5,7,10,13,15,18,20…
coincide with the upper Wythoff A001950 (⌊nφ²⌋), but diverge later (A330064:
21,24,28 vs A001950: 23,26,28). The run's verified V(R_k) run-start sequence
uses **A001950, not A330064**. Do not use this entry for the Wythoff run
structure.

## Verdict

**Does not help; explicitly excluded.** Flagged so the near-match never
substitutes for A001950.
