# Library cycle notes

The library already contains broad coverage of Sturmian/Fibonacci combinatorics, factor locations, Ostrowski numeration, Rauzy graphs, and universal Euclidean floor sums. New search this cycle confirmed especially relevant primary leads: Chuan–Ho, *Factors of characteristic words: Location and decompositions*, DOI https://doi.org/10.1016/j.tcs.2010.04.013; Hieronymi–Terry, *Ostrowski Numeration Systems, Addition, and Finite Automata*, DOI https://doi.org/10.1215/00294527-2017-0027; and Praveen–Rama, *A Note On ℓ-Rauzy Graphs for the Infinite Fibonacci Word*, https://doi.org/10.48550/arxiv.2210.08629.
