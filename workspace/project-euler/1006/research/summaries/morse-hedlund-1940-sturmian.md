# Morse & Hedlund, "Symbolic Dynamics II: Sturmian trajectories" (1940) — paywalled cover only

<!-- source: https://www.jstor.org/stable/2371487 | converted from HTML -->

The original 1940 paper establishing the connection "aperiodic balanced => exactly n+1
factors of length n" (Sturmian trajectories). The JSTOR page returned only a paywall cover
(307 bytes, client-challenge), so **no mathematical content was obtained**. Cited for
provenance only.

The theorem this paper is famous for is recovered, with a usable statement, from Wojcik's
note (`research/summaries/morse-hedlund-theorem-sturmian-characterization.md`, Theorem 1:
p(x,n)<=n iff ultimately periodic; aperiodic => p>=n+1; balanced => p<=n+1) and from
Cassaigne–Fici–Sciortino–Zamboni (`research/summaries/character-of-sturmian-words.md`,
Prop 6). Do not re-fetch the JSTOR page expecting content.
