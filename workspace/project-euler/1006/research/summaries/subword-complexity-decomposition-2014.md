# Subword complexity and decomposition of the set of factors

Source: https://ar5iv.labs.arxiv.org/html/1406.3974
Full text: [[subword-complexity-decomposition-2014.full]]

The paper defines classes of factor languages contained in concatenations of a fixed number of bounded-complexity languages. Its main theorem is that the class W2 equals the class of infinite words with linear factor complexity; more generally W_{k+1} is contained in polynomial complexity O(n^k), strictly for k>2. Sturmian languages are in W2 because they have complexity n+1.

This is useful context for the present problem: linear factor complexity does not itself imply a constant-state evaluator for an arbitrary weighted statistic on factors. The source gives no theorem for decimal-weighted second moments and no sublinear-in-k algorithm for Psi.
