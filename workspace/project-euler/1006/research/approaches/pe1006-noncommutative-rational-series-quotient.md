# Schützenberger quotient for the decimal-weighted factor series

```approach
slug: pe1006-noncommutative-rational-series-quotient
status: refuted
precedent: https://www.sciencedirect.com/science/article/pii/S0304397508003642; https://doi.org/10.1007/s00029-021-00629-2; claim: governing-sturmian; claim: cobham-bes-frougny-multiplicatively-independent-conversion
killed-by: Schützenberger's theorem supplies only an equivalence: a series is recognizable iff it has a finite-dimensional linear representation. It does not assert that the Fibonacci factor characteristic series, after the decimal morphism modulo M, has a bounded syntactic quotient. The proposed bounded quotient is exactly the missing finite-state closure. The Fibonacci/Sturmian language is not automatic in a fixed integer base, and no source found applies a finite quotient or tensor-square representation to the PE1006 decimal observable. Thus the literature grounds the vocabulary but not the decisive hypothesis.
```

The theorem is therefore useful as a diagnostic, not as an algorithm here: the required bounded quotient would itself be the theorem still to prove. No larger finite computation would establish it.
