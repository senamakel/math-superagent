# PE1006 — C-finite / Berlekamp–Massey

```approach
idea: Treat Psi(k) mod M = 101001001 as a single-indexed sequence and decide whether it is C-finite (satisfies a linear recurrence with CONSTANT coefficients over the field F_M), then evaluate Psi(10^18) by fast exponentiation of the companion matrix. This is a completely different O(log k) engine from the floor-sum monoid and from the Rauzy-extension recurrence, and — if the recurrence is real — a fully independent route to the answer that cross-checks both. Named mathematics: Berlekamp–Massey (minimal linear recurrence from 2L samples over a finite field), the theory of C-finite (constant-coefficient linear-recursive) sequences, fast linear recurrence evaluation by binary exponentiation of the companion matrix.
mechanism: The adopted Rauzy thread already writes Psi(k+1) = 100*Psi(k) + (terms in auxiliary sequences S1(k), J(k), V(R_k)^2). If that auxiliary vector is itself C-finite over F_M, then the closed system (Psi and the auxiliaries) is C-finite, so Psi(k) mod M is a C-finite sequence. Berlekamp–Massey recovers the minimal recurrence from O(L) consecutive residues with zero assumptions about where the sequence came from — purely empirical, and the negative case (BM returns an order L that fails to predict values outside the training window) is itself a decisive, cheap finding that the sequence is NOT C-finite. If it is C-finite, Psi(10^18) mod M is obtained by exponentiating the companion matrix — O(L^3 log k), independent of and checkable against the floor-sum answer. Because M is asserted prime, F_M is a field and BM is exact; if primality fails, run per-prime-power and CRT.
status: refuted
killed-by: Psi(k) mod M is not a C-finite sequence, and this is structural, not a gap in the search. (1) The run's own exact tools already answered the empirical question the candidate opens: the pattern hunt (research/notes/pattern-hunt-pe1006.md, pattern-hunt-pe1006-cycle3.md) applied find_linear_recurrence to the residue sequence Psi(k) mod M for k=1..400 and found NO constant-coefficient linear recurrence of any order <= 12; the residues are noise-flat (within 2-sigma, uniform leading digit, zero collisions) — so Berlekamp–Massey on the available residues would return an order growing with the window and would fail to predict held-out residues. This is exactly the candidate's own stated negative case, and it is the delivered result. (2) The reason it fails is the right-extension recurrence the run proved exactly (cycle3 §1): Psi(k+1) = 100·Psi(k) + 100·V(R_k)^2 + 20·S1(k) + J(k), where the "corrections" are not constants — J(k) = c1(k+1) = 1 + floor((k+1)/phi^2) grows with k, and V(R_k), S1(k) are Sturmian-mechanical objects with no constant-coefficient form. A C-finite sequence needs constant coefficients; the recurrence's coefficients themselves depend on k, and over the finite field F_M a genuine constant-coefficient recurrence forces the sequence into a finite state cycle (eventual periodicity with period dividing |F_M|^L or a divisor). The measured residues show no such cycle. (3) The literature confirms the correct frame: a linear-recursive sequence over a finite field is eventually periodic precisely because its state space (F_M)^L is finite — so the only way Psi(k) mod M could be C-finite is if it were eventually periodic over F_M, which the independence of the auxiliary corrections blocks; a k-dependent-coefficient recurrence (the very object that makes Ψ a Sturmian/floor-sum quantity) is not C-finite. (4) A subtlety: even if some auxiliary C-finite closure existed, the companion-matrix power would O(L^3 log k) in the true minimal order L; but L would have to be small (< ~100) for that to be the payoff, and the measured minimal order is not bounded (find_linear_recurrence fails at every order <= 12 tried). Hence the negative case is decisive and cheap, exactly as the candidate's first-step framed it. The deliverable for this candidate is the recorded refutation, not a residue.
```

## Assessment

**Refuted — decisively, and cheaply, exactly as the candidate predicted.** The
candidate's own fallback ("the negative case is itself a decisive cheap
result") is what materialised, and the run had already produced it: exact
scanning of the mod-M residues found no constant-coefficient recurrence (order
≤ 12, noise-flat), and the right-extension recurrence that governs Ψ has
corrections J(k) = 1 + ⌊(k+1)/φ²⌋ that grow with k, so Ψ is not C-finite over
F_M. Over a finite field, C-finite = eventual periodic, which the data rule
out. The literature (Ben Atti–Díaz-Toca–Lombardi, Norton, Baragaña–Roca)
grounds what Berlekamp–Massey can and cannot do, but no theorem rescues a
sequence that is not C-finite. No residue is produced here because none is
earned; the refutation is the deliverable.
