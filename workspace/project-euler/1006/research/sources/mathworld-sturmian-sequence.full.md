# Sturmian Sequence -- from Wolfram MathWorld

A Sturmian sequence is a right-infinite aperiodic binary sequence whose factor
complexity is p(n) = n+1 for every positive integer n. By the Morse-Hedlund
theorem, this is the smallest possible factor complexity for an aperiodic
infinite word.

An example is the sequence arising from the substitution system
0 -> 01, 1 -> 0, yielding 0 -> 01 -> 010 -> 01001 -> 01001010 -> ...,
which gives the Sturmian sequence 01001010....

Sturm functions are sometimes also said to form a Sturmian sequence.
