# Project Euler Problem 1006 — official statement

Source URL: https://projecteuler.net/minimal=1006

Starting with S_0=0 and S_1=01, define S_n=S_{n−1}S_{n−2}. A Fibonacci subword is a contiguous substring of some S_n. There are k+1 different Fibonacci subwords of length k. Interpret them as decimal numbers and let Ψ(k) be the sum of their squares. The examples are F_3={001,010,100,101}, Ψ(3)=20302, and Ψ(10)≡10699667 mod 101001001. Find Ψ(10^18) mod 101001001.
