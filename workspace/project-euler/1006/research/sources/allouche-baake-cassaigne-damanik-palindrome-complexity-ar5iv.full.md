"Palindrome complexity" (TCS 292 (2003) 9–31). **It is not.** The actual
content at that arXiv id is Cassaigne's "Some explicit badly approximable
pairs" — a Diophantine-approximation paper unrelated to the target. The URL
was guessed, not verified in a search result first, which violated the
workspace rule. Do not cite this file as the palindrome complexity paper.
