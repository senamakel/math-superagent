# Morse-Hedlund Theorem -- from Wolfram MathWorld

The Morse-Hedlund theorem states that a right-infinite word is ultimately
periodic if and only if its factor complexity satisfies p(n) <= n for some
positive integer n. A bi-infinite word is periodic if and only if the same
inequality holds for some n.

Equivalently, every aperiodic right-infinite or bi-infinite word satisfies
p(n) >= n+1 for every positive integer n. This lower bound is sharp: the
aperiodic binary words satisfying p(n) = n+1 for all n are precisely the
Sturmian sequences.
