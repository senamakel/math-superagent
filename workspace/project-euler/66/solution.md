# Solution: Project Euler 66 — largest minimal solution of x^2 − D·y^2 = 1

## 1. Problem restatement (Phase 1 recap)

For each D in {1, 2, …, 1000} that is **not a perfect square**, consider the
Diophantine equation

    x^2 − D·y^2 = 1                                      (Pell)

in positive integers x, y. By classical theory (and as the problem states can be
assumed) there is **no** positive solution when D is a square: then
x^2 − (k^2)y^2 = 1 gives (x − ky)(x + ky) = 1, forcing y = 0.

For each non-square D there is a unique **minimal** positive solution
(x_D, y_D): minimal x (equivalently minimal y — the two are forced together by
the structure of units, see §2). Find the D ≤ 1000 for which x_D is **largest**.

**Oracle facts from the statement (test oracle):**
| D | minimal x | minimal y | check |
|---|-----------|-----------|-------|
| 2 | 3 | 2 | 9 − 2·4 = 1 |
| 3 | 2 | 1 | 4 − 3·1 = 1 |
| 5 | 9 | 4 | 81 − 5·16 = 1 |
| 6 | 5 | 2 | 25 − 6·4 = 1 |
| 7 | 8 | 3 | 64 − 7·9 = 1 |
| 13 | 649 | 180 | 421201 − 13·32400 = 1 |

And: among D ≤ 7 (non-square), the largest x is 9, obtained at D = 5.

Hand-check of the theory against the D = 13 oracle: sqrt(13) = [3; 1,1,1,1,6],
period L = 5 (odd). Convergents: 3/1, 4/1, 7/2, 11/3, 18/5 (norm 18^2 − 13·5^2
= −1), …, p_9/q_9 = 649/180 with 649^2 − 13·180^2 = 1. So the fundamental
solution appears at index 2L − 1 = 9, exactly as the parity rule (§3) predicts.
This hand computation confirms the method on the oracle.

## 2. The mathematical object

The equation is **Pell's equation**. Setting N(a + b√D) = a^2 − D·b^2, the
norm in the ring Z[√D], the equation reads N(x + y√D) = 1: find the positive
units of Z[√D] of norm 1. **Dirichlet's unit theorem / Pell structure:**
the units of norm 1 form an infinite cyclic group
{(x_1 + y_1√D)^k : k ∈ Z}, generated by the **fundamental unit**
ε_1 = x_1 + y_1√D with least x_1 > 1. Hence every solution is a power of the
minimal one, and "minimal x" and "minimal y" are synonyms.

## 3. The governing theorem and the method it yields

**Lagrange's theorem (periodicity).** For non-square D, the simple continued
fraction of √D is

    √D = [a_0; a_1, …, a_{L−1}, 2a_0],   a_0 = ⌊√D⌋,

with period length L ≥ 1. (Hypotheses required: D positive integer, non-square.)

**Fundamental solution is a convergent.** Let p_n/q_n be the convergents,
p_{−2} = 0, p_{−1} = 1, q_{−2} = 1, q_{−1} = 0, and for n ≥ 0
p_n = a_n·p_{n−1} + p_{n−2}, q_n = a_n·q_{n−1} + q_{n−2}. Then

    p_{L−1}^2 − D·q_{L−1}^2 = (−1)^L,

and the fundamental solution (x_1, y_1) of Pell's +1 equation is
(p_{L−1}, q_{L−1}) when L is even, and (p_{2L−1}, q_{2L−1}) = (p_{L−1}^2 +
D·q_{L−1}^2, 2·p_{L−1}·q_{L−1}) when L is odd (squaring the norm −1 unit).
All positive solutions are powers of this unit, so the **first convergent with
p_n^2 − D q_n^2 = 1 is exactly the minimal solution** in both x and y.

**Why it applies here.** √D is a quadratic irrational of degree 2, so Lagrange
gives periodicity; the periodicity plus the convergent recurrences let us walk
the convergents in O(L) exact big-integer steps instead of searching x upward.

**What it reduces the work to.** Per D: generate CF terms and convergents with
the integer recurrences below until the norm condition holds; guaranteed within
two periods, i.e. at most index 2L − 1, L = O(√D). Cost per D is O(L) steps of
big-integer arithmetic on numbers with O(√D) digits (explicitly: the answer
x_D for the winning D has ~39 decimal digits — searching x upward is impossible;
the method's cost depends only on the *input* D, on the period length, not on
the size of the answer).

## 4. Exact-integer algorithm (per non-square D ≤ 1000)

Continued-fraction iteration, all integers, no floats:

    a0 = isqrt(D)                       # exact integer sqrt
    if a0*a0 == D: skip (square D)
    m, d, a = 0, 1, a0
    p_prev2, p_prev1 = 0, 1             # p_{-2}, p_{-1}
    q_prev2, q_prev1 = 1, 0
    # convergent 0:
    p, q = a0, 1                          # p_0, q_0
    assert p*p - D*q*q != 1 (since D > a0^2)
    k = 0
    loop (k = 1, 2, …) until p*p − D*q*q == 1:
        m2   = d*a − m
        d2   = (D − m2*m2) // d          # exact division, integer
        a2   = (a0 + m2) // d2
        p, q = a2*p + p_prev1, a2*q + q_prev1
        shift (p_prev1, p_prev2), (q_prev1, q_prev2)
    return (p, q)                        # minimal solution (x_D, y_D)

Termination is guaranteed by §3 (first hit is at L−1 or 2L−1, both O(√D));
guard with a generous cap (e.g., 4·a0 + 10 iterations, with an assertion) purely
as a bug check. Track argmax x_D over D; answer = that D.

**Complexity.** O(Σ_{D ≤ 1000, non-square} L(D)) big-integer ops, L(D) ≤ ~60 for
D ≤ 1000; total ≈ 10^4–10^5 arithmetic steps. Space O(1) per D. No exponential
anything; no dependence on the (huge) answer magnitudes beyond the digit cost of
the final values (digits ≈ O(√D) per D).

## 5. Verification plan (Phase 5)

1. Reproduce the six oracle facts (D = 2,3,5,6,7,13) with the exact algorithm
   before the full run.
2. Full run D ≤ 1000, record argmax D and its (x, y); directly verify
   x^2 − D·y^2 = 1 by exact arithmetic on the winner.
3. **Second independent route:** an independent program implementing the
   **Chakravala (cyclic) method** of Bhaskara II — a classical algorithm for the
   fundamental solution that uses no continued fractions (invariant
   a^2 − D b^2 = k, choose m minimizing |m^2 − D| subject to a + b·m ≡ 0 mod k,
   update a' = (a·m + D·b)/|k|, b' = (a + b·m)/|k|, k' = (m^2 − D)/k, stop at
   |k| = 1, square the unit if k = −1). Both programs write per-D (D, x_D)
   tables; results are compared for **all** D, and their argmax D must agree.
4. Cross-check the winning pair and a sample of others (e.g., known large-x
   cases D = 421, 661, 991 ↔ their x's) between the two routes.
