# OEIS A035485 — R. K. Guy's shuffling problem — **NOT the out-shuffle sequence; do not cite for s(n)**

> Source: https://oeis.org/A035485 · full text: [[oeis-A035485.full]]
> **Status: WRONG MATCH — downloaded in error, retained only to record the negative so nobody fetches it again.**

## What it actually is

A035485 is "Card on top of deck at n-th stage of R. K. Guy's shuffling problem":
at step n, pick up the top n cards and interlace them with the next n. This is a
completely different shuffle from the problem's perfect out-faro shuffle (which
keeps the whole deck in two equal halves and interleaves exactly). It is *not*
the sequence `s(n)` of out-shuffle orders, and must never be used as that
reference.

## Why it must not be used for PE622

- The problem's `s(n)` = perfect out-shuffle order = order of 2 mod (n−1).
  That sequence is **A002326** (`a(k) = ord_{2k+1}(2)` for a 2k+2 deck), which is
  already the library's canonical source (see `oeis-A002326`).
- A035485 concerns a *variant* shuffle (Guy's incremental interlacing), which
  produces a different sequence with a different modulus and different values.
  Citing it for the out-shuffle order would reproduce, in miniature, the exact
  failure the library is built to prevent.

## Negative result recorded

The OEIS canonical record for out-shuffle order is A002326, **not** A035485.
A035485 was downloaded and rejected; retained as a struck-through negative so a
later search never voices the same guess now that the answer is on disk.
