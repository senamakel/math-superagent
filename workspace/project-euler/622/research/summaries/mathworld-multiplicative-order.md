# MathWorld — Multiplicative Order

Source: https://mathworld.wolfram.com/MultiplicativeOrder.html · full text: [[mathworld-multiplicative-order.full]]

## What it establishes

Definition: the smallest exponent e for which b^e ≡ 1 (mod n) is the
multiplicative order of b mod n (exists when (b,n)=1). The number of bases
having multiplicative order e is φ(e). For n having primitive roots, if g is a
primitive root the reduced residue system is 1,g,...,g^{φ(n)−1}.

## Consequences for this problem

Standard definitional reference for the multiplicative order underlying
`order-divisibility-conrad` and `outshuffle-order-equals-ord`. Adds nothing
beyond Conrad's treatment. The φ(e) count of order-e bases is not needed for
this exact-sum computation.
