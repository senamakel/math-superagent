| `pattern_study.py` | Empirical structural study (Q1/Q2/Q3) of PE 597: correlates race parity with three candidate scalar-priority treaps (w_i = v_i/(L-40i), finish time, raw speed) counted mod 2 against the oracle, searches for any scalar treap matching parity, and characterizes the bump directed graph (out-degree, index monotonicity, and distinct chronological edge sets with frequencies vs. the n=3,L=160 probability table). Assumes it lives in the workspace root (imports code/brute via a path relative to its own directory). |

| `race_spec.md` | Exact chronological race-dynamics specification for implementation: event simulation, bump/OUT/FINISH treatment, and the bump-chain parity definition. Reference contract for any race solver. |
| `research_recursion_test.py` | Decisive test of the research-library treap recursion against the brute oracle: implements the exact distance-ratio recursion p([a,b])=sum over min-W root r of w(r)*p(left)*p(right)*(-1)^cross in Fractions, tries both cross=|L|*|R| and cross=0 instantiations, and shows they give WRONG values (p(3,160)=2/3 vs 56/135, p(4,400)=5/6 vs 0.5107843137). Then searches for the smallest per-vector counterexample where the min-W-rooted parity recursion disagrees with the oracle, and tests the two crux claims C1 (sub-race decoupling) and C2 (cross=|L||R|) — both REFUTED. Establishes that the sum-of-products treap form fails because cross and sub-race parity are set by the real bump chronology. Diagnostic of the recursion hypothesis, not a solver. |
| `structure_report.md` | PE 597 structure report: reproduces the full n=3,L=160 worked-example table and the 56/135 even-sum and p(4,400) MC check, then a bump-graph taxonomy over 360k MC trials proving the bump graph is ALWAYS a directed forest with strictly index-increasing edges (out-degree≤1, no cycles), documenting degree/geometry statistics, and concluding for the exact solver that parity = #chain-pairs mod 2 and forest components act on disjoint index intervals. Companion to code/structure_taxonomy.py. Structural-result report feeding the exact method, not a solver. |
| `test_treap.py` | Deterministic test of the Cartesian-tree (min-heap treap) hypothesis for PE 597: compares tree-parity (count of ancestor/descendant index pairs in the min-w treap) against the true oracle outcome_parity on many random Exp(1) speed vectors, and Monte-Carlos the tree model's implied p(3,160), p(4,400), p(13,1800). Reports total mismatches and concrete failing cases. |
