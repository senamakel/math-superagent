# Index — code/toolkits

What each file in this folder is for. Keep it current: describe a file when you create it, and refresh this index after adding, renaming, or deleting files.

| File | Purpose |
| --- | --- |
| `arr_enum.py` | Exact cell enumerator of the PE 597 outcome arrangement over the simplex. Speeds normalized to the (n-1)-simplex (Dirichlet uniform); the race outcome is piecewise-constant and its separating set is a straight-line hyperplane arrangement: speed-equalities v_a=v_b plus pairwise equalities of candidate event times (finish F_j=(L-40j)/v_j, catch C_ab=40(b-a)/(v_a-v_b)), each T=const/(affine) so T_i=T_j is affine. enumerate_cells(n,L) recursively slices polytopes by each hyperplane only when straddled, producing leaves each equal to one cell's closure; leaf_interior takes the vertex-average as a strict interior point to read exact parity, summing exact leaf volumes weighted by (n-1)! so p(n,L)=sum of even-cell volumes. Backed by Polytope in toolkits.arr_polytope; consumed by code/p_cell_exact.py. Note: the private _T_aff helper is dead placeholder code (raises NotImplementedError); the live hyperplane set is built by the T() closure inside _hyperplanes. Exact solver for n=3,4. |
| `arr_polytope.py` | Exact-rational convex polytope in free-coordinate H-representation (A.x <= b, Fractions) over the speed simplex, with vertex enumeration, affine evaluation, hyperplane slicing, and exact area (d=2 shoelace) / volume (d=3 tetrahedral decomposition). The building block arr_enum uses to slice cells and p_cell_exact uses to sum even-cell volumes. |
| `pattern_parity.py` | Structural classification of bump-edge patterns: `parity_from_edges(n, edges)` reconstructs the new order, parity, and transitive chain-pair count from a bump-edge set alone (no dynamics), and `race_observed_patterns` collects which edge-sets the real race reaches for small n. Used to verify parity == (#chain pairs) mod 2 and to see which patterns are even/odd. |
| `race_events.py` | Single callable race_events(n,L,speeds) that replays the PE 597 chronological dynamics and returns parity, chronological bump edges, finishes, the bump-chain count, and the new ascending order. Parity independently recomputed via brute.parity_of_new_order; chain count from the reachability `above` sets. |
| `race_outcome.py` | PE 597 brute-force oracle: outcome_parity(n,L,speeds)->parity, the reference every exact method and MC is checked against; wraps fixed brute.py (full-reachability above). |
