# Index — code/toolkits

What each file in this folder is for. Keep it current: describe a file when you create it, and refresh this index after adding, renaming, or deleting files.

| File | Purpose |
| --- | --- |
| `arr_enum.py` | Exact cell enumeration of the PE 597 outcome arrangement over the speed simplex. _hyperplanes(n,L) builds the affine separator planes (v_a=v_b and T_i=T_j for candidate times F_j=(L-40j)/v_j, C_ab=40(b-a)/(v_a-v_b), each const/(linear) so equalities are affine). enumerate_cells(n,L) recursively slices the simplex polytope, producing leaves whose sign vector is constant; parity is constant on each open cell (numeric check: 0 inconsistent buckets per 150k samples). Established correct: n=3,L=160 gives 32 cells and p=56/135 exactly; n=4 gives 1202 cells. |
| `arr_polytope.py` | Exact rational convex polytope in free-coordinate H-representation plus cell slicing for the PE 597 arrangement. Polytope(dim, ineqs) with vertices() via exact Fraction Gaussian elimination over each d-subset of inequalities, affine eval at vertices, cut() to add a halfspace, and exact area2()/volume3()/volume() (shoelace for 2D, scipy-ConvexHull + exact tetra volumes for 3D). Used by arr_enum and p_cell_exact. Correctness anchored via the arrangement anchor checks. |
| `pattern_parity.py` | Structural classification of bump-edge patterns: `parity_from_edges(n, edges)` reconstructs the new order, parity, and transitive chain-pair count from a bump-edge set alone (no dynamics), and `race_observed_patterns` collects which edge-sets the real race reaches for small n. Used to verify parity == (#chain pairs) mod 2 and to see which patterns are even/odd. |
| `race_events.py` | Single callable race_events(n,L,speeds) that replays the PE 597 chronological dynamics and returns parity, chronological bump edges, finishes, the bump-chain count, and the new ascending order. Parity independently recomputed via brute.parity_of_new_order; chain count from the reachability `above` sets. |
| `race_outcome.py` | PE 597 brute-force oracle: outcome_parity(n,L,speeds)->parity, the reference every exact method and MC is checked against; wraps fixed brute.py (full-reachability above). |
