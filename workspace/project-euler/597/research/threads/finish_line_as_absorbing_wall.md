# Thread: the finish line as an absorbing wall

`thread`:
question: Is the finite-finish torpids parity provable from the convex-minorant / record structure of the no-finish race, or is the finish line a genuinely new boundary effect (absorbing wall) with its own region combinatorics?

- **RESOLVED (canonical sources added this cycle):** the run's parity-cell counts (n=3 → 32, n=4 → 1202, L-independent) are NOT region counts of any standard braid deformation. The canonical region-count formulas are now in the library (Stanley PNAS 1996 `stanley_hyperplane_interval_orders_trees_pnas1996`; Postnikov–Stanley arXiv:math/9712213 `postnikov_stanley_deformations_coxeter_arrangements`; Fishel Shi survey arXiv:1909.01257 `shi_arrangement_survey_fishel`). Standard counts for n=4: braid n!=24, Shi (n+1)^{n−1}=125, Catalan n!C_n=336, semiorder = interval orders, Linial = alternating trees = 2^{1−n}∏_{k=1}^{n−1}(k+1)^{n−1} for n>1 — none equals 1202 (nor 32 at n=3). So the torpids parity arrangement is NOT a transitive x_i−x_j∈ℤ deformation; moreover its hyperplanes are inverse-speed equalities, not x_i−x_j∈ℤ. The braid-deformation/tree route is ruled out. The exact route stays the run's own (rational functions of m=L/40 — verified n=2,3,4).

- **NEW this cycle — the signed-cell-sum machinery the parity needs now has primary standard references.** The torpids parity is a signed sum over cells (sign weight = parity) of simplex-section volumes of an arrangement; the run wants it without enumerating the (super-exponentially many) cells. Four primary sources now in the library show "signed/weighted sums over arrangement regions collapse to a characteristic-polynomial / Tits-algebra object with no region enumeration":

  - Kabluchko arXiv:2008.06719: affine-chamber analogue; number of chambers with projection-dimension k = |charpoly coeff_k|, x-independent.
