# Postnikov & Stanley, "Deformations of Coxeter hyperplane arrangements" — summary

- Source: Alexander Postnikov & Richard P. Stanley, *Deformations of Coxeter hyperplane arrangements*, arXiv:math/9712213 (also J. Combin. Theory Ser. A 91 (2000) 544–597). URL: https://arxiv.org/pdf/math/9712213 (full text: research/sources/postnikov_stanley_deformations_coxeter_arrangements.full.md)
- Content: proves Linial & Stanley's conjecture that the number of regions of the Linial arrangement (x_i − x_j = 1, 1 ≤ i < j ≤ n) equals the number of alternating trees on n+1 vertices, equivalently local binary search trees on [n]. General region/Poincaré formulas for finite subarrangements of the affine Coxeter arrangement of type A_{n−1}. Concretely, for the Linial arrangement in R^n:
    r(L_{n−1}) = 2^{−n} Σ_{k=0}^{n} C(n,k) (k+1)^{n−1}  (= number of alternating trees on n+1 vertices),
  giving small values r(L_2)=7 (n=3), r(L_3)=36 (n=4). Also Catalan-type deformations: regions = n! C_n. For generic deformations (all a_ij distinct), regions = number of forests on n labelled vertices = (n+1)^{n−1}·(1/2)·... (the Laplacian-tree count). Shi arrangement (arxiv:1909.01257 survey) has (n+1)^{n−1} regions.
- Bearing on PE597: provides the exact canonical region counts for the standard braid-deformation families. Compared with the run's L-independent parity-cell counts — n=3 → 32, n=4 → 1202 — none of the standard families matches (Shi 16/125, Linial 7/36, Catalan 30/336, braid 6/24 for n=3/4). Together with Stanley PNAS 1996 and Bernardi (tree bijections), this closes the "parity arrangement is a known braid deformation" question in the negative. The torpids hyperplanes are inverse-speed equalities, outside the x_i−x_j∈ℤ class these papers treat. See `research/threads/finish_line_as_absorbing_wall.md`.
