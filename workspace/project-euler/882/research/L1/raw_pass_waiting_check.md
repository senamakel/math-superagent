# When Waiting Moves You in Scoring Games (Larsson–Nowakowski–Santos 2015)

- Source: https://arxiv.org/abs/1505.01907 — full text `research/L0/raw_pass_waiting_check.full.md`.
- **Proper analysis in [[pass_waiting]]** (same paper). This note is just the
  raw arXiv abstract.
- Topic: combinatorial **scoring games** with **passes/waiting moves**.
- Result: characterizes scoring games where "extra pass moves do no harm" — the
  winner/structure then reduces via an **order-embedding into Conway's
  Normal-play theory**; generalizes Ettinger's dicot-scoring theory to comparing
  numeric games.
- Consequence for this problem: a skip is a genuine pass/waiting device governed
  by zugzwang ([[zugzwang]]); the framing corroborates that the skip is not a
  normal-play move and S(n) is not a closed-form CGT value — it comes from the
  (A,B) skip DP. Caveat: scoring-game hypotheses ≠ our fixed-budget normal-play
  skip; structural analogue only.
