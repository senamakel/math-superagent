# L0.1 seal — skip/loopy theory, pass theory, surreal values, weighted sums

Seals the ten original notes of batch **L0.1** (the skip-as-phenomenon and the
weighted-sums leg). Together they promote the game from a plain short-game count
to the loopy/zugzwang object the skip actually is, and add a second primary
source for the polylog arithmetic engine. Three files are mis-saves (duplicate
full-text saves of a note that also has a proper analysis); two are dead ends.

## The skip is loopy ∨ zugzwang, not a short-game rule
- [[loopy]] with its L0.1 original [[loopy.full.md]] (Wikipedia loopy games): a
  skip is a self-loop in the game graph, so the DP is a **fixpoint**, not a DAG;
  the game is a **stopper** (moves strictly decrease A or B), so no forced tie
  and **S(n) is finite**.
- [[siegel_zugzwang]] with its L0.1 originals [[siegel_zugzwang.full.md]] (full
  "Coping with cycles") and [[siegel_zugzwang.md]] (summary): the rigorous
  theorem-level frame — partizan **loopy games**, stoppers (canonical form), sides
  `s & t`, **Li's Theorem**: a zugzwang game equals `x & y` for dyadic `x ≤ y`,
  pseudonumbers. One's forced 1-bit consumption is exactly zugzwang.
- Together: the no-skip value A−B ([[disjsum]] etc.) is only the loopfree start;
  the skip opens a loopy component, so **S(n) ≠ A−B**.

## Passes (the skip is a budgeted, Zero-only pass)
- [[pass_waiting]] with its L0.1 original [[pass_waiting.full.md]]
  (Larsson–Nowakowski–Santos 2015, scoring games with waiting moves): characterizes
  when an extra pass is harmless (order-embedding into normal play); zugzwang/tempo
  framing of a move that is best skipped.
- [[raw_mfl_pass]] with its original [[raw_mfl_pass.full.md]]
  (Morrison–Friedman–Landsberg 2011): a one-time pass can radically change a game
  (Nim vs Chomp) — a pass perturbs structure, so it cannot be read off the no-skip
  value.
- [[raw_pass_waiting_check]] with its original [[raw_pass_waiting_check.full.md]]:
  raw abstract double-check of 1505.01907, folded into [[pass_waiting]].
- Caveat (both): scoring / one-time pass, not our budgeted repeated Zero-only
  skip; structural warrant, not a formula for S(n).

## Surreal value (why a−b is exact)
- [[surreal]] with its original [[surreal.full.md]]: each component
  G(a,b)={a−b−1|a−b+1} is a surreal; simplest value between options is the integer
  a−b, so board value = A−B. Outside short-game numbers when the skip is added.

## Second primary source for the arithmetic engine
- [[minabutdinov_qweighted]] with its L0.1 originals
  [[minabutdinov_qweighted.full.md]] (full arXiv:1801.03120) and
  [[minabutdinov_qweighted.full.full.md]] (the same full text, mis-saved as a
  doubled suffix): generalized **Trollope–Delange** for *weighted* binary digit
  sums (positional `q^{i+1}` weights) → Takagi–Landsberg limit curves; corroborates,
  from a primary text, that k·-weighted A(n),B(n) stay polylog +
  1-periodic-fluctuation at n=10⁵.

## Dead end
- [[strategy]] with its original [[strategy.full.md]]: generic game-theory
  strategy article; no combinatorial-game, normal-play, or pass content. Examined
  and ruled out.

## What this batch does NOT settle
It makes the skip a legitimate loopy/zugzwang object and adds the weighted-sum
warrant, but gives no closed form for the **budgeted** S(n). That stays the live
DP problem (see L2.0/[[game-reduction-and-pass]] and [[counting-arithmetic]]).
