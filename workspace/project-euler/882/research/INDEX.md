# Index — research

What each file in this folder is for. Keep it current: describe a file when you create it, and refresh this index after adding, renaming, or deleting files.

This is the way into the reference library. Each subfolder carries its own index:

| Path | Purpose |
| --- | --- |
| `L1/` | L1 summaries — one short file per source, the way in for any specific source. See `L1/INDEX.md`. |
| `L0/` | L0 full-text companions (`.full.md`) behind the L1 summaries. See `L0/INDEX.md`; read the L1 summary first. |
| `L2/` | L2 syntheses that fold several sources into one argument (counting-arithmetic; game-reduction-and-pass). See `L2/INDEX.md`. |
| `folds/` | Fold notes linking sources into working arguments (game-core, passes, counting-arithmetic, deadends). See `folds/INDEX.md`. |

The single most useful entry points for the goal: `L2/game-reduction-and-pass.md`
(why the game reduces to the (A,B) counters and why S(n) must come from the DP)
and `L2/counting-arithmetic.md` (polylog A(n),B(n) at the n=10⁵ scale).

Known dead ends are recorded in `L1/misfiled.md` (four accidental downloads in
`L0/` unrelated to the problem, no result used) and `folds/deadends.md`
(S(n) ∉ OEIS; generic strategy article irrelevant).
