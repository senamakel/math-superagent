# Index — research

What each file in this folder is for. Keep it current: describe a file when you create it, and refresh this index after adding, renaming, or deleting files.

Downloaded sources are stored twice: `<name>.md` is the (still-undigested) Wikipedia excerpt — read this first — and `<name>.full.md` is the complete converted text for when the excerpt does not answer the question. Rows describe the files below; excerpts are not yet digested into scholar summaries.

| File | Purpose |
| --- | --- |
| `cgt.md` | Wikipedia excerpt on combinatorial game theory (two-player sequential perfect-information games). Framing background for the partisan bit-deletion game. |
| `cgt.full.md` | Complete converted Wikipedia article "Combinatorial game theory"; fallback full text for when cgt.md does not answer the question. |
| `disjsum.md` | Wikipedia excerpt on disjunctive sum (playing games in parallel, move in one per turn). Relevant should the game decompose into independent components. |
| `disjsum.full.md` | Complete converted Wikipedia article "Disjunctive sum"; fallback full text for when disjsum.md does not answer the question. |
| `loopy.md` | Wikipedia excerpt on loopy games (game tree with cycles, adds a tie/draw outcome). Relevant because a skip can revisit the same (A,B) counting state. |
| `loopy.full.md` | Complete converted Wikipedia article "Loopy game"; fallback full text for when loopy.md does not answer the question. |
| `normalplay.md` | Wikipedia excerpt on the normal play convention (last player able to move wins; misère is the opposite). Background for the win/loss convention used here. |
| `partisan.md` | Wikipedia excerpt on partisan games (not impartial; asymmetric player moves, Sprague–Grundy does not apply). The bit-deletion game is partisan: One deletes 1-bits, Zero deletes 0-bits. |
| `strategy.md` | Wikipedia excerpt on strategy in game theory (complete plan of play vs a single move). Background on move-vs-strategy terminology. |
| `strategy.full.md` | Complete converted Wikipedia article "Strategy (game theory)"; fallback full text for when strategy.md does not answer the question. |
| `surreal.md` | Wikipedia excerpt on surreal numbers (ordered field generalizing the reals, originating in Go endgame analysis). Possible lens for assigning numeric values to game positions. |
| `surreal.full.md` | Complete converted Wikipedia article "Surreal number"; fallback full text for when surreal.md does not answer the question. |
| `zugzwang.md` | Wikipedia excerpt on zugzwang (obligation to move is a disadvantage; passing, if allowed, would be best). Directly relevant to the skip/pass mechanic. |
| `zugzwang.full.md` | Complete converted Wikipedia article "Zugzwang"; fallback full text for when zugzwang.md does not answer the question. |
