# Index — research

What each file in this folder is for. Keep it current: describe a file when you
create it, and refresh this index after adding, renaming, or deleting files.

The research is organised in tiers; the per-file index that matters is
`L1/INDEX.md` (one short summary per source). Everything else on disk is
full-text or derived notes reachable through it.

| Folder | Purpose |
| --- | --- |
| `L0/` | Full downloaded source texts (one `.full.md` per source, with `.full.full.md` duplicate pairs catalogued in L1/misfiled.md). Read the L1 summary first; open these only when the summary does not answer the question. |
| `L1/` | One short summary note per source, each linking its full text in `L0/`. The way in for any single source. Read `L1/INDEX.md`. |
| `L2/` | Derived notes restating the applied mathematics (counting arithmetic, game reduction + pass) on top of L1. |
| `folds/` | One-subject synthesis notes aggregating the L1 sources they link. Most useful ordering of the material; read `folds/INDEX.md`. |

Recommended reading order (most useful first): `L1/INDEX.md`, `folds/INDEX.md`,
then the L1 notes each fold links, opening an `L0/` full text only when a
summary is insufficient.
