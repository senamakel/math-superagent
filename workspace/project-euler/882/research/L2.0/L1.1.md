# Sealing note — batch L1.1: why the game is not impartial, why a skip is a real (loopy/pass) object, and the polylog arithmetic engine behind A(n), B(n)

Batch `L1.1` (10 notes) covers two quite different bodies of material that together
justify the run's whole approach to Project Euler 882. Group (A): the **structure of
the game itself** — why Sprague–Grundy is inapplicable, why the skip is a genuine
zugzwang/pass/loopy device so S(n) ≠ A−B, and why each number's no-skip value is the
integer a−b via surreal numbers. Group (B): the **arithmetic engine** — why A(n) and
B(n) are computable in polylog time (Trollope–Delange structure for weighted digit
sums) so the DP can run at n=10⁵ without iterating to n. One note ([[strategy]]) is a
ruled-out dead end. Sealed once; never revisited.

## Group (A): game structure

### [[partisan]] — the game is strictly partisan, so Sprague–Grundy does not apply
Source: en.wikipedia.org/wiki/Partisan_game (Winning Ways vol.1 p.17; Conway ONAG 1976).
Definition: a game is **partisan/partizan** when it is not impartial — some moves are
open to one player and not the other, or payoffs are asymmetric. For partisan games the
**Sprague–Grundy theorem (the universal reduction to Nim heaps/nimbers) does not hold**;
analysis proceeds through Conway's numbers-as-games (surreal) values instead.
Why it holds here: One deletes only 1-bits, Zero only 0-bits — disjoint move sets — so
the bit game is strictly partisan. **Consequence: the run must not and does not use
nimbers/Grundy values; it uses minimax over (A,B).**

### [[surreal]] — each number's no-skip value is exactly the integer a−b
Source: en.wikipedia.org/wiki/Surreal_number ; Conway, *On Numbers and Games* (1976).
Definitions: surreal numbers generalize the reals (all reals plus infinite/infinitesimal
objects) and form an ordered field; any game position that "is" a number compares and
adds like ordinary numbers. The game {L|R} with all L<R equals the **simplest surreal
strictly between L and R** (simplest integers are the standard ones; 0 simplest, then
±1, ±2, …).
Application: in the counting model each component is G(a,b) = {a−b−1 | a−b+1}, a number
(left<right), whose simplest value between the options is the integer **a−b**. Surreal
addition = integer addition, so the whole board's no-skip value is **A−B** (A=Σ1-bits,
B=Σ0-bits). This is the exact statement that "the position reduces to a single integer."
**Limits: skips are not ordinary moves** — a skip is a self-loop outside the short-game
number framework, so the surreal value A−B captures only the no-skip outcome; S(n) is a
different object computed by the DP. (Also exact only for the counting model, which real
leading-bit deletions can violate.)

### [[siegel_zugzwang]] — the rigorous loopy theory: stoppers, Li zugzwang games, why the skip is a loop
Source: A. Siegel, "Coping with cycles", Games of No Chance 3, MSRI Publ. 56 (2009),
library.slmath.org/books/Book56/files/12siegel.pdf. Primary, theorem-level partizan
loopy CGT. Key definitions and theorems:
- **Stopper** = a loopy game with no infinite alternating play from any subposition;
  stoppers always terminate in isolation and have a canonical form (Thm 1, 2; Conway).
  The bit game **without** skips is a stopper, so its value is a well-founded canonical
  game.
- **Sides / canonical s&t** (Thm 5, Swivel Chair): a loopy game's behaviour is captured
  by its onside/offside stoppers; pass moves are **exactly the loops**
  (`f0|passg=over`, `fpass|g=on`, `fpass|passg=dud`).
- **Zugzwang games (Li 1976)**: games where moving is a disadvantage — every follower
  has all Left options `<` it and all Right options `>` it. **Li's Theorem 7**: a loopy
  game equals a zugzwang game iff it is `x & y` for **dyadic rationals** x ≤ y. Weak
  zugzwang games (Thm 9) are exactly the `x & y` with each side on/off/dyadic/z±over/
  z±under.
- **Pseudonumbers** = infinite stoppers generalising surreals; `bZ={0,1,2,…|pass}=ω:off`
  is the least upper bound of the integers.
Why it applies: each number's game G(a,b)={G(a−1,b)|G(a,b−1)} is the loopfree integer
a−b (a well-founded pseudo/surreal), and the board is the disjunctive sum of these
stoppers. Zero's skip introduces a **pass loop**, so the comparative value is governed
by this stopper/loopy theory: Li's zugzwang games generalise ordinary numbers precisely
because in zugzwang moving is disadvantageous, which is exactly One's situation (forced
1-bit consumption on every One turn). **Caveat: this is value/outcome theory, not the
budgeted minimum-skip count S(n); our skip costs budget and only Zero may use it,
outside this theory's comparison framing. It warrants the structural model, not a
formula for S(n) — that still comes from the (A,B) fixpoint DP.**

### [[siegel_zugzwang]] — the rigorous loopy/canonical-form theory that makes the skip a loop
Source: A. Siegel, "Coping with cycles," Games of No Chance 3, MSRI Publ. 56 (2009),
library.slmath.org/books/Book56/files/12siegel.pdf — the primary, theorem-level theory
of **partizan loopy games**. Key objects: a **stopper** is a loopy game with no
infinite alternating play (canonical form, Thm 1/2); **sides / s&t** (Thm 5) capture a
loopy game by onside/offside stoppers, the **pass being exactly the loop**
(`f0|passg=over`, `fpass|g=on`, `fpass|passg=dud`); Li's **zugzwang games** (moving is a
disadvantage) with **Li's Thm 7** = games `x&y` for dyadic x≤y; **pseudonumbers** =
infinite stoppers generalising surreals. Why it applies: the no-skip game is a stopper
whose value is the loopfree integer a−b (=A−B on the board), and Zero's skip is a pass
loop; Li's zugzwang frames One's forced 1-bit consumption. Caveat: this is
value/outcome theory with unlimited passes, not the budgeted, Zero-only skip count
S(n) — it warrants the (A,B) fixpoint DP as the structural model, not a formula for S(n).

### [[pass_waiting]] and [[raw_pass_waiting_check]] — passes/waiting moves in scoring games
Source: Larsson, Nowakowski & Santos, "When waiting moves you in scoring combinatorial
games," arXiv:1505.01907 (2015); the raw abstract is `raw_pass_waiting_check.md`, the
proper analysis is `pass_waiting.md` (same paper).
Content: studies **scoring games** (player with the higher final score wins) with
**passes/waiting moves** — an extra move a player may take instead of a substantive one.
Characterizes the class of scoring games where "extra pass moves for a player do **no
harm**": they admit an **order-embedding into Conway's normal-play games**, so winner/
structure reduces to the short-normal-play theory. Generalizes Ettinger's dicot-scoring
theory to comparing games with scores via the pass/waiting structure. **Zugzwang/tempo
framing**: a waiting move is exactly what a player uses when moving is a disadvantage —
the position's value to the player who must move is lower than to the one who may pass.
Why it applies: the problem's skip ("only Zero may skip; turn passes to One, skip count
+1") is a waiting move/pass. This is a primary, math-rigorous treatment of exactly that,
framing the pass as an order-embedding into normal-play values and corroborating that a
skip is not a normal-play move. **Caveat: scoring-game framework (maximize score); our
game is normal-play with a fixed budget and the skip costs budget, so the theorem's
hypotheses are not literally our rule — a structural analogue, not a recipe for S(n).**

### [[raw_mfl_pass]] and [[mfl_pass]] — a pass can radically change game structure
Source: Morrison, Friedman & Landsberg, "Combinatorial games with a pass: a dynamical
systems approach," arXiv:1204.3222 (2011); `raw_mfl_pass.md` is the raw abstract,
proper analysis in [[mfl_pass]] (an L1.0 note for the same paper). Treats games as
dynamical systems to study how a one-time "pass" move changes them. **Nim: a pass
radically restructures the game (S–G solution breaks). Chomp: minimal impact.**
Consequence for this problem: a pass can perturb structure unpredictably, so **S(n)
cannot be read off the no-skip value A−B**; it must come from the skip-budget DP.
(Agile caveat: our skip is repeated, budgeted, partisan — not their one-time impartial
pass.)

### [[strategy]] — dead end, ruled out
Source: en.wikipedia.org/wiki/Strategy_(game_theory). A generic article on strategy/
strategy profiles in economic normal-form game theory. Contains no combinatorial-game,
normal-play, outcome-class, or pass/skip results; computes/bounds nothing about S(n).
Retained only to mark it examined and ruled out; do not read again.

### Net structural claim from Group (A)
The bit game is strictly partisan (no S–G); each number's no-skip value is the integer
a−b (surreal), so the board's no-skip value is A−B; the skip is a genuine zugzwang/pass
(waiting-move) loop governed by loopy/pass theory (Siegel; LNS 2015; MFL 2011), and a
pass can perturb structure unpredictably — so **S(n) ≠ A−B and S(n) is not a closed-form
CGT value; it comes from the (A,B) minimax DP with a budgeted skip**. This is why S(n)
grows faster than A−B (e.g. S(10)=64 vs A−B=19).

## Group (B): the arithmetic engine — polylog evaluation of A(n), B(n)

### [[trollopedelange]] — primary proof of the Trollope–Delange structure for ones and zeros
Source: R. Girgensohn, "Digital sums and functional equations", INTEGERS 11 (2011) #A54,
emis.muni.cz/journals/INTEGERS/papers/l54/l54.pdf.
Notation: s(j) = number of 1-bits of j (A000120/popcount); S(n)=Σ_{j=0}^{n-1}s(j) the
summatory 1-bit count (A000788 is the same sum). s⁰(j) = number of 0-bits (no leading
zeros), summatory S⁰₁(n). p(n) = largest power of 2 ≤ n; x=(n−p(n))/p(n) ∈ [0,1).
- **Trollope–Delange (ones), exact**: (1/n)S(n)=(1/2)log₂n+(1/2)F̃(log₂n) with 1-periodic
  F̃ built from Takagi's function; equivalently S(n)=(n/2)log₂p(n)+p(n)F(x) with F the
  continuous solution of a pair of functional equations. At powers of two S(p)=(1/2)p
  log₂p; the whole sequence is fixed by the divide-and-conquer identities:
  S(2n)=2S(n)+n; S(n+p(n))=S(n)+S(p(n))+p(n); S(n+2p(n))=S(n)+S(2p(n))+n; S(2ᵉ)=e·2ᵉ⁻¹.
- **Same structure for zeros (analogue, (99))**: (1/n)S⁰₁(n)=(1/2)log₂n−1−(1/2)log₂
  (x+1)+F⁰₁(x)/(x+1) with F⁰₁(x)=x+(1/2)T(x).
- **Key method (why it is efficient)**: the whole summatory sequence is fixed by its
  values at powers of two plus one continuous 1-periodic fluctuation; explicit power
  sums Σs(j)^k (Thm 2, (73)) and zero analogues (98) are given.
Why it applies: the DP runs on A(n)=Σ_{k=1..n}k·popcount(k) and B(n)=Σ_{k=1..n}
k·zerocount(k), the k·-**weighted** ranges of these unweighted summatory functions. This
paper is the primary, locally-held evidence that the unweighted one- and zero-count
summatory functions each have an exact Trollope–Delange form and, decisively, are
determined by the O(log n) divide-and-conquer identities — i.e. **computable in polylog
time**, not by iterating to n. **Caveats: unweighted only (the k·-weighting is the run's
own bit-position decomposition); (99) uses s⁰(0):=−1 normalisation, so be careful
quoting it numerically (see [[verify_trollopedelange]]).**

### [[weightedmom]] — weighted sum-of-digits moments admit Delange-type closed forms
Source: Larcher & Pillichshammer, "Moments of the weighted sum-of-digits function,"
Quaestiones Mathematicae 28(3) (2005) 321–336, DOI 10.2989/16073600509486132. Only the
abstract is locally available (full PDF subscription-gated on AJOL); stored twice
(weightedmom.md summary, weightedmom.full.md the AJOL landing page).
Content: the **weighted sum-of-digits function** generalises the ordinary one by
assigning a weight to each digit (alternating sum a special case). The authors compute
the **first and second moments** of it and give an **alternative representation to
Delange's formula** for the first moment of the ordinary sum-of-digits function with a
*non-periodic, piece-wise differentiable* fluctuation replacing Delange's periodic,
nowhere-differentiable one. A (weak) **Delange-type result for the first moment of the
weighted sum-of-digits function holds iff the weight sequence converges**.
Why it applies: A(n) and B(n) are first-moment/weighted sums of binary digit-count
functions — exactly this object. The structural claim that such weighted digit sums
admit main-term+fluctuation closed forms (rather than needing term-by-term iteration) is
the theoretical warrant that A(n), B(n) are computable in O(poly log n). **Caveats:
only the abstract is local (no numeric formula used from here); the board's weighting
(k copies of k) is not the paper's positional weighting — the shared object is "first
moment of a digit-sum function", not identical sums.**

### Net arithmetic claim from Group (B)
A(n)=Σk·popcount(k) and B(n)=Σk·zerocount(k) are first-moment weighted digit sums whose
underlying unweighted summatory functions obey the O(log n) Trollope–Delange
divide-and-conquer recurrences (Girgensohn 2011, with the run's own k·-weighting
decomposition) and which admit Delange-type closed-form structure (Larcher &
Pillichshammer 2005). Hence both are computable in polylog time, letting the (A,B)
minimax DP run at n=10⁵. S(n) itself is not closed-form (a pass perturbs structure,
MFL 2011) and is not in OEIS — it must be computed by the DP.
