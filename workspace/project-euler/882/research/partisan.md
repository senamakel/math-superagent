Combinatorial game with asymmetric players

In [combinatorial game theory][1], a game is **partisan**(sometimes **partizan**) if it is not [impartial][2]. That is, some moves are available to one player and not to the other, or the payoffs are not symmetric. [1]

Most games are partisan. For example, in [chess][3], only one player can move the white pieces. More strongly, when analyzed using combinatorial game theory, many chess positions have values that cannot be expressed as the value of an impartial game, for instance when one side has a number of extra tempos that can be used to put the other side into [zugzwang][4]. [2]

Partisan games are more difficult to analyze than [impartial games][2], as the [Sprague–Grundy theorem][5] does not apply. [3] However, the application of combinatorial game theory to partisan games allows the significance of *numbers as games*to be seen, in a way that is not possible with impartial games. [4]
