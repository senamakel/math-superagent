# Index — code

What each file in this folder is for. Keep it current: describe a file when you create it, and refresh this index after adding, renaming, or deleting files.

| File | Purpose |
| --- | --- |
| `AGENTS.md` | How to work in code/: every program lives here, all output in code/out/, one job per file, the naive program is the oracle and stays, exact arithmetic, never delete a program carrying a result. |
| `brute.py` | TASK A: naive minimax on the REAL game (multiset state, whose turn, skip budget). Prints S(n) for n=1..8 and verifies n=1..3 against an explicit move-search. |
| `compare.py` | Cross-check: real-game S(n) (brute.py, n=1..8) vs counting-game S(n) (counting.py) for n=1..8; prints match/mismatch per row. |
| `counting.py` | TASK B: the same minimax DP on the reduced counting game (A,B) where A=total 1-bits, B=total 0-bits; One-move (A-1,B), Zero-move (A,B-1), skip passes. Verifies S(2)=2, S(5)=17, S(10)=64; prints S(n) n=1..10 and the need_oneturn/need_zeroturn grids for A,B in 0..12. |
| `counting_proper.py` | Counting surrogate (A,B) with CORRECT aggregated skip semantics: One-move (A-1,B), Zero-move (A,B-1), skip costs 1 and passes the turn (always allowed, even B==0); O(0,B)=0 (Zero wins as soon as One has no 1-bit on One's turn). Recurrences O(A,B)=Z(A-1,B), Z(A,B)=min(O(A,B-1) B>=1, 1+O(A,B)), well-founded in A. Builds exact tables to N=2000, prints O(A,B) for A,B in 0..24, S_counting(n)=O(A(n),B(n)) for n=1..30, compares to real-game oracle S(1..5)=1,2,8,9,17. RESULT: O(A,B)=max(0,A-B) exactly; only n=1 matches the real oracle — the single-(A,B) aggregation is REFUTED as a faithful surrogate (real game S climbs 1,2,8,9,17; counting gives 1,1,7,3,8). Output in code/out/counting_proper.txt. |
| `dyadic.py` | Scratch derivation program: computes the dyadic CGT value g(k) of the single-number game for each k via the Simplicity Rule (Left=delete a 1-bit, Right=delete a 0-bit, simplest dyadic between option values), then the board value G(n)=sum_{k=1..n} k*g(k) and S_theory=ceil(G(n)) compared against the given S(2),S(5),S(10). Exploratory; stdout only (no saved output), it does not define the final method. |
| `dyadic_clean.py` | Cleaned-up version of dyadic.py: computes the dyadic CGT value g(k) of each single-number bit-deletion game via the Simplicity Rule (Left=delete a 1-bit, Right=delete a 0-bit, simplest dyadic strictly between option values), then board value G(n)=sum k*g(k) and S_theory=ceil(G(n)) compared with the real-game oracle S(1..5)=1,2,8,9,17. Exploratory scratch (same line of work as dyadic.py); stdout only, no saved output. |
| `fastbrute.py` | TASK A (optimized): real-game minimax taking the same game semantics as brute.py but removing the skip-budget dimension — the memoized value f(state,turn) is the minimal skips Zero needs (unlimited budget), so S(n) = f(init, One) with one memo over (state,turn) instead of S(n) separate memo runs. Oracle agreement with brute.py is asserted for S(1..8). |
| `progress_n.py` | Budget-sweep of the real-game solver for one n with per-budget progress/state/time reporting. For n=6 it showed need=inf through budget=18 (1.5M states) then timed out, establishing S(6)>18 and infeasibility of n=6 within ~5min. |
| `run_real.py` | Driver for the real-game minimax oracle (budget-removed optimizer of fastbrute.py, per-n solver with flushed stdout). Prints S(n) for a requested range (default 1..9). Canonical real-game S values S(1..5)=1,2,8,9,17 come from runs of this/branch of fastbrute. |
| `scratch_run2.py` | Scratch harness: imports counting.py's DP (up to `def main`) and prints S(n) for n=1..10 via need_oneturn with the (A,B) totals — a quick re-run of the TASK-B table outside counting.py's main. Scratch; superseded by counting.py itself. |
| `scratchpad_td.py` | Superseded scratch verification harness: the Trollope–Delange checklist it encoded was moved to research/verify_trollopedelange.md for tool_builder to execute. Kept only as a record; no numerical claims from Girgensohn (2011) were confirmed by a run. |
| `temperature.py` | Pyrometric scratch: computes the dyadic board value V(n)=sum_{k=1..n} k*G(k) with G(k)=popcount(k)-zerocount(k) per the disjunctive-sum/additivity and Simplicity-Rule model, printing exact fractions for n=1..40. O(n) per call. Exploratory; the closed-form/efficient evaluation of G(n) at n=10^5 remains open. |
| `test_simplest_dyadic.py` | Validation test for toolkits/simplest_dyadic.simplest_between: cross-checks it against an independent birthday-oracle enumeration of dyadics (birthday<=16) over fixed + 150 random intervals; reports mismatch count. Establishes the helper the dyadic sweep relies on. |
| `time_n.py` | Time S(n) for a single n using the budgeted real-game solver (brute.py logic); prints S, memoized-state count, wall time. Scratch timing harness. |
