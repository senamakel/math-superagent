# Index — prompts

What each file in this folder is for. Keep it current: describe a file when you create it, and refresh this index after adding, renaming, or deleting files.

| File | Purpose |
| --- | --- |
| `goals.md` | Goals agent: translate the goal into observable completion criteria, delegate computation to the tool-builder, require a small-case check before a full-size run. |
| `inventor.md` | Inventor agent: propose a change of representation when an approach stalls; cite it against known theory; one concrete proposal, never enumeration. |
| `librarian.md` | Librarian agent: build and maintain the research/ reference library, descriptive names, keep research/INDEX.md current, index each document. |
| `orchestrator.md` | Orchestrator agent: sequence work (understand, research, derive, implement, verify), spawn research and tool-builder tasks in parallel, combine into one derivation. |
| `organizer.md` | Organizer agent (this role): own the shape of the workspace, keep every INDEX.md matching what is on disk, describe files, never change what files say. |
| `pattern_finder.md` | Pattern-finder agent: analyze computed integer sequences with difference/recurrence tools; report exact findings as conjectures, never invented patterns. |
| `reflection.md` | Reflection agent: judge whether an attempt actually solved and made real progress; name the specific misstep and a specific alternative as the lesson. |
| `research.md` | Research agent: prefer primary sources, return exact URLs, precise theorem statements with hypotheses; do not hunt for contest answers. |
| `scholar.md` | Scholar agent: digest downloaded sources into sub-1000-token summaries in research/, verify hypotheses hold for this problem, flag contradictions. |
| `tool_builder.md` | Tool-builder agent: run programs, reproduce worked examples first, prefer exact arithmetic, build one-function-per-file toolkits, never exponential methods. |
