# Legendre — Number system for cyclic-shift-generated permutations

**Source:** https://arxiv.org/abs/1007.2870 (arXiv:1007.2870, math.CO, 2010/2011, 14pp)

## What it establishes
A number system (code) for ranking/unranking the permutations produced by
**cyclic shift** — i.e. the orbit {σ_i} of a one-line word under left-rotation
of its entries (n permutations, all in the same cyclic orbit). Given how a
permutation was generated it gives its **rank**; given a rank it reconstructs
the permutation; and the code encodes the symmetry of the whole cyclic set.
The author conjectures this code is a combinatorial **Gray code** listing the
cyclic orbit (a Hamiltonian path of minimal weight in an associated regular
digraph).

## Bearing on PE 903
- Thematically it is *ranking a permutation within the subset generated by one
  map on S_n*, which is precisely the shape of the run's open core (summing
  ranks over the cyclic subgroup {π^i}). It is the closest located treatment
  of "rank of a permutation inside a cyclic-orbit/subgroup."
- **Limitation (clean negative):** the map here is a rotation of the one-line
  *word* (an n-cycle acting on positions), giving an orbit of size n; PE 903
  sums over {π^i}, the order-d subgroup generated by the *permutation power*
  map on the whole symmetric group, whose orbit is size d=lcm of cycle
  lengths. Same question shape, different algebra — the Legendre rank code is
  for rotation orbits, not power orbits, and supplies no closed form for
  A_n,B_n. Filed as a related-framework source, not a solution.
