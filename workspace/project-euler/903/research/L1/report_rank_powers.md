# Rank & powers: established facts for Q(n)

Q(n) = Σ_π Σ_{i=1}^{n!} rank(π^i), rank = 1-based lexicographic position. What the
sources establish, the derived reduction, and what is still unresolved.

## Established facts (cited)
1. **Lexicographic rank = Lehmer code in factorial base.** rank0(s)=Σ c_i·(n−i)!,
   c_i = #{j>i : s_j<s_i}; 1-based rank = rank0+1. It bijects S_n onto {1..n!}.
   [Wikipedia: Lehmer code, Factorial number system; OEIS A033312]
2. **ord(π) = lcm of cycle lengths**; powers repeat with period ord(π), and
   ord(π) | n! (Lagrange). [Wikipedia: Permutation; abstractalgebra.net L12 Thm
   5.3; Wolfram PermutationOrder]
3. **Σ_{π∈S_n} rank(π) = n!(n!+1)/2** — corollary of 1 (each rank occurs once).
4. **m-th roots.** Wilf existence criterion: σ has an m-th root iff for every l,
   its #l-cycles is divisible by gcd(l,m). Exact counts: Leaños–Moreno–Rivera-
   Martínez [arXiv:1005.1531]; Pouyanne EGF [eljc v9i1r3].
   → NOT directly usable here: root counts don't feed the size-|H| rank-sum.
5. **#cyclic subgroups of S_n** = A051625 (formula given); Cyclic sieving
   phenomenon (Ahlbach–Swanson) — background only, no closed form for the
   rank-sum over a cyclic subgroup.

## Derived reduction (this run; hand-verified)
For a fixed π the n! values π^1..π^{n!} visit each of its ord(π) distinct powers
(n!/ord π) times each (ord | n! by Lag—range). Hence
    Σ_{i=1}^{n!} rank(π^i) = (n!/ord π) · Σ_{τ∈⟨π⟩} rank(τ).
Grouping by cyclic subgroup H (each H of size m is generated by exactly φ(m)
elements π), and every π generating exactly one H:
    Q(n) = Σ_{H⩽S_n cyclic} φ(|H|) · (n!/|H|) · Σ_{τ∈H} rank(τ).
Hand-enumerated: n=2 → 5; n=3 → 88. Both match the problem statement, so the
decomposition and the ranks/orders used to build it are confirmed (oracle:
research/verify_facts.py, same method).

## What it lets this run do / not do
- Reduces the double sum to a sum over cyclic subgroups weighted by an
  intra-H rank-sum — the correct object to attack.
- Does **not** give a closed form for Σ_{τ∈H} rank(τ), nor a way to aggregate
  over all cyclic subgroups at n=10^6 (A051625 count is astronomically large).
  **That core is unresolved and no source supplies it.** The rank-sum over a
  cyclic subgroup—equivalently over the powers of one π—is what must be derived
  to beat enumeration at n=10^6.
