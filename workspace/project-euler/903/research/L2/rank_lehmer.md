# Fold: rank / Lehmer (factoradic) structure

Lexicographic rank is computed by Lehmer/factoradic digits; this is the rank machinery the problem's `sum rank(π^i)` rests on. Neither source addresses powers or the cyclic subgroup {π^i} — they define the rank model only.
