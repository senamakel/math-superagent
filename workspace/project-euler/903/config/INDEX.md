# Index — config

What each file in this folder is for. Keep it current: describe a file when you create it, and refresh this index after adding, renaming, or deleting files.

| File | Purpose |
| --- | --- |
| `config.toml` | Run configuration: workspace kind (mathematical-research), solver flags (show derivation, verify with code, exact arithmetic, cite external claims, 600 s max tool runtime, forbid exponential time/space), artifact file paths (goal.md, tasks.md, memory.md, scratchpad.md, solution.md) |
| `problem.url` | Source URL for the problem statement: https://projecteuler.net/minimal=903 (the problem.html saved at the workspace root was downloaded from here) |
