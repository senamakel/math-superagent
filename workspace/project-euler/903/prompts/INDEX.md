# Index — prompts

What each file in this folder is for. Keep it current: describe a file when you create it, and refresh this index after adding, renaming, or deleting files.

| File | Purpose |
| --- | --- |
| `goals.md` | Workspace goals guidance: turn the goal into observable completion criteria before delegating; use the research agent for sourced facts and the tool-builder for calculation/files/verification; nothing is real until a running program exists |
| `inventor.md` | Workspace inventor guidance: when an approach stalls, propose one change of representation (generating function, bijection, transform, recursive decomposition) that matches a named theory; no enumeration, no cost growing with the problem bound |
| `librarian.md` | Workspace librarian guidance: build the reference library under `research/`, descriptive filenames, current research/INDEX.md, index each document; source URLs attached; never store a published contest answer |
| `orchestrator.md` | Workspace orchestrator guidance: sequence understand → research → derive → implement → verify; delegate math to research agent, checks to tool-builder; reject answer-space search; combine children's work into one derivation |
| `organizer.md` | Workspace organizer guidance: keep every folder's INDEX.md matching disk, describe undescribed files, keep research/ and toolkits/ navigable, never touch reflections/, never edit derivations — only describe them |
| `pattern_finder.md` | Workspace pattern-recognition guidance: work from computed result files; use sequence analysis / linear-recurrence tools (exact over supplied terms but not proof); report structure as conjecture, or say none found |
| `reflection.md` | Workspace reflection guidance: judge whether the attempt was solved (needs second independent confirmation) and whether progress actually happened; give an actionable, specific lesson for the next attempt |
| `research.md` | Workspace research guidance: prefer primary/official/university sources, exact URLs, search several angles, return precise theorem statements; do not fetch the published answer to a contest problem; downloads live under `research/` |
| `scholar.md` | Workspace scholar guidance: read a source's `<name>.md` excerpt, then the `.full.md`, then replace the excerpt with a sub-1000-token summary stating definitions/theorems, whether hypotheses hold here, what it settles and what it does not; describe_file it afterward |
| `tool_builder.md` | Workspace tool-builder guidance: inspect AGENTS.md, config.toml, GOAL.md, MEMORY.md first; state method, theory, complexity before full-size runs; reproduce worked examples first; exact arithmetic; build one-function-per-file toolkits and describe_file each |
