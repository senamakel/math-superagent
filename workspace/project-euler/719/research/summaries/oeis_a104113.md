# A104113 — Numbers which when chopped into one, two or more parts, added and squared result in the same number.

Source: https://oeis.org/A104113 (full record page at
`research/sources/oeis_a104113.full.md`; b-file at
`research/sources/oeis_a104113_b.full.md`).

**What this record establishes (the canonical tier for this problem).**

- The S-numbers are exactly the terms of A104113: integers n whose decimal
  digit string is chopped into **one, two or more** parts, added, and squared
  to give n itself. That is precisely the definition of Project Euler 719's
  S-numbers (the problem's ≥2-block rule excludes only the trivial single
  block 0,1 case; the record's "one" part is the single-block degenerate
  split).
- **This OEIS record links the Project Euler problem itself** (projecteuler.net/problem=719, 2020) — it is the authoritative catalogued statement that
  A104113 *is* the PE 719 sequence family.
- Terms begin 0,1,81,100,1296,2025,3025,6724,8281,9801,10000 — whose
  n ≤ 10^4 terms (81,100,1296,2025,3025,6724,8281,9801,10000) sum to the
  oracle 41333.
- `a(n) = A038206(n)^2` (Tarantini): S-number = root squared, the root
  bijection the whole method rests on.
- Every term ≡ 0 or 1 (mod 9) (Tarantini) — the mod-9 filter.
- **The exact solver recursion (Michael S. Branicky, 2021), verbatim from the
  record**, identical to the one on A038206 and used by code/solution.py:

```python
def expr(t, d): # can you express target t with digits d, only adding +'s
    if t < 0: return False
    if t == int(d): return True
    return any(expr(t-int(d[:i]), d[i:]) for i in range(1, len(d)))
def aupto(limit):
    alst, k, k2 = [], 0, 0
    while k2 <= limit:
        if expr(k, str(k2)):
            alst.append(k2)
        k, k2 = k+1, k2 + 2*k + 1
    return alst
print(aupto(7500000)) # Michael S. Branicky, Sep 27 2021
```

  (Note: it iterates k over roots and emits k² — the root scan. Claim
  `a038206-expr-recursion` anchors this recursion; this record page is its
  other primary source.)
