# A038206 — Can express a(n) with the digits of a(n)^2 in order, only adding plus signs.

Source: https://oeis.org/A038206 (b-file at `research/sources/oeis_a038206_b.full.md`).

This is the sequence of S-number **roots** m: a term m satisfies that the
decimal digits of m^2, read left to right, can be split into 2+ contiguous
blocks whose sum equals m.

**The full treatment lives in `research/summaries/oeis_a038206_b.md`**, which
reproduces Branicky's exact `expr` recursion (claim `a038206-expr-recursion`),
the b-file coverage claim (term 408 = 1000000 = isqrt(10^12), claim
`a038206-bfile-cover`), and confirms every term ≡ 0 or 1 (mod 9). The b-file
itself is at `research/sources/oeis_a038206_b.full.md`.

**Quick facts from the record.**
- Terms begin 0,1,9,10,36,45,55,82,91,99,100,235,297,369,370,379,414,...

  (so n = m² gives the A104113 S-numbers 0,1,81,100,1296,2025,3025,6724,8281,
  9801,10000,...).
- a(n) = sqrt(A104113(n)) (Tarantini).
- Every term ≡ 0 or 1 (mod 9).
- **The exact solver (Michael S. Branicky, 2021):**

  ```python
  def expr(t, d):                 # can target t be built from digits d (add +'s)?
      if t < 0: return False
      if t == int(d): return True
      return any(expr(t - int(d[:i]), d[i:]) for i in range(1, len(d)))
  def ok(n): return expr(n, str(n*n))
  ```

  `ok(n)` is True for exactly the roots. This is the method code/solution.py
  implements (claim `a038206-expr-recursion`).
