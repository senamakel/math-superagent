# Hamilton–Kedlaya–Picciotto — Square–Sum Pair Partitions

Source (accessible full text):
https://www.mathed.page/attc/in-addition/cmj-sq-sum-partitions.pdf

College Math. J. 46(4) 264–269, 2015/2017 (available online Nov 2017).

**What this paper is about.** A *classroom* problem: partition {1,2,…,2n} into
n pairs each summing to a perfect square. **Main result (Theorem):** such a
partition exists for every n except n ∈ {1,2,3,5,6,10,11}. Content is
pedagogical — pairing *distinct integers* so their *sum* is a square — and is
unrelated to PE 719's rule (splitting the *digit string of one square* into
contiguous blocks that sum to the *root*).

**Bearing on PE 719.** Only the shared keywords "square" and "partition."
This is a *pairing* of the set {1,…,2n} into sum-of-two-is-a-square pairs, a
different object from the S-number digit-split. It does **not** describe
S-numbers, gives no method for T(10¹²), and should not be leaned on. It was
captured (in full, from the author's mirror) to be complete as a library
record, not because it contributes to the computation.

**Does not help** the run: tangential; retained as a sourced record and for the
record's bibliographic completeness, not for the mathematics of PE 719.
