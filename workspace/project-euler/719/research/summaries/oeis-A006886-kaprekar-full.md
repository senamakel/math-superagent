# OEIS A006886 b-file — Kaprekar numbers (two-block), tiny list

Source: https://oeis.org/A006886/b006886.txt
(`research/sources/oeis-A006886-kaprekar-full.full.md`).

Term list of two-block Kaprekar numbers up to index 274
(6603773584906). This is the two-block subcase catalogue only. It is *not* the
S-number list: e.g. it contains 703 (494+209=703, two blocks) but an S-number
root like 82 requires three blocks and does not appear here as a Kaprekar term.

**Bearing.** Confirms the two-block Kaprekar catalogue cannot substitute for the
full S-number enumeration. No claim needed; see `oeis-A006886-kaprekar.md`.

**Does not help** the run for T(10¹²) — incomplete for the S-numbers (which
include multi-block roots), so it cannot be used as a verification catalogue.
