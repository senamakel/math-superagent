# Goal

Solve Project Euler problem 175 (downloaded at /workspace/problem.html), verify the result by a
second independent route, and record all work in this workspace.

## Completion criteria

1. A precise restatement of the problem with every symbol defined, in this file.
2. A naive, obviously-correct program /workspace/brute.py that reproduces every worked example in
   the statement.
3. The governing theory recorded in /workspace/memory.md, with sourced statements (URLs kept).
4. The efficient derivation written to /workspace/solution.md, with complexity stated.
5. /workspace/solution.py implements that method with exact arithmetic, agrees with brute.py on every
   case brute.py can reach, and reproduces every worked example.
6. Final answer verified by a second independent route, and reported with the verification command.
