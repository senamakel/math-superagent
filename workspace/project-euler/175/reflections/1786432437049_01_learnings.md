LESSON: The misstep is stopping at an empirical recursion without turning it into a computation. Use the recursion in reverse to walk directly on the fraction: since f(2m)/f(2m-1) = 1 + f(m)/f(m-1) (bit 0) and f(2m+1)/f(2m) = 1/(1 + f(m)/f(m-1)) (bit 1), start from the reduced target p/q and peel off low bits, reducing the fraction each step to reconstruct the binary string (then its run lengths = SBE); this runs in O(bits) time, independent of the bound.
