# A308685 — triangular lattice points in a Euclidean disk (do not use for the orchard)

<!-- source: https://oeis.org/A308685 | raw lookup, now summarised -->

## What this source establishes

**Definition.** a(n) = the number of triangular-lattice points whose Euclidean
distance from the origin is ≤ n (equivalently A053416(2n)). Values
1, 7, 19, 37, 61, 91, 127, **187**, … — it matches A003215 (hex numbers) up to
n = 6 and then diverges (187 vs A003215's 169), because the region is a
**disk**, not the hexagon of side n.

## Why it must not be used here

PE 351's orchard is the order-n hexagon {|a|,|b|,|a+b| ≤ n}, which has exactly
3n²+3n+1 points (A003215). A308685 counts a different region (Euclidean ball)
on the same lattice; substituting it would give the wrong point count from n = 7
on. This sequence is the "trap" version of A003215.

## Hypotheses

n ≥ 0 integer. Does **not** hold for the orchard's region.

## Claims

None — this sequence is not load-bearing and must not be substituted for
A003215 or A216453.
