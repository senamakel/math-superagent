# A002088 — summatory totient (raw OEIS lookup, now summarised)

**Definition.** a(n) = Σ_{k=1..n} φ(k), the summatory totient; the run's
Φ(n). a(0)=0.

**Terms (a(0..57)).** 0, 1, 2, 4, 6, 10, 12, 18, 22, 28, 32, 42, 46, 58, 64,
72, 80, 96, 102, 120, 128, 140, 150, 172, 180, 200, 212, 230, 242, 270, 278,

**Formulas (from the entry).**
- a(n) = (3/π²)n² + O(n log n) (Walfisz: O(n (log n)^{2/3}
  (log log n)^{4/3}).
- a(n) = (1/2) Σ_{k≥1} μ(k)·⌊n/k⌋·⌊1 + n/k⌋ (Cloitre, 2003) — the Möbius
  form `verify_mobius.py` implements.
- a(n) = A000217(n) − A063985(n).
- a(n) = A018805(n) − A015614(n) = A005728(n) − 1 (Farey length minus one).
- a(n) = Σ_{k=1..n} k·M(⌊n/k⌋) (Oudra) — the Mertens-weighted form Brown's
  algorithm uses.
- Recurrence a(n) = A000217(n) − Σ_{k=2..n} a(⌊n/k⌋) (Xu, 2024), from
  φ = id ∗ μ summed: the Gauss-recursion route.

**Comments.** Counts ordered coprime pairs {(x,y) : 1 ≤ x ≤ y ≤ n,
gcd(x,y)=1} (Somos, 1999); the number of rationals p/q ∈ (0,1] with q ≤ n;
#{(x,y) : 1 ≤ x+y ≤ n, x ≥ 0, y > 0, gcd(x,y)=1} — exactly the per-sector
visible-point count in the orchard's six sectors, which is how
H(n) = 6(C(n+1,2) − Φ(n)) arises. Also a(n) = A092249(n).

## What it establishes for this problem

Φ(n) is the per-sector visible count; its value at 10^8 =
3039635516365908 (verified two ways by this run, plus A064018's catalogue)
is the only hard number H(10^8) needs: H = 3n²+3n − 6Φ.
