# A051953 — cototient (raw OEIS lookup, now summarised)

<!-- source: https://oeis.org/A051953 -->

**Definition.** a(n) = n − φ(n), the cototient: the number of integers
1 ≤ k ≤ n that share a prime factor with n. a(1) = 0.

**Key facts (from the entry).**
- a(n) = n − φ(n); a(n) = Σ_{d|n, d<n} φ(d).
- Partial sums are A063985; **H(n) = 6·A063985(n)** for the hexagonal
  orchard (A216453), i.e. each of the six sectors contributes Σ(k − φ(k))
  hidden points.
- cototient(n) ≡ n (mod 2), so consecutive cototients never agree — the
  reason A063985(n) mod 2 has no small period (checked over 200000 terms
  in this run).
- Dirichlet series ζ(s−1)(1 − 1/ζ(s)).

## What it establishes for this problem

n − φ(n) is the number of hidden points on the n-th ring (per sector): the
n-th ring of a sector has n points, φ(n) of them visible (coprime), so
n − φ(n) hidden. Summing rings gives H(n) = 6·Σ_{k≤n}(k − φ(k)) = 6·A063985.
This is the ring-wise derivation recorded in solution.md.
