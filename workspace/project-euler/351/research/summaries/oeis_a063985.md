# A063985 — partial sums of the cototient (raw OEIS lookup, now summarised)

**Definition.** a(n) = Σ_{x=1..n} (x − φ(x)) = A000217(n) − A002088(n),
the partial sums of the cototient n − φ(n). **H(n) = 6·a(n)** for the
hexagonal orchard (A216453), so a(10^8) = H(10^8)/6 =
1960364533634092 (computed by this run via patterns.py).

**Formulas (from the entry).**
- a(n) = A000217(n) − A002088(n).
- a(n) = n² − A091369(n) (Pérez Herrero, 2012).
- **Chai Wah Wu's recursion (Mar 24 2021):**
  A063985(0)=0; j=2; c=0; while (k1 := n//j) > 1: j2 = n//k1 + 1;
  c += (j2−j)·(k1·(k1+1) − 2·A063985(k1) − 1); j, k1 = j2, n//j2;
  return (2n + c − j)//2 — the floor-grouped O(√n)-values recursion
  `code/out/patterns.py` uses as the third independent route to H(10^8).
- a(n) = (1/2 − 3/π²)n² + O(n log n) (Eldar, 2022).

**Comments.** Counts pairs {(x,y) : 1 ≤ x ≤ y ≤ n, gcd(x,y) > 1}
(Zumkeller; the entry's "1 = gcd(x,y)" is a typo for "1 ≠ gcd(x,y)" — the
formula A000217(n) − A002088(n) and the Haskell `gcd x y > 1` confirm).
8·a(n) counts dots not in direct reach of the centre of a (2n+1)×(2n+1)
array (Bacche, 2022).
