# A216453 — hidden points in the hexagonal orchard (raw OEIS lookup, now summarised)

**Definition.** a(n) = number of points hidden from the central point by a
closer point in a hexagonal orchard of order n (OEIS A216453; the entry
explicitly links Project Euler 351).

**Terms (a(1..58)).** 0, 6, 12, 24, 30, 54, 60, 84, 102, 138, 144, 192, 198,
246, 288, 336, 342, 414, 420, 492, 546, 618, 624, 720, 750, 834, 888, 984,
990, 1122, 1128, 1224, 1302, 1410, 1476, 1620, 1626, 1746, 1836, 1980, 1986,
2166, 2172, 2316, 2442, 2586, 2592, 2784, 2826, 3006, 3120, 3288, 3294, 3510,
3600, 3792, 3918 — matches the run's computed H(1..58) and the brute-force
oracle at 5, 10, 1000.

**Formula (the closed form this run uses).**

    a(n) = 6·(C(n+1,2) − Σ_{i=1..n} φ(i))    [Piyush Kumar, Robert Israel, Aug 26 2014]
    a(n) = 6·A063985(n)                       [Jon Maiga, Jan 12 2019]

where C(n+1,2) = n(n+1)/2. Cross-check: a(1000) = 6·(500500 − 304192) =
6·196308 = 1177848 ✓ (matches the statement's H(1000)).
