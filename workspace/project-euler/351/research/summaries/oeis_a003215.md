# A003215 — Hex (centered hexagonal) numbers: 3n(n+1)+1

<!-- source: https://oeis.org/A003215 | raw lookup, now summarised -->

## What this source establishes

**Definition.** a(n) = 3n² + 3n + 1, n ≥ 0: the number of dots in a centered
hexagonal figure with n+1 dots on each side; the crystal ball sequence of the
hexagonal (A₂ / triangular) lattice; also the number of ordered integer triples
(a,b,c) with −n ≤ a,b,c ≤ n and a+b+c = 0.

**Values.** 1, 7, 19, 37, 61, 91, 127, 169, … (a(n) − a(n−1) = 6n).

## Hypotheses

n ≥ 0 integer. Holds here.

## What it lets this run do

- Fixes the **total point count** of the order-n hexagonal orchard:
  |Orchard(n)| = 3n² + 3n + 1 (GOAL.md states this and `code/brute.py` asserts
  it on every run). This is the Ehrhart polynomial of the hexagon
  {|a|,|b|,|a+b| ≤ n}, and the quantity H(n) is subtracted from it.
- Distinguishes the orchard's hexagon count from A308685 (a Euclidean-disk
  count on the same lattice — different region, do not substitute).
