In [mathematics][6], the **Farey sequence**of order *n*is the [sequence][7] of completely reduced [fractions][8], either between 0 and 1, or without this restriction, {{cite book |author1-link=Ivan M. Niven |first1=Ivan M. |last1=Niven |first2=Herbert S. |last2=Zuckerman |title=An Introduction to the Theory of Numbers |edition=Third |publisher=John Wiley and Sons |year=1972 |at=Definition&nbsp;6.1}}</ref>"}},"i":0}}]}'> [a] which have [denominators][9] less than or equal to *n*, arranged in order of increasing size.

With the restricted definition, each Farey sequence starts with the value 0, denoted by the fraction ⁠ 0 / 1 ⁠, and ends with the value 1, denoted by the fraction ⁠ 1 / 1 ⁠ (although some authors omit these terms).

A *Farey sequence*is sometimes called a Farey **[series][10], which is not strictly correct, because the terms are not summed. [2]

## History

[[edit][18]]

*The history of 'Farey series' is very curious*— Hardy & Wright (1979) [3]*... once again the man whose name was given to a mathematical relation was not the original discoverer so far as the records go.*— Beiler (1964) [4]

Farey sequences are named after the [British][19] [geologist][20] [John Farey, Sr.][21], whose letter about these sequences was published in the *[Philosophical Magazine][22]*in 1816. [5] Farey conjectured, without offering proof, that each new term in a Farey sequence expansion is the [mediant][23] of its neighbours. Farey's letter was read by [Cauchy][24], who provided a proof in his *Exercices de mathématique*, and attributed this result to Farey. In fact, another mathematician, [Charles Haros][25], had published similar results in 1802 which were not known either to Farey or to Cauchy. [4] Thus it was a historical accident that linked Farey's name with these sequences. This is an example of [Stigler's law of eponymy][26].

### Farey neighbours

[[edit][37]]

Fractions which are neighbouring terms in any Farey sequence are known as a *Farey pair*and have the following properties.

If ⁠*a*/*b*⁠ and ⁠*c*/*d*⁠ are neighbours in a Farey sequence, with ⁠*a*/*b*⁠ < ⁠*c*/*d*⁠, then their difference ⁠*c*/*d*⁠ − ⁠*a*/*b*⁠ is equal to ⁠ 1 /*bd*⁠. Since c d − a b = b c − a d b d, {\displaystyle {\frac {c}{d}}-{\frac {a}{b}}={\frac {bc-ad}{bd}},}[image: {\displaystyle {\frac {c}{d}}-{\frac {a}{b}}={\frac {bc-ad}{bd}},}]

this is equivalent to saying that b c − a d = 1. {\displaystyle bc-ad=1.}[image: {\displaystyle bc-ad=1.}]

Thus ⁠ 1 / 3 ⁠ and ⁠ 2 / 5 ⁠ are neighbours in 5</sub>"}},"i":0}}]}'>*F*5, and their difference is ⁠ 1 / 15 ⁠.

The converse is also true. If b c − a d = 1 {\displaystyle bc-ad=1}[image: {\displaystyle bc-ad=1}]

for positive integers *a*, *b*, *c*, *d*with *a*< *b*and *c*< *d*, then ⁠*a*/*b*⁠ and ⁠*c*/*d*⁠ will be neighbours in the Farey sequence of order max(*b,d*).

If ⁠*p*/*q*⁠ has neighbours ⁠*a*/*b*⁠ and ⁠*c*/*d*⁠ in some Farey sequence, with ⁠*a*/*b*⁠ < ⁠*p*/*q*⁠ < ⁠*c*/*d*⁠, then ⁠*p*/*q*⁠ is the [mediant][23] of ⁠*a*/*b*⁠ and ⁠*c*/*d*⁠ – in other words, p q = a + c b + d. {\displaystyle {\frac {p}{q}}={\frac {a+c}{b+d}}.}[image: {\displaystyle {\frac {p}{q}}={\frac {a+c}{b+d}}.}]

This follows easily from the previous property, since if b p − a q = q c − p d = 1, ⟹ b p + p d = q c + a q, ⟹ p ( b + d) = q ( a + c), ⟹ p q = a + c b + d. {\displaystyle {\begin{aligned}&&bp-aq&=qc-pd=1,\\[4pt]\implies &&bp+pd&=qc+aq,\\[4pt]\implies &&p(b+d)&=q(a+c),\\\implies &&{\frac {p}{q}}&={\frac {a+c}{b+d}}.\end{aligned}}}[image: {\displaystyle {\begin{aligned}&&bp-aq&=qc-pd=1,\\[4pt]\implies &&bp+pd&=qc+aq,\\[4pt]\implies &&p(b+d)&=q(a+c),\\\implies &&{\frac {p}{q}}&={\frac {a+c}{b+d}}.\end{aligned}}}]

It follows that if ⁠*a*/*b*⁠ and ⁠*c*/*d*⁠ are neighbours in a Farey sequence then the first term that appears between them as the order of the Farey sequence is incremented is a + c b + d, {\displaystyle {\frac {a+c}{b+d}},}[image: {\displaystyle {\frac {a+c}{b+d}},}]

which first appears in the Farey sequence of order *b*+ *d*.

Thus the first term to appear between ⁠ 1 / 3 ⁠ and ⁠ 2 / 5 ⁠ is ⁠ 3 / 8 ⁠, which appears in 8</sub>"}},"i":0}}]}'>*F*8.

The total number of Farey neighbour pairs in n</sub>"}},"i":0}}]}'>F n is n</sub>''}} &minus; 3"}},"i":0}}]}'>2 |*F n*| − 3.

The *[Stern–Brocot tree][38]*is a [data structure][39] showing how the sequence is built up from 0 ( = ⁠ 0 / 1 ⁠) and 1 ( = ⁠ 1 / 1 ⁠), by taking successive mediants. Note, however, that at the *n*th step of the construction of the Stern–Brocot tree all mediants are included, not only the ones with denominator equal to *n*.

### Farey neighbours and continued fractions

[[edit][41]]

Fractions that appear as neighbours in a Farey sequence have closely related [continued fraction][42] expansions. ### Applications

[[edit][50]]

Farey sequences are very useful to find rational approximations of [irrational numbers][51]. [15] For example, the construction by Eliahou [16] of a lower bound on the length of non-trivial cycles in the **[3 x +1 process][52] uses Farey sequences to calculate a continued fraction expansion of the number 2</sub>(3)"}},"i":0}}]}'>log 2 (3).

In physical systems with resonance phenomena, Farey sequences provide a very elegant and efficient method to compute resonance locations in 1D [17] and 2D. [18] [19]

Farey sequences are prominent in studies of [any-angle path planning][53] on square-celled grids, for example in characterizing their computational complexity [20] or optimality. [21] The connection can be considered in terms of r -constrained paths, namely paths made up of line segments that each traverse at most r rows and at most r columns of cells. Let Q be the set of vectors (*q*, *p*) such that 1 ≤ q ≤ r {\displaystyle 1\leq q\leq r}[image: {\displaystyle 1\leq q\leq r}], 0 ≤ p ≤ q {\displaystyle 0\leq p\leq q}[image: {\displaystyle 0\leq p\leq q}], and p, q are coprime. Let Q*be the result of reflecting Q in the line *y*= *x*. Let S = { ( ± x, ± y): ( x, y) ∈ Q ∪ Q ∗ } {\displaystyle S=\{(\pm x,\pm y):(x,y)\in Q\cup Q*\}}[image: {\displaystyle S=\{(\pm x,\pm y):(x,y)\in Q\cup Q*\}}]. Then any r -constrained path can be described as a sequence of vectors from S. There is a [bijection][54] between Q and the Farey sequence of order r given by (*q*, *p*) mapping to p q {\displaystyle {\tfrac {p}{q}}}[image: {\displaystyle {\tfrac {p}{q}}}].

### Riemann hypothesis

[[edit][63]]

Farey sequences are used in two equivalent formulations of the [Riemann hypothesis][35]. Suppose the terms of F n are { a k, n: k = 0, 1, …, m n }. {\displaystyle \{a_{k,n}:k=0,1,\ldots ,m_{n}\}.}[image: {\displaystyle \{a_{k,n}:k=0,1,\ldots ,m_{n}\}.}] Define d k, n = a k, n − k m n, {\displaystyle d_{k,n}=a_{k,n}-{\tfrac {k}{m_{n}}},}[image: {\displaystyle d_{k,n}=a_{k,n}-{\tfrac {k}{m_{n}}},}] in other words d k, n {\displaystyle d_{k,n}}[image: {\displaystyle d_{k,n}}] is the difference between the k th term of the n th Farey sequence, and the k th member of a set of the same number of points, distributed evenly on the [unit interval][64]. In 1924 [Jérôme Franel][65] [23] proved that the statement

-1"}}'> -1}"> ∑ k = 1 m n d k, n 2 = O ( n r) ∀ r > − 1 {\displaystyle \sum _{k=1}^{m_{n}}d_{k,n}^{2}=O(n^{r})\quad \forall r>-1} -1}"/>

is equivalent to the Riemann hypothesis, and then [Edmund Landau][66] [24] remarked (just after Franel's paper) that the statement \\frac{1}{2}"}}'> {\frac {1}{2}}}"> ∑ k = 1 m n | d k, n | = O ( n r) ∀ r > 1 2 {\displaystyle \sum _{k=1}^{m_{n}}|d_{k,n}|=O(n^{r})\quad \forall r>{\frac {1}{2}}} {\frac {1}{2}}}"/>

is also equivalent to the Riemann hypothesis. An unconditional upper bound of this sum is directly established from the fact that | d k, n | ≤ 1 / n {\displaystyle |d_{k,n}|\leq 1/n}[image: {\displaystyle |d_{k,n}|\leq 1/n}] [9] as

∑ k = 1 m n | d k, n | ≤ 3 π 2 n + O ( log ⁡ n). {\displaystyle \sum _{k=1}^{m_{n}}|d_{k,n}|\leq {\frac {3}{\pi ^{2}}}n+O(\log n).}[image: {\displaystyle \sum _{k=1}^{m_{n}}|d_{k,n}|\leq {\frac {3}{\pi ^{2}}}n+O(\log n).}]

An unconditional lower bound is established using the known gap distribution of the Farey sequence as [25]

∑ k = 1 m n | d k, n | ≥ 9 π 2 ( π 2 − 3) ( log ⁡ ( 3 n π 2) + γ − ζ ′ ( 2) ζ ( 2) − 6 π 2 + 9 2 π 4) + O ( log ⁡ n n), {\displaystyle \sum _{k=1}^{m_{n}}|d_{k,n}|\geq {\frac {9}{\pi ^{2}(\pi ^{2}-3)}}\left(\log \left({\frac {3n}{\pi ^{2}}}\right)+\gamma -{\frac {\zeta '(2)}{\zeta (2)}}-{\frac {6}{\pi ^{2}}}+{\frac {9}{2\pi ^{4}}}\right)+O\!\left({\frac {\log n}{n}}\right),}[image: {\displaystyle \sum _{k=1}^{m_{n}}|d_{k,n}|\geq {\frac {9}{\pi ^{2}(\pi ^{2}-3)}}\left(\log \left({\frac {3n}{\pi ^{2}}}\right)+\gamma -{\frac {\zeta '(2)}{\zeta (2)}}-{\frac {6}{\pi ^{2}}}+{\frac {9}{2\pi ^{4}}}\right)+O\!\left({\frac {\log n}{n}}\right),}]

where ζ ( x) {\displaystyle \zeta (x)}[image: {\displaystyle \zeta (x)}] is the [Riemann zeta function][67] and γ {\displaystyle \gamma }[image: {\displaystyle \gamma }] is [Euler's constant][68].

## Next term

[[edit][71]]

A surprisingly simple algorithm exists to generate the terms of *F n*in either traditional order (ascending) or non-traditional order (descending). The algorithm computes each successive entry in terms of the previous two entries using the mediant property given above. If ⁠*a*/*b*⁠ and ⁠*c*/*d*⁠ are the two given entries, and ⁠*p*/*q*⁠ is the unknown next entry, then ⁠*c*/*d*⁠ = ⁠*a*+ *p*/*b*+ *q*⁠. Since ⁠*c*/*d*⁠ is in lowest terms, there must be an integer *k*such that *kc*= *a*+ *p*and *kd*= *b*+ *q*, giving *p*= *kc*−*a*and *q*= *kd*−*b*. If we consider *p*and *q*to be functions of *k*, then

p ( k) q ( k) − c d = c b − d a d ( k d − b) {\displaystyle {\frac {p(k)}{q(k)}}-{\frac {c}{d}}={\frac {cb-da}{d(kd-b)}}}[image: {\displaystyle {\frac {p(k)}{q(k)}}-{\frac {c}{d}}={\frac {cb-da}{d(kd-b)}}}]

so the larger *k*gets, the closer ⁠*p*/*q*⁠ gets to ⁠*c*/*d*⁠.

To give the next term in the sequence *k*must be as large as possible, subject to *kd*−*b*≤ *n*(as we are only considering numbers with denominators not greater than *n*), so *k*is the greatest integer ≤ ⁠*n*+ *b*/*d*⁠. Putting this value of *k*back into the equations for *p*and *q*gives

p = ⌊ n + b d ⌋ c − a {\displaystyle p=\left\lfloor {\frac {n+b}{d}}\right\rfloor c-a}[image: {\displaystyle p=\left\lfloor {\frac {n+b}{d}}\right\rfloor c-a}] q = ⌊ n + b d ⌋ d − b {\displaystyle q=\left\lfloor {\frac {n+b}{d}}\right\rfloor d-b}[image: {\displaystyle q=\left\lfloor {\frac {n+b}{d}}\right\rfloor d-b}]

This is implemented in [Python][72] as follows:

Generator[Fraction]:\n \"\"\"\n Print the n'th Farey sequence. Allow for either ascending or descending.\n\n >>> print(*farey_sequence(5), sep=' ')\n 0 1/5 1/4 1/3 2/5 1/2 3/5 2/3 3/4 4/5 1\n \"\"\"\n a, b, c, d = 0, 1, 1, n\n if descending:\n a, c = 1, n - 1\n yield Fraction(a, b)\n while 0 <= c <= n:\n k = (n + b) // d\n a, b, c, d = c, d, k * c - a, k * d - b\n yield Fraction(a, b)\n"}}'>

```
from fractions import Fraction
from collections.abc import Generator

def farey_sequence(n: int, descending: bool = False) -> Generator[Fraction]:
    """
    Print the n'th Farey sequence. Allow for either ascending or descending.

    >>> print(*farey_sequence(5), sep=' ')
    0 1/5 1/4 1/3 2/5 1/2 3/5 2/3 3/4 4/5 1
    """
    a, b, c, d = 0, 1, 1, n
    if descending:
        a, c = 1, n - 1
    yield Fraction(a, b)
    while 0 <= c <= n:
        k = (n + b) // d
        a, b, c, d = c, d, k * c - a, k * d - b
        yield Fraction(a, b)
```

Brute-force searches for solutions to [Diophantine equations][73] in rationals can often take advantage of the Farey series (to search only reduced forms). While this code uses the first two terms of the sequence to initialize *a*, *b*, *c*, and *d*, one could substitute any pair of adjacent terms in order to exclude those less than (or greater than) a particular threshold.
