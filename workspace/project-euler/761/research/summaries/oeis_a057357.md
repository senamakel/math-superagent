# OEIS A057357 — a(n) = floor(3n/7)

Source: https://oeis.org/A057357

## What the record establishes

A057357 is simply `floor(3n/7)` — an integer sequence with a closed form
`a(n) = floor(3n/7)`, generating function `(1+x²+x⁴)·x³/((1−x)(1−x⁷))`, and a
period-7 residue pattern (0,0,0,1,1,2,2 mod arithmetic). It is a calendrical
computation sequence (Dershowitz–Reingold), not a pursuit-game sequence.

## Why it matters for this run (and what it does not settle)

This run's `K(n)` — the index in the stewbasic general-n critical-speed formula,
`K` = largest integer with `sin(Kθ)−(K+n)tanθ·cos(Kθ) < 0`, θ=π/n — **matches**
A057357's values for small n: `K(n) = floor(3n/7)` holds exactly for n = 3..85
(the run's own `code/patseq_k*.py`, `code/pattern_k_verify.py` established this
and the deviation point).

The correct reading is therefore:

- **The small-term coincidence is exactly that — a coincidence, not a
  theorem.** `floor(3n/7)` FAILS at n=86 (K(86)=37 vs floor(36)), and the
  period-7 recurrence also breaks there. A catalogued closed form for
  n≤85 does not extend.
- The true asymptotic slope is `c = lim K(n)/n = 0.430296653…`, the root of
  `tan(cπ)=π(c+1)` — which is `B_circle/π` (the circle staging angle over π),
  established in the run's own scratch and `code/pattern_asymptotic*.py`.
  `3/7 ≈ 0.42857` is not c; A057357 is the 𝘸𝘳𝘰𝘯𝘨 sequence asymptotically.
- **No bearing on the 8-decimal answer.** K is an auxiliary index in V(n);
  V(n) changes smoothly, and the deviation at n=86 does not touch n=6.
  `V_hexagon = 5.0550504633…` is unaffected (already exact: 2 + 2√21/3).
