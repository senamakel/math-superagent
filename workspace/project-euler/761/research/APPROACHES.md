## What closed, and why

Do not propose these again. A reason stated precisely is what makes that possible; one left blank makes this row worthless.

- [[angular-speed-safe-region]] (refuted): For a regular polygon the angular-speed-matching staging boundary {r ≤ ρ(φ)/v} IS the 1/v homothetic scaled copy of the pool — the very same safe region stewbasic's model uses. So constructing it from the angular-speed constraint is NOT an independent model; it reproduces the same region and, minimized maximally, the same V. It is a restatement of the ansatz, not a confirm-or-falsify. Moreover any genuinely DIFFERENT safe region (inner circle, diamond, octagon, square) is a strict LOWER BOUND on V — documented in the held math.SE n-gon thread (TMM/Jens: inner square 5.00, diamond 5.25, circle 5.27, octagon 5.38, vs the optimal homothetic scaled-pool 5.7886 for the square). The run's own independent game-encoding solver (code/indep_game_encoding.py) took exactly this "max over dash landing point from a staged region" form and produced 3.98 for the hexagon — below the true 5.055 — i.e. the same lower-bound trap. A safe-region route can land at or below the true value but cannot exceed it, so it can never falsify the stewbasic value upward; it can only ever confirm a (possibly strict) lower bound. The angular-MATCHING principle itself is real and sourced for the CIRCLE (Lady in the Lake auxiliary differential game: L stages at antipodal radius r=1/v where angular speeds match, then dashes — claim lady-in-the-lake-differential-game-equilibrium; also Hesterberg, Ponder This), but on polygons it degenerates into the escaper's lower-bound construction.
- [[eikonal-characteristics]] (refuted): The naive Eikonal / Hopf-Lax formulation max_s d_R(s)/|Q(s)| gives π+1 for the circle — the documented red herring — because it models only the straight dash and omits the staging phase.  The approach acknowledges this and proposes to incorporate staging into the boundary data τ_R(Q), but doing so requires knowing the staging curve, which brings us back to the homothetic ansatz.  The PDE framework is not wrong in principle — the correct value function does satisfy the Eikonal equation — but the boundary data is not τ_R(Q) alone; it is τ_R(Q) modified by the staging time, which is not known a priori.  Turning this into a computable independent route means solving for the staging curve within the PDE, which is the same difficulty as the PMP approach without its adjoint machinery.  The algebraic elimination route is more direct: it specifies the staging point (the homothetic ansatz, which every other approach confirms) and verifies the closed form by an independent algebraic computation rather than by re-deriving the ansatz.
- [[pontryagin-maximum-principle]] (refuted): The PMP formulation is not wrong, but it is too heavy to carry through to a computable condition in one step.  The adjoint equations are piecewise because the runner's dynamics change at hexagon vertices, making the two-point boundary value problem non-smooth and the transversality conditions vertex-dependent.  The staging curve that emerges from the ODE is exactly the 1/v-scaled homothetic boundary (this is what the known theory already establishes), so PMP would re-derive the ansatz rather than supply an independent check on the answer.  The cost of making it computable — discretising the BVP, handling vertex switches, solving for the switching surface — is much larger than the algebraic elimination route, which gives the exact polynomial in one sympy call.  Worth returning to if the resultant approach fails, but not the right first tool_builder step today.
- [[schwarz-christoffel-conformal-mapping]] (refuted): The critical speed is NOT a conformal invariant. Disk and hexagon are conformally equivalent (an SC map exists — the premise is true), yet V_disk = 4.60333885 ≠ V_hexagon = 5.05505046. The run's OWN two oracle values for conformally-equivalent domains are a direct counterexample to the idea that the disk answer "pulls back" to the hexagon. Reason: the game's data are Euclidean distances (swimmer straight dash) and boundary ARC LENGTHS (runner time). Conformal maps preserve only angles, not either of these — they do not preserve the swimmer's straight-line distance (hexagon chords) or the runner's perimeter arc length. After any conformal map the game lives in a non-Euclidean Riemannian metric, and there is no Euclidean-interpretation relation between the two games. The Schwarz-Christoffel map exists but maps the Euclidean game to a curved-metrized game whose solution is a NEW problem, not the known flat-disk one. Searching the literature (web, research papers, and all 20 held primary sources) returns NO work applying conformal/Schwarz-Christoffel methods to escape or critical-speed pursuit games — this is an absence: the premise that the flat-disk answer transfers is false on its face (the two oracle values falsify it), independent of whether anyone has attempted it.

## Not yet taken to the literature

Nobody has checked whether these are known theory. Grounding one is cheaper than pursuing it: a named theorem arrives with its hypotheses, and a reformulation somebody already tried arrives with the reason it failed.

- [[polynomial-resultant-elimination]]: The hexagon (inradius 1, flat-top) has vertex coordinates and edge equations involving only √3, so every geometric quantity is algebraic of degree at most 2 over Q. Parameterize the exit point Q on one edge by a single rational parameter t ∈ [0,1] (or by coordinate x along the edge). The swimmer's staging point P is on the 1/v-scaled homothetic inner hexagon, centrally opposite the runner at R′ on the outer boundary. The chord distance |PQ|² is a quadratic polynomial in t with coefficients involving v and √3. The runner's perimeter distance from R′ to Q along the hexagon boundary is piecewise-linear in the edge index and linear in t. The critical-speed condition is: max_{edge e, t∈[0,1]} [perim(R′ → Q_e(t))] / |P − Q_e(t)| = v At the maximizing t (interior to the edge), the derivative of the ratio with respect to t vanishes, giving the first-order condition d/dt [perim/|PQ|] = 0. After clearing denominators, this is a polynomial equation in t and v² (and √3). Isolate √3 by squaring, then use resultants to eliminate t, yielding the minimal polynomial for v². For n=6 the result should be the known quadratic 9v⁴ − 240v² + 256 = 0, recovered by a route that never references K, α, arccos, or tan(xθ) = (x+n)tanθ. The key structural advantage: the hexagon's critical exit point lies on an edge adjacent to the edge opposite the runner's position (established pattern from the square case and the known K=2 result). So only a small number of edge candidates need to be checked, and the elimination can be done edge-by-edge with sympy's resultant or groebner.
