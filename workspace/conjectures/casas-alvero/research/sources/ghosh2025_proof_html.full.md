# Proof of the Casas-Alvero conjecture

Soham Ghosh Address: Department of Mathematics, University of Washington, Seattle, WA 98195, USA Email address: [soham13@uw.edu][3]

Date: August 11, 2026

###### Abstract.

The Casas-Alvero conjecture states that if f ⁡ ( X) f(X) is a monic univariate polynomial of degree d d over a characteristic 0 0 field 𝕂 \mathbb{K} such that gcd ⁡ ( f, f i) \gcd(f,f_{i}) is non-trivial for each i = 1, …, d − 1 i=1,\dots,d-1, then f ⁡ ( X) = ( X − α) d f(X)=(X-\alpha)^{d} for some α ∈ 𝕂 \alpha\in\mathbb{K}. In this paper, we prove the Casas-Alvero conjecture for polynomials of any degree d ≥ 3 d\geq 3 over any characteristic 0 0 field, by using Koszul homology. Along the way we show existence of various “almost counterexamples” over ℂ \mathbb{C}, satisfying mildly weaker hypotheses, using Brouwer degree techniques.

Casas-Alvero conjecture, regular sequences, Koszul homology

## 1. Introduction

### 1.1. Aim and main results of the paper

Let 𝕂 \mathbb{K} be a field and f ⁡ ( X) ∈ 𝕂 ⁡ [X] f(X)\in\mathbb{K}[X] be a monic polynomial of degree d > 1 d>1. Let f ( i) ​ ( X):= d i ​ f ​ ( X) / d ​ X i f^{(i)}(X):=d^{i}f(X)/dX^{i} be the i t ​ h i^{th} formal derivative of f ⁡ ( X) f(X) with respect to X X and let f i ​ ( X) f_{i}(X) be the i t ​ h i^{th} Hasse–Schmidt derivative of f ⁡ ( X) f(X). Over fields of characteristic 0 0, the two derivatives are related via f i ​ ( X) = f ( i) ​ ( X) / i! f_{i}(X)=f^{(i)}(X)/i!. This paper is concerned with the following question posed by E. Casas-Alvero in connection with his work [4] on higher-order polar germs:

###### Conjecture CA (Casas-Alvero, 2001).

Let f ⁡ ( X) f(X) be a monic univariate polynomial of degree d d over a field 𝕂 \mathbb{K}. Then gcd ⁡ ( f, f i) \gcd(f,f_{i}) is non-trivial for each i = 1, …, d − 1 i=1,\dots,d-1 if and only if f ⁡ ( X) = ( X − α) d f(X)=(X-\alpha)^{d} for some α ∈ 𝕂 \alpha\in\mathbb{K}.

Conjecture CA was originally posed over characteristic 0 0 fields using ordinary formal derivatives. Using Hasse-Schmidt derivatives, the conjecture has been studied in the literature in the above generalized form over any field irrespective of the characteristic. We review the existing literature on this problem in Section 1.2 below. It is well-known that the conjecture is false in general in any positive characteristic, leaving only the characteristic zero case open. The following theorem, which is the main result of this paper, settles Conjecture CA over any characteristic zero field and in all positive degrees (degrees 1 1 and 2 2 being trivially known).

###### Theorem A.

Let f ⁡ ( X) f(X) be a monic univariate polynomial of degree d ≥ 3 d\geq 3 over a characteristic zero field 𝕂 \mathbb{K}. Then gcd ⁡ ( f, f i) \gcd(f,f_{i}) is non-trivial for each i = 1, …, d − 1 i=1,\dots,d-1 if and only if f ⁡ ( X) = ( X − α) d f(X)=(X-\alpha)^{d} for some α ∈ 𝕂 \alpha\in\mathbb{K}.

By Theorem A and the work of [16], we also obtain the following.

###### Corollary B.

Let f ⁡ ( X) f(X) be a monic univariate polynomial of degree d d over a field 𝕂 \mathbb{K}. Then there exists a finite set 𝒫 ⁡ ( d) \mathcal{P}(d) of primes such that if char ⁡ 𝕂 ∉ 𝒫 ⁡ ( d) \operatorname{char}\mathbb{K}\notin\mathcal{P}(d), then gcd ⁡ ( f, f i) \gcd(f,f_{i}) is non-trivial for each i = 1, …, d − 1 i=1,\dots,d-1 if and only if f ⁡ ( X) = ( X − α) d f(X)=(X-\alpha)^{d} for some α ∈ 𝕂 \alpha\in\mathbb{K}.

By [14, Remark 5.9 5.9], we also obtain the following strengthening of Corollary B.

###### Corollary C.

Let X d ⊆ ℙ ℤ ​ ( 1, 2, …, d − 1) X_{d}\subseteq\mathbb{P}_{\mathbb{Z}}(1,2,\dots,d-1) be the d t ​ h d^{th} arithmetic Casas-Alvero scheme as defined in [16]. Then dim X d = 0 \dim X_{d}=0 for all d ≥ 3 d\geq 3.

#### 1.1.1. Idea of the proof

We briefly sketch the idea of the proof of Theorem A. Without loss of generality we will assume our fields to be algebraically closed. We build on the work done by the present author in [14], whereby Conjecture CA can be reformulated as a complete intersection problem and further as a problem of demonstrating regular sequences of certain homogeneous polynomials in multivariate polynomial rings (see [14, Proposition 5.2 5.2]). We pursue a downward induction argument on the degree d ≥ 3 d\geq 3, namely by assuming the conjecture in degree d = n + 1 d=n+1, we prove the conjecture in degree d = n d=n. This step assumes that the characteristic of the ground field is 0 0.

To establish the downward induction we need two ingredients- both algebraic and topological. First, we prove that the local and global minimal number of generators of the relevant ideals are equal to the expected number- we reduce the local problem to the global problem and utilize Abel-Gontcharoff polynomials and the topological theory of Brouwer degree to prove the global result. We note that this step works only over ℂ \mathbb{C}. For the second part, we complete the downward induction by homological methods, in particular Koszul homology. We relate the relevant (truncated) Koszul complexes in degrees d = n + 1 d=n+1 and d = n d=n by introducing a filtration. By using the local minimal number of generators information we show that the induced map on 0 t ​ h 0^{th} Koszul homology by the filtration is injective. Furthermore, by depth sensitivity of Koszul homology and finiteness results of [14], we obtain the vanishing of second and higher homologies. By the long exact sequence in homology obtained from the filtration, we conclude vanishing of the first Koszul homology for the complex in degree d = n d=n, completing the downward induction.

Finally, we invoke the results of [16] (or [11]) which verify the conjecture in infinitely many degrees, and thereby along with our downward induction argument, prove Conjecture CA in all degrees.

### 1.2. Existing results and methods

Conjecture CA was originally posed over characteristic 0 0 fields 𝕂 \mathbb{K}. In general, the conjecture is false over positive characteristic (cf. [16] for counterexamples). The authors of [16] also show that the truth of Conjecture CA for algebraically closed fields and in a particular degree d d is independent of the choice of field, and only depends on the characteristic of the field. The first progress over characteristic 0 0 was made for degree ≤ 7 \leq 7 polynomials via computational methods in [9]. Soon after, in [16] the authors related the conjecture for a general polynomial P ⁡ ( X) P(X) of degree d d over any field 𝕂 \mathbb{K} to the absence of 𝕂 \mathbb{K} -rational points of a weighted projective ℤ \mathbb{Z} -subscheme X d X_{d} of ℙ ℤ ​ ( 1, 2, …, d − 1) \mathbb{P}_{\mathbb{Z}}(1,2,\dots,d-1) defined by vanishing of resultants Res X ⁡ ( P, P i) \Res_{X}(P,P_{i}) for all 1 ≤ i < deg ⁡ P = d 1\leq i<\deg P=d. Their methods, utilizing reduction modulo prime arguments, successfully proved the conjecture over fields of characteristic 0 0 for polynomials of degree p k p^{k}, 2 ​ p k 2p^{k} for any prime p p. Furthermore, by [16, Proposition 2.2], if Conjecture CA holds for all polynomials of degree n n over fields of characteristic p p, for some p = 0 p=0 or p p prime, then Conjecture CA holds true for degree d d polynomials over fields of any characteristic except finitely many primes. The finitely many primes p p for a given d d such that the Conjecture does not hold true in degree d d and characteristic p p are called bad primes for d d. These methods were reformulated and extended in [11] using p p -adic valuations, where the authors also proved the Conjecture over characteristic 0 0 for polynomials of degrees 3 ​ p k 3p^{k} and 4 ​ p k 4p^{k} for primes p p greater than 3 3 and 4 4 respectively (except p = 5, 7 p=5,7 when d = 4 d=4).

In this spirit, further results for certain polynomials of degree 5 ​ p k 5p^{k} were shown in [7]. There have also been several computational studies, cf. [6], where the authors verified the conjecture for polynomials of degrees d = 5 ​ p k, 6 ​ p k d=5p^{k},\ 6p^{k} and 7 ​ p k 7p^{k} barring the bad primes in each case, which were also completely classified. These are the only existing positive results towards Conjecture CA. In addition to these, [6] also studied obstructions to hypothetical counterexamples and have verified the conjecture for degree 12 12. (which is missed by the cases considered above). Computational approaches involving Gröbner bases, even though theoretically possible, get practically infeasible for large degrees due to the complexity of resultants. Alternate approaches to the conjecture have involved analytic tools via the Gauss–Lucas theorem and to a further extent, the theory of Abel-Gontcharoff polynomials: see [27], [28] and [20].

Recently, Daniel Schaub and Mark Spivakovsky have published a series of papers addressing the conjecture. Their first paper [24] provides a partial result towards “independence” of the higher resultants Res X ⁡ ( P, P i) \Res_{X}(P,P_{i}) for 1 ≤ i ≤ d − 1 1\leq i\leq d-1. Their second paper [23] attempts to extend the reduction modulo prime techniques of existing positive results by obtaining a non-exhaustive list of bad primes p p for each d > 1 d>1. The conjecture over characteristic 0 0 fields follows for degree n n polynomials if and only if there are finitely many bad primes for p p, which signifies the importance of studying bad primes. However, the bad primes p p for a given d d can be very large as demonstrated in [16]. This has seemed to hinder a purely algebraic approach to the conjecture so far.

More recently a new approach to Conjecture CA has been initiated by the present author in [14]. The basis of the main results of [14] is the following reformulation of Conjecture CA over any algebraically closed field 𝕂 \mathbb{K} and degree d ≥ 3 d\geq 3.

###### Proposition D.

(Proposition 5.2 5.2, [14]) Conjecture CA is true for all monic degree d d polynomials over 𝕂 \mathbb{K} if and only if for all choices of 1 ≤ j 1, …, j d − 1 ≤ d 1\leq j_{1},\dots,j_{d-1}\leq d, the sequence Φ j 1 #​ ( H ​ D d − 1 0 ​ 𝐱 d − 1) \Phi^{\#}_{j_{1}}(HD^{0}_{d-1}\mathbf{x}_{d-1}), …,,\dots, Φ j d − 1 #​ ( H ​ D d − 1 d − 2 ​ 𝐱 d − 1) \Phi^{\#}_{j_{d-1}}(HD^{d-2}_{d-1}\mathbf{x}_{d-1}) forms a regular sequence of homogeneous polynomials in 𝕂 ⁡ [x 1, …, x d − 1] \mathbb{K}[x_{1},\dots,x_{d-1}].

We refer the reader to Section 4.1 for the relevant notation. Using this reformulation [14] proves that the set of 𝕂 \mathbb{K} -rational points X d ​ ( 𝕂) X_{d}(\mathbb{K}) of the d t ​ h d^{th} -arithmetic Casas-Alvero scheme X d X_{d} is finite for all d ≥ 3 d\geq 3 and fields 𝕂 \mathbb{K}. Concretely, this implies that for any d ≥ 3 d\geq 3 there are only finitely many (up to affine transformations, i.e., those of the form f ⁡ ( X) → f ⁡ ( a ​ X + b) f(X)\to f(aX+b)) counterexamples to Conjecture CA in degree d d over any field 𝕂 \mathbb{K} (irrespective of characteristic). ### 1.3. Historical note

Besides being of independent interest, Conjecture CA originated in the context of Casas-Alvero’s work [4] on higher-order polar germs of complex analytic plane curve singularities. This problem has also been considered among a list of forty questions on singularities of algebraic varieties ( [17, Problem 14 ⋆ ⁣ ⋆ 14^{\star\star}]) compiled by Hauser and Schicho. The following [5] is the original context of the conjecture. The main result of [4] is a factorization theorem for higher-order polars of an irreducible germ of a complex analytic plane curve, generalizing the known one for first order polars. As a corollary, Casas-Alvero then computed the intersection multiplicity of the r t ​ h r^{th} polar and the original germs, which when viewed as a function in r r is defined to be the Plücker function of the germ. The Plücker function can be defined even for a non-irreducible germ. The question that led Casas-Alvero to formulate Conjecture CA is that if the Plücker function of a not necessarily irreducible germ is equal to the Plücker function of an irreducible germ, then is the original germ irreducible to start with. If yes, then one would obtain an easy criterion for irreducibility of complex power series in two variables involving the intersection multiplicities of the germ and its polars.
