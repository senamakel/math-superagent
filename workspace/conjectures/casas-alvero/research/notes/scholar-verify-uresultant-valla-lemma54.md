## 2. Valabrega–Valla, "Form rings and regular sequences" (Nagoya 1978) — reference corrected, verified

The stale "(not held)" line in `uresultant-multiplicity-literature.md` is
corrected: the file IS held. I verified **Thm 2.3 and Cor 2.4** verbatim this
cycle (lines 216-265 of the full text):

- **Thm 2.3**: for noetherian A and ideals a, b=(f_1,…,f_r) with a+b ≠ A, the
  initial forms f_1*,…,f_r* form a G_A(a)-sequence iff (ii) f_{i-1} : f_i ⊆ A_{i-1}
  and A_i ∩ a^n = Σ_j a^{n-p_j} f_j for all n≥1 (weights p_j = ord_a(f_j)).
- **Cor 2.4**: if A is local and b* is generated by a G_A(a)-sequence, then b is
  generated by an A-sequence.
- **Remark 2.5** (the caveat that matters): if f_1*,…,f_r* form a regular
  sequence it is NOT necessarily true that f_1,…,f_r form an A-sequence.

Bearing on the run's `uresultant` thread: this is the precise statement under
which the Samuel multiplicity equals ∏_i ord_0(R_i) — the B = ∏ ord_0 identity
the u-resultant thread validates. A mismatch B ≠ ∏ ord is evidence the
associated graded ring is NOT Cohen–Macaulay (Cor 2.4 fails / Remark 2.5), NOT
a counterexample to CA. Claim already in the ledger:
`valabrega-valla-initial-forms-regular-sequence`.
