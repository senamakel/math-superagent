# Wouter Castryck's homepage — provenance of the degree-7 bad-prime companion file

Source URL: https://homes.esat.kuleuven.be/~wcastryc/ (held in full at
`research/sources/tmp-castryck-homepage.full.md`).

## Why this page was fetched

To locate the author's own companion files for
Castryck–Laterveer–Ounaïes, "Constraints on counterexamples to the
Casas-Alvero conjecture, and a verification in degree 12" (Math. Comp. 83
(2014) 3017–3037; arXiv:1208.5404). The page's publication record for that
paper lists the accompanying files with relative links that resolve to:

- `https://homes.esat.kuleuven.be/~wcastryc/code/badprimes7.txt` — **the
  degree-7 bad-prime list** (downloaded; held at
  `research/sources/castryck2012_badprimes7.txt.full.md`)
- `code/CAbadprimes7test.m` (Magma verification script)
- `code/precompscenarios12.zip`, `code/CAdeg12.m`, `code/CAbadprimes.m`
  (degree-12/degree-n computation scripts)

The page's own mathematical content is his publication list (mostly elliptic
curves / isogeny cryptography); none of the other papers bear on the
Casas-Alvero conjecture. Its single load-bearing value to this library is the
provenance link above.

## What it establishes

That the arXiv-listed companion file `badprimes7.txt` is served from the
author's institutional homepage, i.e. the authoritative source for the d=7
bad-prime list. The count from that file is **366** (see the badprimes7
summary), settling the run's 366-vs-661 discrepancy in favour of 366.

## Status

Pointer/provenance record only. Not a mathematical source in its own right.
Do not cite this page for any mathematical claim; cite the companion file and
the paper.
