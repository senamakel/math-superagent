# A011560 — Stirling numbers of the second kind S2(11,n)

**What it establishes for this problem.**

Row S2(11,1..11) = 1, 1023, 28501, 145750, 246730, 179487, 63987, 11880,
1155, 55, 1. This is exactly the Castryck–Laterveer–Ounaïes 2012 (eq 1.3)
degree-12 scenario count by type, verified by this run's brute-force RGS
enumeration (the scenario-count law: type-t count = S2(d−1, t+1), total =
Bell(d−1); see [[oeis_a008277]]).

Hypotheses: none. Holds-here: yes (d=12 scenario table). Status: catalogued;
the equality with the scenario counts is verified-computational.

Supports the Stirling/Bell scenario law as a catalogue fact, exact for all d,
not a fit. The d=20 open-degree type counts would be S2(19, t+1), t=0..18.
