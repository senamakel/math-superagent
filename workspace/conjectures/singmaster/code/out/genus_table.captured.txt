GENUS of the plane curve C(x,k1) = C(y,k2) = 0
C(z,k) = z(z-1)...(z-k+1)/k!  (degree k in z)
======================================================================
Method: CAS computation, exact integer arithmetic.
  (1) Singular 4.3.1, normal.lib, genus(ideal) -- geometric genus p_g
      via resolution of singularities of the projective closure.
  (2) Sage, Curve(f).genus() -- for the original 8x11 grid and the
      k2=3,4,5 extended rows ONLY (Sage is not installed in this
      container; the k2=6..10 rows are Singular-only).
The two routes agree on every entry for 2<=k1,k2<=12 (and k2=3,4,5
extended to k1=24). The 23 rows added since (k2=6 n=13..18, k2=7..10
n=13..19) rest on Singular alone — the Sage check errored
(NameError: PolynomialRing is not defined) and never ran. Do not
describe these rows as independently verified.
Genus is symmetric in (k1,k2).  Diagonal (k,k) is REDUCIBLE (x-y factor);
excluded (package returns nonsense/negative there).

Threshold (Faltings applies, i.e. genus >= 2):
  genus = 1  exactly for {k1,k2} = {2,3} and {2,4}.
  genus >= 2 for every OTHER distinct pair 2 <= k1,k2.
  So the Faltings threshold is crossed as soon as the pair is not {2,3}/{2,4};
  all other fixed pairs have genus >= 2 and finitely many rational points.

VERIFIED closed forms (checked against EVERY computed entry of the family):
  k2=2 (pairs {2,n}):  y(y-1)=2C(x,n),  HYPER-ELLIPTIC,  genus = floor((n-1)/2)
  k2=3 (pairs {3,n}):  Y^3 - Y = 6C(x,n) with Y=y-1,  CYCLIC-TRIGONAL (3:1 cover of P^1),
                       genus = n-1 if 3 does not divide n, else n-2
  k2=4 (pairs {4,n}):  2:1 cover of the hyperelliptic curve w^2 = 1+24C(x,n)
                       via w = y^2-3y+1;
                       genus = 3(n-1)/2            n odd
                               3(n-2)/2 + 1        n even, n = 2 mod 4
                               3(n-2)/2            n even, n = 0 mod 4
  (formulas stated in terms of the larger parameter n; all verified
   against the full table above for n <= 24)

Sanity / literature cross-checks:
  * (3,4) = genus 3  -> matches de Weger (1997): C(n,3)=C(m,4) is genus 3,
        a double cover of the elliptic curve Y^2+Y=X^3-X (so NOT hyperelliptic).
  * (2,5) = genus 2  -> matches Bugeaud-et-al (2008): hyperelliptic, solved by
        Mordell-Weil sieve.
  * (2,n) = floor((n-1)/2) reproduces the stated hyperelliptic formula.
  * Adjacent pairs (n-1,n): genus = (n-1)(n-2)/2, the smooth-plane-curve value
        (nonsingular affine model, degree n).  e.g. (4,5)->6=(4)(3)/2,
        (5,6)->10=(5)(4)/2.

Convention / scope note: genus is of the projective closure of the affine
curve; affine smoothness assumed at derived singularities removed by normal.lib.
Diagonal pairs excluded (reducible due to the factor x-y).
