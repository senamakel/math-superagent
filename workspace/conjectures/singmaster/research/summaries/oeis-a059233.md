# OEIS A059233 — number of rows in which n appears in Pascal's triangle

Source: https://oeis.org/A059233 (Fabian Rothelius, Jan 2001; comments by M. F.
Hasler 2023). Full text: `research/sources/oeis-a059233.full.md`.

## What it records

a(n) = number of **rows** of Pascal's triangle containing n (A007318), n >= 2.
Terms: 1,1,1,1,2,1,1,1,2,... (offset 2). This is the object of Erdős Problem
849's strong form: 120 appears in exactly 3 rows, 3003 in exactly 4.

## Key facts from the entry

- **Formula (Hasler 2023):** a(n) = ceiling(A003016(n)/2), where A003016(n) =
  number of occurrences of n in rows <= n of Pascal's triangle. For a > 1 all
  occurrences lie in rows <= a (C(m,k) >= m for 1<=k<=m-1 is the trivial-row
  bound), so A003016(a) = N(a) in this run's both-mirrors-plus-trivial
  convention, and **row-count(a) = ceiling(N(a)/2) = the half-triangle count**.
  This is exactly the counting-convention translation the run needs.
- Central-binomial case: for c = C(2n,n) > 1, a(c) = (A003016(c)+1)/2 (the
  middle-column occurrence is its own mirror).
- a(A180058(n)) = n; a(A182237(n)) = 2; a(A098565(n)) = 3 (Zumkeller 2012).
- Cites Erdős Problem 849 and Singmaster 1971 (JSTOR 2316907).
