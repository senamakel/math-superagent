A180058

Smallest number occurring in exactly n rows of Pascal's triangle.

4

2, 6, 120, 3003

( [list][4]; [graph][5]; [refs][6]; [listen][7]; [history][8]; [text][9]; [internal format][10])

OFFSET

1,1

COMMENTS

[A059233][11] (a(n)) = n and [A059233][11] (m) < n for m < a(n).

LINKS

Erdős problems database contributors, [Erdős problem database][14], see no. 849.

Wikipedia, [Singmaster's conjecture][15]

EXAMPLE

. 1 2 C (2, 1) 1

. 2 6 C (4, 2) C (6, 1) 2

. 3 120 C (10, 3) C (16, 2) C (120, 1) 3

. 4 3003 C (14, 6) C (15, 5) C (78, 2) C (3003, 1) 4 .
