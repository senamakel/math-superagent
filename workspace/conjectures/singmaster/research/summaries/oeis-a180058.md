# OEIS A180058 — smallest number occurring in exactly n rows of Pascal's triangle

Source: https://oeis.org/A180058 (Zumkeller, Dec 2012). Full text:
`research/sources/oeis-a180058.full.md`.

## What it records

A180058: 2, 6, 120, 3003 (n = 1..4). Smallest a with a059233(a) = n (a appears
in exactly n rows = n half-triangle solutions). Explicit decompositions:

- a(1) = 2  = C(2,1)
- a(2) = 6  = C(4,2) = C(6,1)
- a(3) = 120 = C(10,3) = C(16,2) = C(120,1)
- a(4) = 3003 = C(14,6) = C(15,5) = C(78,2) = C(3003,1)
