# Catalogue caution: claimed resolutions of Singmaster (2025–2026)

Purpose: flag non-peer-reviewed "proofs" of Singmaster's conjecture that a later
run could be misled into citing as established progress. These are catalogue
warnings, not sources. None is a peer-reviewed theorem; none is held in
`research/sources/`.

## Zenodo preprints claiming a complete proof

- **Okolo, H. P., "A Resolution of Singmaster's Conjecture and the Principle of
  Bounded Multiplicity", Zenodo 16655044, 2025-08.**
  Claims a full proof inside an "Organized Complexity" framework, a "Harmonic
  Divisor Fan" lattice, and an axiom of "Global Harmony" forbidding "conspiratorial
  alignment of prime factors". 0 citations, no peer review, nonstandard machinery.
  **Do not cite as a result.** No overlap with the classical Diophantine/height
  route this run pursues.

- **Keen, J. R., "Singmaster's Conjecture", Zenodo 19216671, 2026-03.**
  Claims a bound on binomial occurrences; abstract redacted "pending IP review".
  No verifiable statement. **Do not cite.**

- **Hall, M., "Singmaster Proof Program", Zenodo 20584442, 2026-06.** Private
  research log, not a result.

## Genuine adjacent 2025 result (relevant, but NOT held — download 403-blocked)

- **"Tian's Conjecture on the Prime Factorization of the Binomial Coefficient
  C(n+1,2)", Mathematics (MDPI) 14(1) 127, 2025-12-29.** Peer-reviewed.
  Tian's conjecture: for fixed distinct primes p1..pm, the equation
  C(n+1,2) = p1^a1 ... pm^am has at most m solutions; proven for m=2,3 and via
  Zsigmondy's theorem as an alternative. This is fixed-column structure
  (k=2 column carries the triangular-series witnesses), adjacent to, not the same
  as, Singmaster's N(a). The MDPI page returns HTTP 403 to this container;
  only the abstract/search summary is available. If a later run wants it,
  retrieve via intechopen/search engine mirror, and note the paper's own method:
  Zsigmondy on the primitive prime divisor of a^b - c^d.

## Bottom line

As of this run, Singmaster remains open and is not resolved by any held or
findable peer-reviewed source. The only multiplicity-8 value is 3003; the only
infinite family has N(a) >= 6. Treat any claimed proof appearing in 2025–2026
that is not in this library's `research/sources/` as unverified unless it
survives the witness set (N(3003)=8) and gives an effective, uniform,
witness-compatible bound.
