# OEIS A003016 — number of occurrences of n as a binomial coefficient (rows ≤ n)

Source: https://oeis.org/A003016
Full text: `research/sources/oeis-a003016.full.md`

## What it is

A003016(n) = number of occurrences of n as an entry in rows ≤ n of Pascal's
triangle (i.e. among C(r,k) with 0 ≤ r ≤ n). The "rows ≤ n" restriction only
matters for n=1 (which occurs infinitely often); any other n can only appear
in rows ≤ n.

Sequence: 0, 3, 1, 2, 2, 2, 3, 2, 2, 2, 4, 2, 2, 2, 2, 4, 2, 2, 2, 2, 3, 4, ...

This counts **entries** (each (n,k) pair), NOT rows. Example from the entry
itself: a(6)=3 because 6 = C(6,1) = C(6,5) = C(4,2) — three entries in two
rows (4 and 6). For a > 1 all occurrences lie in rows <= a (C(m,k) >= m > a for
m > a, k >= 1), so **A003016(a) = N(a) exactly under this run's both-mirror
plus trivial-pair convention**. The row count (number of rows containing a) is
the different sequence **A059233(a) = ceil(A003016(a)/2)** = the half-triangle
solution count; when a = C(2r,r) is a central-column entry, N(a) = 2·A059233(a)
− 1 (the central entry is its own mirror). Checked on 3003: A003016(3003)=8
(brute.captured.txt lists exactly 8 entries), A059233(3003)=4 rows.
