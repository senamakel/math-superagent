# OEIS A003016 — number of occurrences of n as a binomial coefficient (rows ≤ n)

Source: https://oeis.org/A003016
Full text: `research/sources/oeis-a003016.full.md`

## What it is

A003016(n) = number of occurrences of n as an entry in rows ≤ n of Pascal's
triangle (i.e. among C(r,k) with 0 ≤ r ≤ n). The "rows ≤ n" restriction only
matters for n=1 (which occurs infinitely often); any other n can only appear
in rows ≤ n.

Sequence: 0, 3, 1, 2, 2, 2, 3, 2, 2, 2, 4, 2, 2, 2, 2, 4, 2, 2, 2, 2, 3, 4, ...

Note this is a DIFFERENT counting from the run's N(a): A003016 counts rows,
not individual (n,k) pairs — a(6)=3 since 6 = C(6,1)=C(6,5)=C(4,2); the
run's both-mirror convention gives 6 twice in row 6 plus once in row 4 = 3 by
rows. The OEIS entry A059233 = ⌈A003016/2⌉ is the row count.
