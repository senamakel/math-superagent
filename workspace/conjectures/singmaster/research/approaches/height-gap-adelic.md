```approach
idea: Adelic height machine plus a "gap principle" — use the fact that if an integer a has many representations C(n_i,k_i) = a, then the corresponding rational points on distinct curves force a contradiction via the global height pairing on the product of the Jacobians. This is the Faltings–Elkies–Bombieri "product theorem" / Vojta's inequality route, but aimed at a specific structural consequence rather than a full proof.

mechanism: For each representation (n_i, k_i) of a, we have a rational point P_i on the curve X_{k_i} : C(y,k_i) = a (viewed as a curve in the y-variable, with a as a parameter). Each X_{k_i} is a curve of genus g(k_i) that grows with k_i. If a has many representations with distinct k_i values, then we have points P_i on CURVES OF DIFFERENT GENERA simultaneously representing the same value. Vojta's inequality on the product of curves says that if the heights are "too close together," the points must lie on a proper subvariety.

status: refuted
killed-by: Four obstructions. (1) Vojta's inequality is a RATIONAL-point statement (it bounds #X(K) for a number field K), not an INTEGER-point statement; the curve X_k(a): C(y,k) = a for fixed a has rational points y but the integer condition n = y is an integrality constraint that Vojta does not control — this is the same rational-vs-integral gap that sank chabauty-coleman-uniform. (2) Vojta's constant is INEFFECTIVE: the "2 + ε" has no computable ε from the proof; Rémond's explicit version (2000, Compositio 117) requires the heights of the Jacobians and the Northcott number of the field, which grow with k and a. The claimed "effective" Rémond constants exist in theory but have never been computed for any nontrivial family, and the dependence on the genus (which grows with k) makes them astronomical. (3) The approach conflates the PARAMETER a with the COORDINATE: X_k(a) is a DIFFERENT curve for each a — it's not a fixed curve with varying a. Vojta applies to a FIXED variety, not to a family parameterized by a. Each different a gives a completely different set of curves with no shared geometry. (4) Even if a height inequality forced k ≤ K for large N(a), it would not give an effective K — the dependence on the height constants is implicit and Vojta's method does not produce computable constants without solving the effective Mordell conjecture, which is open. The known witnesses (3003 with k=5,6; the N=6 values with k=2,3) are consistent with "k is small" but provide no evidence that a height-based proof exists.

precedent: _unchecked_ (no source applies Vojta's inequality or the product theorem to equal binomial coefficients)
first-step: none — the method is ineffective at every step; do not re-propose.
```
