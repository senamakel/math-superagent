[TEST 3] STAIRCASE / CONTIGUOUS-BLOCK convexity characterization
  claim: S (|S|>=4) is in convex position  <=>  some projection order
         in the sweep has the elements of S as ONE CONTIGUOUS BLOCK.
  compared against exact oracle es_geom.in_convex_position.
  n=4: |S|>=4 subsets: agree=0  disagree=1  -> FAIL
      disagreement kinds (pred,oracle): {(True, False): 1}
      first disagreement: S=[0, 1, 2, 3] pred=True oracle=False
  n=5: |S|>=4 subsets: agree=88  disagree=75  -> FAIL
      disagreement kinds (pred,oracle): {(False, True): 27, (True, False): 48}
      first disagreement: S=[0, 1, 4, 5] pred=False oracle=True
  n=6: |S|>=4 subsets: agree=62096  disagree=2743  -> FAIL
      disagreement kinds (pred,oracle): {(False, True): 1814, (True, False): 929}
      first disagreement: S=[0, 1, 5, 6] pred=False oracle=True
  Notes on the (pred,oracle) kind map: (True,False)=predicted convex
  but not (a false positive, e.g. any full set is trivially one
  contiguous block even when not convex); (False,True)=predicted not
  convex but actually convex (e.g. a 4-set whose four points are not
  separable from an interior point in any projection).  The correct
  convexity characterization is instead: every p in S is a vertex of
  conv(S), i.e. p is the unique extreme of its own projection within S
  for some direction.
