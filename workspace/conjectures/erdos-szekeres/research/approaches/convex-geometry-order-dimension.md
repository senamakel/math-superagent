```approach
idea: Reformulate the conjecture as an order-dimension bound on the convex-geometry closed-set lattice. A planar point set X is a convex geometry on ground set X (a closure operator: cl(S) = conv(S) ∩ X), and its closed sets form a lattice L (the lattice of convex hulls of subsets, ordered by inclusion). The conjecture becomes an extremal statement about dim(L), the order dimension of that lattice. Jonathan Beagley (Order 30 (2013) 837–845) proved: the closed-set lattice of the 1961 ES construction (2^{n-2} points, no convex n-gon) has order dimension n−1, and any larger planar point set has order dimension ≥ n.
mechanism: Poset-theoretic — Dushnik–Miller order dimension (least d such that the poset embeds in a product of d chains), the standard fact that the Boolean lattice B_m has dimension m, and convex-geometry rank. Different counting variable from everything closed (not f-vector/Kruskal–Katona, not a shattering family, not an achievable order-ideal count).
status: refuted-as-reduction
precedent: REAL and directly on the mark. Beagley, "On the Order Dimension of Convex Geometries", Order 30 (2013) 837–845, DOI 10.1007/s11083-012-9280-2: closed-set lattice of the 1961 ES construction has order dimension n−1, and every larger planar point set has order dimension ≥ n. Knauer–Trotter, "Concepts of Dimension for Convex Geometries", arXiv:2303.08945: for convex geometries cdim(P) ≥ dim(P) ≥ b(P), where b(P) = largest independent set = largest convex-position vertex set. Morris, "Convex Dimension of Locally Planar Convex Geometries", DCG 25 (2001) 109–118 (convex dimension, a different invariant, 2^{n-1}).
killed-by: The bridge "dim(L) ≥ n ⟹ X contains a convex n-gon" is NOT established by any of this literature and is exactly the ES conjecture in new language. Order dimension counts total orders, which can grow from rich closed-set structure unrelated to a large convex polygon; Knauer–Trotter gives b only as a LOWER bound on dim. Beagley's bounds are one-sided (lower bound on dim from |X|, never an upper bound on |X| from dim). To prove ES(n)≤2^{n-2}+1 via dim you need exactly "dim≥n ⟹ convex n-gon on ≤2^{n-2}+1 points", which is the conjecture. Refuted AS A REDUCTION.
caveat/adopt: The exact |X|↔dim threshold is nevertheless a REAL new invariant of the extremal object, held only as an unverified abstract. Repurposed (not as a proof of ES) as a realization-invariant structural marker: any 2^{n-2}+1-point counterexample must have closed-set lattice dimension exactly n (Beagley), while the ES construction has dimension n−1. See research/approaches/order-dimension-realization-invariant.md for the adopted scoped use.
first-step: (old, NOT recommended) — computing dim on es_construct confirms n−1, already known from Beagley.
```
