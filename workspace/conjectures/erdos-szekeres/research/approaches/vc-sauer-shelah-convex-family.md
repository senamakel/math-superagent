```approach
idea: Reformulate the conjecture through VC dimension / the Sauer–Shelah lemma on the set system of convex-position subsets. The Sauer–Shelah lemma states: a set system of VC-dimension d on m ground elements has at most Σ_{i≤d} C(m,i) members — and Σ_{i=0}^{n-2} C(n-2,i) = 2^{n-2} is EXACTLY the conjectured constant. So the conjecture would follow from a statement of the form "the convex-position structure of a planar set with no convex n-gon is a set system of VC-dimension at most (n−2), and it attains the Sauer–Shelah maximum only at the ES construction." The known lossy cups-and-caps bound C(2n-4,n-2) ≈ 4^n arises because the naive (cap-length, cup-length) pair statistic is a *product* of two independent binomial counts; a correct shattering/VC formulation should recover the *sum* Σ C(n-2,i) = 2^{n-2} by counting antichains/ideals with a single shared parameter, which is precisely what a VC bound supplies (it sums binomials, it does not multiply them).

mechanism: The named machinery is VC theory / shattering + Sauer–Shelah and its set-packing sibling (Vapnik–Chervonenkis; Sauer 1972; Shelah 1972). The question to make precise: what is the "shattering" relation that a planar point set induces, such that (a) 'no convex n-gon' ⟺ 'VC-dimension ≤ n−2' for the induced set system, and (b) the ES construction realizes the maximal VC-dim−(n−2) family of size exactly 2^{n-2}? A natural candidate target: the system of "p is in conv(S)" / "the star of points separable from a subset by a line" relations, which are exactly the order-type data (3x3 determinant signs) and are hereditary — the right substrate for a shattering argument. This is a genuinely different counting variable from the refuted convexity-complex (which was a simplicial-complex f-vector / Kruskal–Katona shadow bound — Sauer–Shelah is an *upper* bound on family size from bounded dimension, the direction KK gets wrong, and it sums binomials rather than counting faces).

status: refuted-as-reduction
precedent: VC theory itself is standard and correctly quoted — Sauer–Shelah–Vapnik–Chervonenkis (Sauer 1972; Shelah 1972; Vapnik–Chervonenkis 1971; refinements in the forbidden-matrix literature e.g. arXiv:1011.xxx, Anstee–Sali) and the VC-dimension-of-geometric-set-systems literature (e.g. "On the VC-dimension of half-spaces with respect to convex sets", Grelier–Ilchi–Miltzow–Smorodinsky, Discrete Math & Theoretical Computer Science 2021, DOI 10.46298/dmtcs.6631, which computes the VC-dim of a family of convex sets under halfspace shattering — but nothing in that literature touches the ES conjecture). A serious search of the ES literature finds NO published shattering/VC treatment that resolves or even reformulates the ES conjecture; research on convex point sets via VC dimension exists only for concrete concept classes (rectangles, halfspaces) and does not connect to the 2^{n-2} constant.
killed-by: The constant 2^{n-2} = Σ_{i≤n-2} C(n-2,i) is the Sauer–Shelah cap for a family over a ground set of size n−2 — but the conjecture bounds an N-point set where N = 2^{n-2} is the cardinality being ESTIMATED, not the shattering ground set. There is a fatal match between the parameters: Sauer–Shelah says |family| ≤ Σ_{i≤d} C(m,i) where m is the size of the shattering ground set. If the ground set is the N points (m = N = 2^{n-2}), the bound Σ_{i≤d} C(N,i) GROWS with N — the wrong direction entirely (it cannot bound N). If the ground set is n−2 elements (m = n−2), then the bound caps a family of sets over n−2 atoms, which does not bound N = the number of planar points at all. The ES construction's own convex-subset family has 38/802/39648 members at n=5,6,7 (from the run's enumeration, in the approach's own caveat), all far above 2^{n-2}=8/16/32, confirming the plain convex-subset family is not the right set system and no alternative shattering relation is specified. To make Sauer–Shelah bite one needs a set system whose VC-dim is n−2 AND whose maximum size over an N-point configuration is 2^{n-2} — which is over N points, so its Sauer–Shelah bound must be independent of N and equal to 2^{n-2}, i.e. one must have already encoded "no convex n-gon ⟺ ground set size ≤ n−2" into the system, which is the conjecture. The reformulation supplies no inequality the ES construction fails only past 2^{n-2}.
first-step: (NOT RECOMMENDED as a mechanism.) Any concrete shattering relation consistent with the order type will have the VC-dim bound either growing in N (ground set too big) or not bounding N (ground set too small). The run could verify on es_construct that no natural order-type-derived family has both VC-dim = n−2 and family size capped at 2^{n-2}, confirming the ground-set mismatch.
caveat: 2^{n-2} here is the trivial size of the Boolean lattice B_{n-2} (all subsets), not a nontrivial extremal cap; matching a binomial sum to a constant is not the same as the conjecture providing that constant. The only way the 2^{n-2} could be a Sauer–Shelah cap with the right ground set is if the ground set were the n−2 "levels" of the construction, and then one is not bounding the number of points.
```
