```approach
idea: Use the Erdős–Tuza–Valtr α-statistic, which injects an (a-cap, b-cup)-free configuration into the grid simplex T_{a,b} = {(x_1≤…≤x_{a-2}) : 1≤x_1≤…≤x_{a-2}≤b−1} of size C(a+b-4, a-2) (library claim etv-alpha-statistic-injective), as a *compression / isoperimetric* object rather than a bare counting object. The ETV reformulation is already known to be *equivalent* to the conjecture (claim etv-equivalent-to-es): N(n,a,b) = Σ_{i=n-b}^{a-2} C(n-2,i), and P(n,n,n) gives Σ_{i=0}^{n-2} C(n-2,i) = 2^{n-2}. So the conjecture is not refuted by picking ETV as a mechanism — the open step is the *optimal shape* of the α-image. The new mechanism: an extremal set must have a **compressed / left-justified (order-ideal) α-image inside the grid simplex**, and the number of lattice points of such a compressed filling is the partial binomial sum — giving 2^{n-2} as a lattice-point / Young-diagram count, not as a Sperner/antichain bound. This differs from the refuted boolean-lattice-injection because the target is the *grid simplex of a joint type* (a lattice-point / order-ideal / isoperimetric count) rather than B_{n-2} closed by Sperner, and from the lossy cups-caps bound because it keeps the *joint* profile (all a−2 coordinates), not the single (cup,cap) pair whose count multiplies to 4^n.

mechanism: Named machinery: order ideals of a grid poset and their enumeration as lattice points (Gale–Ryser / Ferrers diagrams; the number of order ideals of the a×(b) grid); isoperimetric/compression lemmas (clearing, shifting) that say an extremal family can be taken left-justified. The α-image of the ES construction should be an order ideal of the grid simplex realizing exactly C(n-2,i) lattice points on level i. The delicate part — and what separates this from known-lossy cups-caps — is that the full (a−2)-dimensional α-vector is injective, whereas the 2-coordinate truncation to (cup,cap) is where the product-of-binomials loss enters (ms-cups-caps-tight). So the claim to attack: "an extremal n-avoiding set's full α-image is a compressed order ideal of the n−2 level grid simplex, of size exactly 2^{n-2}".

status: refuted-as-reduction
precedent: The α-statistic machinery and ETV equivalence are REAL and correctly cited (Baek, arXiv:2206.04260, "On the Erdős–Tuza–Valtr Conjecture"; the injectivity into the grid simplex T_{a,b} of size C(a+b-4,a-2) is the library claim etv-alpha-statistic-injective, and etv-equivalent-to-es gives N(n,a,b)=Σ_{i=n-b}^{a-2}C(n-2,i) with P(n,n,n)=2^{n-2}). The deeper source of this injectivity is Moshkovitz–Shapira, "Ramsey Theory, Integer Partitions and a New Proof of the Erdős–Szekeres Theorem", arXiv:1206.4001 (Adv. Math. 262 (2014) 1107–1129), which proves N3(q,n)=P_{q-1}(n)+1 where P_d(n) is the number of d-dimensional integer partitions, and where the down-set D(v) injection is exactly the order-ideal/compression mechanism the inventor proposes — Seidenberg-style injectivity of a down-set map, down-sets bijecting with partitions (library claim ms-esz-downset-injectivity). So the "compressed order-ideal image" substrate is not speculative; it is the known proof of the cups-caps bound.
killed-by: The size of the full α-injectivity host kills the "2^{n-2} as an order-ideal count" hope. The full (a−2)-coordinate α-image injects into the grid simplex T_{a,b} of size C(a+b-4,a-2). For the symmetric case a=b=n this is T_{n,n} of size C(2n-4,n-2) ≈ 4^n/√n, NOT 2^{n-2}. The Moshkovitz–Shapira down-set injectivity proves the extremal order-ideal/partition count for avoiding both caps and cups is N3(2,n)=C(2n,n)+1 ≈ 4^n — the partition count is exactly the ~4^n loss the inventor hoped compression would remove. Keeping the full vector does NOT escape the loss: the full-vector host is the SAME size as the truncated one (C(a+b-4,a-2) either way). So the premise "the (cup,cap) truncation is where the product-of-binomials loss enters" is FALSE — the loss is intrinsic to the α/grid-simplex/partition picture, not to the truncation; the full joint statistic's count is the same 4^n binomial. There is no published compression/order-ideal lemma for realizable point sets that delivers 2^{n-2} — and there cannot be one uniformly over all abstract configurations, because the abstract analogue (Balko–Valtr, baek-balko-weak7-fails / balko-valtr-refutes-PS) fills the 4^n simplex, so the 2^{n-2} would have to come from realizability (pseudolinearity), which is exactly where the difficulty lives and where no compression lemma applies. The ETV equality N(n,a,b)=Σ_{i=n-b}^{a-2}C(n-2,i)=2^{n-2} at (n,n,n) is the TRIVIAL Boolean-lattice count (all subsets of [n−2]), not an order-ideal count of a grid — no new counting is smuggled in.
first-step: (NOT RECOMMENDED as a mechanism.) Computing the full α-image on es_construct and a Horton-type set can confirm the order-ideal shape holds on realizable sets, but the shape alone cannot push the size of the α-image from C(2n-4,n-2) (what the injectivity guarantees) down to 2^{n-2}; that extra factor of ~2^n/√n would have to come from realizability, where no compression lemma lands.
caveat: The valuable survivor is NOT a new bound but the qualitative structure: any no-convex-n-gon set that is also 4-cap- and n-cup-free and near the (n-1 choose 2) size must be a nearly-full (α,β)-triangle (Baek Thm 3.6/4.2) — a genuine MEMORY.md structural fact. But that is a statement about the (n,4,n) level of the ETV pyramid, polynomially far below the 2^{n-2} diameter, and it does not move the ES bound.
```
