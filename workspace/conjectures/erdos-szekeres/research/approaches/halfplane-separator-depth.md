idea: Replace the failed single-line (and single-sector/wedge) balanced split by a recursion over a *separating family of half-planes* of bounded complexity, and bound N by how few cells the family forces the no-convex-n-gon set into. The run's own decisive empirical finding is that the single-line split of the ES construction fails at n=7 (0 valid single half-plane splits into two 6-avoiding 16-sets) yet the even/odd block bipartition of es_construct(7) is realized by *exactly a triple* open half-plane intersection (k=3; `code/out/triple_inter.captured.txt`: one C(16,3) triple equals E, one equals O). So the recursion the ES construction actually respects lives at separator-complexity > 1. Wedge-split (the adopted approach) changes the separator from a line to a single sector/ray-pair; this candidate changes it instead to a general boolean combination of several half-planes, and asks for the *minimum separator count k(n)* over which a no-convex-n-gon set splits into (n-1)-avoiding pieces of controlled size. Distinct from wedge-split: the separator is a covering *family* (a cell decomposition), not one sector, and k is allowed to grow with n.

mechanism: In the plane, the arrangement of k half-planes has O(k) cells (an acyclic set of k "pseudolines"; the number of distinct cells that are boolean combinations is at most O(k) regions of the arrangement, and by definition ≤ 2^k sign vectors). If X can be covered by a family of k half-planes whose sign-vector classes are each (n-1)-avoiding, then N ≤ Σ_{classes} (max per class), and if the recursion zeroes in on a bound 2^{n-2} it is a "doubling" in the number of cells rather than the number of halves. Weakening the obstinate single line to 2–3 half-planes already provably works for the ES construction's bipartition (run's k=3 witness), so the structural G-split generalization is: *every* extremal n-avoiding set admits a k(n)-half-plane balanced (n-1)-splitting with k(n) small (2 ≤ k(n) ≤ n−3), and the recursion f(n) ≤ (number of cells)·f(n−1) recovers 2^{n-2}. The named machinery to check against: the classical (≤k)-set / separating-hyperplane / "Erdős–Szekeres via half-space" literature and the fact that a convex n-gon would require points in ~2^n distinct "generic" sign positions, forcing the extremal set onto few sign-cells. Attack the composite claim: any n-avoiding set of size 2^{n-2} has a k-half-plane balanced (n-1)-splitting for the minimal k(n) = the separator complexity of es_construct.

State the falsifier: an n-avoiding set whose every k-half-plane balanced (n-1)-splitting needs k(n) growing superlinearly in n, killing the 2^{n-2} doubling. CRITICAL CORRECTION to the mechanism: the number of regions of an arrangement of k lines/half-plane-boundaries in the plane is O(k²), not O(k) — a boolean combination of k half-planes takes a convex polygon with ≤ k sides, and the sign-vector count is ≤ 2^k (much larger than k). So the "O(k) cells" doubling claim at the heart of the mechanism arithmetic is wrong; the recursion would be f(n) ≤ (regions)·f(n−1) with regions polynomial-to-exponential in k, and no 2^{n-2} doubling follows at constant k.
