# Dyadic-scale martingale decomposition of the character sum: Azuma–Hoeffding on the odometer, with the drift priced as a variance input

```approach
idea: >
  Split S(n) = Σ_{d=2}^{n−1} (−1)^{T(n,d)} into one martingale per dyadic scale
  and bound each with a concentration inequality, leaving the *drift* as the only
  arithmetic input. By the run telescope, every depth d with ν₂(d+1) = g reads the
  prime sign string only at separation 2^g, so S_g(n) := Σ_{d: ν₂(d+1)=g} ε_d(n)
  is a functional of the dyadic blocks of length 2^g. Revealing the prime sign
  string block by block defines the dyadic (odometer) filtration; S_g is a
  martingale difference sequence with respect to it, and the predictable drift is
  exactly a low-order dyadic-block correlation of χ_4 along the primes. Azuma–
  Hoeffding / Burkholder then bound the martingale part by its quadratic variation,
  which is a *variance/second-moment* statement on h — the GOAL priority-2 input
  the run has been trying to price — strictly weaker-looking than positive mod-4
  switch density.

mechanism: >
  The three adopted routes bound S(n) by its second moment through either the
  row-code distance distribution (Krawtchouk/MacWilliams) or an ergodic limit
  (Pivato–Yassawi). Neither gives a FINITE, per-n decomposition of S(n) into a
  zero-mean part plus a drift. The martingale route does: for fixed n, order the
  blocks of the odometer by scale g = 0,1,…,⌊log₂ n⌋, and condition on the
  σ-algebra generated by the prime sign string up to block scale g−1. Each S_g is
  then an increment of a martingale whose Doob decomposition is
  S(n) = M_n + A_n, where M_n is a martingale (bounded increments at each dyadic
  scale) and A_n is the predictable part — a sum of conditional expectations that
  is a pure function of low-order dyadic correlations of χ_4(q_j). The engine is
  the named inequality Azuma–Hoeffding (or Burkholder's L^p inequality) applied to
  the martingale on the odometer; the arithmetic content is compressed into the
  drift A_n and the quadratic variation, both explicit and machine-computable.
  The priced input is then: the prime sign sequence has bounded dyadic-block
  autocorrelation (its variance at scale 2^g decays), which is a second-moment
  statement orthogonal to switch density (a mean statement) — exactly the
  separation the Lucas-mixing precision note established for Bernoulli(ρ). If the
  drift is O(√n) and the quadratic variation is O(n), Azuma gives S(n) = O(√(n log
  n)), hence ν₂/n → 1/2 on a density-1 set.

status: refuted

precedent: >
  The named inequalities are real and standard, with precise statements:
  - Azuma, "Weighted sums of certain dependent random variables", Tohoku Math. J.
    (1967), DOI 10.2748/tmj/1178243286 — Azuma–Hoeffding for bounded martingale
    differences: P(|M_n − M_0| ≥ t) ≤ 2 exp(−t²/(2 Σ c_i²)) when |X_i − X_{i−1}| ≤ c_i.
  - Rio, "Extensions of the Hoeffding-Azuma inequalities", Electron. Commun.
    Probab. 18 (2013), DOI 10.1214/ecp.v18-2690 — p-norm and subgaussian refinements;
    explicit Doob-decomposition formalism.
  - Doob's decomposition S_n = M_n + A_n: classical (Rio paper §1; any martingale text).
  - Inside-workspace: the run telescope is VERIFIED (code/gfold/g_run_telescope_verify.py,
    C2 both brute and prefix-XOR on real prime h and random h; C1 run structure
    d=0..2^14): depth d reads the residue string at separation 2^{ν₂(d+1)}, so the
    g=0 scale reads ADJACENT residues. Parity-barrier claims: abgs-p1-wide-open,
    lau-nonconstant-pattern-open, abgs-pair-frequency-equality-open.

killed-by: >
  Two independent defects, either alone fatal.
  (1) The martingale is over a probability space; SUPPLY's S(n) is deterministic.
  Azuma–Hoeffding and Burkholder are statements about a RANDOM process: they bound
  P(|M_n − M_0| ≥ t) for a martingale with respect to a filtration of σ-fields.
  For a FIXED prime string h, every filtration only reveals deterministic values:
  the Doob decomposition has M_n ≡ 0 and A_n = S(n), the conditional expectation
  of each S_g given the earlier blocks equals S_g itself, so the martingale is the
  zero process and Azuma's bound is |M_n| = 0 — it says nothing about |S(n)|. To
  get the claimed S(n) = O(√(n log n)) the argument must RANDOMIZE h (make the
  blocks random variables), and then the conclusion is a high-probability bound on
  a RANDOM string — which the fair model already supplies exactly:
  wt(Φ_n h) is Binomial(n−2, 1/2) for uniform h (claim fair-model-exact-binomial,
  proved from rank Φ_n = n−2). The transfer from "h uniform" (or "random string
  w.h.p. has linear fold weight") to "the FIXED prime string has linear fold
  weight" is precisely the missing gate — the same finite-prefix transfer the
  ergodic route (lucas-mixing) lacks and that no source supplies. Azuma does not
  reach a deterministic string.
  (2) Even granting the random-martingale framing, the drift at the g=0 scale is
  the parity barrier. The run telescope (verified) puts the g=0 (separation 2^0 =
  1) terms at ADJACENT residues: the drift A_n contains Σ_j χ_4(q_j)χ_4(q_{j+1}),
  the mod-4 switch-pair correlation. Its positivity/decay is exactly the open
  problem abgs-p1-wide-open ("cannot be treated using L-functions") and
  lau-nonconstant-pattern-open (even ONE non-constant 2-term pattern is unproved
  to occur infinitely often). So "drift A_n = O(√n)" (=: the g=0 scale contributes
  o(n)) IS positive switch density, not a weaker second-moment input. The promised
  "variance input orthogonal to switch density" does not exist at the coarsest
  dyadic scale, which is where the real weight sits. The route's priced input is
  not weaker than switch density; it is switch density itself.

first-step: >
  (parked.) tool_builder may still run step (2) of the original first-step — print
  the per-scale decomposition of S(n) = Σ_g S_g(n) against the brute oracle and
  the drift/quadratic variation at each g for n ≤ 8000 — as a MEASUREMENT that will
  confirm the g=0 (adjacent-switch) stratum carries a non-negligible fraction of
  the mass and that the drift is not o(n) for the controls (all-ones and
  Thue-Morse). But this is diagnostic, not a route: defect (2) says the drift
  cannot be bounded from a variance input, and defect (1) says Azuma cannot apply
  to the deterministic string at all. Run it only to record the g=0 dominance.
```

## Research verdict (grounding check)

**The reformulation is named (Azuma–Hoeffding martingale concentration on an
odometer filtration, with a Doob decomposition into martingale + drift), the
inequalities are real with precise hypotheses, and the run-telescope structure it
rests on is machine-verified on this very workspace. But the route is dead on two
independent defects, both fatal.**

**Defect 1 — there is no probability space for a deterministic string.** Azuma–
Hoeffding and Burkholder are tail bounds for a martingale on a *probability
space*: they control `P(|M_n − M_0| ≥ t)`. For SUPPLY's fixed prime string `h`,
every filtration over the odometer reveals *deterministic* values; the Doob
decomposition gives `M_n ≡ 0` and `A_n = S(n)`, so the martingale is the zero
process and Azuma returns `|M_n| = 0`, i.e. no information about `|S(n)|`. To
obtain `S(n) = O(√(n log n))` one must randomize `h`, in which case the fair model
already gives the exact law — `wt(Φ_n h)` is `Binomial(n−2, 1/2)` for uniform
`h` (claim `fair-model-exact-binomial`, proved) — and the missing step is the
transfer from "random strings have linear fold weight w.h.p." to "the *fixed*
prime string has linear fold weight". That transfer is the same finite-prefix gate
the Lucas-mixing ergodic route lacks, and no concentration theorem supplies it.

**Defect 2 — the drift at the g=0 scale is the parity barrier, not a weaker
input.** The verification (`code/gfold/g_run_telescope_verify.py`) confirms depth
`d` with `ν₂(d+1)=g` reads the residue string at separation `2^g`. So the `g=0`
scale reads *adjacent* residues, and the drift `A_n` contains
`Σ_j χ_4(q_j)χ_4(q_{j+1})` — the mod-4 switch-pair correlation whose positive
density is the open problem `abgs-p1-wide-open` / `lau-nonconstant-pattern-open`.
Thus "the drift is `o(n)`" is not a weaker variance input; it is positive mod-4
switch density. The route's central promise ("the priced input is a second-moment
statement orthogonal to switch density") fails at the coarsest dyadic scale,
which is precisely where the real `S(n)` mass sits (measured: the pointwise sum is
dominated by the dense lower scales).

**Does it reopen a closed door?** It is the switch-density dead end dressed as a
martingale, and it depends on a random-variability the fixed string does not
have. **Refuted**, on evidence (the deterministic-strand defect and the g=0
drift), not on absence.
