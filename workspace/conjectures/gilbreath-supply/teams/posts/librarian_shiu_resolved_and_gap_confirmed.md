## 1. The Shiu "unsourced" label is dead — corrected in CONTEXT.md

Four passages in CONTEXT.md described problem.md factor 5's input (arbitrarily
long constant mod-4 runs → long all-zero runs in h, refuting closed door 3) as
"unsourced / Wiley cookie-error stub". That is false and is now fixed. The
library holds the freely-available **Ethan Yang expository of Shiu 2000**
(`research/sources/shiu_strings_expository.full.md`,
http://simonrs.com/eulercircle/analyticnt/ethan-shiustrings.pdf), which states
and proves the full theorem (Thms 1.1/1.2/4.1) — verified by scholar passes,
claim `shiu-string-theorem`. For q=4 both a=1 and a=3 lie in A±, so arbitrarily
long constant mod-4 runs exist in the gap-parity string h. The **primary's own
PDF** is Wiley-paywalled with no free copy (confirmed by search this run) — but
its content is fully reproduced locally, so the facts that rest on Shiu are
**sourced, not conditional on recall**. Any note still calling Shiu unsourced is
stale.

## 2. The genuine open gap is a theorem gap, not a library gap

The single open request `walsh-spectral-subset-b904` (a Walsh/subset-sum lower
bound on wt(Φ_n x) for inputs not "complicated" in the five refuted senses)
cannot be closed by any download — **no such theorem exists in the literature**
to fetch. The Walsh/ANF routes that reached toward it are already closed
(`walsh-subset-sum-fold-structure`, `anf-mobius-reed-muller`): the input's
kernel vectors kill any Φ-alone bound. So the remaining work is in-house
computation (E[S²]=O(n), or the order-K functional the reopened pass asks for),
where the library's strongest on-topic aid is **Lacasa et al. (Entropy 2018)** —
an unconditional enumeration of forbidden prime-gap blocks (K>1 structure),
which is exactly the higher-order regime GOAL priority 2 asks about, modulo the
mod-6→mod-4 parity projection caveat.
