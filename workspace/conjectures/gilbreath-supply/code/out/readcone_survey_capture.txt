=== (1b) FIXED single 1 (j CONSTANT across n) — the strict 'fixed' reading ===
Here h = e_j with j fixed (does NOT move with n). Cell reads h[j] when
o = d-(n-1-j) in [0,d] submask-fits, i.e. d in [n-1-j, n-1]: only j+1
depths are EVER eligible, so nu2(n) <= j+1 = O(1) and S(n)=(n-2)-2*nu2(n)
is LINEAR (not O(sqrt n)).  This is the fixed-1 bound, re-read at the S level:
     fixed j=0  : S=[46, 96, 196, 496, 996]  (nu2~O(1), so S/n->1)
     fixed j=1  : S=[44, 94, 194, 494, 994]  (nu2~O(1), so S/n->1)
     fixed j=2  : S=[46, 94, 194, 494, 994]  (nu2~O(1), so S/n->1)
     fixed j=5  : S=[40, 94, 190, 494, 990]  (nu2~O(1), so S/n->1)
     fixed j=50 : S=[48, 82, 182, 446, 990]  (nu2~O(1), so S/n->1)
So the per-window e_{n-2} family (S in {0,1}) is doing all the work; a FIXED
single 1 is linear in S.  This is the core contrast the survey exposes.

=== (3) READ-CONE SIZE |C_j(n)|: EXACT closed form (verified) ===
C_j(n) = { d in [2,n-1] : (d-(n-1-j)) submask of d }, needs d>=n-1-j.
Identity (proved): (d-r) subseteq d  <=>  r subseteq d  for d>=r, r=n-1-j.
Hence EXACT: |C_j(n)| = #{ d in [2,n-1] : (n-1-j) bitwise-submask of d }.

Supermask-count interpretation: |C_j| counts d in [2,n-1] whose bits
contain those of r=n-1-j.  For r = 2^a (popcount 1) that is ~ (n-1-r)/2;
for r with popcount k it is roughly (n - r)/2^k (leading term).  This is
exactly the read-cone-column-equivalence weight 2^{-popcount(n-1-j)} per 1.

=== CONCLUSION: does a FIXED density-0 string keep S(n) = O(sqrt n)? ===
Measured up to n=4000, both fixed sparse candidates FAIL: max|S| ~ n (linear),
located at n = 2^m - 2 (candidate A) and n = 2^m (candidate B), i.e. exactly
where a 1 lands at or just below the read-boundary.
Regime-check -- candidate A: max|S| = 50@62, 112@126, 238@254, 492@510, 966@990,
  1956@1982, 2958@2998, 3950@3998  -> max|S| ~ n-2, i.e. ~ (n) (linear), and the
  ratio max|S|/sqrt(n) GROWS (6.25 -> 62.5), so S(n) is NOT O(sqrt n).
Regime-check -- candidate B: identical asymptotics (max|S| ~ n), grows too.
So NO fixed dense-0 string among these two structural families keeps S=O(sqrt n)
through n=4000: the per-window linear amplification reappears infinitely often
because a large support member lands at n-1 or n-2.  G-input-strictness for a
FIXED infinite string is NOT witnessed by these; the read-cone closed form
explains it: a 1 at position n-1-k (r=k) is read by ~ (n-k)/2^{pc(k)} depths,
i.e. about a 1/2^{pc(k)} fraction of the window (all depths when pc(k)=0, i.e.
position n-1; half when pc(k)=1, i.e. n-2 or n-1 minus a power of 2; a quarter
when pc(k)=2).  So a fixed 1 near the boundary keeps |S| ~ n whenever n-1-j has
low popcount for infinitely many n, and any fixed support containing arbitrarily
many low-popcount boundary-near members is forced to S = Omega(n) infinitely
often.  An S=O(sqrt n) witness must avoid all
boundary-near positions at every n, a strictly finer (growing, carefully-placed)
object than any fixed S -- consistent with the refuter's finding that the
G-weak-input-strictness witness cannot be a fixed sparse string.
