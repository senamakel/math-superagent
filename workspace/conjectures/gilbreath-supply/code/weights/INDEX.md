# Index — code/weights

What each file in this folder is for. Keep it current: describe a file when you create it, and refresh this index after adding, renaming, or deleting files.

| File | Purpose |
| --- | --- |
| `check_threshold_margin.py` | Standalone robustness check for the third-pass threshold column: re-samples the fraction nu2/n>=0.40 at S=8000 (fresh RNG) at weights {first_w-1, first_w, first_w+1} around a reported first_typical, printing exact mean and sampled frac per w. Used to confirm the "typical" crossing is a real boundary not a 1-sigma fluke of the S=4000 run. Arguments: n and first_w. Reuses weights.linear_supply_threshold_extend.batch_sos_ones and scholar.threshold_limit_run.ExactMean. Its output is folded into PART 5 of the main capture. |
| `linear_supply_by_weight.py` | Characterises which binary h of length n have linear supply (nu2(n)=wt(Phi_n h)>=c*n) as a function of Hamming weight w. Part0 reproduces the e_{n-2} mechanism (nu2=count of odd d in [2,n-1]) and the n=8 witness (e_6:(S,nu2)=(0,3), e_5=(-2,4)); Part1 exhaustively enumerates all 2^n strings for n in {6,8,10,12,14,16} reporting per-(n,w) count/mean/fraction of nu2/n>=0.25/0.40/0.45; Part2 samples 300 random strings of exact weight {1,2,3,4,5,8,16,32,n//2,n} for n in {32,64,128}; Part3 states the min weight at which linear supply is typical (mean>=0.40 and frac>=0.40>=0.5); all-ones string is a negative control (kernel, nu2/n=0). Uses canonical oracle lib.supply_fold.s_sos (returns (S,nu2)) cross-checked on a random 5% sample against s_direct — all agree. Captured to code/out/linear_supply_by_weight.txt. Verified: n=8 witness reproduced exactly, mechanism confirmed n=3..40. |
| `linear_supply_threshold_extend.py` | Vectorized int8 submask-product SOS fold (batch_sos_ones) + batch oracle verification helpers. The vectorized fold that makes Monte-Carlo extension to n=8192 affordable. Imports into linear_supply_threshold_run.py. |
| `linear_supply_threshold_pass3.py` | Third-pass owed computation: the min-weight-ratio w/n at which "linear supply becomes typical" (mean nu2/n>=0.40 AND frac(nu2/n>=0.40)>=0.5). MEAN half EXACT (Krawtchouk grouped-by-popcount closed form from scholar.threshold_limit_run.ExactMean), FRAC half sampled at S=4000 per (n,w) with fresh RNG per (n,w) via vectorized int8 batch_sos_ones fold; first_typical = first w whose exact mean (gate) passes 0.40 AND sampled frac>=0.5. Covers n in {8..4096}; asserts guard nu2(53)==18, nu2(64)==27 on the prime h; cross-checks batch==s_sos/s_direct (verify_batch 32..1024 + spot); reproduces n=8 witness (w=3 mean 0.4464, frac 0.518); all-ones kernel negative control -> nu2/n=0. PART 5 independently re-samples frac at S=8000 around the threshold to show the crossing is real (w-1 stays <0.5) not a 1-sigma fluke. Captured to code/out/linear_supply_threshold_pass3.txt. Correctness: exact-mean formula validated against exhaustive brute s_sos on small n (threshold_limit_run.cross_check), batch fold cross-checked vs s_sos/s_direct; n=64 exact threshold 0.109375 matches the operator's stated 0.1094. Result: both halves fall monotonically toward 0 (exact 0.1094@64 -> 0.0188@4096), verdict tends-to-0, labelled measurement-not-proof. |
| `linear_supply_threshold_run.py` | Third-pass owed computation: extends the min weight ratio w/n at which linear supply becomes typical to n=256..8192 (fresh-RNG Monte Carlo, S=2000-3000/weight), decisively breaking the pass-two n=64/128 plateau at 1/8. The answer to the pass's one question. |
| `threshold_exponent_report.py` | Final capture-producing report for the third-pass exponent item: exact threshold column to n=2^18, power-law fits with se, closed-form candidate spreads, and the directive-48 log-periodicity residual test. Output written to code/out/threshold_exponent_report.captured.txt. Reads only lib.krawtchouk_sphere; exact per-n w*, fits labelled measured-not-proved. |
| `threshold_exponent_test.py` | Deciding computation for directives 46/47/48: fits log2(w*) vs log2(n) with error bar over the exact threshold column (n=64..2^18), tests w=c*sqrt(n), w=c*sqrt(n)*log n, w=c*n^(log_4 3) by rel-spread, and tests log-periodicity of w*/n^E residuals vs log2 n. Uses exact lib.krawtchouk_sphere.theta_mean. Captured to code/out/threshold_exponent_report.captured.txt (via threshold_exponent_report.py). |
