Derived from the files under `research/backward/`, and rewritten whenever one of them is written. Do not edit this file; the next write re-derives it. One skeleton is one decomposition of the goal: open `research/backward/<name>.md` to work on it.

This is not the approach ledger. An approach is a *route* — a reformulation that might get there. A skeleton is a *decomposition* — the goal itself, broken into propositions that can each be attacked on their own. `research/APPROACHES.md` answers what else could get us there; this file answers what would be enough.

Every open gap below is a task. A gap with a `next` a tool_builder or a theorem_prover could start on today is worth more than three lemmas nobody can begin.

## Gaps already discharged

Do not state these again. Each one is a lemma this run has, and the claim beside it is where to read it.

- [[collapse-by-evenness]] `G-evenness-of-symmetric-difference` — > For every n and every 2 ≤ d,d' ≤ n−1, the symmetric difference M_d △ M_{d'} has even cardinality. This follows from |M_d| = 2^{pc(d)} even for d ≥ 2 (row d is the indicator of the down-set of d, so |M_d| = #submasks(d) = 2^{pc(d)}), and the parity identity |M_d △ M_{d'}| = |M_d| + |M_{d'}| − 2|M_d ∩ M_{d'}| ≡ 2^{pc(d)} + 2^{pc(d')} ≡ 0 + 0 ≡ 0 (mod 2). The full meet-semilattice formula |M_d △ M_{d'}| = 2^{pc(d)} + 2^{pc(d')} − 2^{pc(d∧d')+1} (imported-result-3) gives the same conclusion and is the stronger cross-check. (closed by elementary parity (submask count |M_d| = 2^{pc(d)}, d ≥ 2); agrees with imported-result-3)
- [[collapse-by-evenness]] `G-even-set-is-product-of-pairs` — > For any even-size A ⊆ {0,…,n−1}, A admits a perfect matching, and chi_A(h) = ∏_{{i,j} in the matching} chi_{i,j}(h) for every h. (closed by elementary (pair consecutive elements of the sorted set A))
- [[collapse-by-evenness]] `G-pair-telescopes-to-adjacent` — > For all i < j and all h, chi_{i,j}(h) = (−1)^{h_i ⊕ h_j} = ∏_{k=i}^{j−1} (−1)^{h_k ⊕ h_{k+1}} = ∏_{k=i}^{j−1} chi_{k,k+1}(h). (closed by elementary F₂ telescoping (h_i ⊕ h_j = Σ_{k=i}^{j−1} (h_k ⊕ h_{k+1})))
