## What it is, precisely

`a(n) = 1 + (n-2)(n-1)/2 = A000124(n-2)`. Also `a(n) = 1 + C(n-1,2)`.

## Bearing on COLLAPSE

The computed distinct-set count of the S² index multiset is
`D(n) = 1 + C(n-2,2)` (measured to n=256: `code/out/pf_s2multiset.md`,
`census-multiplicity-injective-pairs`). This is **`A000124(n-3)` = `A152947(n-1)`**,
**not** `A152947(n)`. The pattern-finder notes that cite "A152947" for the count
omit the offset and read one high.

Exact identification (catalogue values, offset fixed):
- `D(4)=2, D(5)=4, D(6)=7, D(7)=11, D(8)=16, …`
- A000124: 1,2,4,7,11,16,… with index n−3: A000124(1)=2=D(4), … ✓
- A152947: 1,1,2,4,7,11,16,… with index n−1: A152947(3)=2=D(4), … ✓

The closed form `D(n) = 1+C(n-2,2)` is verified by this run's own computation,
so this is a catalogue *confirmation* of a computed result, not the reason the
result holds.
