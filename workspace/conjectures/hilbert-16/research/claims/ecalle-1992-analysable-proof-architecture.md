# Écalle 1992 book: analysable-function proof architecture (author's own account)

```claim
id: ecalle-1992-analysable-proof-architecture
statement: Écalle's 1992 book (Hermann, Actualités mathématiques, ISBN 2-7056-6199-9) proves Dulac's conjecture (finitely many limit cycles for an individual analytic planar field) by: decomposing the first-return map F of a polycycle into passage maps F = G_r ∘ … ∘ G_1 at the vertices; passing to the formal median transseries F̃ = G̃_r ∘ … ∘ G̃_1; proving F̃ is always accelero-summable, so its sum F is an analysable function which, if it differs from the identity, has only isolated fixed points. Analyticity enters through analysability+cohesivity (the formal transseries determines the map only within the analysable class — a flat C^∞ germ is invisible to the transseries). The author states the factors are each summable by Borel–Laplace without acceleration (single critical time each), that one immiscibility lemma of §4.6 was unproved at writing but not load-bearing, and that the proof is constructive (median accelero-summation is the only explicit reconstruction of F from F̃).
hypotheses: individual analytic planar vector field; return map near a polycycle (possibly reduced to a point or a cycle); analysable/cohesive function theory (closure under composition); real-coefficient formal transseries with exp/log stackings; accelero-summation through finitely many models.
holds-here: yes — this is the Test-1 answer for the Écalle route: the step that fails for C^∞ fields is analysability/cohesivity determining the map from its transseries.
status: asserted-by-source (author's own avant-propos page; book full text not held)
falsifier: A source showing Écalle's 1992 proof has a genuine unfillable gap (analogous to the Ilyashenko contention) would falsify the "proof complete as described" reading; a source showing analysable functions do not suffice to force isolated fixed points would falsify the method claim. The unproved immiscibility lemma does NOT falsify — the author states the acquired ones already suffice.
sources: https://www.imo.universite-paris-saclay.fr/~jean.ecalle/ecadulac.html
anchors: research/sources/ecalle-ecadulac-page.full.md (avant-propos, January 1991; full text of the page)
```
