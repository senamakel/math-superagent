###### Аннотация

We consider the multiplicity of limit cycles that appear when a hyperbolic polycycle is perturbed. We prove, in particular, that if such unfolding happens in generic finite-parameter families, the multiplicity of every new limit cycle does not exceed the number of separatrix connections in the polycycle.

—–

В статье рассматривается вопрос о кратности предельных циклов, рождающихся при разрушении произвольного гиперболического полицикла. В частности, доказано, что при возмущении внутри типичного конечно-параметрического семейства кратность любого родившегося предельного цикла не превосходит числа сепаратрисных связок, образующих полицикл.

## 1 Введение

Рассмотрим произвольное векторное поле v 0 v_{0} на двумерном многообразии ℳ \mathcal{M}. На протяжении всей статьи многообразие ℳ \mathcal{M} полагаем ориентируемым. Напомним определение полицикла:

###### Определение 1.

Полициклом векторного поля называется любой конечный ориентируемый граф Γ \Gamma, удовлетворяющий следующим требованиям:

- •

вершинами графа Γ \Gamma являются особые точки поля;

- •

рёбрами графа Γ \Gamma являются фазовые кривые поля, не являющиеся особыми точками; ориентация задаётся временем;

- •

граф Γ \Gamma — эйлеров (существует цикл, обходящий каждое ребро по одному разу).

Пусть поле v 0 v_{0} имеет некоторый полицикл γ \gamma. Рассмотрим k k -параметрическое семейство V = { v δ } V=\{v_{\delta}\}, δ ∈ B = ( ℝ k, 0) \delta\in B=(\mathbb{R}^{k},0), возмущающее данный полицикл. Будем говорить, что при разрушении полицикла γ \gamma поля v 0 v_{0} в семействе V V рождается предельный цикл (кратности m m), если существует такая стремящаяся к нулю (которому соответствует поле v 0 v_{0}) последовательность значений параметров { δ α } α ∈ ℕ \{\delta_{\alpha}\}_{\alpha\in\mathbb{N}}, что для любого α \alpha поле v δ α v_{\delta_{\alpha}} имеет предельный цикл L ​ C ​ ( δ α) LC(\delta_{\alpha}) (кратности m m), причём последовательность предельных циклов L ​ C ​ ( δ α) LC(\delta_{\alpha}) при δ α → 0 \delta_{\alpha}\to 0 стремится в метрике Хаусдорфа к полициклу γ \gamma или к его непустой части.

Максимальное число предельных циклов, которые рождаются при разрушении полицикла γ \gamma при переходе к близкому к v 0 v_{0} полю семейства, называется цикличностью данного полицикла. Полицикл называется элементарным, если он образован лишь элементарными особыми точками, то есть только особыми точками с хотя бы одним ненулевым собственным значением. Максимальная цикличность, которую может иметь нетривиальный элементарный полицикл, возмущаемый в типичном k k -параметрическом семействе, обозначается через E ⁡ ( k) E(k) или же E ⁡ ( n, k) E(n,k), где n n — число особых точек, образующих полицикл.

В 30-х годах Андронов и Леонтович, а несколько позже и Хопф доказали равенство E ⁡ ( 1) = 1 E(1)=1. С 1970-х по 1993гг. в результате трудов целого ряда математиков (Муртада, Руссари, Руссо, Дюмортье [DRR], Грозовский [Gr], Ройтенберг [R], Трифонов [Trif]) было получено равенство E ⁡ ( 2) = 2 E(2)=2. Подробнее об истории исследования цикличности полициклов коразмерности 1 и 2 см. [DRR]. В 1997 году Трифоновым получена оценка E ⁡ ( 3) = 3 E(3)=3 [Trif].

На рубеже веков были предприняты попытки оценить цикличность элементарных полициклов для произвольного числа параметров k k. В 1995 году Ильяшенко и Яковенко доказали, что для любого k k число E ⁡ ( k) E(k) конечно [IY]. В 2003 году в работе [K] Калошиным получена оценка:

 | E ⁡ ( k) ≤ 2 25 ​ k 2. \displaystyle E(k)\leq 2^{25k^{2}}. |  |

Чуть позже в 2010 году Каледа и Щуров [KS] доказали неравенство:

 | E ⁡ ( n, k) ≤ C ⁡ ( n) ​ k 3 ​ n, \displaystyle E(n,k)\leq C(n)k^{3n}, |  |

где C ⁡ ( n) = 2 5 ​ n 2 + 20 ​ n C(n)=2^{5n^{2}+20n}, n n — число вершин полицикла.

Как видно из приведённого обзора, ранние оценки были точны, но относились лишь к полициклам малой коразмерности. Поздние оценки, полученные Калошиным, Каледой и Щуровым, распространяются на произвольное число параметров, но при этом вряд ли являются точными. Это объясняется тем, что вопрос об оценке цикличности достаточно сложен.

В связи с этим возникает идея рассмотреть заведомо более простую задачу: какова максимальная кратность предельного цикла, рождающегося при разрушении полицикла в типичном конечно-параметрическом семействе? Обратим внимание, что в работе речь пойдёт не об элементарных, а лишь о гиперболических полициклах, то есть образованными лишь гиперболическими сёдлами. Оказывается, что поставленная задача легко решается для произвольного числа параметров, причём оценка кратности зависит от количества сёдел полицикла не более чем линейно.

#### Основные результаты.

Пусть поле v 0 v_{0} содержит полицикл γ \gamma, образованный n n сепаратрисными связками гиперболических сёдел S 1, …, S n S_{1},\ldots,S_{n} (некоторые из сёдел могут совпадать). Обозначим характеристические числа сёдел S 1, …, S n S_{1},\ldots,S_{n} через λ 1, …, λ n \lambda_{1},\ldots,\lambda_{n} соответственно. Напомним, что характеристическим числом седла называется модуль отношения собственных чисел, причём отрицательное стоит в числителе.

Основной результат работы представлен следующими двумя теоремами.

###### Теорема 1.

При возмущении полицикла γ \gamma в типичном n n -параметрическом семействе V V кратность любого рождающегося предельного цикла не превосходит n n.

Условие типичности следующее: характеристические числа λ 1, …, λ n \lambda_{1},\ldots,\lambda_{n} сёдел, образующих полицикл γ \gamma, должны удовлетворять неравенству

 | ℒ n ​ ( λ 1, …, λ n) ≠ 0, \displaystyle\mathcal{L}_{n}(\lambda_{1},\ldots,\lambda_{n})\neq 0, |  | (1) |

где ℒ n \mathcal{L}_{n} — некоторый нетривиальный многочлен. При заданном числе n n данный многочлен можно выбрать не зависящим ни от полицикла γ \gamma, ни от поля v 0 v_{0}.

Как будет видно далее в параграфе 2.6, из наличия кратного предельного цикла следует, что некоторая полиномиальная система однородных уравнений, коэффициенты которой зависят от характеристических чисел λ 1, …, λ n \lambda_{1},\ldots,\lambda_{n}, имеет нетривиальное решение. Забегая вперёд, отметим, что многочлен ℒ n \mathcal{L}_{n} выражается через результант данной полиномиальной системы.

###### Следствие.

Пусть поле v 0 ∈ V ​ e ​ c ​ t ∞ ​ ( ℳ) v_{0}\in Vect^{\infty}(\mathcal{M}) имеет описанный выше полицикл γ \gamma. Пусть характеристические числа сёдел данного полицикла удовлетворяют неравенству ( 1). Тогда при возмущении поля v 0 v_{0} в пространстве V ​ e ​ c ​ t ∞ ​ ( ℳ) Vect^{\infty}(\mathcal{M}) из полицикла γ \gamma не рождается предельный цикл кратности больше n n.

###### Доказательство.

Предположим, что существует последовательность полей v k → v 0 v_{k}\to v_{0}, содержащих предельный цикл L ​ C ​ ( v k) LC(v_{k}) кратности n + 1 n+1 или более, причём данный цикл стремится при k → ∞ k\to\infty к полициклу γ \gamma. Тогда рассмотрим такое n n -параметрическое семейство V: ℝ n → V ​ e ​ c ​ t ∞ ​ ( ℳ) V:\mathbb{R}^{n}\to Vect^{\infty}(\mathcal{M}), что для любого натурального k k отрезок δ 1 ∈ [1 k, 1 k + 1] \delta_{1}\in[\frac{1}{k},\frac{1}{k+1}] переходит в отрезок [v k, v k + 1] [v_{k},v_{k+1}], луч δ 1 ∈ [1, + ∞) \delta_{1}\in[1,+\infty) отображается в поле v 1 v_{1}, а луч δ 1 ∈ ( − ∞, 0] \delta_{1}\in(-\infty,0] — в поле v 0 v_{0}. Зависимость от остальных параметров δ 2, …, δ n \delta_{2},\ldots,\delta_{n} полагаем фиктивной. Тогда семейство V V удовлетворяет описанному выше условию типичности. Таким образом, приходим к противоречию с теоремой 1. ∎

В случае полицикла малой коразмерности многочлен ℒ n \mathcal{L}_{n} можно выписать явно. Для этого нам потребуется определить несколько многочленов.

Для любого натурального n n обозначим через Λ n \Lambda_{n} следующий многочлен от характеристических чисел λ 1, …, λ n \lambda_{1},\ldots,\lambda_{n}:

 | Λ n ​ ( λ 1, …, λ n) = ∏ I ≠ ( 0, …, 0) ( λ I − 1), \displaystyle\Lambda_{n}(\lambda_{1},\ldots,\lambda_{n})=\prod\limits_{I\neq(0,\ldots,0)}(\lambda^{I}-1), |  |

где I = ( i 1, …, i n) I=(i_{1},\ldots,i_{n}) — мультииндекс. Через λ I \lambda^{I} мы обозначили произведение λ 1 i 1 ​ … ​ λ n i n \lambda_{1}^{i_{1}}\ldots\lambda_{n}^{i_{n}}. Для любого j = 1, …, n j=1,\ldots,n компонента мультииндекса i j ∈ { 0, 1 } i_{j}\in\{0,1\} определяет, входит ли число λ j \lambda_{j} в произведение λ I \lambda^{I} или нет. Например, Λ 2 ​ ( λ 1, λ 2) = ( λ 1 − 1) ​ ( λ 2 − 1) ​ ( λ 1 ​ λ 2 − 1) \Lambda_{2}(\lambda_{1},\lambda_{2})=(\lambda_{1}-1)(\lambda_{2}-1)(\lambda_{1}\lambda_{2}-1).

Помимо этого, через M ⁡ ( λ 1, λ 2, λ 3) M(\lambda_{1},\lambda_{2},\lambda_{3}) обозначим следующий многочлен:

 | M ⁡ ( λ 1, λ 2, λ 3) = 4 ​ ( λ 1 ​ λ 2 ​ λ 3 − 1) − ( λ 1 − 1) ​ ( λ 2 − 1) ​ ( λ 3 − 1). \displaystyle M(\lambda_{1},\lambda_{2},\lambda_{3})=4(\lambda_{1}\lambda_{2}\lambda_{3}-1)-(\lambda_{1}-1)(\lambda_{2}-1)(\lambda_{3}-1). |  |

###### Теорема 2.

При n = 1, 2, 3, 4 n=1,2,3,4 в качестве многочлена ℒ n \mathcal{L}_{n}, задающего условие типичности ( 1), можно взять следующие многочлены:

2. 2.

ℒ 3 ​ ( λ 1, λ 2, λ 3) = Λ 3 ​ ( λ 1, λ 2, λ 3) \mathcal{L}_{3}(\lambda_{1},\lambda_{2},\lambda_{3})=\Lambda_{3}(\lambda_{1},\lambda_{2},\lambda_{3});

4. 4.

ℒ 4 ( λ 1, λ 2, λ 3, λ 4) = Λ 4 ( λ 1, λ 2, λ 3, λ 4) ⋅ \mathcal{L}_{4}(\lambda_{1},\lambda_{2},\lambda_{3},\lambda_{4})=\Lambda_{4}(\lambda_{1},\lambda_{2},\lambda_{3},\lambda_{4})\cdot

⋅ M ⁡ ( λ 1, λ 2, λ 3) ​ M ​ ( λ 1, λ 2, λ 4) ​ M ​ ( λ 1, λ 3, λ 4) ​ M ​ ( λ 2, λ 3, λ 4). \cdot M(\lambda_{1},\lambda_{2},\lambda_{3})M(\lambda_{1},\lambda_{2},\lambda_{4})M(\lambda_{1},\lambda_{3},\lambda_{4})M(\lambda_{2},\lambda_{3},\lambda_{4}).

Вся работа разбита на два раздела. Первый раздел целиком занимают промежуточные вычисления, основная задача которых — свести вопрос о наличии кратного предельного цикла к наличию решения некоторой системы алгебраических уравнений. ## 2 От векторных полей к многочленам

### 2.1 Отображения соответствия сёдел

На протяжении всей статьи полагаем, что выполнены условия теоремы 1. К каждой сепаратрисной связке полицикла γ \gamma проведём C ∞ C^{\infty} -гладкую трансверсаль: для любого i = 1, …, n i=1,\ldots,n трансверсаль к связке сёдел S i S_{i} и S i + 1 S_{i+1} обозначим через Γ i \Gamma_{i} (рис. 1 a). Также считаем, что для любого i = 1, …, n i=1,\ldots,n трансверсаль Γ i \Gamma_{i} не зависит от параметра δ \delta и параметр δ \delta выбирается настолько малым, что каждая из трансверсалей Γ i \Gamma_{i} остаётся трансверсалной возмущённому полю v δ v_{\delta}.

В поле v δ v_{\delta} рассмотрим произвольное седло S i ​ ( δ) S_{i}(\delta) и две соседние к нему трансверсали Γ i − 1 \Gamma_{i-1} и Γ i \Gamma_{i} (полагаем, что Γ 0 = Γ n \Gamma_{0}=\Gamma_{n}). Точку пересечения трансверсали Γ i − 1 \Gamma_{i-1} и входящей сепаратрисы седла S i ​ ( δ) S_{i}(\delta) обозначим через s i ​ ( δ) s_{i}(\delta) (от слова <<stable>>). Точку пересечения трансверсали Γ i \Gamma_{i} и выходящей сепаратрисы седла S i ​ ( δ) S_{i}(\delta) обозначим через u i ​ ( δ) u_{i}(\delta) (от слова <<unstable>>).

Точка s i ​ ( δ) s_{i}(\delta) делит трансверсаль Γ i − 1 \Gamma_{i-1} на две полутрансверсали: фазовые кривые, начинающиеся с одной из полутрансверсалей, проходят вдоль седла S i ​ ( δ) S_{i}(\delta) и либо покидают окрестность полицикла, либо пересекают трансверсаль, отличную от Γ i \Gamma_{i} (здесь и далее речь идёт о первом пересечении с любой из трансверсалей); фазовые кривые, начинающиеся с другой полутрансверсали, проходят вдоль седла S i ​ ( δ) S_{i}(\delta) и пересекают трансверсаль Γ i \Gamma_{i}. Последнюю из этих двух полутрансверсалей обозначим через Γ i − 1 − ​ ( δ) \Gamma_{i-1}^{-}(\delta).

Выберем на трансверсали Γ i − 1 \Gamma_{i-1} такой натуральный параметр (карту), что точка s i ​ ( δ) s_{i}(\delta) имеет в этой карте координату 0, а любая точка полутрансвесали Γ i − 1 − ​ ( δ) \Gamma_{i-1}^{-}(\delta) имеет положительную координату.

Точка u i ​ ( δ) u_{i}(\delta) делит трансверсаль Γ i \Gamma_{i} на две полутрансверсали. Ту из этих полутрансверсалей, которую пересекают фазовые кривые, берущие начало с полутрансверсали Γ i − 1 − ​ ( δ) \Gamma_{i-1}^{-}(\delta), обозначим через Γ i + ​ ( δ) \Gamma_{i}^{+}(\delta). Выберем на трансверсали Γ i \Gamma_{i} такой натуральный параметр (карту), что точка u i ​ ( δ) u_{i}(\delta) имеет в этой карте координату 0, а любая точка полутрансверсали Γ i + ​ ( δ) \Gamma_{i}^{+}(\delta) имеет положительную координату.

Таким образом, на каждой трансверсали Γ i \Gamma_{i} нами выбраны две карты. Обозначим координату точки u i ​ ( δ) u_{i}(\delta) в карте, соответствующей полутрансверсали Γ i − ​ ( δ) \Gamma_{i}^{-}(\delta), через τ i ​ ( δ) \tau_{i}(\delta). Тогда переход из карты, соответствующей полутрансверсали Γ i + ​ ( δ) \Gamma_{i}^{+}(\delta), в карту, соответствующую полутрансверсали Γ i − ​ ( δ) \Gamma_{i}^{-}(\delta), осуществляется отображением x ↦ τ i ​ ( δ) ± x x\mapsto\tau_{i}(\delta)\pm x.

### 2.2 Уравнения на кратные предельные циклы

Пусть при некотором значении δ \delta поле v δ v_{\delta} имеет предельный цикл L ​ C ​ ( δ) LC(\delta), родившийся при разрушении исходного полицикла γ \gamma. Пусть этот цикл пересекает полутрансверсаль Γ n − ​ ( δ) \Gamma_{n}^{-}(\delta) в точке с координатой x 0 = x 0 ​ ( δ) x_{0}=x_{0}(\delta). Тогда отображение Пуанкаре имеет неподвижную точку, то есть пара ( δ, x 0 ​ ( δ)) (\delta,x_{0}(\delta)) является решением уравнения:

 | Δ ⁡ ( δ, x) = x. \displaystyle\Delta(\delta,x)=x. |  | (4) |

Если же предельный цикл имеет кратность n + 1 n+1 или более, то при x = x 0 ​ ( δ) x=x_{0}(\delta) также выполнены следующие равенства:

 | Δ ′ ​ ( δ, x) = 1, \displaystyle\Delta^{\prime}(\delta,x)=1, |  | (5) |

 | Δ ( l + 1) ( δ, x) = 0, l = 1, …, n − 1. \displaystyle\Delta^{(l+1)}(\delta,x)=0,\quad l=1,\ldots,n-1. |  | (6) |

На протяжении всей статьи под производными ( ⋅) ′ (\cdot)^{\prime} и ( ⋅) ( l) (\cdot)^{(l)} будем понимать производную по аргументу x x. Рассмотрим функцию

 | 𝒟 ⁡ ( δ, x) = ln ⁡ Δ ′ ​ ( δ, x) \displaystyle\mathcal{D}(\delta,x)=\ln\Delta^{\prime}(\delta,x) |  | (7) |

## 6 Открытые вопросы

Мы начали статью с описания имеющихся на сегодняшний день результатов, касающихся оценки цикличности полициклов. Может ли изучение кратных предельных циклов помочь в оценке цикличности? Да. Но лишь в оценке снизу. Это можно сформулировать в виде следующих двух гипотез.

Пусть γ \gamma — гиперболический полицикл поля v 0 v_{0} на двумерном ориентируемом многообразии, образованный n n (возможно, совпадающими) сёдлами с характеристическими числами λ 1, …, λ n \lambda_{1},\ldots,\lambda_{n}.

###### Гипотеза 1.

Существует такое открытое подмножество U ⊂ ℝ > 0 n U\subset\mathbb{R}^{n}_{>0}, что для любого набора характеристических чисел ( λ 1, …, λ n) ∈ U (\lambda_{1},\ldots,\lambda_{n})\in U в типичном n n -параметрическом семействе, возмущающем полицикл γ \gamma, рождается предельный цикл кратности n n ( n n предельных циклов).

###### Гипотеза 2.

Существует такое открытое (в индуцированной топологии) подмножество W W поверхности { ( λ 1, …, λ n) ∈ ℝ > 0 n | λ 1 ​ … ​ λ n = 1 } \{(\lambda_{1},\ldots,\lambda_{n})\in\mathbb{R}^{n}_{>0}|\lambda_{1}\ldots\lambda_{n}=1\}, что для любого набора характеристических чисел ( λ 1, …, λ n) ∈ W (\lambda_{1},\ldots,\lambda_{n})\in W в типичном ( n + 1) (n+1) -параметрическом семействе, возмущающем полицикл γ \gamma, рождается предельный цикл кратности n + 1 n+1 ( n + 1 n+1 предельный цикл).

В обеих гипотезах типичнось подразумевает, что семейство размыкает каждую сепаратрисную связку с ненулевой скоростью. Вполне вероятно, что доказательство этих двух гипотез станет основным сюжетом следующей статьи.
