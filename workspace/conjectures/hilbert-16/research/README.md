# Reference-set report

This folder contains the local reference library for Hilbert's sixteenth problem, second part. See `research/REFERENCE-SET-REPORT.md` for the source inventory and exact URLs. The library includes primary treatments of DRR quadratic graphics, nilpotent and saddle-node normal forms, elementary polycycle cyclicity, Écalle–Ilyashenko individual finiteness, Abelian-integral/Picard–Fuchs bounds, Bautin local cyclicity, lower bounds, slow–fast counterexamples, and recent status papers. Full texts are under `research/sources/`; bounded digests are under `research/summaries/`.

The phase-1 stopping criterion in `research/ROOT.md` is met. The central open issue remains uniform finite cyclicity for degenerate quadratic graphics, not individual-field finiteness. No source in this set justifies claiming H(n)<∞ or H(2)=4.
