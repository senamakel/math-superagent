# Librarian cycle — 2026-08-18

## Scope
The objective is Hilbert's 16.2: for polynomial planar vector fields X=(P,Q), max degree ≤ n, whether a uniform finite H(n) bounds isolated periodic orbits. The object used by bifurcation theory is the displacement function (return map minus identity), not numerical orbit plots.
