# Reference-set update: Gavrilov two-saddle cycles

The local library now includes `research/sources/primary-gavrilov-two-saddle-cycles-2011.full.md`, downloaded from https://arxiv.org/abs/1106.0857. Its summary and source-backed claim are in `research/summaries/primary-gavrilov-two-saddle-cycles-2011.md`.

This source adds a restricted analytic result: finite cyclicity of heteroclinic two-saddle cycles in analytic finite-parameter families, via complex continuation and the argument principle/Petrov trick. It is relevant to the displacement-function methodology because it avoids the invalid inference from an asymptotic Dulac expansion alone; it does not settle uniform H16.2 or arbitrary nilpotent/degenerate graphics.

The reference set was already sufficient for Phase 1: `research/ROOT.md` records the minimal counterexample structure, verification boundary, and at least three settled restricted classes. No source downloaded here establishes `H(n)<∞` or `H(2)=4`.
