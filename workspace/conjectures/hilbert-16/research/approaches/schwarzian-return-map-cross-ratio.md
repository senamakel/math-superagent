```approach
slug: schwarzian-return-map-cross-ratio
status: narrowed
idea: Bound fixed points of a one-dimensional return map P through the Schwarzian derivative S(P)=P'''/P' − (3/2)(P''/P')² and cross-ratio distortion (Singer/Kozlovski): a certified global sign of S(P) plus endpoint multiplier data forces an alternating fixed-point pattern.
mechanism: S(P)<0 is equivalent to strict convexity of |P'|^{-1/2} and implies cross-ratio expansion; Singer-type results constrain attracting periodic orbits via critical/boundary points. This is real for maps with a critical point, but the analytic planar Poincare return map on a regular transversal is normally an orientation-preserving diffeomorphism with no critical point, so the hypotheses do not transfer.
precedent: https://www.sciencedirect.com/science/article/pii/S0022039696901771 (Schwarzian return-map limit-cycle bounds in a nonsmooth class); https://doi.org/10.48550/arxiv.math/0011266 (Kozlovski, cross-ratio/negative-Schwarzian theorems); https://doi.org/10.3934/dcds.2009.24.1393 (Webb, Singer/cross-ratio framework); claim:h16-drr-121-graphics

killed-by: As a general route to the DRR/H16 displacement it fails: an analytic planar Poincare return map on a regular transversal is an orientation-preserving local diffeomorphism, not a unimodal map with a nonflat critical point, so the Kozlovski/Singer hypotheses do not transfer, and no theorem turns a certified sign of S(P) plus endpoint multiplier data into a universal finite fixed-point bound for the nonhyperbolic return maps.
first-step: (none adopted — kept only for the surviving restricted class; revive when a return map with a proved critical point and global S(P) sign is in hand)
```

**Why not adopted.** Research moved this to `narrowed` and it stays there: the honest status is that the method survives only on a restricted class (piecewise-smooth/unimodal/Abel-reduction return maps with a proved critical point and global Schwarzian sign), and the general hypothesis set fails for the analytic planar Poincare maps that carry the DRR displacement. Adopting it now would mean spending an attempt proving a critical point exists where the generic answer is that it does not. The surviving restriction is retained for the case where a future reduction produces a genuinely unimodal one-dimensional map; it is not the line for this pass.
