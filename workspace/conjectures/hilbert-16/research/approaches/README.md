# Approaches — the lines of attack this run has considered

One file per candidate, `<slug>.md`, each carrying a fenced `approach` block.
`derived/APPROACHES.md` beside this folder is derived from them and is not
yours to edit.

This folder exists from the first second of a run because the inventor is told
to write here before it reports, and a directory the prompt names must be a
directory. On PE620 it was not: the inventor spent eight model calls, read the
two files recording that both oracle models had failed — exactly the right place
to start — and then `list_workspace research/approaches` returned
`is not a directory in the workspace`. The run's approach ledger stayed empty
while the cheapest question in the runtime, "is there a different line of
attack", had already been answered and had nowhere to go.

Record why a line was dropped as carefully as why one was taken up. A known dead
end is a result, and the reason it died is what stops the next attempt paying
for it again.
