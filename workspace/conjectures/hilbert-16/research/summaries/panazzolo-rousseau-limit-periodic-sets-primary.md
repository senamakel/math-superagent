# Panazzolo–Rousseau 2017 — topological classification (primary digest)

Full text: [[panazzolo-rousseau-limit-periodic-sets-primary.full]]
(arXiv:1702.04965, published QTDS 2020).

## What is established

**Theorem 1.3 (main):** for polynomial planar families, every limit periodic set Γ
compactifies (via Bendixson) to a connected semialgebraic subset of 𝕊² of dimension 0
or 1 up to homeomorphism; conversely every nonempty closed semialgebraic connected
set of dimension 0 or 1 (with connected compactification) occurs as a limit periodic
set of some polynomial family.

**Proposition 1.2:** the compactified candidate is a singular point, periodic orbit,
polycycle, or degenerate limit cycle (non-isolated singularities).

**Definition 1.1 (limit periodic set):** Hausdorff limit of limit cycles γ_n of
fields X_{λ_n} with λ_n → λ₀ — the exact object the Roussarie/DRR reduction operates
on.

## What it lets this run conclude

- The structural topological underpinning of the Roussarie/DRR reduction is complete:
  the objects whose finite cyclicity must be proved are exactly the four
  Poincaré–Bendixson types, and no smaller topological class suffices (the converse
  direction shows all semialgebraic 0/1-dimensional connected sets arise). The DRR
  program is the case-by-case analysis for the quadratic family (source's own words:
  "divided in 121 case-by-case analysis based on the limit periodic sets").
- Does not prove finite cyclicity or H(2)<∞.
