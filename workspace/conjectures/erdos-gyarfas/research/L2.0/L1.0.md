# L1.0 — seal: the conjecture's primary statement, the structure of a minimal counterexample, and the restricted classes settled

Seal of `research/L1.0/`, ten digest notes. The full texts they digest live in
`research/L0.0/` (already sealed by `research/L1.2/L0.0.md`). Two pairs are twins of the
same paper (Carr PDF/abs; Sudakov–Verstraëte PDF/abs), so ten notes carry eight distinct
sources. All hypotheses are stated as in the source. This batch is the run's *foundation*
layer: it pins the exact target, the structural facts a minimal counterexample must obey,
and which restricted classes are already closed (so the run does not re-derive them).

## 1. The exact statement — what the run is proving

[[erdosproblems-open-Er96]] (primary, via erdosproblems.com, curated T.F. Bloom; cites
Erdős's own Er93 p.343, Er94b, Er95 p.174, Er96, Er97b, Er97c) and [[wikipedia-erdos-gyarfas]]
(secondary) agree on the target:

> Every finite simple graph with minimum degree ≥ 3 contains a simple cycle whose length is
> a power of 2 — equivalently 2^k for some k ≥ 2, i.e. length in {4, 8, 16, …}. (A simple
> graph has no 2-cycle, so powers below 4 are excluded automatically.)

_Holds here:_ this is exactly the statement to attack. **Finiteness is essential** — the
Erdős Problems note records that an infinite min-degree-3 tree is a trivial counterexample;
every *finite* instance is the domain. **Prizes:** Erdős offered $100 proof / $50
counterexample (Wikipedia). **Date:** sources disagree — 1995 (Wikipedia), 1994 (Hegde),
a 1993–96 range (Erdős Problems, multiple Er pages). Safe: "mid-1990s".

**Critical provenance — original belief.** The Erdős Problems page states that Erdős and
Gyárfás themselves **believed the answer was negative**, and asserted the *stronger* claim
that for every r there is a min-degree-r graph with no power-of-2 cycle. That stronger
claim is **disproved by Liu–Montgomery** (see obstruction note below). The run should treat
"conjecture" as "unresolved, and originally expected false" — not as something the
proposers were sure is true.

## 2. The structure of a minimal counterexample — the run's central anchor

[[carr-minimal-counterexample-cubic]] [[carr-minimal-counterexample-cubic-pdf]] (Carr,
"Every Minimal Counterexample to the Erdős–Gyárfás Conjecture is Predominantly Cubic",
arXiv:2605.22844). Define a **minimal counterexample** G = graph of minimum possible order
*and* size with δ≥3 and no power-of-2 cycle. About any such G, Carr proves:

- **Lemma 0.1:** δ(H) ≤ 2 for every proper subgraph H ⊊ G (every proper subgraph has a
  vertex of degree ≤ 2). *Holds here:* yes — this is exactly the minimality structure the
  run reasons with.
- **Cor 0.2:** if G is regular, G is cubic. (Via Markström's observation: any minimal
  counterexample has an independent set of degree-≥4 vertices *and* a nonempty set of
  degree-3 vertices; equal degrees force 3.)
- **Theorem 0.1:** at least 4/7 of the vertices of G have degree exactly 3.
- Every vertex of G is adjacent to a vertex of degree exactly 3.

*Use:* the minimal-counterexample argument never handles a regular case beyond cubic, and
the degree-3 vertices are dense (≥4/7) and dominate the graph by adjacency. These are the
input hypotheses any structural lemma the run states must respect — and the natural
counterexample to hunt is predominantly cubic with δ=3.

## 3. The computational verification bound — the oracle anchor

[[wikipedia-erdos-gyarfas]] gives the bounds the run's brute-force oracle must reproduce
and exceed:
- Any counterexample has **≥ 17 vertices** (searches of Gordon Royle and Klas Markström).
- Any **cubic** counterexample has **≥ 30 vertices**.
- Markström found **four graphs on 24 vertices** whose only power-of-2 cycle has length 16;
  **one of the four is planar**.
- The conjecture is **proved true for 3-connected cubic planar graphs** (Heckman–Krakovski,
  below) — so that 24-vertex planar near-counterexample is necessarily *not* 3-connected.
- Stated open for bipartite graphs.

*Use:* 17 (all graphs) and 30 (cubic) are the floors to reproduce; the four 24-vertex
near-counterexamples are concrete extremal test inputs for any checker. Exhaustive search
below ~17–30 is settled, so Phase-3 counting only *extends* past these — it never
re-derives them.

## 4. Restricted classes already closed (do not re-derive)

- **3-connected cubic planar** — [[heckman-krakovski-cubic-planar]] (Heckman & Krakovski,
  "Erdős–Gyárfás Conjecture for Cubic Planar Graphs", Electron. J. Combin. 20(2) #P7,
  2013, DOI 10.37236/3252). Proved; long, computer-based in parts, uses the Discharging
  Method in a novel way. Needs 3-connectivity as well as cubic planar.
- **P13-free** — [[hegde-sandeep-shashank-p13-free]] (Hegde, Sandeep & Shashank,
  arXiv:2410.22842; computer-aided). **Theorem 1:** every P13-free graph with δ≥3 has a
  power-of-two cycle. **Theorem 2:** every P12-free graph with δ≥3 has a 4- or 8-cycle.
  Method `explore(G,k)`; Corollary 1 — if G* is a minimal counterexample and k the smallest
  integer with G* Pk-free but containing an induced P_{k−1}, then explore returns False.
- **P8-free** — [[gao-shan-p8-free]] (Gao & Shan, arXiv:2109.01277, Graphs and
  Combinatorics 2022). **Theorem 1.2:** every P8-free graph with δ≥3 contains a *4-cycle*.
  **Theorem 1.1:** every P5-free graph with δ≥3 contains a 4-cycle.
- **P10-free** — Hu & Shen 2024 (proved, cited inside Hegde; not itself in this batch).
- **Planar claw-free** and **K_{1,m}-free with degree constraints** — [[west-openproblems-2powcyc]]
  (West's open-problem page): Daniel & Shauger proved planar claw-free [DS 2001]; Shauger
  proved K_{1,m}-free graphs with min degree ≥ m+1 or max degree ≥ 2m−1 [S 1998]. West's
  page also records **Yair Caro's weaker suggestion**: every min-degree-3 graph has a cycle
  whose length is a nontrivial power of *some* natural number (not necessarily 2).
- **Large average (hence large min) degree** — Liu–Montgomery (stated in
  [[erdosproblems-open-Er96]] and [[hegde-sandeep-shashank-p13-free]]).

## 5. The cycle-spectrum / sparse-graph bound — the likely engine

[[sudakov-verstraete-sparse]] [[sudakov-verstraete-sparse-pdf]] (Sudakov & Verstraëte,
"Cycle lengths in sparse graphs", arXiv:0707.2117). Two parts:

- **Part 1 (cycle spectrum):** for avg degree d and girth g, |C(G)| = Ω(d^{⌊(g−1)/2⌋})
  (proves an Erdős conjecture; tight via d-regular Moore graphs). Also Ω(d^{⌊(g−1)/2⌋})
  *odd* cycle lengths for chromatic number d and girth g; H-free graphs of avg degree d
  give Ω(d^{t/(t−1)}) consecutive even integers.
- **Part 2 (EG-bearing):** for any infinite exponentially-bounded even sequence σ, an
  n-vertex graph with *no σ-cycle* has average degree **exp(O(log* n))** (Cor 1.4). The
  powers of two form such a σ, so:
  - **a counterexample to EG has average degree ≤ exp(O(log* n))** — it cannot be dense;
  - combined with δ≥3 (avg degree ≥ 3), a counterexample's density is pinned between 3 and
    exp(O(log* n)). This is probably the single most exploitable external bound: any
    structural argument may assume the counterexample is *sparse*.

## 6. Obstruction note (carried from MEMORY.md, arithmetic)

An interval-of-cycle-lengths result on [a, b] forces a power of two only when **b ≥ 2a**,
because the gap below 2^{k+1} is 2^k. So any "interval of lengths" guarantee must either
hit a power of two directly or span a factor of two. This is the obstruction every approach
must beat, and it is why Liu–Montgomery's huge even-length interval settles only
large-average-degree: outside that regime the length-sets a δ=3 graph is guaranteed to have
(as in the admissible-cycle machinery, below) are too sparse to force a power of two by
this argument alone.

## 7. Agreements and disagreements across the batch

- **Agreement:** the conjecture is open, min degree 3 is the threshold, finiteness is
  essential, verification floor 17 (all) / 30 (cubic), and the restricted classes listed
  above are all confirmed. The batch is internally consistent on every substantive result.
- **Disagreement — date:** 1995 (Wikipedia) vs 1994 (Hegde) vs 1993–96 (Erdős Problems).
  Resolve as "mid-1990s"; cite the Erdős papers if precision matters.
- **Disagreement — original belief:** Erdős Problems says the proposers believed it false
  (stronger claim, later disproved by Liu–Montgomery); the common textbook framing
  "conjectured true" is therefore not what the proposers believed. Not a contradiction in
  facts, but a difference in framing the run should keep in view: the safe prior is that a
  counterexample may exist.

## 8. What this batch lets the run bound, compute, or rule out

- **Structure of a counterexample:** predominantly cubic — ≥4/7 degree-3 vertices, every
  vertex adjacent to a degree-3 vertex, regular ⇒ cubic (Carr). Cheaper on structure than
  the run could have hoped.
- **Density of a counterexample:** avg degree between 3 and exp(O(log* n)) (Sudakov–
  Verstraëte + δ≥3) — sparse.
- **Oracle targets:** reproduce n≥17 (all graphs), n≥30 (cubic), and the four 24-vertex
  only-16-cycle graphs as correctness checks.
- **Restricted classes already closed** (never re-derive): P13-free, P10-free, P8-free,
  3-connected cubic planar, claw-free planar, K_{1,m}-free with the stated degree
  constraints, large average degree.
- **Cycle-length machinery to reach for** (in the neighboring L1.1 batch): admissible
  cycles (min degree k+1 ⇒ k of them — Dean, Gao–Huo–Liu–Ma), mod-k cycle lengths,
  consecutive-length cycles, the trigonal/tetragonal framework — the tools that might turn
  a sparse-graph structure into a power-of-two cycle.

**Bottom line for the run:** the target is fixed and sparse; a minimal counterexample is
predominantly cubic with redundant degree-3 neighbourhoods; and every restricted class so
far settled (paths, cubic planar 3-connected, claw-free, large degree) is *not* where the
run should look — the open ground is general graph structure near δ=3, which this batch
says is cubic-dominated and sparse, and which Sat/SMT and structural argument must now
probe beyond n=30.
