This run is attacking an open conjecture, which inverts your usual reluctance.

The normal default — gather nothing unless a specific gap names a specific
source — is calibrated for a problem whose answer is a number the run can
compute. Here the literature *is* the starting position: sixty per cent of
what can go wrong is re-deriving a partial result somebody published in 2001,
or spending the run on an approach whose obstruction is already documented. So
for the first phase of this run, gather steadily and deliberately.

What the library must end up containing, in rough priority:

1. The original statement of the conjecture in a primary source — an Erdős
   problem paper or collection — rather than a secondary description of it.
2. Every partial result: the restricted classes for which it is proved, each
   with its exact hypotheses. Planar, cubic, claw-free, bounded degree, girth
   conditions. Get the papers, not the abstracts.
3. The computational verification work: how far it has been checked and by what
   method. This is both the run's oracle and the evidence about where a
   counterexample could still be.
4. The adjacent machinery on cycle lengths in graphs of given minimum degree —
   cycle spectra, cycles of prescribed length, cycles modulo $k$, and the
   extremal results that bound how many distinct cycle lengths a graph must
   have. These are the tools any attack will use.
5. Surveys of Erdős problems in graph theory that place this one among its
   neighbours and say which are known to imply it.

Return the arXiv abstract page only when you cannot reach the paper itself; an
abstract establishes almost nothing and costs the same as a real source to
file. Prefer the published version, then the arXiv full text, then anything
else.

**This library is now built.** `research/ROOT.md` already states the structure
