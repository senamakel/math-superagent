# OEIS A055513 — full class number h = h^-·h^+ of Q(ζ_p), p = prime(n)

Source: https://oeis.org/A055513 (catalogued term list; not a proof source).

## What this source is

The **full class number** `h(Q(ζ_p)) = h^+·h^-` of the cyclotomic field
`Q(ζ_p)`, `p = prime(n)`, `n ≥ 2` (term 1 = h(3) = 1). The entry's own
cross-references state the structural fact behind term equality with A000927:

- `h^+(p)` is the class number of the real subfield
  `Q(ζ_p + ζ_p^{-1})`; primes with `h^+(p) ≠ 1` are `A230869`.
- `a(n) = A000927(n)` if `prime(n) ∉ A230869`, else `A000927(n) · A230870(m)`.
- The comment "agrees for the first 36 terms, assuming GRH" is loose: reading
  the two **full term lists** against each other, they are identical through
  term 37 (p = 163) and first differ at term 38 (p = 167), where
  `A055513(167) = 4 × A000927(167)` — that is, `h^+(167) = 4` is the first
  non-trivial plus class number on the list.

## What it establishes for this problem

The `h = h^-` span (p ≤ 163 in fact, GRH) is *conjectural*, not proved — the
known `h^+` values are few and hard (Schoof: `h^+` not known for a single prime
`p ≥ 71`; run holds `plus-class-proxy-bounds-true`, `minus-class-computable-plus-not`).
So this catalogue:
- **corroborates the plus/minus split**: `h = h^-·h^+`, with `h^-` computable
  and `h^+` not certifiable past p ≥ 71;
- **pins the first non-trivial plus part** at p = 167 (`h^+(167)=4`) from the
  term lists — a concrete fact the run can state, but only as a catalogued one
  (the value depends on a GRH-computed `h^+`, not a proof).

## Relation to A000927 (same digit span)

`A055513` and `A000927` diverge exactly where the plus part first stops being 1:
at p = 167, `h^+(167) = 4`, ratio exactly 4. Beyond that the divergence keeps
growing with the multiplicative `h^+`. For the run, `A000927` (the computable
minus half) is the quantity a descent evaluates; `A055513` adds only that the
*full* class number is never certifiable past p ≥ 71, which the run already
holds from the plus-minus split. This entry adds no new lemma, only corroborates.

## Caveats

- The `h = h^-` span and the `h^+(167)=4` value are **GRH-conditional / not
  re-derived** here — term-by-term re-derivation needs the plus class number,
  which is exactly what cannot be certified for p ≥ 71. `status: catalogued`,
  not checked.
- The known solution `3^2-2^3=1` has p=2 (even); no `Q(ζ_p)` with p odd prime
  is involved, so this catalogue never excludes it.
