# OEIS A000927 — relative class number h^- of Q(ζ_p), p = prime(n)

Source: https://oeis.org/A000927 (catalogued term list; not a proof source).

## What this source is

The **minus (relative) class number** `h^-(Q(ζ_p))` of the cyclotomic field
`Q(ζ_p)`, indexed by `p = A000040(n)`, for `n ≥ 2` (term 1 = h^-(3) = 1).
It is a catalogue of the order of the minus part of the class group — the exact
obstruction the both-odd-prime case of `x^p - y^q = 1` sits in.

## Closed forms the entry gives (this is why it is not just a table)

- **Alekseyev determinant**: `a(n) = |det M|`, `M_{ij} = ⌊i·j/p⌋ − ⌊(i−1)·j/p⌋`,
  `3 ≤ i,j ≤ (p−1)/2`, `p = prime(n)`. Determinant of a `((p−3)/2)²` integer
  matrix — exact, computable.
- Bernoulli product (run's route): `h^- = 2p·∏_{χ odd mod p} (−½ B_{1,χ})`,
  `B_{1,χ} = (1/p)Σ_{a} χ(a)a` (Washington Thm 4.17, Shokrollahi eq. 2.1).

## Structure the terms certify (read off the catalogue, exact over the span)

- **Trivial region**: `h^- = 1` for all odd primes p ≤ 19.
- **First value > 1**: `h^-(23) = 3`. (The earlier approach note and a first
  draft of this digest called p=29 the first > 1 — wrong; the captured output
  `p=23 → 3` is authoritative.)
- **First even value**: `h^-(29) = 8`.
- **Irregular primes**: `p | h^-(p)` exactly at p ∈ {37, 59, 67} for p < 100
  (p-torsion of the class group, the irregular/regular split), and at no regular
  p < 100.
- **Washington-table errata the entry itself flags**: Washington gave a(17)=
  41421 (p=59) and a(25)=411322842001 (p=97), both wrong; correct values (2nd
  edition) are 41241 and 411322824001 — which is what the run reproduces. A
  trap avoided: quoting the 1st-edition table would have propagated an error.
- No linear recurrence of order ≤ 8 fits; h^- grows near-exponentially
  (p=97 → 4.1e11). No shortcut to the minus class number of the simple kinds.

## Caveats

- Exact over p ≤ 97 is verified-numerically, not a proof for all p; the closed
  form itself is the classical analytic class number formula
  (asserted-by-source, `minus-class-number-formula`).
- `h^-` is a quantity a descent *evaluates*; this catalogue proves nothing about
  the equation `x^p - y^q = 1` by itself.
