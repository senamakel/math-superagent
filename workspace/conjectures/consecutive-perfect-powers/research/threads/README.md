# Threads — the directions this run is pursuing

One file per direction, `<name>.md`, each carrying a fenced `thread` block with
`question`, `status`, `rests-on` (claim ids), `blocked-by`, and `next`.
`research/THREADS.md` beside this folder is derived from them; do not edit it.

This is the library's topic axis. The arrival tree under `research/` folds by
*when* a download happened, which scatters one subject across batches; a thread
gathers one subject and stays live.

The folder is seeded because roles are handed these paths before anything has
written here — a live `symbolic_math` run failed `list_workspace research/threads`
with `is not a directory` while doing exactly the work a thread should record.
