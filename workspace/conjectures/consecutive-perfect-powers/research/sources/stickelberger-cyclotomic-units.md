## Stickelberger element and ideal (Hida, Lec1)

Let `F = Q(zeta_N)`, `G = Gal(F/Q)`. For each `a` coprime to `N`, `{a/N}` is the
fractional part of `a/N`. The Stickelberger element is

    theta_F = sum_{a in (Z/NZ)^x} {a/N} sigma_a^{-1}   in Q[G].

Let `I0 = { beta in Z[G] : beta theta_F in Z[G] }` and the **Stickelberger
ideal** `s_F = I0 theta_F = Z[G] theta_F cap Z[G]`.

- Lemma 5.1: `I0` is generated by the elements `c - sigma_c` for primes `c` not
  dividing `N`.
- **Theorem 5.2 (Stickelberger):** `s_F` annihilates the class group `Cl(F)`:
  for every fractional ideal `A` of `F` and every `beta in I0`, the ideal
  `A^{beta theta_F}` is principal.

For `F = Q(zeta_p)` with `p` an odd prime, `G = (Z/pZ)^x`,
`theta = (1/p) sum_{a=1}^{p-1} a sigma_a^{-1}`.

**Iwasawa's index formula:** `[Z[G]^- : s^-] = h^-` (the relative class number
of `Q(zeta_p)`). So the index of the minus part of the Stickelberger ideal *is*
the minus class number — the two descriptions of the obstruction coincide.

**Ichimura's refinement (p ≡ 3 mod 4, [G:H] = 2):**
`[Z[H] : s_H] = h^- / h(Q(sqrt(-p)))`.

## Sinnott's index results

For an imaginary cyclotomic field `k` of conductor `m`, with `h, h^+, h^-` the
class number, plus-part, and relative class number, and `C` the group of
circular (cyclotomic) units of `k`:

- `[R^- : S^-]` (minus index of Stickelberger ideal in the group ring) is given
  in terms of `h, h^+` (equivalently `h^-`),
- `[E+ : C+]` (index of circular units in the full unit group of the real
  subfield) is given in terms of `h^+`.

These are the *unit side* of the same obstruction: the quotient of global units
by cyclotomic units has order controlled by `h^+`, which is the non-computable
half.

## Why this matters for the run

The descent that would close the open content runs: the equation
`x^p - y^q = 1` in `Z[zeta_p]` forces a product of pairwise-coprime ideals to be
a `q`-th power; Stickelberger's theorem / the cyclotomic-unit index decides when
one of those ideals is principal (i.e. when the ideal relation can be promoted
to an element relation). The minus part is computable (previous note); the plus
part is not, so a proof must not need `h^+`.

Sources agree: the Stickelberger ideal index equals the (minus) class number,
and the cyclotomic-unit index equals the plus part. These are standard, multiply
attested results; the exact scalar powers of 2 in Sinnott's formulas should be
pinned to the source text before any use.
