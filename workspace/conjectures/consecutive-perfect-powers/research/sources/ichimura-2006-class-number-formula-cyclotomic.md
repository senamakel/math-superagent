## What the source establishes

For `p` an odd prime, `G = Gal(Q(ζ_p)/Q)`, and `S_G` the classical Stickelberger
ideal of `Z[G]`: Iwasawa proved `[Z[G]- : S_G-] = h_p-`, the minus class number
of `Q(ζ_p)`. This paper extends the setup: for a subgroup `H ≤ G` with
`[G : H] = 2` and `p ≡ 3 (mod 4)`, the index of the associated Stickelberger
ideal in `Z[H]` equals `h_p- / h(Q(√-p))` — the minus class number divided by
the class number of the associated quadratic field.

## Why the run wants it

Refines the Stickelberger/class-number index machinery (sibling of Sinnott) in
the exact ring `Z[ζ_p]` where the odd-prime equation lives. The `p ≡ 3 (mod 4)`
sub-case and the connection to the quadratic subfield `Q(√-p)` are useful if
the run ever splits the odd-prime argument by `p mod 4`.
