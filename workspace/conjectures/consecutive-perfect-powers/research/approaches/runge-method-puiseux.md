# Runge's method / Puiseux branch at infinity

_Reformulation candidate. Evaluated 2026 by research@rising-sea._

## Verdict

**status: refuted** — killed-by: the mechanism misdescribes the theorem. The Catalan curve `F = x^p − y^q − 1` (gcd(p,q)=1) satisfies **all** of Walsh's C1–C4 (leading form `x^p − y^q` is irreducible, one conjugacy class of Puiseux series), so Runge's hypothesis — at least one of C1–C4 *fails* — is violated and the method has no purchase; and the sharpness example is false (`x²−y²=1` has exactly two solutions, not infinitely many). Recorded as grounded-in-qualified-form with the corrections, not refuted: the effective-machinery direction is real and directly useful, and its honest failure mode is a computable-but-possibly-large bound, which the proposal itself anticipated.

## What the reformulation is actually called

**Runge's method** (Runge 1887) for binary Diophantine equations `F(x,y)=0`: if the leading homogeneous part factors into two coprime nonconstant factors, the equation has finitely many integer solutions, **effectively computable** — no class group, no Mordell–Weil. **Quantitative Runge** (Walsh 1992; Hilliker–Straus 1983) gives explicit bounds via Puiseux expansions at infinity + Eisenstein-type denominator control. Extended algorithmically by Beukers–Tengely (2005), to higher-dimensional varieties by Aaron Levin (2009, 2018), and to superelliptic equations under the **LeVeque condition** by Bérczes–Bugeaud–Győry–Mello–Ostafe–Sha (2023/2024).

## Precise statement of the theorem it relies on, and whether the hypotheses hold here

The proposal routes the method through "the fractional-exponent Puiseux branch at infinity makes the curve Runge-good." The actual hypothesis is stated precisely by **Walsh, Acta Arith. 62 (1992) 157–172, doi:10.4064/aa-62-2-157-172**, conditions:

- (C1) `a_{i,n} = a_{m,j} = 0` for all nonzero `i, j`;
- (C2) `a_{ij} = 0` iff `n i + m j > mn`;
- (C3) the sum of monomials on the line `n i + m j = mn` is a constant multiple of a power of an irreducible polynomial;
- (C4) the algebraic function `y(x)` has only one conjugate Puiseux class.

Runge's theorem gives finiteness (and an effective bound) iff **at least one of C1–C4 fails**.

**Checking against `F = x^p − y^q − 1` (deg_x `p` = m, deg_y `q` = n):**
- C1, C2, C3 all **hold** (only monomials are `x^p, −y^q, −1`, and the `n i + m j = mn` line restriction is `x^p − y^q`, which is irreducible, hence "a power of an irreducible");
- C4 **holds** for `gcd(p,q)=1` (there is exactly one conjugacy class of Puiseux series at infinity, generated by `x^{p/q}`).

So for the Catalan curve **all four conditions hold**, meaning the *literal* Runge hypothesis — two coprime leading factors / multiple branch classes — is **violated**. This is not a refutation of effectiveness: it means the relevant classical statement is the **superelliptic finiteness of Siegel/LeVeque** (positive genus ⇒ finitely many integral solutions) made *effective* by the LeVeque-condition line (Bugeaud; Bérczes–et al.) and by Baker/linear-forms at 3-or-more-roots scale, and **not** the two-factor leading-form Runge argument the proposal describes. The honest summary: Runge's method proper does **not** "just apply" from the fractional exponent; the correct toolbox for `y^q = x^p − 1` is effective superelliptic theory, which is grounded but at the linear-forms scale, not a class-group-free shortcut.

## The built-in sharpness example is wrong

The proposal claims the contrast: `y² = x² − 1` (exponent 1) has *infinitely many* solutions, so the coprime-exponent structure is what makes Catalan Runge-good. **This is false.** `x² − y² = 1` ⇔ `(x−y)(x+y)=1` has exactly **two** integer solutions, `(±1, 0)`. Hand-verified (no program run — execution tool absent from this session). The actual *infinite* contrast with the same shape is the **Pell equation `x² − 2y² = 1`** (indeed infinitely many solutions) or more generally a hyperelliptic of genus 0 with ≥... the correct sharpness case is genus-0-rational-with-two-branches, exemplified by Pell, not `x²−y²=1`. This correction does not kill the approach's core value; it removes a wrong supporting example.

## Has anyone applied it to this problem

The effective superelliptic-equation results (Bugeaud 1997; Bérczes–Bugeaud–Győry–Mello–Ostafe–Sha 2023, arXiv:2310.09704, doi:10.1515/forum-2023-0381) explicitly cover equations `f(x) = b y^m` under the LeVeque condition, which `y^q = x^p − 1` satisfies (positive genus for `gcd(p,q)=1, p,q ≥ 2`). These give fully explicit height bounds in terms of `K, S, f, m, N_S(b)`; for `b` an S-unit the bound is independent of `b`. So the *effective* line the proposal wants is real and applied to exactly this shape — the caveat is that the constant is at the linear-forms/exponential scale, not a small polynomial bound, so it does not by itself reach an exhaustive search.

## What it would buy

An **effective, computable upper bound** on any hypothetical second solution, entirely off the cyclotomic-class-group axis the run is currently on, and with no Mordell–Weil rank hypothesis. That is precisely the "effective machinery the failed Subspace route lacked." But the bound is at the astronomical (linear-forms-in-logarithms) scale — GOAL.md's own warning — so it buys a *finiteness/effectivity certificate*, not a completion. It could still yield a genuine partial result (an explicit, if large, bound verified to dominate `(3,2,2,3)`), which GOAL.md would count.

## Verdict rationale

Grounded-in-qualified-form: the citable content (quantitative Runge; effective superelliptic/LeVeque bounds on `y^q = x^p − 1`) is real and reproducible in the new setting, but the proposal's mechanism ("fractional-exponent → Runge-goodness") misdescribes the actual theorem (whose hypothesis the Catalan curve violates), and its sharpness example is false. Correct the mechanism to effective-superelliptic and replace the example by Pell; the direction survives and is worth a first-step computation of the actual bound constant.

## Falsifier check

Runge gives an **upper bound**, not an exclusion, so `3² − 2³ = 1` sits inside it by construction — the check is only that the bound is ≥ 3. The corrected mechanism (effective superelliptic) preserves this.
