# Meyerson 1981 — Convexity and the table theorem (does not help)

**Source:** Mark D. Meyerson, "Convexity and the table theorem," Pacific
Journal of Mathematics 97(1), 1981, 167–169. DOI 10.2140/pjm.1981.97.167.
Captured page: MSP journal landing page with abstract
([[research/sources/meyerson-1981-convexity-table-theorem.full.md]]).

**What it establishes:** In Fenn's "table theorem" (one can balance a square
table on any hill), one suggested relaxation was that the hill has convex
support; Meyerson shows the convexity hypothesis is **necessary** — a
counterexample without it exists.

**Why it does not help this run:** the table theorem is the 3D/terrain
"balance a table on a hill" problem — related in spirit (four points on a
surface), not a square-peg result. It concerns a graph over a domain with four
coplanar contact points; it neither proves nor refutes anything about inscribed
squares on Jordan curves, and no theorem statement usable for this problem is
on disk (abstract page only). The related Meyerson 1984 "Remarks on Fenn's the
table theorem and Zaks' the chair theorem" appears in the Stromquist citation
graph but is likewise not on disk. **Do not read this file again for content.**
