# Sources that do not help — and why (scholar pass, phase 2)

Read against the goal (partial result strictly extending the locally-monotone
class, or a precise obstruction), the tasks (G-named-class-membrane,
G-nondegeneracy-bound, G-curve-outside-published-classes), and the thesis
(continuous-Legendre-lift frontier). These sources carry no content the run can
use, or content already carried elsewhere:

## Acquisition failures (content not on disk — do not cite as established)

- **Fung 2021 "Every Jordan curve inscribes uncountably many rhombi"**
  (`research/sources/fung-2021-uncountably-many-rhombi.full.md`): the download
  is an unrelated astrophysics preprint (Gu et al., IllustrisTNG galaxy
  simulations). No rhombi theorem is established on disk. If the rhombi result
  is wanted, re-acquire the correct text; the citation record confirms the
  paper exists (Fung, Geom. Dedicata 215, 2021; plus Wright 2025 Amer. Math.
  Monthly "Every Jordan Curve Contains All Vertices of Uncountably Many
  Rhombi—A Short Proof", and Wright 2026 Aequationes Math.). **Relevant to the
  run:** a no-regularity continuous-curve rhombi result would show a minimal
  counterexample still inscribes rhombi, narrowing the obstruction to the
  diagonal-equality condition. Lead only.
- **Rius Casado 2019 thesis** (`rius-casado-2019-square-peg-problem-thesis`):
  only the repository landing page was captured; the PDF (hdl.handle.net/
  2445/151918) was never downloaded. The claims `rius2019-stromquist-lemma-3.24`
  and `rius2019-locally-monotone-definition` are NOT established on disk and
  must not be cited. The thesis would have been an exposition of Stromquist's
  proof (substitute for the paywalled primary).
- **Schwartz BAMS survey** (schwartz2021/2022): both captures are AMS landing-
  page boilerplate, no article text. Nothing is lost: its content (Vaughan's
  rectangle theorem, the GL Klein-bottle mechanism) is carried by the primaries
  (Matschke 2014 survey Thm 7; Greene–Lobb 2021 Annals).
- **Greene–Lobb 2026** (`greene-lobb-2026-positive-measure-rectangles.full.md`):
  the full text is only the arXiv abstract page (229 lines, all navigation).
  The abstract itself does state the theorem (positive-measure angle set I of
  measure ≥ A/R² for any Jordan curve), which is what the summary's claims
  rest on; there is no proof text on disk. Treat the theorem as asserted-by-
  source (abstract level), not proof-verified.
- **Stromquist 1989 primary** (`stromquist-1989-cambridge-abstract`): the
  Cambridge Core abstract page only. Confirms the weaker condition is satisfied
  by convex, polygonal, piecewise-C¹ curves; the exact Condition A is paywalled.
  The verbatim locally-monotone definition is now carried by Barber 2026 Def 1.9
  and Asano–Ike 2024 Def 5.10 (both quote Stromquist [Str89, §6]).
- **Meyerson 1981 "Convexity and the table theorem"** (`meyerson-1981-...`):
  abstract page only; shows necessity of convex support in Fenn's table theorem.
  Not a square-peg source; no theorem for this problem is on disk. Does not help.
- **OpenAlex / Google Scholar records** (openalex-asano-ike, scholar-asano-ike):
  bibliographic status checks, no mathematics. Their one use: Asano–Ike is a
  preprint (not published, not retracted, 0 citations) as of ~Aug 2026.
- **Citation-graph files** (citations_w*): existence + citation counts only,
  explicitly "not evidence". The useful leads: Wright 2025/2026 (rhombi short
  proofs — re-acquire if rhombi matter), van Heijst 2014 algebraic count bound,
  Aslam et al. 2020 "Splitting loops and necklaces" (continuous-curve
  rectangle variants), Friedl–İnce 2023 (table theorem vs square peg).
