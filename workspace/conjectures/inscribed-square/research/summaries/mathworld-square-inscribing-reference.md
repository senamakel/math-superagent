# Square Inscribing

---

The square peg problem, posed by Toeplitz in 1911, asks whether every [Jordan curve][1] in the [Euclidean plane][2] contains the vertices of a [square][3]. It remains open in this generality (Greene and Lobb 2021). Schnirelman (1944) proved that a square can be [inscribed][4] in any closed [convex][5] curve.

For smooth [Jordan curves][1], Greene and Lobb (2021) proved the stronger [rectangular peg theorem][6], which prescribes the similarity class of the inscribed rectangle. Choosing that similarity class to be a [square][3] gives the square peg conclusion for smooth curves. However, because the rectangular peg theorem assumes smoothness, it does not settle the square peg problem for arbitrary [Jordan curves][1]. By contrast, a square can be [circumscribed][7] about *any*[Jordan curve][1] (Steinhaus 1999, p. 104).
