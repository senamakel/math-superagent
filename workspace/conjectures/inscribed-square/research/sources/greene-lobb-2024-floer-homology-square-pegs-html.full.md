###### Abstract.

We construct a version of Lagrangian Floer homology whose chain complex is generated by the inscriptions of a rectangle into a real analytic Jordan curve. By using its associated spectral invariants, we establish that a rectifiable Jordan curve admits inscriptions of a whole interval of rectangles. In particular, it inscribes a square if the area it encloses is more than half that of a circle of equal diameter.

## 1. Introduction.

This paper is motivated by the Square Peg Problem:

Does every Jordan curve in the plane inscribe a square?

Here a curve γ \gamma inscribes a polygon Q Q – and Q Q inscribes in γ \gamma – if γ \gamma contains the vertices of an orientation-preserving similar copy of Q Q. The problem was posed by Otto Toeplitz in 1911 [16]. It was affirmatively solved for smooth curves by Schnirelmann in 1929 [15], and it is known to be true for several other classes of curves [9]. However, the general case of continuous curves remains open to this day. The difficulty with promoting the solution for smooth curves to continuous curves is the issue of shrinkout.

### 1.1. Shrinkout and symplectic geometry.

To describe the issue, suppose that γ \gamma is a (continuous) Jordan curve and γ n \gamma_{n} is a sequence of smooth Jordan curves approximating it. Schnirelmann’s result shows that each γ n \gamma_{n} contains the vertices of a square □ n \square_{n}. It is tempting to use compactness to pass to a subsequence of □ n \square_{n} and conclude that they limit to a square □ \square whose vertices are contained in γ \gamma. However, the subsequence may limit to a single point ∙ ∈ γ \bullet\in\gamma. Surmounting shrinkout has impeded progress on the Square Peg Problem for nearly a century.

The goal of this paper is to show how to preclude shrinkout for a wide class of curves using tools from symplectic geometry. In order to describe the framework, we recall our earlier result specific to the case of smooth curves:

###### Theorem 1.1 ( [6]).

Every smooth Jordan curve in the plane inscribes every cyclic quadrilateral. In other words, every quadrilateral which inscribes in a circle also inscribes in every smooth Jordan curve.

The proof of 1.1 proceeds by constructing a pair of embedded Lagrangian tori L 0 L_{0} and L 1 L_{1} in standard symplectic ℂ 2 {\mathbb{C}}^{2} associated with a cyclic quadrilateral Q Q and a smooth Jordan curve γ \gamma. The intersection between L 0 L_{0} and L 1 L_{1} consists of a clean loop C C and a disjoint set P P. The set P P parametrizes the inscriptions of Q Q in γ \gamma. The loop C C parametrizes degenerate inscriptions, regarding each point on γ \gamma as an degenerate copy of Q Q. By surgering C C away, a single immersed Lagrangian torus L L results, and it self-intersects precisely in the set P P. This torus has minimum Maslov number 4. On the other hand, an embedded Lagrangian torus in ℂ 2 {\mathbb{C}}^{2} has minimum Maslov number 2. (This is the resolution of Audin’s conjecture for tori in ℂ 2 {\mathbb{C}}^{2}, independently due to Polterovich [12] and Viterbo [17].) This shows that L L self-intersects, so P P is non-empty, and this implies the existence of the desired inscription of Q Q in γ \gamma.

1.1 is optimal in a couple of senses. Firstly, certainly no other quadrilateral can inscribe in every smooth Jordan curve since the circle is itself such a curve. Secondly, the regularity condition on the curves cannot be weakened from smooth all the way down to continuous. Indeed, for every cyclic quadrilateral which is not an isosceles trapezoid, there exists a continuous Jordan curve (even a triangle) which does not inscribe it. This underscores the seriousness of shrinkout. For suppose that Q Q is a cyclic quadrilateral which is not an isosceles trapezoid, γ \gamma is a triangle which does not inscribe Q Q, and γ n \gamma_{n} is a sequence of smooth approximations to γ \gamma with γ n → γ \gamma_{n}\rightarrow\gamma as n → ∞ n\rightarrow\infty. 1.1 shows that there exists a copy Q n Q_{n} of Q Q inscribed in each γ n \gamma_{n}. However, they necessarily limit to a single point ∙ ∈ γ \bullet\in\gamma.

### 1.2. Jordan Floer homology.

Nevertheless, the framework for proving 1.1 contains a clue to precluding shrinkout for squares and, more generally, for rectangles. The reason is that when Q Q is a rectangle, the associated tori L 0 L_{0} and L 1 L_{1} are monotone and Hamiltonian isotopic to one another. This suggests defining a version of Lagrangian Floer homology for the pair ( L 0, L 1) (L_{0},L_{1}) in order to gain greater control over inscribed rectangles in γ \gamma. A large part of this paper carries out such a construction.

In sketch, the construction begins with a chain complex JFC ⁡ ( γ, θ) {\rm JFC}(\gamma,\theta) associated with a generic pair of a real analytic Jordan curve γ \gamma and an angle 0 < θ < π 0<\theta<\pi. The restriction to this class of curves is made to overcome an analytical issue, but such curves are C 0 C^{0} -dense in the space of all Jordan curves. The complex is generated by the set P P of inscriptions of a θ \theta -rectangle Q θ Q_{\theta} in γ \gamma (a θ \theta -rectangle is one whose diagonals meet in the angle θ \theta). The differential ∂ {\partial} on the complex counts pseudoholomorphic strips with boundary on L 0 L_{0} and L 1 L_{1} which join pairs of points in P ⊂ L 0 ∩ L 1 P\subset L_{0}\cap L_{1}. A novelty in the construction, and a key part of the proof that ∂ 2 = 0 {\partial}^{2}=0, is that the strips must avoid a complex line which cuts through both L 0 L_{0} and L 1 L_{1} in the loop C C.

The construction furnishes chain homotopy equivalences JFC ⁡ ( γ, θ 1) ≃ JFC ⁡ ( γ, θ 2) {\rm JFC}(\gamma,\theta_{1})\simeq{\rm JFC}(\gamma,\theta_{2}) for different choices of angles 0 < θ 1, θ 2 < π 0<\theta_{1},\theta_{2}<\pi, and for θ \theta close to 0 0 we identify JFC ⁡ ( γ, θ) {\rm JFC}(\gamma,\theta) with a relative Morse chain complex of the pair ( L 0, C) (L_{0},C). These properties lead to the fact that the total homology JF ⁡ ( γ, θ) {\rm JF}(\gamma,\theta) is two-dimensional. Associated to each homology generator of JF ⁡ ( γ, θ) {\rm JF}(\gamma,\theta) is a spectral invariant, a real number induced from a filtration on the complex JFC {\rm JFC} by action. The spectral invariants are robust under approximation of an arbitrary Jordan curve by real analytic ones. This robustness provides control over shrinkout for rectangles for a wide class of curves.

### 1.3. Square pegs.

The application we give is the following result. Recall that a Jordan curve γ ⊂ ℝ 2 \gamma\subset{\mathbb{R}}^{2} of finite length is rectifiable; in other words, γ \gamma is rectifiable if it can be approximated by a sequence of smooth curves of uniformly bounded length. Let Area ⁡ ( γ) {\mathrm{Area}}(\gamma) denote the area of the region that γ \gamma encloses, and let Rad ⁡ ( γ) {\mathrm{Rad}}(\gamma) denote half of its diameter, Rad ( γ) = 1 2 sup { | z − w |: z, w ∈ γ } {\mathrm{Rad}}(\gamma)=\frac{1}{2}\sup\{|z-w|:z,w\in\gamma\}. Note that Area ⁡ ( γ) / Rad ​ ( γ) 2 ≤ π {\mathrm{Area}}(\gamma)/{\mathrm{Rad}}(\gamma)^{2}\leq\pi, with equality exactly when γ \gamma is a circle.

###### Theorem A.

If γ ⊂ ℝ 2 \gamma\subset{\mathbb{R}}^{2} is a rectifiable Jordan curve, then there exists an interval I ⊂ ( 0, π) I\subset(0,\pi) of length at least Area ⁡ ( γ) / Rad ​ ( γ) 2 {\mathrm{Area}}(\gamma)/{\mathrm{Rad}}(\gamma)^{2} such that γ \gamma inscribes every θ \theta -rectangle with θ ∈ I \theta\in I.

The following corollary is immediate.

###### Corollary.

If γ \gamma is rectifiable and encloses more than half the area of a circle of equal radius, then γ \gamma inscribes a square. ∎

### 1.5. Spectral invariants.

As remarked, JFC ∗ ​ ( γ, θ, 𝔻) {\rm JFC}_{*}(\gamma,\theta,\mathbb{D}) also comes with an ℝ {\mathbb{R}} -valued action filtration. The action filtration of a generator is treated concretely in Section 3.

The action filtration on JFC ∗ ​ ( γ, θ, 𝔻) {\rm JFC}_{*}(\gamma,\theta,\mathbb{D}) descends to a filtration on JF ∗ ​ ( γ, θ, 𝔻) {\rm JF}_{*}(\gamma,\theta,\mathbb{D}) studied in Section 4. Each homology class in the group JF ∗ ​ ( γ, θ, 𝔻) {\rm JF}_{*}(\gamma,\theta,\mathbb{D}) possesses a spectral invariant, its induced filtration grading. All of the information in our setting is contained in the spectral invariant ℓ ⁡ ( γ, θ) \ell(\gamma,\theta) attached to the top dimensional generator. As the notation suggests, it is independent of the choice of analytic data 𝔻 \mathbb{D}.

The application to A follows from properties of this spectral invariant collected in 4.1. More precisely, ℓ ⁡ ( γ, θ) \ell(\gamma,\theta) is a continuous, monotonic non-decreasing function of θ ∈ ( 0, π) \theta\in(0,\pi) which limits to 0 as θ → 0 \theta\to 0 and to Area ⁡ ( γ) {\mathrm{Area}}(\gamma) as θ → π \theta\to\pi. Since it is monotonic, it is differentiable almost everywhere, and its derivative is bounded above by Rad ​ ( γ) 2 {\mathrm{Rad}}(\gamma)^{2}. These properties enable us to establish A for a real analytic Jordan curve γ \gamma with bounds on the spectral invariants of the inscriptions of Q θ Q_{\theta} in γ \gamma with θ ∈ I \theta\in I.

If γ \gamma is a rectifiable Jordan curve, then we may approximate it by a sequence of real analytic Jordan curves γ n \gamma_{n} of bounded length by the Riesz-Prasolov theorem, a precise form of the Riemann mapping theorem for a domain with rectifiable boundary [13, Theorem 6.8]. If θ ∈ I \theta\in I and Q n Q_{n} is an inscription of a θ \theta -rectangle in γ n \gamma_{n}, then the action bound on Q n Q_{n} and the length bound on γ n \gamma_{n} combine to show that the sequence Q n Q_{n} converges to a nondegenerate θ \theta -rectangle Q Q inscribed in γ \gamma.

### 1.6. Varying the curve.

In this paper we study how JF ⁡ ( γ, θ) {\rm JF}(\gamma,\theta) (and in particular its spectral invariants) vary with θ \theta. It is a natural idea to try to perform the same kind of analysis while varying rather the Jordan curve γ \gamma by a Hamiltonian flow on ℂ {\mathbb{C}}. There are some difficulties with this idea, the first analytic and the others topological, which we summarize here.

The analytic difficulty is that it is tricky to define continuation maps giving chain homotopy equivalences between chain complexes JFC ⁡ ( γ, θ) {\rm JFC}(\gamma,\theta) for varying γ \gamma. The problem is to guarantee that diagonal-avoiding strips do not degenerate in 1 1 -parameter families to strips meeting the diagonal. In a sequel [7], we overcome this analytic difficulty by abandoning continuation maps and turning to Floer’s original approach for defining chain maps, the *bifurcation*method [3]. In the current paper we borrow from this method in Section 4 when studying the rate of change of spectral invariants.

The second difficulty is that it seems hard, even in this setting, to circumvent the rectifiability hypothesis.

The third difficulty is that one would like to control the rate of change of the action with varying γ \gamma in a way that might, for example, lead to the resolution of the Square Peg Problem for all rectifiable curves. Looking ahead to Figures 6 and 9 which depict the action associated to an inscribed rectangle, we warn the reader that this example shows the rectangle elegantly inscribed in the Jordan curve. It seems unlikely that for a general real analytic Jordan curve one should expect the spectral invariant to be attained by the action of such a rectangle. For the Jordan curve γ \gamma and rectangle Q Q in Figure 6, any local isotopy of γ \gamma, performed away from the vertices of γ \gamma, that adds ϵ \epsilon to the area bounded by γ \gamma, will change the action of the rectangle by at most ϵ \epsilon. On the other hand, given any N ≫ 0 N\gg 0, it is possible to draw a Jordan curve with an inscribed rectangle whose action changes, under a small local isotopy adding ϵ \epsilon to the area bounded by the curve, by N ​ ϵ N\epsilon. That such bad rectangles can exist is at the root of this third difficulty. The sequel [7] examines a case in which a priori all inscriptions are elegant, leading to some inscription results which fall outside the scope of A.

### 2.7. The continuation package.

Once one has defined a Lagrangian Floer chain complex for a choice of Lagrangian, Hamiltonian, Hamiltonian perturbation, and almost-complex structure, there is a general procedure available for showing that its chain homotopy type is independent of choice of perturbation and almost-complex structure, and moreover for setting up isomorphisms between the homologies corresponding to different choice of Hamiltonian. This general procedure involves counts of moduli spaces of strips in which the Hamiltonians and the almost-complex structures are now allowed to be strip-dependent. The chain maps are sometimes known as *continuation*maps, and we refer to the collection of strip counts from which one can define chain maps, chain homotopies, and so on as the ‘continuation package’. For a readable account we refer the reader to [2, Section 1.5].

We begin by addressing chain maps in our setting. Suppose that we are considering the admissible quadruples ( γ, θ 1, h t 1, J t 1) (\gamma,\theta_{1},h^{1}_{t},J^{1}_{t}) and ( γ, θ 2, h t 2, J t 2) (\gamma,\theta_{2},h^{2}_{t},J^{2}_{t}). #### 2.7.1. Conclusion.

We have shown that the continuation package of maps continues to function without modification when restricted to our setting of diagonal-avoiding strips. Thus we have well-defined homology groups JF ⁡ ( γ, θ) {\rm JF}(\gamma,\theta) for pairs of a real analytic Jordan curve and angle 0 < θ < π 0<\theta<\pi. These are defined as limits of directed systems of homology groups depending on choices of analytic data. We further have well-defined isomorphisms JF ⁡ ( γ, θ 1) → JF ⁡ ( γ, θ 2) {\rm JF}(\gamma,\theta_{1})\rightarrow{\rm JF}(\gamma,\theta_{2}) for any pairs 0 < θ 1, θ 2 < π 0<\theta_{1},\theta_{2}<\pi.

#### 2.7.2. An observation and a warning.

We close this subsection with an observation about the proof of Lemma 2.22: that it was important for the winding number arguments that we had 0 < θ −, θ + < π 0<\theta^{-},\theta^{+}<\pi. There is nothing to stop the reader defining Jordan Floer homology groups for pairs ( γ, θ) (\gamma,\theta) in which θ < 0 \theta<0 or θ > π \theta>\pi, but they should be wary of an attempt, for example, to define a continuation map following the principles above to give an isomorphism JF ⁡ ( γ, − θ) → JF ⁡ ( γ, θ) {\rm JF}(\gamma,-\theta)\rightarrow{\rm JF}(\gamma,\theta) for 0 < θ < π 0<\theta<\pi. Such an attempt is doomed to fail simply by virtue of the support of the homologies in different Maslov degrees: on the left the support is in degrees 0, 1 0,1, while on the right it is in degrees 1, 2 1,2, as we shall see in Section 2.8. In this paper we only use angles within the range 0 < θ < π 0<\theta<\pi, so we do not investigate this further here.

## 4. Spectral Invariants.

A useful reference for the general discussion in this section is provided by [8].

We are interested in studying the *spectral invariants*of the group JF ⁡ ( γ, θ) {\rm JF}(\gamma,\theta) for pairs consisting of a real analytic Jordan curve γ \gamma and aspect angle 0 < θ < π 0<\theta<\pi. Spectral invariants are, in our case, real numbers associated to a choice of Jordan Floer homology class. They arise since the Jordan Floer differential (and the Floer differential in general) respects the action filtration, allowing one to associate to a non-zero homology class the largest action among cycle representatives of that class.

More precisely, the action 𝒜 θ ​ H t + h t {\mathcal{A}}_{\theta H_{t}+h_{t}} gives a map

 | 𝒜 θ ​ H t + h t: 𝒢 ⁡ ( γ, θ, h t) ⟶ ℝ {\mathcal{A}}_{\theta H_{t}+h_{t}}\colon{\mathcal{G}}(\gamma,\theta,h_{t})\longrightarrow{\mathbb{R}} |  |

on the set of generators of the chain group of an admissible triple ( γ, θ, h t) (\gamma,\theta,h_{t}). We then filter this chain group JFC ⁡ ( γ, θ, h t) {\rm JFC}(\gamma,\theta,h_{t}) by subgroups JFC a ​ ( γ, θ, h t) {\rm JFC}^{a}(\gamma,\theta,h_{t}) generated by all elements of 𝒢 ⁡ ( γ, θ, h t) {\mathcal{G}}(\gamma,\theta,h_{t}) whose action is less than a a. Choosing an admissible J t ∈ 𝒥 reg ​ ( γ, θ, h t) J_{t}\in{\mathcal{J}_{\mathrm{reg}}}(\gamma,\theta,h_{t}) gives a chain map ∂ = ∂ ( γ, θ, h t, J t) \partial=\partial_{(\gamma,\theta,h_{t},J_{t})} and this respects the filtration.
