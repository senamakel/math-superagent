#
# Question: does the n3 seed, grown to its stable local fixpoint,
#   pin forced lines/incidences that over-subscribe the fixed
#   global budget of the partial STS (99 pts, 231 lines, 693 inc,
#   7 lines/point)?  This is the k=14-specific step the order-6
#   identities cannot see.
#
# Method (see lib/n3patch.py, the single home of seed/growth):
#   grow the seed to a lambda-witness fixpoint (rule 3), enumerate
#   interior completions under the SOUND upper-bound criterion,
#   reach a stable fixpoint with fully-decided survivors.  Then the
#   forced ledger is EXACT: forced lines = #patch 3-cliques L_in,
#   forced incidences = 3*L_in, residual = 231-L_in / 693-3L_in,
#   and every patch vertex v still needs 7 - (patch 3-cliques
#   through v) lines, all with both other points OUTSIDE.
#   Identity: per-vertex line deficits sum to 7*|patch| - 3*L_in,
#   and +7*(99-|patch|) outside lines == 693 - 3*L_in (exact).
#   The residual is absorbable iff every patch vertex has even
#   |I(v)| (matching-pairing closure), <=7 patch lines, and
#   nonnegative deficit.  Otherwise it is a genuine obstruction
#   or over-subscription; if all survivors pass, NO counting floor
#   over-subscribes -- the obstruction (if any) is structural.
#   EXACT integer arithmetic throughout, no floats.
