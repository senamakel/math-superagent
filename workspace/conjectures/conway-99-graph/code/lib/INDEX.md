# Index — code/lib

What each file in this folder is for. Keep it current: describe a file when you create it, and refresh this index after adding, renaming, or deleting files.

| File | Purpose |
| --- | --- |
| `hexagons.py` | Exact induced-C6 counter. count_induced_C6(A) counts induced hexagons of a 0/1 integer matrix via anchored oriented induced P4s with a boolean matvec completion trick; O(n^4) time, O(n^2) space, exact integer arithmetic. hexagon_formula(n,k) is the closed form (1/12)n k (k-2)(2k^2-21k+53). Validated against independent brute force on rook(3)=6, bare C6=1, two triangles=0. BvLS(243,22) gives 4,980,690, equal to the closed form, cross-checked by a second anchor (see code/out/hexagon_count_bvls.py and verify_hexagons_edge_anchor.py). |
| `localprop.py` | Exact partial-graph arc-consistency engine for lambda=1, mu=2, locally-7K2 local structure. PartialGraph holds a partial 0/1/-1 adjacency; propagate() computes the least forced fixpoint by sound deductions only: (1) excess common neighbours (adjacent pair >=2, non-adjacent >=3 established) => contradiction; (2) saturated pair prunes each candidate's single undecided side to 0; (3) exact 7K2 pairing rule prunes a paired neighbourhood vertex off all other neighbours of its apex; (4) an adjacent edge with no in-patch lambda witness forces an external witness vertex, materialised one per deficient edge (distinct, conservative). mu=2 deficits are NOT contradictions (outside vertices supply them) and are reported via mu_witness_deficits(); lambda deficits via lambda_witness_deficits(). Correctness: passes both real positive controls rook(3)=srg(9,4,1,2) and bvls_graph()=srg(243,22,1,2) fully seeded with ZERO fabricated deductions AND correctly flags genuine excess contradictions (adjacent pair with 2 established common neighbours; non-adjacent pair with 3). Previously had an unsound saturation branch (forced a-v=0 AND b-v=0, flipping fixed bits) that fabricated a CONTRADICTION on real configs; that bug is FIXED here — the sound conclusion from saturation is only the at-least-one-off rule, and no fixed bit is ever flipped. neighbourhood_is_7k2(A,v,k) exact-check helper. |
| `n3patch.py` | Single reusable home of the n3 seed (2-edge-joined disjoint triangle pair) and its sound local-growth machinery for the srg(99,14,1,2) search: seed(), undecided_pairs, upper_ok (sound upper-bound criterion: ADJ<=1 CN, NONADJ<=2, 7K2, degree<=14; only excesses are contradictions), closure_rule3 (lambda-witness fixpoint growth — the only growth rule), assignments (complete enumeration), patch_cliques (forced lines as patch 3-cliques), forced_ledger (exact forced line/incidence ledger vs global budget 99/231/693). Radius-1 reproduces 8v/2 survivors; growth reaches a stable fixpoint with 19 fully-decided survivors matched to n3_grow_radius.captured.txt. Dedups copies that previously appeared in n3_seed_consistency_ub.py and n3_grow_radius.py. |
| `srg.py` | Canonical exact oracle is_srg(A,v,k,lam,mu) (integer common-neighbour counts over the 0/1 adjacency matrix, no floats) plus control-graph builders: rook(3)=srg(9,4,1,2), bvls_graph()=srg(243,22,1,2), doily()=srg(15,6,1,3) (GQ(2,2)=Kneser K(6,2)), gq24_graph()=srg(27,10,1,5) (O^-(6,2) polar space = complement of Schlaefli), and negative controls random_regular_14_99() and circulant(n,conn). Correctness: every builder verified by is_srg on its own parameters; rook/bvls negatives and near-misses rejected, LAMBDA vs MU rejection path exercised (code/out/oracle-controls.captured.txt). |
| `triangles.py` | Exact triangle (3-clique) graph C3(Gamma) construction and Phillips spectrum prediction, for the lambda=1 SRG family. triangle_graph(A) builds the C3 adjacency from the integer matrix and lists triangles; c3_spectrum_prediction gives the predicted eigenvalue/multiplicity multiset for comparison. |
