# Verstraëte 2005 — Unavoidable cycle lengths

Source: J. Graph Theory 49(2):151–167, 2005, doi:10.1002/jgt.20072. **Full
text paywalled** (Wiley cookie wall; only the abstract was retrievable).
Statement below is from the abstract, which is all the run holds.

## Abstract statement

There is a zero-density set S of integers, with |S ∩ {1,…,n}| = O(n^0.99),
such that every graph of **average degree ≥ 10** contains a cycle whose length
is in S.

## For this problem

This is the framework Sudakov–Verstraëte generalise. The "unavoidable set" is
sparse in n (sublinear), so it deliberately *does not* force a dense interval;
a single graph need only hit a sparse prescribed set S. This is the right
shape of theorem for a prescribed length — but the average-degree-10
hypothesis is again far above δ ≥ 3, so it does not settle the conjecture.
It is the conceptual ancestor of the 2-power "prescribed-length" question:
the available results need average degree well above 3 to force a cycle in
even a sparse unavoidable set.
