| `biconnected_gen.py` | _(undescribed)_ |
| `biconnected_gen_hash.py` | Fast exact generation of all 2-connected graphs by ear decomposition with WL-hash bucket + VF2 dedup. Generate_2connected_levels_hash(n) -> {n: [Graphs]}, matching OEIS A002218 (n3=1,n4=3,n5=10,n6=56,n7=468,n8=7123). |
| `canonical.py` | Exact canonical form canonical_key(G) for small graphs (networkx 2.8.8 lacks nx.canonical_label), built from canonical WL colour refinement + enumeration within colour classes. Equal keys <=> isomorphic. Correctness: cross-checked that per-level distinct-key counts match VF2 isomorphism-class counts on all graphs on 4,5 labeled vertices (11,34) and that the corrected generator's 2-connected counts (A002218: 1,3,10,56,468,7123) are reproduced at n=3..8. |
| `erdos_gyarfas.py` | Naive brute-force oracle for the Erdős–Gyárfás conjecture: exact detection of whether a graph has a cycle of length 2^k (k>=2). Public API: has_power_of_two_cycle(adj)->(bool,len), cycles_by_length(adj)->dict, all_cycles(adj)->set of edge-frozensets, powers_of_two_up_to(n). Exponential by design, run only on small graphs (n<=32). Correctness established by code/out/validate_oracle.py on hand-computable ground truths (K3/C5/C7/C9->False; C4/C8/C16/Petersen/K4->True) and by an independent connected-2-regular edge-subset enumerator. Cycles are keyed by EDGE set, not vertex set: two distinct Hamilton cycles on the same vertices are different cycles (Petersen has 20 distinct 9-cycles, 10 vertex sets); the existence decision is unaffected by this distinction. |
| `girth5_gen.py` | generate_2connected_girth_atleast5(n): all 2-connected graphs per vertex count with girth>=5, via C5-seeded open-ear decomposition with girth pruning and WL-hash+VF2 dedup. girth(G): shortest cycle length (per-edge BFS). Complete for the min-degree>=3 class below the Moore-bound floor (n<=11): those graphs have a 5-cycle and an open ear decomposition from it, and adding ears only adds edges so no girth-5 graph is ever pruned. min_degree(G) helper. Correctness: validated in code/out/check_girth5_gen.py against the full 2-connected generator filtered by girth>=5 AND min-degree>=3 (all n<=7 match; the only girth>5 discrepancies are min-degree-2 graphs correctly excluded). |
| `girth6_gen.py` | Exact generation of 2-connected graphs of girth exactly g via C_g-seeded open-ear decomposition with girth-pruning and WL-hash+VF2 dedup. Generalizes lib/girth5_gen.py. Key functions: girth(G) (shortest cycle via per-edge BFS); generate_2connected_girth_atleast(n_target, seed_len, min_girth) returns dict n->list of 2-connected graphs with girth>=min_girth seeded with C_seed_len; generate_2connected_girth6(n_target) = C6-seed/girth>=6 (exactly the 2-connected girth-6 class, since every reached graph contains the 6-cycle seed and pruning forbids shorter); generate_2connected_girth5(n_target) = C5-seed/girth>=5 (exactly the girth-5 class, same argument); min_degree(G). Correctness: open ear decomposition theorem (Diestel) — girth pruning cannot discard girth-g graphs (ears only add edges), and every girth-g graph has an ear decomposition starting at a g-cycle. Base-case reproductions: girth5 on n=10 = {Petersen}; girth6 on n=14 must contain the Heawood graph. |
