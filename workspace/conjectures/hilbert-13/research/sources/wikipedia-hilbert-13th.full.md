**Hilbert's thirteenth problem**is one of the 23 [Hilbert problems][8] set out in a celebrated list compiled in 1900 by [David Hilbert][9]. It entails proving whether a solution exists for all [7th-degree equations][10] using [algebraic][11] (variant: [continuous][12]) [functions][13] of two [arguments][14]. It was first presented in the context of [nomography][15], and in particular "nomographic construction" — a process whereby a function of several variables is constructed using functions of two variables. The variant for continuous functions was resolved affirmatively in 1957 by [Vladimir Arnold][16] when he proved the [Kolmogorov–Arnold representation theorem][17], but the variant for algebraic functions remains unresolved.

## Introduction

[[edit][18]]

Using the methods pioneered by [Ehrenfried Walther von Tschirnhaus][19] (1683), [Erland Samuel Bring][20] (1786), and [George Jerrard][21] (1834), [1] [William Rowan Hamilton][22] showed in 1836 that every [seventh-degree][10] equation can be reduced via radicals to the form x 7 + a x 3 + b x 2 + c x + 1 = 0 {\displaystyle x^{7}+ax^{3}+bx^{2}+cx+1=0}[image: {\displaystyle x^{7}+ax^{3}+bx^{2}+cx+1=0}]. [2] [3]

Regarding this equation, Hilbert asked whether its solution, *x*, considered as a function of the three variables *a*, *b*and *c*, can be expressed as the [composition][23] of a finite number of two-variable functions.

## History

[[edit][24]]

Hilbert originally posed his problem for [algebraic functions][11] [4] ("...Existenz von algebraischen Funktionen...", i.e., "...existence of algebraic functions..."; also see Abhyankar 1997, [5] Vitushkin 2004 [6]). However, later in that article, Hilbert also conjectured there isn't a solution to a seventh-degree equation, even using arbitrary [continuous functions][12] in two variables. [7]

A generalization of the second ("continuous") variant of the problem is the following question: can every continuous function of three variables be expressed as a [composition][23] of finitely many continuous functions of two variables? The affirmative answer to this general question was given in 1957 by [Vladimir Arnold][16], then only nineteen years old and a student of [Andrey Kolmogorov][25]. Kolmogorov had shown in the previous year that any function of several variables can be constructed with a finite number of three-variable functions. [8] Arnold then expanded on this work to show that only two-variable functions were in fact required, thus answering Hilbert's question when posed for the class of continuous functions. [9] Later, Kolmogorov slightly simplified Arnold's result. [10]

Arnold later returned to the algebraic version of the problem, jointly with [Goro Shimura][26] (Arnold and Shimura 1976). [11]
