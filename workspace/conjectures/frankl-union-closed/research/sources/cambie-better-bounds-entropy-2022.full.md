# Title: Better bounds for the union-closed sets conjecture using the entropy approach

Authors: [Stijn Cambie][3]

View a PDF of the paper titled Better bounds for the union-closed sets conjecture using the entropy approach, by Stijn Cambie

[View PDF][4] [HTML (experimental)][5]

Abstract: We improve the best known constant $\frac{3-\sqrt 5}{2}$ for which the union-closed conjecture is known to be true, by using dependent samples as suggested by Sawin and the entropy approach on this problem initiated by Gilmer. Meanwhile, we focus on the intuition behind this entropy approach and its boundaries.
