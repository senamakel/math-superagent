# Frankl's Conjecture is True for Modular Lattices

## Abstract.

It is shown that every finite modular lattice *L*with |*L*|≥2 contains a join-irreducible element *x*∈*L*such that at most |*L*|/2 elements *y*∈*L*satisfy *y*≥*x*.
