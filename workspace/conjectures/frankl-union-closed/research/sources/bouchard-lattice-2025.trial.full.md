# On the lattice formulation of the union-closed sets conjecture

Christopher Bouchard

###### Abstract

The union-closed sets conjecture, also known as Frankl’s conjecture, is a well-studied problem with various formulations. In terms of lattices, the conjecture states that every finite lattice L L with more than one element contains a join-irreducible element that is less than or equal to at most half of the elements in L L. In this work, we obtain several necessary conditions for any counterexample L ~ \tilde{L} of minimum size.

## 1. Introduction

Let 𝒜 \mathcal{A} be a finite family of distinct finite sets with at least one nonempty member set. The union-closed sets conjecture, also known as Frankl’s conjecture, states that if X, Y ∈ 𝒜 X,Y\in\mathcal{A} implies that X ∪ Y ∈ 𝒜 X\cup Y\in\mathcal{A}, then there exists an element of ⋃ A ∈ 𝒜 A \bigcup_{A\in\mathcal{A}}A that is in at least | 𝒜 | 2 \frac{|\mathcal{A}|}{2} member sets of 𝒜 \mathcal{A}. With respect to this standard formulation of the conjecture, minimal counterexamples have been studied. For example, in [7] it was shown that for any counterexample 𝒜 ~ \tilde{\mathcal{A}} of minimum size | 𝒜 ~ | |\tilde{\mathcal{A}}|, there must exist at least three elements of ⋃ A ∈ 𝒜 ~ A \bigcup_{A\in\tilde{\mathcal{A}}}A that are each in exactly | 𝒜 ~ | − 1 2 \frac{|\tilde{\mathcal{A}}|-1}{2} member sets of 𝒜 ~ \tilde{\mathcal{A}}. Another result, from [6] and [10], is that | 𝒜 ~ | ≥ 4 ​ | ⋃ A ∈ 𝒜 ∗ A | − 1 |\tilde{\mathcal{A}}|\geq 4|\bigcup_{A\in\mathcal{A}^{*}}A|-1, where 𝒜 ∗ \mathcal{A}^{*} is a counterexample, in this case, with minimum | ⋃ A ∈ 𝒜 ∗ A | |\bigcup_{A\in\mathcal{A}^{*}}A|. In the present work, we consider the lattice formulation of the union-closed sets conjecture (found, for instance, in [8] and [11]), obtaining several necessary conditions for any counterexample of minimum size.

To begin, we recall some terminology. A poset (or partially ordered set) ⟨ P; ≤ P ⟩ \langle P;\leq_{P}\rangle is a set P P equipped with a binary relation ≤ P \leq_{P} on P P that is reflexive, antisymmetric, and transitive. For x, y ∈ P x,y\in P, if x ≤ P y x\leq_{P}y, then we state that x x is less than or equal to y y (and y y is greater than or equal to x x) in P P. Similarly, if x ≤ P y x\leq_{P}y and x ≠ y x\neq y (denoted by x < P y x<_{P}y), then we state that x x is less than y y (and y y is greater than x x) in P P. Two elements x, y ∈ P x,y\in P are comparable in P P if x ≤ P y x\leq_{P}y or y ≤ P x y\leq_{P}x. Otherwise, x x and y y are incomparable in P P, denoted by x ∥ P y x\parallel_{P}y (or y ∥ P x y\parallel_{P}x). We define a subposet ⟨ S; ≤ S ⟩ \langle S;\leq_{S}\rangle of P P to be a poset such that S ⊆ P S\subseteq P and, for all x x and y y in S S, x ≤ S y x\leq_{S}y if and only if x ≤ P y x\leq_{P}y. A poset is linearly ordered if every two of its elements are comparable, and a chain ⟨ C; ≤ C ⟩ \langle C;\leq_{C}\rangle in P P is a linearly ordered subposet of P P. We use the notation ( ↑ x) P = { y ∈ P | x ≤ P y } ({\uparrow}x)_{P}=\{y\in P\ |\ x\leq_{P}y\}, ( ↓ x) P = { y ∈ P | y ≤ P x } ({\downarrow}x)_{P}=\{y\in P\ |\ y\leq_{P}x\}, and ( ∥ x) P = { y ∈ P | x ∥ P y } ({\parallel}x)_{P}=\{y\in P\ |\ x\parallel_{P}y\}. Two elements x, y ∈ P x,y\in P have a join sup P { x, y } \sup_{P}\{x,y\} in P P if sup P { x, y } \sup_{P}\{x,y\} is an element of P P such that both x ≤ sup P P ⁡ { x, y } x\leq_{P}\sup_{P}\{x,y\} and y ≤ sup P P ⁡ { x, y } y\leq_{P}\sup_{P}\{x,y\}, and x ≤ P z x\leq_{P}z and y ≤ P z y\leq_{P}z together imply that sup P { x, y } ≤ P z \sup_{P}\{x,y\}\leq_{P}z for all z ∈ P z\in P. Similarly, x x and y y have a meet inf P { x, y } \inf_{P}\{x,y\} in P P if inf P { x, y } \inf_{P}\{x,y\} is an element of P P such that inf P { x, y } ≤ P x \inf_{P}\{x,y\}\leq_{P}x and inf P { x, y } ≤ P y \inf_{P}\{x,y\}\leq_{P}y, and z ≤ P x z\leq_{P}x and z ≤ P y z\leq_{P}y imply that z ≤ inf P P ⁡ { x, y } z\leq_{P}\inf_{P}\{x,y\}. An element x x upper covers an element y y (and y y lower covers x x) in P P if y < P x y<_{P}x, and for all z ∈ P z\in P, y < P z ≤ P x y<_{P}z\leq_{P}x implies that z = x z=x. An element is join-irreducible in P P if it upper covers exactly one element in P P, meet-irreducible if it lower covers exactly one element, and doubly irreducible if it is both join and meet-irreducible. On the other hand, an element is join-reducible in P P if it upper covers more than one element in P P, meet-reducible if it lower covers more than one element, and doubly reducible if it is both join and meet-reducible.

A poset ⟨ L; ≤ L ⟩ \langle L;\leq_{L}\rangle is a lattice if every two elements x, y ∈ L x,y\in L have both a join and meet in L L. When L L is finite, its greatest element is denoted by 1 L 1_{L} and least element by 0 L 0_{L}. An element that upper covers 0 L 0_{L} in L L is an atom, and an element that lower covers 1 L 1_{L} is a dual atom. For more information on lattices, see [2]. The lattice formulation of the union-closed sets conjecture (phrased, as usual, according to the intersection-closed dual) is stated as follows:

Conjecture 1.1. Any finite lattice L L with more than one element contains a join-irreducible element j j such that | ( ↑ j) L | ≤ | L | 2 |({\uparrow}j)_{L}|\leq\frac{|L|}{2}.

In the next section, we characterize any counterexample L ~ \tilde{L} to Conjecture 1.1 of minimum size | L ~ | |\tilde{L}|. We conclude the current section by considering some pertinent statements regarding lattices in general.

Lemma 1.2 (Agalave, Shewale, and Kharat [1]). An element x ∈ L x\in L is join or meet-irreducible in a finite lattice L L with | L | > 1 |L|>1 if and only if the subposet L ∖ { x } L\setminus\{x\} of L L is a lattice.

Proof. See Lemma 2.1 of [1]. We include here a proof using the present notation. First, we show that if x x is join-irreducible in L L, upper covering a unique element z z in L L, then the subposet L ∖ { x } L\setminus\{x\} of L L is a lattice. Consider any y 1, y 2 ∈ L ∖ { x } y_{1},y_{2}\in L\setminus\{x\}. If inf L { y 1, y 2 } = x \inf_{L}\{y_{1},y_{2}\}=x, then inf L ∖ { x } { y 1, y 2 } = z \inf_{L\setminus\{x\}}\{y_{1},y_{2}\}=z. (Otherwise, there exists an element l l less than or equal to y 1 y_{1} and y 2 y_{2} in L ∖ { x } L\setminus\{x\} such that z < L ∖ { x } l z<_{L\setminus\{x\}}l or z ∥ L ∖ { x } l z\parallel_{L\setminus\{x\}}l (with l < L x l<_{L}x because inf L { y 1, y 2 } = x \inf_{L}\{y_{1},y_{2}\}=x and l ≠ x l\neq x). However, z < L ∖ { x } l z<_{L\setminus\{x\}}l does not hold (because z z lower covers x x in L L), and if z ∥ L ∖ { x } l z\parallel_{L\setminus\{x\}}l, then l ≤ L w l\leq_{L}w for some w ∈ L w\in L such that w ≠ z w\neq z and w w lower covers x x in L L, contradicting the join-irreducibility of x x in L L.) Now, if inf L { y 1, y 2 } ≠ x \inf_{L}\{y_{1},y_{2}\}\neq x, then inf L { y 1, y 2 } ∈ L ∖ { x } \inf_{L}\{y_{1},y_{2}\}\in L\setminus\{x\} and inf L ∖ { x } { y 1, y 2 } = inf L { y 1, y 2 } \inf_{L\setminus\{x\}}\{y_{1},y_{2}\}=\inf_{L}\{y_{1},y_{2}\}. Also, y 1, y 2 ∈ L ∖ { x } y_{1},y_{2}\in L\setminus\{x\} and x x being join-irreducible in L L together imply that sup L { y 1, y 2 } ∈ L ∖ { x } \sup_{L}\{y_{1},y_{2}\}\in L\setminus\{x\}, so we have that sup L ∖ { x } { y 1, y 2 } = sup L { y 1, y 2 } \sup_{L\setminus\{x\}}\{y_{1},y_{2}\}=\sup_{L}\{y_{1},y_{2}\}. Thus, a meet and join exist in L ∖ { x } L\setminus\{x\} for y 1 y_{1} and y 2 y_{2}, and L ∖ { x } L\setminus\{x\} a lattice. If x x is meet-irreducible in L L, then L ∖ { x } L\setminus\{x\} is a lattice by duality.

Next, we show by contraposition that for all x ∈ L x\in L, if the subposet L ∖ { x } L\setminus\{x\} of L L is a lattice, then x x is join or meet-irreducible in L L. If x = 1 L x=1_{L} and is join-reducible in L L, or x = 0 L x=0_{L} and is meet-reducible in L L, then there are, respectively, two dual atoms from L L without a join in L ∖ { x } L\setminus\{x\}, or two atoms from L L without a meet in L ∖ { x } L\setminus\{x\}, so L ∖ { x } L\setminus\{x\} is not a lattice. If x x is doubly reducible in L L, then there exist two elements y 1 y_{1}, y 2 y_{2} that upper cover x x and two elements z 1 z_{1}, z 2 z_{2} that lower cover x x in L L, all distinct. In this case, if sup L ∖ { x } { z 1, z 2 } \sup_{L\setminus\{x\}}\{z_{1},z_{2}\} exists, then x = sup L { z 1, z 2 } < L sup L ∖ { x } { z 1, z 2 } ≤ L y 1 x=\sup_{L}\{z_{1},z_{2}\}<_{L}\sup_{L\setminus\{x\}}\{z_{1},z_{2}\}\leq_{L}y_{1} and x = sup L { z 1, z 2 } < L sup L ∖ { x } { z 1, z 2 } ≤ L y 2 x=\sup_{L}\{z_{1},z_{2}\}<_{L}\sup_{L\setminus\{x\}}\{z_{1},z_{2}\}\leq_{L}y_{2}. Because y 1 ≠ y 2 y_{1}\neq y_{2}, we then have that x < L sup L ∖ { x } { z 1, z 2 } < L y 1 x<_{L}\sup_{L\setminus\{x\}}\{z_{1},z_{2}\}<_{L}y_{1} or x < L sup L ∖ { x } { z 1, z 2 } < L y 2 x<_{L}\sup_{L\setminus\{x\}}\{z_{1},z_{2}\}<_{L}y_{2}, so y 1 y_{1} or y 2 y_{2} does not upper cover x x in L L, a contradiction. Thus, sup L ∖ { x } { z 1, z 2 } \sup_{L\setminus\{x\}}\{z_{1},z_{2}\} does not exist, and L ∖ { x } L\setminus\{x\} is not a lattice, as illustrated in the following figure. This completes the proof of Lemma 1.2.

Lemma 1.3. (i) If j 1 j_{1} and j 2 j_{2} are join-irreducible elements in a finite lattice L L, then j 2 j_{2} is join-irreducible in the subposet L ∖ { j 1 } L\setminus\{j_{1}\} of L L; (ii) If m 1 m_{1} and m 2 m_{2} are meet-irreducible elements in a finite lattice L L, then m 2 m_{2} is meet-irreducible in the subposet L ∖ { m 1 } L\setminus\{m_{1}\} of L L.

Proof. For part (i), we denote by l 1 l_{1} and l 2 l_{2} the unique elements that respectively lower cover j 1 j_{1} and j 2 j_{2} in L L. If l 2 ≠ j 1 l_{2}\neq j_{1}, then l 2 l_{2} is the only element that lower covers j 2 j_{2} in L ∖ { j 1 } L\setminus\{j_{1}\}. Else, l 2 = j 1 l_{2}=j_{1}, making l 1 l_{1} the only element that lower covers l 2 l_{2} in L L. Together with l 2 l_{2} being the only element that lower covers j 2 j_{2} in L L, this implies that l 1 l_{1} is the only element that lower covers j 2 j_{2} in L ∖ { j 1 } L\setminus\{j_{1}\}. Thus, j 2 j_{2} is also join-irreducible in L ∖ { j 1 } L\setminus\{j_{1}\}. Part (ii) follows by duality.

We note that the converse of Lemma 1.3 does not hold (for both parts (i) and (ii)). We consider part (i). Let j j be a join-irreducible element in a finite lattice L L, and x x be an element that upper covers only j j and one other element y y in L L such that y y upper covers the unique element z z that lower covers j j in L L. Here, the converse of the lemma is not satisfied in that, although x x is join-irreducible in the subposet L ∖ { j } L\setminus\{j\} of L L, x x is not join-irreducible in L L.

Theorem 1.4. (i) If J J is a set of join-irreducible elements in a finite lattice L L, then the subposet L ∖ J L\setminus J of L L is a lattice; (ii) If M M is a set of meet-irreducible elements in a finite lattice L L, then the subposet L ∖ M L\setminus M of L L is a lattice.

Proof. Again, we consider only part (i). Without loss of generality, let J = { j 1, ⋯, j | J | } J=\{j_{1},\cdots,j_{|J|}\}. If | J | = 1 |J|=1, then the subposet L ∖ J L\setminus J of L L is a lattice by Lemma 1.2. If | J | > 1 |J|>1, then we first have that the subposet L 1 = L ∖ { j 1 } L_{1}=L\setminus\{j_{1}\} of L L is a lattice by Lemma 1.2, and j 2, ⋯, j | J | j_{2},\cdots,j_{|J|} are join-irreducible in L 1 L_{1} by Lemma 1.3. Then, for all integers k k such that 1 ≤ k ≤ | J | − 1 1\leq k\leq|J|-1, if the subposet L k = L ∖ { j 1, ⋯, j k } L_{k}=L\setminus\{j_{1},\cdots,j_{k}\} of L L is a lattice and j k + 1, ⋯, j | J | j_{k+1},\cdots,j_{|J|} are join-irreducible in L k L_{k}, then the subposet L k + 1 = L k ∖ { j k + 1 } L_{k+1}=L_{k}\setminus\{j_{k+1}\} of L k L_{k} is a lattice by Lemma 1.2 and, when k < | J | − 1 k<|J|-1, j k + 2, ⋯, j | J | j_{k+2},\cdots,j_{|J|} are join-irreducible in L k + 1 L_{k+1} by Lemma 1.3. Thus, we have that the subposet L ∖ J = L | J | = L | J | − 1 ∖ { j | J | } L\setminus J=L_{|J|}=L_{|J|-1}\setminus\{j_{|J|}\} of L | J | − 1 L_{|J|-1} (and therefore of L L) is a lattice, completing the proof of Theorem 1.4.

Theorem 1.4 does not extend, in general, to a finite lattice L L and set I I of join and meet-irreducible elements in L L. A counterexample that demonstrates this is any finite lattice L L with I = { j, m } I=\{j,m\} such that j j is join-irreducible and meet-reducible in L L, m m is meet-irreducible and join-reducible in L L, and j j upper covers m m in L L. In this case, the conclusion of Theorem 1.4 is not satisfied because the subposet L ∖ I L\setminus I of L L is not a lattice.

## 2. Characterizing a counterexample to Conjecture 1.1 of minimum size

We now obtain necessary conditions for any counterexample L ~ \tilde{L} to Conjecture 1.1 such that no counterexample L ^ \hat{L} exists with | L ^ | < | L ~ | |\hat{L}|<|\tilde{L}|. We note that L ~ \tilde{L} must contain more than two elements.

Theorem 2.1. Every join-irreducible element j j in L ~ \tilde{L} (with the unique element that it upper covers in L ~ \tilde{L} denoted by x x) lower covers an element y y in L ~ \tilde{L}, where y y is not less than or equal to any join-irreducible element and y y upper covers exactly one other element z z in L ~ \tilde{L} such that x < L ~ z x<_{\tilde{L}}z.

Proof. If not, then there exists a join-irreducible element j j in L ~ \tilde{L} such that any element y y that upper covers j j in L ~ \tilde{L} satisfies at least one of the following criteria:

(i) y y upper covers more than two elements in L ~ \tilde{L};

(ii) y ≤ L ~ j ∗ y\leq_{\tilde{L}}j^{*} for some join-irreducible j ∗ j^{*} in L ~ \tilde{L};

(iii) y y upper covers j j and exactly one other element z z in L ~ \tilde{L} such that z z is incomparable with x x in L ~ \tilde{L}.

We consider the subposet L ^ = L ~ ∖ { j } \hat{L}=\tilde{L}\setminus\{j\} of L ~ \tilde{L}, which is a lattice by Lemma 1.2, and consider any join-irreducible element ȷ ^ \hat{\jmath} in L ^ \hat{L}. First, we assume that ȷ ^ \hat{\jmath} is also join-irreducible in L ~ \tilde{L}. If ȷ ^ < L ~ j \hat{\jmath}<_{\tilde{L}}j, then | ( ↑ ȷ ^) L ^ | ≥ | ( ↑ j) L ~ | > | L ~ | 2 = | L ^ | + 1 2 |({\uparrow}\hat{\jmath})_{\hat{L}}|\geq|({\uparrow}j)_{\tilde{L}}|>\frac{|\tilde{L}|}{2}=\frac{|\hat{L}|+1}{2}. Else, | ( ↑ ȷ ^) L ^ | = | ( ↑ ȷ ^) L ~ | > | L ~ | 2 = | L ^ | + 1 2 |({\uparrow}\hat{\jmath})_{\hat{L}}|=|({\uparrow}\hat{\jmath})_{\tilde{L}}|>\frac{|\tilde{L}|}{2}=\frac{|\hat{L}|+1}{2}. Next, we assume that ȷ ^ \hat{\jmath} is join-reducible in L ~ \tilde{L}. In this case, ȷ ^ \hat{\jmath} upper covers j j in L ~ \tilde{L}, and so must satisfy at least one of the three criteria in question. (i) is not satisfied, as it implies that ȷ ^ \hat{\jmath} is join-reducible in L ^ \hat{L}. (iii) is not satisfied, as it implies that ȷ ^ \hat{\jmath} upper covers both x x and z z in L ^ \hat{L}, and thus again that ȷ ^ \hat{\jmath} is join-reducible in L ^ \hat{L}. Therefore, any join-irreducible element ȷ ^ \hat{\jmath} in L ^ \hat{L} has | ( ↑ ȷ ^) L ^ | > | L ^ | 2 |({\uparrow}\hat{\jmath})_{\hat{L}}|>\frac{|\hat{L}|}{2}, and L ^ \hat{L} is a counterexample to Conjecture 1.1, contradicting the minimality of | L ~ | |\tilde{L}|. This completes the proof of Theorem 2.1.

Corollary 2.2. 0 L ~ 0_{\tilde{L}} is meet-reducible in L ~ \tilde{L}.

Proof. Otherwise, denote by a a the unique atom of L ~ \tilde{L}. For all x ∈ L ~ ∖ { a } x\in\tilde{L}\setminus\{a\}, sup L ~ { a, x } ∈ { a, x } \sup_{\tilde{L}}\{a,x\}\in\{a,x\}. Corollary 2.4. 1 L ~ 1_{\tilde{L}} is join-reducible in L ~ \tilde{L}.

Proof. If not, then 1 L ~ 1_{\tilde{L}} is join-irreducible in L ~ \tilde{L}, upper covering exactly one dual atom. This contradicts Theorem 2.3, as all dual atoms of a lattice are meet-irreducible.

Theorem 2.6. There is at most one doubly irreducible element in L ~ \tilde{L}.
