# Falgas-Ravry, "Minimal weight in union-closed families" (EJC 18 P95, 2011; arXiv:1101.2589)

**Full text:** [[falgas-ravry-minimal-weight-2011.full]]

Weight-theoretic bound, the combinatorial-line ancestor that the entropy results supersede in the large-|F| regime.

```claim
id: falgasravry-separating-weight
statement: If a union-closed family S separates the points of Ω (i.e. for x≠y some A∈S contains exactly one), then its weight w(S)=Σ_{A∈S}|A| ≥ C(|Ω|,2). Also, point-separating UC families have average degree ≥ ½√(|S|log₂|S|) + O(1), best possible up to factor 2.
hypotheses: S union-closed, point-separating on Ω
holds-here: yes
status: proved
bearing: a weight lower bound in the separating/`|Ω|` regime; relevant to the separating-families line (UC holds if |F| ≤ 2n + n log₂n − log₂log₂n as in the survey, improving this 2n).
anchor: research/sources/falgas-ravry-minimal-weight-2011.full.md
```

**Bearing:** part of the combinatorial/weight line. Not central after the entropy era; of use if the run targets separating families or weight/budget arguments.
