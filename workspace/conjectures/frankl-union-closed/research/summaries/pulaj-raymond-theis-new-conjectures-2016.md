# Pulaj, Raymond, Theis, "New conjectures for union-closed families" (EJC 23(3)#P3.23, 2016)

**Full text:** [[pulaj-raymond-theis-new-conjectures-2016.full]] (EJC abstract only; body paywalled)

Optimization formulation: prove Frankl by showing 2a is an upper bound on the number of sets in a UC family on n elements with each element in ≤a sets, for all a,n. Conjectures (from computed optimal values) that the optimum does not vary with n; the conjectures are shown NOT equivalent to Frankl while having wide-reaching implications.

```claim
id: prt-optimization-formulation
statement: Frankl's conjecture is equivalent to: in a UC family on an n-element ground set with each element in ≤a sets, the number of member sets is ≤ 2a, for all a,n — and (their conjecture) this optimum is n-independent.
hypotheses: union-closed, finite, each element in ≤a sets
holds-here: yes
status: asserted (equivalence/proof sketch; the n-independence is a conjecture, not proved; shown NOT equivalent to Frankl)
bearing: the optimization reformulation GOAL.md cites; a candidate route but the n-independence conjecture is distinct from Frankl itself.
anchor: research/sources/pulaj-raymond-theis-new-conjectures-2016.full.md
```

**Bearing:** the optimization/FC formulation cited in GOAL.md. Its conjectures are weaker-different from Frankl; pursuing them is a distinct line (n-independence), not a step toward UC.
