## What it establishes — new settled lattice classes

New restricted classes (lattice form of Frankl: some join-irreducible a has |[a, 1̂]| ≤ |L|/2), beyond the Poonen/Reinhold/Abe–Nakano/Czédli classes already in the library.

```claim
id: awz-subgroup-lattices
statement: The subgroup lattice L(G) of any finite group G satisfies Frankl's
  (union-closed) conjecture.
hypotheses: G finite group; lattice form (|L(G)| ≥ 2).
holds-here: yes (a whole class of finite lattices settled).
status: proved (Theorem 1.2, source).
bearing: a natural lattice class (subgroup lattices) verified — extends the "restricted
  classes already settled" list in ROOT; the run had no group-theoretic class before.
anchor: research/sources/abdollahi-woodroofe-zaimi-subgroup-lattices-2017.full.md
```

```claim
id: awz-modular-coatom
statement: Every finite lattice with a left-modular coatom m satisfies Frankl's
  conjecture; hence all comodernistic lattices do (these include supersolvable,
  left-modular, and dually semimodular lattices). Also, if L is a lattice with
  1̂ = x∨y for join-irreducibles x,y, then L satisfies Frankl's conjecture.
hypotheses: finite lattice with a left-modular coatom / comodernistic; or 1̂ a join
  of two join-irreducibles.
holds-here: yes
status: proved (Cor 1.7, Thm 1.9, Cor 1.11, source).
bearing: new named lattice classes settled. Comodernistic ⊇ supersolvable ⊇
  dually semimodular — the last is a broad fresh class vs. Reinhold's lower
  semimodular. Meets ROOT's "which lattice classes are settled" item with new rows.
anchor: research/sources/abdollahi-woodroofe-zaimi-subgroup-lattices-2017.full.md
```

```claim
id: awz-main-technical
statement: (Technical theorem) For L a finite lattice, m left-modular in L\{1̂}, and
  x,y join-irreducibles with m ∨ x ∨ y = 1̂, then L satisfies Frankl's conjecture
  with either x or y. Corollary: if G/N is generated by ≤ 2 elements of prime-power
  order for N ◁ G, then L(G) satisfies Frankl's conjecture.
hypotheses: finite lattice; conditions stated.
holds-here: yes
status: proved (Thm 1.3, Cor 1.4, source).
bearing: the reusable structural engine (left-modular element + two join-irreducibles
  join to top) — a concrete sufficient condition the run could hunt for in its own
  minimal-counterexample structural line.
anchor: research/sources/abdollahi-woodroofe-zaimi-subgroup-lattices-2017.full.md
```

## Bearing for this run
The subgroup-lattice and comodernistic-lattice results are new settled classes
nobody in this run had sourced before. The `m ∨ x ∨ y = 1̂` criterion is a sharp,
checkable sufficient condition for UC (lattice form) — directly usable in GOAL
result class 5 (structural theorem about a minimal counterexample): a minimum
counterexample lattice cannot have such an m and two join-irreducibles covering 1̂,
nor can it be comodernistic or a subgroup lattice.
