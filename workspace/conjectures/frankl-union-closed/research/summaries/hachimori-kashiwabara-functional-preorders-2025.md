# Hachimori–Kashiwabara, "Average-Rare Order Ideals in Functional Preorders" (arXiv:2511.19833)

<!-- source: https://arxiv.org/pdf/2511.19833 | converted from PDF -->

Nov 2025 preprint; follow-up to the same authors' arXiv:2504.13454 (on disk as
`hachimori-kashiwabara-averaging-ideal-families-lean-2025.full.md`). All proofs
formally verified in Lean 4; code in the public repository
`github.com/kashiwabarakenji/avg-rare` (claimed by the paper).

## Setting (dual / intersection-closed form)

Work with an intersection-closed family C ⊆ 2^V containing V and ∅ (a closure
system plus ∅). An element is *rare* if it lies in ≤ |C|/2 members; UC is
equivalent to every such family having a rare element (complement symmetry).

**Average-rare (stronger than rare-element existence):** the average over u ∈ V
of deg(u)/|C| is ≤ 1/2, equivalently

    NDS(C) := 2·Σ_{F∈C}|F| − |C|·|V| ≤ 0.

NDS ≤ 0 ⟹ the family is average-rare ⟹ (by averaging) a rare element exists.

Closure systems are represented by *rooted sets* (A, r), r ∉ A: the constraint
"A ⊆ F ⟹ r ∈ F". If every stem has size 1, the closure system is exactly the
family of order ideals of a preorder (Lemma 1.5).

## The two theorems

- **Theorem 2.8 (Main).** For any finite set V and any function f: V → V, the
  functional preorder induced by f (v ≤ w iff f^k(v) = w for some k ≥ 0) has
  order-ideal family I(V, ≤) with NDS(I(V, ≤)) ≤ 0. I.e. the ideal family is
  average-rare.
- **Theorem 2.9 (Secondary).** For a functional partial order — equivalently,
  a *rooted forest* (Lemma 2.10: a poset is functional iff its Hasse diagram is
  acyclic and each component has a unique maximal element) — the order-ideal
  family is average-rare. This is the base case and the reduction target.

The Main Theorem reduces to the Secondary one (Section 3); Section 4 gives an
induction on the number of vertices (remove the unique maximal element;
`NDS(I(V,≤)) = NDS(I(V′,≤′)) + (|V| − |I(V,≤)| + 1) ≤ NDS(I(V′,≤′))`).

## Where this sits for UC

- **Settled class (new, machine-checked):** the order-ideal family of any
  functional preorder is average-rare, hence satisfies Frankl's conjecture.
  This covers rooted-forest posets. The 2504.13454 paper showed ideal families
  (downward-closed except ground set) are average-rare; this paper generalises
  to a preorder setting where each element is the root of at most one rooted
  set (functionality).
- **Why UC is not immediate:** average-rarity fails for general preorders
  (Example 2.7: V = {a,b,c} with rooted sets ({b},a), ({c},a) has NDS = 1 > 0,
  yet Frankl's conjecture still holds there by Lemma 3.1 — a rare element exists
  for *any* preorder's ideal family).
- **Conjecture 6.1 (their extension attempt):** if C is an intersection-closed
  family on finite V, ∅ ∈ C, admitting a rooted-set representation in which
  every element is the root of at most one rooted set, then C is average-rare.
  The rare-element conclusion for this class is still open; a positive answer
  would confirm Frankl's conjecture for that case. If some element is root of no
  rooted set, it is easily rare, so the interesting case is each element the
  root of exactly one rooted set.

## Falsifiers / caveats

- The paper is a v1 arXiv preprint (25 Nov 2025), formally verified but not
  journal-published.
- The claim is about a *restricted class* (closure systems generated by
  singleton-stem rooted sets under a functional constraint); it does not bear
  on the general conjecture beyond providing a verified settled class.
- NDS/rare-element claims are machine-checked; the *reduction* (Theorem 2.8
  from 2.9) is the mathematically substantive step and is also formalised.
