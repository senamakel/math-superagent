## Not yet taken to the literature

Nobody has checked whether these are known theory. Grounding one is cheaper than pursuing it: a named theorem arrives with its hypotheses, and a reformulation somebody already tried arrives with the reason it failed.

- [[automaton-cantor]]: Abram–Lagarias (Part I, arXiv:1308.3133; Part II, arXiv:1508.05967) proved that for integers 1 ≤ M_1 < ... < M_n, the intersection C(M_1,...,M_n) = (1/M_1)Σ_{0,1} ∩ ... ∩ (1/M_n)Σ_{0,1} is a 3-adic fractal whose points have 3-adic expansions described by labeled paths in a finite automaton. The automaton states correspond to "carry configurations" when multiplying a {0,1}-digit Cantor set element by the M_i. For M_i = 2^i (powers of 2), the automaton describes exactly which 3-adic integers λ satisfy (λ·2^i) ∈ Σ_{0,1} for all i ≤ n. The Erdős conjecture is: the set of n such that 2^n = λ (with λ being 2^n itself in Z_3^×) has (2^i·2^n) ∈ Σ_{0,1} for all i is only {0,2,8}. Now, the Sieve-Exact result says: for each fixed k, the low k digits can be made to avoid 2 by 2^(k-1) residue classes of n. In the automaton picture, this means: the automaton for C(1,2,4,...,2^k) has 2^(k-1) accepting paths of length k. The question is whether the automaton state count grows without bound (suggesting infinite intersection) or stabilizes (suggesting finite intersection). Computing the automaton explicitly for growing k and tracking its state count is a direct computational attack on the conjecture via the Abram-Lagarias characterization. Why it fits: This is the one structural characterization of the problem that is provably finite-description: every finite intersection C(1,2,4,...,2^k) is an automaton, and the state-minimized automaton at level k has a well-defined size s(k). If s(k) stabilizes, the infinite intersection is also finite-state and the conjecture can be resolved by inspecting the automaton's cycle structure. If s(k) grows, the growth rate measures how far the orbit is from automatic. Either way, it converts the conjecture into a concrete computational task: build the automaton, minimize it, and read off the answer. No one appears to have done this computation at scale.
- [[joint-real-3adic]]: Lagarias (LAG-4) states that the real truncated method controls the ~log_3 X most significant digits and the 3-adic method controls the ~log_3 X least significant digits, and that combining them is open. The specific gap: for a candidate n to be a counterexample, BOTH sets of digits must avoid 2. Let k = ⌊log_3 X⌋. Then: - Leading constraint: the fractional part {n·log_3 2} must avoid a set of "bad intervals" in [0,1) corresponding to digit-2 in the first few ternary digits. The measure of the bad set for the top k digits is 1 − (2/3)^k. The number of n ≤ X satisfying the leading constraint is ~(2/3)^k X = X^{1 − k·(1 − log_3 2)/log_3 X} ≈ X^{log_3 2} — matching Narkiewicz's exponent. - Trailing constraint: n mod 2·3^(k-1) must lie in A_k, which has 2^(k-1) classes out of 2·3^(k-1). The proportion is (1/2)(2/3)^(k-1). If the two constraints were independent, the joint proportion would be O((2/3)^{2k}) = O(X^{2·log_3(2/3)}) ≈ X^{-0.738...}, which is summable. The difficulty is proving they are sufficiently uncorrelated. But there is a theorem in the right direction: Weyl's criterion and the Koksma–Hlawka inequality. The sequence n ↦ (n·log_3 2 mod 1, n mod M) for M = 2·3^(k-1) is a linear flow on the product of the circle and a finite cyclic group. Its discrepancy can be bounded using the continued fraction expansion of log_3 2. The key: because log_3 2 has bounded partial quotients (or at least, there is a bound on the approximation quality), the joint distribution is close to uniform over ranges of length M·q where q is a convergent denominator. This allows bounding the joint count of n ≤ X that survive both sieves simultaneously. Why it fits: This is the most direct attack on "the middle digits" as Lagarias frames it. The 3-adic method (trailing digits) gives a set of residue classes on n; the real method (leading digits) gives a set of intervals for {n·log_3 2}. The intersection is a set of n that satisfy a simultaneous Diophantine condition. The continued fraction of α_0 = log_3 2 determines the discrepancy between the real and 3-adic constraints. If the discrepancy is small enough relative to the densities, one gets a bound below X^{log_3 2}, which is a genuine improvement on Narkiewicz. This is speculative — the required discrepancy bound may not hold — but it is the natural theorem to attempt.
- [[lucas-binomial]]: For n ≥ 1, write n = 2t + ε with ε ∈ {0,1}. Then 2^n = 2^ε · 4^t = 2^ε · (1+3)^t = 2^ε · Σ_{j=0}^t binom(t,j) 3^j. The coefficient of 3^j in this expansion is binom(t,j) mod (3, carries from lower positions). By Lucas's theorem, binom(t,j) mod 3 = Π_i binom(t_i, j_i) mod 3 where t_i, j_i are the base-3 digits of t and j. The digit at position j in the final ternary expansion is not binom(t,j) alone — carries from lower positions propagate upward. But the carry structure is constrained: a carry of size c into position j can only occur if Σ_{h<j} binom(t,h) 3^{h-j} ≥ 1, i.e., if there is "overflow" from below. The conjecture says: for t large enough (n > 8), there is always at least one position j where the sum of binom(t,j) plus incoming carry ≡ 2 mod 3. The Lucas decomposition means the presence of a digit 2 is determined by the base-3 digit patterns of t and j — this is a completely different structural lens than the residue-class sieve, and it ties the problem to the 2-adic and 3-adic structure of binomial coefficients simultaneously. Why it fits: The sieve-dynamics thread proved |A_k| = 2^(k-1) forever — the low-digit structure never forces a 2. The binomial expansion exposes the whole number at once, not just the trailing digits. The Lucas decomposition of binom(t,j) mod 3 means every ternary digit is a product of LOCAL decisions (one per base-3 digit of t and j), but carries are NONLOCAL. The obstruction to digit-2-free-ness would then be: the nonlocal carry structure must produce a 2 somewhere, even though locally (at each digit position) the binomial coefficients mod 3 avoid creating one. This is a "global constraint from local rules" problem, which is the right shape for a theorem.
