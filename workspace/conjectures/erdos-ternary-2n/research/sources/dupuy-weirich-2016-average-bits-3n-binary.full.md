# Dupuy & Weirich — Bits of 3^n in binary (2016): source status

This file is a note, not a primary source. `https://tdupu.github.io/papers.html`
is Taylor Dupuy's publication list; it confirms the paper's existence and
citation but contains no mathematics. It was downloaded while hunting a free
full text, which is not openly available.

The correct paper: T. Dupuy and D. E. Weirich, *Bits of 3^n in binary,
Wieferich primes and a conjecture of Erdős*, J. Number Theory **158** (2016),
268–280. DOI: https://doi.org/10.1016/j.jnt.2015.05.022 (paywalled).

What the run holds about it:
- `research/sources/dupuy-weirich-2015-bits-of-3n-binary-wieferich-erdos.full.md`
  is a correction note (the file originally held an unrelated astrophysics paper
  downloaded from the wrong arXiv ID).
- The paper's theorem is reported secondhand by the library-held Li–Zhao 2026
  source: for distinct primes p, q and a digit b, the frequency of b in the
  q-ary expansion of p^n tends to 1/q as n → ∞ (equidistribution of the ternary
  digits of 2^n in the limit). This is asserted-by-source (secondary), not
  read here.

Gap: no primary full text of Dupuy–Weirich is in the library. If the run needs
the theorem's exact hypotheses (which p, q, b, and under what uniformity), it
must be requested via `research/REQUESTS.md`.
