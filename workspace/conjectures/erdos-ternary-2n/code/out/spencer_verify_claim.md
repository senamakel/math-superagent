## Why the proof is still unsound

Theorem 12.1 rests on a length-3 local classification (Lemma 6.1) and asserts, without
an induction, that every arbitrary-length clean word decomposes into isolated primitive
packets. Carries couple across block boundaries (Remark 6.3 concedes `20` is only a
carry-propagation segment), and the canonical packet `2101_3 = 64` is itself a 4-digit
coupling NOT generated by the length-3 exhaustion — it is found by inspection. So other
longer couplings are not ruled out. This is a missing induction, not a wrong witness:
the falsification oracle `n = 0, 2, 8` does NOT catch it.
