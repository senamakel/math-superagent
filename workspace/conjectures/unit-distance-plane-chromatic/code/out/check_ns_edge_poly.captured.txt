Claim: S(a,b) = a^3 + a^2 b + a b^2 + b^3 vanishes iff a != b among the 4th
roots of unity {1, i, -1, -i}.

Proof (exact, by hand):
  S(a,b) = (a^4 - b^4)/(a - b)   [geometric series factorisation, valid a != b]
  For 4th roots of unity, a^4 = b^4 = 1, so a^4 - b^4 = 0.
  - If a != b: denominator a-b != 0, so S = 0/(a-b) = 0.  CORRECT (edge).
  - If a == b: S = 4 a^3, and a^3 is a 4th root of unity so |4a^3| = 4 != 0.
    CORRECT (no edge).

Hence I = <x_v^4 - 1> + <S_e> has variety exactly the proper 4-colourings, and
by the Weak Nullstellensatz over the algebraic closure, V(I) = emptyset iff
1 in I. This is the load-bearing correctness of the nullstellensatz-colouring-
certificate approach and it HOLDS.
