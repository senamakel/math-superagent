# Approach: EDM / stress-matrix rigidity formulation

```approach
idea: Reformulate unit-distance graphs as Euclidean Distance Matrices (rank-2 EDMs), and use the self-stress space of the framework — the kernel of the rigidity matrix / the space of stress matrices — as the rigidity invariant the run has never computed, turning realization and forced-pair detection into exact rank-2 PSD completions.
mechanism: A UDG on n points is exactly an n x n Euclidean Distance Matrix D with zero diagonal, D_ij = 1 on edges, D_ij != 1 off edges, and rank <= 2 (equivalently Cayley-Menger determinants of every 4/5-subset vanishing and the right signs), whose rank-2 factorization D = Gram = X X^T is the coordinate realization the run already owns. The new object is the self-stress space: symmetric matrices Omega with (i) Omega * 1 = 0, (ii) Omega_ij = 0 whenever ij is a non-edge, (iii) Omega * X = 0 (equilibrium). Its dimension is a complete measure of algebraic rigidity: a framework is rigid iff the only self-stress is zero, and second-order rigidity (Connelly's theory) tells when infinitesimal rigidity is genuine. A 5-critical unit-distance graph must be rigid — a flex would preserve all unit edges under a continuous motion, contradicting the finiteness/minimality of a critical structure. So the stress-matrix rank is an exact certificate the run does not currently compute (the adopted Henneberg line is generic/combinatorial rigidity; this is the complementary special-position rigidity that generic methods miss, and the UDG problem lives precisely at special positions). The second payoff: realization of a candidate abstract 4-critical graph H becomes the feasibility of the polynomial system {edge entries = 1, non-edge entries != 1, all 5-point Cayley-Menger determinants = 0}, decided exactly by Groebner basis for fixed small H — a fixed-size algebra computation, not a continuum point-set search.
status: proposed
first-step: Write code/lib/edm_stress.py: from the certified exact coordinates of the Moser spindle and Moser+Moser, build D = X X^T, then solve the linear system Omega X = 0, Omega 1 = 0, Omega_ij = 0 (non-edges) over the exact field Q(sqrt3,sqrt11,sqrt33) and report dim(self-stress space) for each. Calibrate: the Moser spindle (rigid, 4-chromatic) should have trivial stress space; a deliberately flexible gadget (two rhombi sharing only a vertex) should have positive stress dimension. Then wire the stress rank in as the rigidity grader every construction is measured against.
speculative: whether the stress-matrix/EDM realization oracle produces a new forced pair or 5-chromatic witness is open; the certain value is the rigidity invariant plus an exact realization oracle for fixed small candidate graphs.
```
