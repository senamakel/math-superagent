# Approach: Hadwiger / K5-minor size bound

```approach
idea: Convert "5-chromatic unit-distance graph" into "K4-free unit-distance graph containing a K5 minor" via Hadwiger's theorem at k=5, then prove a lower bound on the number of vertices of the latter — a size-bound route orthogonal to the Kostochka-Yancey + Spencer-Szemeredi-Trotter density route that died at N <= 9.
mechanism: Hadwiger's theorem at k=5 (equivalent to the Four-Colour Theorem) gives: chi(G) >= 5 implies G contains a K5 minor (the reverse direction being the 4CT). The plane's unit-distance graph is K4-free — no four mutually unit-distance points exist (certified exactly by the run's sharp-nbhd K4-freeness Groebner certificate) — so a 5-chromatic UDG must carry a K5 minor whose branch sets are spread out, non-clique configurations. The structure of K4-free graphs *without* a K5 minor is a known excluded-minor class (the K4-free, K5-minor-free graphs are partial 2-trees / series-parallel-like, in particular 4-colourable); a K5 minor is therefore exactly what forces the non-4-colourability at the topological level. Concretely a K5 minor forces a specific 5-branch-set topological configuration in the plane, and each branch set's unit-distance realization contributes a minimal number of vertices; a clean counting argument over these five arms gives a lower bound on |V| for any K4-free UDG with a K5 minor, and hence for any 5-chromatic UDG. This attacks the size bound with a *topological/minor obstruction* instead of the edge-density obstruction, which provably cannot beat N=11 (see the discharging refutation).
status: proposed
first-step: Pin the excluded-minor structure theorem (K4-free graphs with no K5 minor) and its exact consequence for minimum vertex count, then realize small K5-subdivisions / wheels / prisms as unit-distance graphs through the exact EDM/realization oracle and compute the minimum vertex count among K4-free UDGs with a K5 minor (minor verified by an exact minor-search). That minimum is the new size-bound candidate; proving no smaller one exists below the pinned N is the theorem.
speculative: whether the K5-minor counting lower bound beats the census's N=11 is open; the minor-structure argument is a derivation to be carried out, and the named mathematics (Hadwiger k=5 = 4CT, Wagner's theorem, the K4-free K5-minor-free excluded class) is standard but its unit-distance vertex-count consequence is unrecorded.
```
