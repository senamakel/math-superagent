# Arithmetic restricted-class bound: UDGs over small fields are 4-colourable

```approach
idea: Prove a restricted-class theorem: every unit-distance graph realisable
over a real quadratic number field is 4-colourable (with a ladder over fields of
small unit rank), and name the exact arithmetic invariant that would have to grow
for a 5-chromatic construction to appear. This is a bound on chi by number
theory — the unit group / norm form of the coordinate field — rather than by
graph combinatorics, and it is the *inverse* of the refuted "field choice =
rigidity lever" heuristic: not "big fields give more unit vectors", but "small
fields cannot realise a 5-chromatic configuration".
status: refuted (hypothesis itself fails on the base field — see killed-by)
first-step: Compute the unit-circle K-point structure for K = Q(sqrt3), Q(sqrt11),
Q(sqrt5): the unit vectors (x,y) in K^2 with x^2+y^2=1 (parametrised by t in K
via the standard conic parametrisation; infinitely many, so this is NOT the
refuted finite-direction claim), identify the subgroup they generate in K^x and
which unit-distance closures they can realise, then run the census of chi over
every UDG the run can construct in each field (SAT oracle, already calibrated).
Deliverable: a verified restricted-class theorem plus the precise arithmetic
obstruction (a needed unit-group/rank datum) that a 5-chromatic construction
would have to exhibit.
mechanism: The problem statement's obstruction says useful point sets must be
rigid via algebraic structure, and the run's own constructions live in the
biquadratic field Q(sqrt3,sqrt11). A unit-distance graph over a field K has its
unit vectors constrained by the multiplicative structure of K: the unit circle's
K-points, the units of bounded norm, and Dirichlet's unit theorem. Over a real
quadratic field the unit rank is 1, which is a strong structural constraint on
which chords can close, plausibly strong enough to force 4-colourability by a
local/global argument. If it holds, it yields a citable, Lean-formalisable
"restricted class already settled" result (exactly the deliverable the run's
ROOT.md asks for) and it isolates, by contraposition, the arithmetic upgrade a
5-chromatic witness would need. The Eisenstein field Q(sqrt-3) (unit rank 0,
contains a 6th root of unity) is already known 3-colourable, so "real quadratic
=> 4-colourable" is the honest first rung; the conjecture may fail for fields
containing a 3rd/6th root of unity, and that failure is itself the named
obstruction. Marked speculative: it is a conjecture to be established by norm
and unit structure, not a known theorem.
precedent:
  - The rational plane is the clearest prior art and it does not behave as the
    candidate hopes: chi(Q^2, 1) = **2** — the rational unit-distance graph is
    bipartite (Woodall 1973; standard exercise: parity of step vectors forbids
    odd cycles). So "small field => low chromatic number" holds in the strongest
    possible way over Q itself (2, not 4).
  - Birch (1964) / Brownman: the real (and rational) unit-distance graph has
    chromatic number ≥ 3; over Q^2 it is exactly 2. (See the Auburn dissertation
    and the Cambridge/Bull. survey: chi(U^2_Q)=2, chi(U^3_Q)=2, chi(U^4_Q)=4.)
  - Dirichlet's unit theorem: for a real quadratic field, unit rank = 1,
    O^× ≅ {±1} × Z generated by a fundamental unit (solves Pell x^2−dy^2=±1).
    Confirmed standard (Stein ANT notes; Conrad "unittheorem"; Reed notes). This
    is the "unit rank 1" the candidate leans on — it is TRUE, but see killed-by
    for why it does not deliver the claim.
  - Eisenstein field Q(sqrt−3): unit rank 0 (only the six roots of unity), and
    the run's claim einstein-lattice-unit-distance already certified its
    triangular lattice is 3-colourable.
  - claim einstein-lattice-unit-distance, maehara-algebraic-rigid-distances
    (algebraic-coordinate machinery the restricted-class statement would need).
killed-by: base-field-2-colorable-not-4 (the rational plane itself is already
  2-colourable, so the claimed ladder's first realistically-cited rung is
  Q^2: chi=2, far below 4 — the "restricted class already settled" framing
  trivialises, and real-quadratic fields sit strictly between the trivial Q
  case and the genuinely hard plane, giving no 4-colourability boundary);
  unit-rank-does-not-control-colourability (Dirichlet's rank-1 structure of the
  unit group, on which the candidate's mechanism rests, is a statement purely
  about multiplicative units in K and has no established connection to whether
  a unit-distance graph's coordinate kernel admits a 4-colouring; unit rank 1
  does not bound the set of unit *vectors* in K^2, which is infinite via the
  conic parametrisation — the exact point the refuted unit-circle-projective
  line already made: P^1(K) is infinite, so the "finite direction set" reading
  is false; and over the actually-used field Q(sqrt3,sqrt11) the run's own
  seven-vertex Moser spindle is 4-chromatic, so the field is NOT trivially
  4-colourable in a way that would make the restricted-class claim interesting
  or false).
```

## Literature verdict (evidence, and why the candidate's own mechanism fails)

The candidate is **explicitly flagged speculative** and the skeleton's hopes do
not survive contact with the literature — not because the number theory is
wrong, but because it does not connect to colorability the way the proposal
assumes.

**The number theory is correct but inert.** Over a real quadratic K, Dirichlet's
unit theorem gives O_K^× ≅ {±1} × Z (rank 1, one fundamental unit, Pell). That
is a true and important statement — but it describes the **multiplicative units
of the ring of integers**, i.e. the solutions to the norm equation x²−dy²=±1. The
unit-distance graph's geometry is controlled by the **points of the unit circle**
x²+y²=1 in K², which by the standard rational parametrisation are an *infinite
family* indexed by t ∈ K, not by the unit group. So the candidate's own premise —
that "unit rank 1 is a strong structural constraint on which chords can close" —
fails at the word "constraint": rank-1 multiplicative units do not bound the
set of unit vectors, and the candidate itself acknowledges this in first-step
("infinitely many, so this is NOT the refuted finite-direction claim"). Rank 1
therefore neither fewer nor bounds the chord directions available; nothing in
the rank-1 structure is known to force 4-colourability. This is exactly the
objection that already closed `unit-circle-projective-parametrization`, and the
candidate does not mount a new argument against it.

**The base-field rung is not where the proposal thinks.** The cleanest
restricted-class result quoted by the literature is over **Q**: χ(Q², 1) = 2
(bipartite), not 4. So the first rung of any "small field" ladder is not
"4-colourable" but "2-colourable" — the restricted-class framing as a *step
toward* chi≤4 collapses, because the base class it would start from gives a
much stronger (2-colourable) statement that already separates it from the hard
plane in the wrong way. A real-quadratic field sits strictly between the trivial
Q case and the plane, and that breathing room gives no boundary at 4:
nothing in the literature shows any real-quadratic UDG is 4-colourable, and the
run's own Moser spindle lives in the *biquadratic* Q(√3,√11) where chi=4 is
attained.

**What the proposal would actually need, and whether anyone has it.** To prove
"every UDG over a real-quadratic field is 4-colourable" one needs a structural
statement about which finite point sets in a quadratic field can be pairwise
jointed, i.e. a rigidity/quantifier bound over the algebraic closure — not a
unit-group fact. No such theorem was found. Without it, the candidate is a
conjecture whose stated supporting mechanism is refuted, not a grounded
restricted-class result.

## Decision — refuted

The literature does not support it, and its named mechanism (Dirichlet unit rank
1 ⇒ chord-set constrained ⇒ 4-colourable) is refuted at the middle step:
unit rank constrains the multiplicative units, not the (infinite) set of unit
vectors, and the cleanest small-field class Q² is 2-colourable, not 4, so the
claimed ladder's first rung trivialises rather than building toward χ≤4. This is
a refutation on evidence, not on absence: the specific path the candidate names
(unit group / norm form ⇒ colorability) has no support and the unit-rank step is
demonstrably a non-sequitur for the reason recorded in `unit-circle-projective-
parametrization`. The conjecture "every real-quadratic UDG is 4-colourable" may
still be true — it is simply not grounded by this candidate's rationale, and no
evidence for it was found.
