# Citation graph — Algebraic Distance Graphs and Rigidity

**M. Homma, H. Maehara** (1990). Transactions of the American Mathematical Society. Cited 1 times.

## Abstract

An algebraic distance graph is defined to be a graph with vertices in ${E^n}$ in which two vertices are adjacent if and only if the distance between them is an algebraic number. It is proved that an algebraic distance graph with finite vertex set is complete if and only if the graph is "rigid". Applying this result, we prove that (1) if all the sides of a convex polygon $\Gamma$ which is inscribed in a circle are algebraic numbers, then the circumradius and all diagonals of $\Gamma$ are also algebraic numbers, (2) the chromatic number of the algebraic distance graph on a circle of radius $r$ is $\infty$ or $2$ accordingly as $r$ is algebraic or not. We also prove that for any $n > 0$, there exists a graph $G$ which cannot be represented as an algebraic distance graph in ${E^n}$.

## What the abstract actually establishes (scholar's digest)

This is the **companion paper** recalled with Maehara 1991 (`maehara-algebraic-rigid-distances`): Homma & Maehara, "Algebraic Distance Graphs and Rigidity", TAMS 319 (1990) 561–572, DOI 10.2307/2001254. The abstract (reproduced above) yields four concrete statements:

1. **Rigid ⟺ complete algebraic-distance graph.** For a finite `X ⊂ E^n`, the *algebraic-distance graph* on X (adjacent iff distance is **algebraic**) is **complete iff X is rigid**. This is the stronger, symmetric form of the direction already in the ledger: rigidity ⟹ all mutual distances algebraic, and conversely the algebraic-completeness forces rigidity.
2. **Convex-polygon closure.** A convex polygon with algebraic sides has algebraic diagonals and algebraic circumradius.
3. **Circle chromatic dichotomy.** The algebraic-distance graph on a circle of radius `r` has chromatic number **∞ iff r is algebraic**, **2 iff r is not**. (Note: this is the *algebraic-distance* graph, a superset of the unit-distance graph; it is a $\infty$/2 dichotomy, not a statement about finite unit-distance colouring.)
4. **Non-representability.** For any `n > 0` there is a graph not representable as an algebraic-distance graph in `E^n`.

**Bearing here:** reinforces the `maehara-algebraic-rigid-distances` exact-arithmetic discipline (no new contradiction; it is the same paper already recalled). Item 3 is a useful caution against over-reading "algebraic ⟹ nice": algebraic point sets can host infinitely-chromatic *algebraic-distance* graphs — so algebraicity alone buys nothing for colouring; only the constrained unit-distance subgraph and its rigidity matter.
