## What closed, and why

- [[alon-tarsi-coefficient-certificate]] (refuted): alon-tarsi-is-upper-bound-not-noncolorability-certificate
- [[circular-chromatic-sharpened-bound]] (refuted): no shortcut and no crossing. (1) chi(G) = ceil(chi_c(G)) is an identity, so deciding chi_c > 4 is exactly as hard as the 4-colourability SAT the run already owns. (2) The only cheap closed form — the vertex-transitive Eisenstein (triangular) lattice — is 3-colourable, so chi_c = 3 there and never crosses 4. What remains is a tightness heuristic, not a certificate.

## Not yet taken to the literature

Nobody has checked whether these are known theory. Grounding one is cheaper than pursuing it: a named theorem arrives with its hypotheses, and a reformulation somebody already tried arrives with the reason it failed.

- [[edm-stress-matrix-rigidity]]: A UDG on n points is exactly an n x n Euclidean Distance Matrix D with zero diagonal, D_ij = 1 on edges, D_ij != 1 off edges, and rank <= 2 (equivalently Cayley-Menger determinants of every 4/5-subset vanishing and the right signs), whose rank-2 factorization D = Gram = X X^T is the coordinate realization the run already owns. The new object is the self-stress space: symmetric matrices Omega with (i) Omega * 1 = 0, (ii) Omega_ij = 0 whenever ij is a non-edge, (iii) Omega * X = 0 (equilibrium). Its dimension is a complete measure of algebraic rigidity: a framework is rigid iff the only self-stress is zero, and second-order rigidity (Connelly's theory) tells when infinitesimal rigidity is genuine. A 5-critical unit-distance graph must be rigid — a flex would preserve all unit edges under a continuous motion, contradicting the finiteness/minimality of a critical structure. So the stress-matrix rank is an exact certificate the run does not currently compute (the adopted Henneberg line is generic/combinatorial rigidity; this is the complementary special-position rigidity that generic methods miss, and the UDG problem lives precisely at special positions). The second payoff: realization of a candidate abstract 4-critical graph H becomes the feasibility of the polynomial system {edge entries = 1, non-edge entries != 1, all 5-point Cayley-Menger determinants = 0}, decided exactly by Groebner basis for fixed small H — a fixed-size algebra computation, not a continuum point-set search.
- [[hadwiger-k5-minor-size-bound]]: Hadwiger's theorem at k=5 (equivalent to the Four-Colour Theorem) gives: chi(G) >= 5 implies G contains a K5 minor (the reverse direction being the 4CT). The plane's unit-distance graph is K4-free — no four mutually unit-distance points exist (certified exactly by the run's sharp-nbhd K4-freeness Groebner certificate) — so a 5-chromatic UDG must carry a K5 minor whose branch sets are spread out, non-clique configurations. The structure of K4-free graphs *without* a K5 minor is a known excluded-minor class (the K4-free, K5-minor-free graphs are partial 2-trees / series-parallel-like, in particular 4-colourable); a K5 minor is therefore exactly what forces the non-4-colourability at the topological level. Concretely a K5 minor forces a specific 5-branch-set topological configuration in the plane, and each branch set's unit-distance realization contributes a minimal number of vertices; a clean counting argument over these five arms gives a lower bound on |V| for any K4-free UDG with a K5 minor, and hence for any 5-chromatic UDG. This attacks the size bound with a *topological/minor obstruction* instead of the edge-density obstruction, which provably cannot beat N=11 (see the discharging refutation).
- [[locally-cyclic-kernel-classification]]: The certified sharp-nbhd lemma gives N(v) max degree 2, i.e. a disjoint union of paths and at most one 6-cycle, with consecutive neighbours 60 degrees apart. A degree-4 or degree-5 vertex has N(v) = a path with a 120-or-180-degree gap; a degree-6 vertex has N(v) = C6. The structural reduction: a vertex whose neighbourhood is a *proper path* is reducible in a 5-critical graph (Kempe-chain / generalized-Brooks argument — four colours suffice to recolour its <= 5 path-neighbours and free the vertex), so a minimal counterexample has every vertex of degree 6 with N(v) = C6 — i.e. is *locally cyclic*. Locally cyclic graphs are classified: the connected locally cyclic graphs are quotients of the infinite triangular (A2) lattice, together with finitely many sporadic examples (the Perkel graph, 57 vertices, is the smallest non-quotient). A K4-free locally cyclic graph is thus a finite quotient of the A2 lattice, and its chromatic number is controlled by the quotient's winding/balanced-ness: balanced quotients inherit the lattice's 3-colouring, and the unbalanced (4-chromatic) quotients form an explicitly characterizable set. If every such quotient is 4-colourable, the size bound holds for *every* N at once, with no enumeration — and the 4-critical quotients form a finite explicit list, which is exactly the set of candidate bases for a 5-chromatic construction.
