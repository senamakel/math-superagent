# arXiv:2605.20475 — Maciejewski, _Bounded-box reductions in the Subbarao–Warren problem for unitary perfect numbers_

**Real digest moved to `research/notes/paper-extraction.md`.** This file is a
pointer; the full text is at `[[maciejewski-bounded-box-subbarao-warren.full]]`.

In one line: the paper does **not** prove finiteness of the Subbarao–Warren
conjecture. It gives a rigorous reduction of the remaining branch to finiteness
of `H_even = { even m : every prime divisor of 2^m+1 is 3-Higgs }`, a strict
finite frontier (`|H_even ∩ [2,40000]| ≤ 201`, `|H_even ∩ [2,50000]| ≤ 272`, no
verified element in `(122,50000]`), an impossibility certificate for the five
impostor kernels, and it identifies the exact missing theorem: **divisor-level
control of the prime divisors of the cyclotomic value `Φ_{4p}(2)`** (Conjectures
23/24/29). Thinness (Theorem 21) and GRH/Chebotarev are shown to be the wrong
scale — the primitive-divisor set of `Φ_{4p}(2)` is a finite set, not a range.

Key structural results: Prop 4 (Higgs-cubefree structure), Prop 5 (`H_even ⊆
{m ≡ 2 mod 4}`), Thm 7 (`|H_even| ≤ 4^N` prime-case reduction), Thm 8 (the ten
verified values), Thms 9–19 (candidate sets), Lemma 20 (deep-Pratt closures),
Thm 21 (power-saving thinness), Thm 30 (conditional finiteness under mod-16
divisor equidistribution H1 + ω-growth H2 — both conjectural, H1 not a
GRH/Chebotarev consequence), Prop 31/Cor 32 (impostor-branch ↔ H_even link).
