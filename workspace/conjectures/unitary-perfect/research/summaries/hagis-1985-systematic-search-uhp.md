# Hagis (1985), *A systematic search for unitary hyperperfect numbers*, Fib. Quart. 25(1) 6–10

Full text: [[hagis-1985-systematic-search-uhp.full]]

**Setup.** `m` is unitary hyperperfect (UHP) of order `t` if
`σ*(m) = (t+1)/t · m`... in the paper's normalization, HP order `t`:
`σ*(m) = ((t+1)/t)·m + (t-1)`-type recurrence — the digest records the worked
form `σ*(m) − m = (m+...)/t`-style; the propositions below are the usable
statements.

**Propositions (proved in the paper):**
- Prop 1: if `m` is UHP of order `t`, then `(m, t) = 1` and `m`, `t` are of
  opposite parity.
- Prop 2: if `m = r^y·s^z·x` is UHP of odd order `t`, then `2 | m` and either
  `m = 2^y·3^x` or `3 | m`.
- Prop 3: if `m = r^y·s^z·x` is UHP of order `t`, then `m > 4t^2`.
- Prop 4: `m` UHP (or HP) of order `t` with `n` prime-power components
  ⇒ `m > (nt)^n`.

Context data: all 151 HPs below 10^8 (te Riele) and all 146 UHPs below 10^8
(Buell) are known.

## Bearing on this run

**None.** Unitary hyperperfect numbers are an adjacent problem (the `σ*(m) =
c·m + d` family); none of Propositions 1–4 constrains unitary perfect numbers
(`σ*(n) = 2n`). The paper is a search-procedure development, which this run has
independently ruled out as the wrong instrument (GOAL.md: no numeric search).
Record once, do not re-read.
