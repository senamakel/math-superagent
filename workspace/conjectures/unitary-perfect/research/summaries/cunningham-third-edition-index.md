# The Third Edition of the Cunningham Book

The Third Edition of the book, Factorizations of b n &plusmn; 1, b = 2, 3, 5, 6, 7, 10, 11, 12, up to High Powers, by John Brillhart, D.H. Lehmer, J.L. Selfridge, Bryant Tuckerman, and S.S. Wagstaff, Jr., is an electronic book published as Contemporary Mathematics, Volume 22, by the [American Mathematical Society][1] in 2002. This Web site gives the on-line and full versions of the tables in that book. This Web site does not give the text of the book. The full version of the book is available as a pdf file at [this Web site.][2]
