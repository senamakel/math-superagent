# Goldbach primary reference set

This library is sufficient for phase 1: `research/ROOT.md` records minimal-counterexample structure, the authoritative exhaustive bound, and at least three settled restricted classes. Full texts are in `research/sources/`, summaries in `research/summaries/`, and source URLs are preserved in each downloaded document.

## Library status
The source set contains approximately 35 full texts and corresponding bounded summaries, including Chen, circle-method, parity, exceptional-set, computational, conditional-GRH/Elliott–Halberstam, and recent restricted-class work. The phase-1 stopping criterion is met. Remaining explicit gaps are recorded in `research/ROOT.md` and `derived/REQUESTS.md`, notably the original Montgomery–Vaughan 1975 full text and Chen’s original 1973 paper.
