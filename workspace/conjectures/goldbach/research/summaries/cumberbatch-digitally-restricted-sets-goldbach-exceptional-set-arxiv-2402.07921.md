# Cumberbatch (2024), digitally restricted sets
[[cumberbatch-digitally-restricted-sets-goldbach-exceptional-set-arxiv-2402.07921.full]]

Source: https://arxiv.org/abs/2402.07921 (v1, 3 Feb 2024).

```claim
id: cumberbatch-digitally-restricted-exceptional
statement: For any base b and digit set D⊆{0,…,b−1} with |D|≥2, there is δ(D,b)>0 such that within the set A of numbers whose base-b digits all lie in D, the number of even n≤X in A not representable as a sum of two primes is ≪ |A(X)|^(1−δ).
hypotheses: base b≥2; digit set D with at least two digits; X large.
holds-here: yes
status: asserted
bearing: A power-saving exceptional-set result on a sparse, digit-restricted set: Goldbach holds for almost all digitally restricted even integers. It is a density result on a thin set (|A(X)| ≪ X^log_b|D|), not an every-n theorem even on A. A new restricted-class angle for the binary problem, but the δ is not explicit.
anchor: research/sources/cumberbatch-digitally-restricted-sets-goldbach-exceptional-set-arxiv-2402.07921.full.md
```

The exceptional set is measured in the counting function of A itself, so the saving is relative to the thin set. This matches the earlier recalled memory of this source.
