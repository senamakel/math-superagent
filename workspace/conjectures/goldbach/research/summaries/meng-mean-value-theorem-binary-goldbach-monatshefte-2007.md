# Meng (2007), mean value theorem for binary Goldbach
[[meng-mean-value-theorem-binary-goldbach-monatshefte-2007.full]]

Source: https://link.springer.com/article/10.1007/s00605-007-0456-6 (Monatsh. Math. 151 (2007) 319–332).

```claim
id: meng-2007-mean-value-ap
statement: For almost all sufficiently large even n with n≢2 (mod 6), the equation p1+p2=n is solvable with p1+2∈P3; for every sufficiently large odd n̄ with n̄≢1 (mod 6), p1+p2+p3=n̄ is solvable with p1+2∈P2 and p2+2∈P3. P_k = integers with at most k prime factors, counted with multiplicity.
hypotheses: n even sufficiently large, n≢2 mod 6; n̄ odd sufficiently large, n̄≢1 mod 6.
holds-here: yes
status: asserted
bearing: The (3,8) result in the chain Tolev (5,7) → Meng (3,8) → Matomäki (2,7) → Grimmelt–Teräväinen (2,3 power-saving) that the 2025/2026 papers improve. Shows binary Goldbach holds for almost all n with one prime shifted to an almost-prime; the exceptional set is only logarithmic. A predecessor in the restricted-class ladder, now superseded.
anchor: research/sources/meng-mean-value-theorem-binary-goldbach-monatshefte-2007.full.md
```
