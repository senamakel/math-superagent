# Brüdern–Kaczorowski–Perelli (2019), explicit formulae for averages of Goldbach representations
[[bkp-explicit-formulae-averages-goldbach-representations-arxiv-1712.00737.full]]

Source: https://arxiv.org/abs/1712.00737 (v1, 3 Dec 2017); published Trans. Amer. Math. Soc. 372 (2019) 6981–6999 (per the arXiv journal reference).

```claim
id: bkp-cesaro-riesz-explicit-formula
statement: There is an explicit formula, analogous to the classical explicit formula for ψ(x), for the Cesàro–Riesz mean of any order k>0 of the number of representations of n as a sum of two primes. The proof uses a double Mellin transform and analytic continuation of the functions arising therein.
hypotheses: k>0 (Cesàro–Riesz order); n the summation variable; no hypothesis beyond convergence of the Mellin transforms used.
holds-here: yes
status: asserted
bearing: The sharpest explicit average formula for Goldbach representation counts; complements Goldston–Suriajaya's unconditional Fujii formula and Pintz's explicit major-arc formula. It is an average identity (Cesàro–Riesz mean), not an every-n statement, so it cannot resolve binary Goldbach; it is a tool for the average-order / RH-equivalence thread and the minor-arc analysis on the R-density-delta rung.
anchor: research/sources/bkp-explicit-formulae-averages-goldbach-representations-arxiv-1712.00737.full.md
```
