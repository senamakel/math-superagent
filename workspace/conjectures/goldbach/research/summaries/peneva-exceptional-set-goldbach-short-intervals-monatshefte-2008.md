# Matomäki (2008), exceptional set in short intervals
[[peneva-exceptional-set-goldbach-short-intervals-monatshefte-2008.full]]

Source: https://link.springer.com/article/10.1007/s00605-008-0561-1 (Monatsh. Math. 155 (2008) 167–189).

**Important: this file is misnamed.** The filename says "peneva-exceptional-set…" but the article is **Kaisa Matomäki, "On the exceptional set in Goldbach's problem in short intervals"**. Peneva's 2001 paper of the same title is a different paper (Monatsh. Math. 132 (2001) 49–65, with a 2004 corrigendum). The library-status note's "(7) Peneva 2008 short-interval exceptional set" should read Matomäki 2008.

```claim
id: matomaki-2008-short-interval-exceptional
statement: For 1/5 < θ ≤ 1, there is a positive constant δ such that the number of even integers in [X, X+X^θ] that are not sums of two primes is ≪ X^(θ−δ).
hypotheses: 1/5 < θ ≤ 1; X large; δ>0 (not explicit).
holds-here: yes
status: asserted
bearing: A short-interval power-saving exceptional-set result: in intervals of length X^θ (θ>1/5), almost all even numbers are Goldbach. It is a density statement about short intervals, not an every-n proof; θ>1/5 is the known threshold for this method (Baker–Harman–Pintz-type). Relevant to the R-density-delta rung: it shows the exceptional set is thin not only globally but in every short interval.
anchor: research/sources/peneva-exceptional-set-goldbach-short-intervals-monatshefte-2008.full.md
```

Proof ingredients: circle method, sieve method, exponential sum estimates, zero-density estimates for L-functions. The prior literature chain is Perelli–Pintz (1993), Jia (1996), Peneva (2001, 2004), Languasco (2004); this paper improves the exponent range.
