# Akeno (2025), small gaps between Goldbach primes
[[akeno-small-gaps-goldbach-primes-arxiv-2508.02769.full]]

Source: https://arxiv.org/abs/2508.02769 (v3).

```claim
id: akeno-2025-small-gaps-goldbach-primes
statement: For almost all even N, the smallest gap in P∩(N−P) is at most 0.76542... times the average gap, improving Tsuda's 0.8201; a Maynard–Tao application gives bounded gaps between Goldbach primes (bounded error) for almost all even N, and a straightforward Maynard–Tao application is shown insufficient to improve the 0.76542 bound.
hypotheses: N even large; gap measured in the Goldbach primes set P∩(N−P).
holds-here: yes
status: asserted
bearing: A Bombieri–Davenport-method result on the internal structure of the Goldbach-prime set for almost all N. Shows Goldbach primes are well distributed inside the representation set, relevant to the small-gaps thread; it is an almost-all statement and does not resolve every-n Goldbach. The 0.76542 constant is the current record for this problem (improving Tsuda's 0.8201, Monatsh. Math. 2025).
anchor: research/sources/akeno-small-gaps-goldbach-primes-arxiv-2508.02769.full.md
```
