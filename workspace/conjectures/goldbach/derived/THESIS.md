## The standing bet

Work under this. `refuted-by` is the evidence that would end it — if the run has produced that evidence, say so and revise, because a thesis nothing can refute costs a run its whole budget.

- `chen-prime-exceptional-set` — The Grimmelt–Teräväinen exceptional set — even n ≡ 4 (mod 6) not expressible as a sum of two Chen primes (primes p with p+2 prime or semiprime) — is empty in every initial segment this run can verify, and the first failing n, if it exists, lies far beyond the verified Goldbach range. Since Chen primes are genuine primes, a nonempty GT exceptional set would be a new obstruction visible to computation; verifying its emptiness in a long initial segment is the concrete first step of the structural-closure gap, and closing the density gap for the n ≡ 4 (mod 6) class is the live attack.
  - because: Grimmelt–Teräväinen (2025) prove all but a power-saving exceptional set of n ≡ 4 (mod 6) are sums of two Chen primes; every small n ≡ 4 (mod 6) checked by hand (4, 10, 16, 22, 28, 34, 40) has a Chen-prime representation, and the exceptional set for the full Goldbach problem is empty below 4×10^18, so any GT exception in range would be a novel finding.
  - refuted-by: A single even n ≡ 4 (mod 6) within our verified bound that is NOT a sum of two Chen primes; or a source establishing the GT exceptional set is provably nonempty.
