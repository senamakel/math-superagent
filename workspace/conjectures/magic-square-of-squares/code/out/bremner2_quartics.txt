=====================================================================
TASK 3  --  what a 2-descent would need (none required here: all genus 1)
=====================================================================
None of the three (13) quartics has genus >= 2 -- all are genus 1 (elliptic),
so a 2-descent on a higher-genus Jacobian is NOT the tool these particular
curves need.

Had any been genus >= 2, a 2-descent to bound the Jacobian rank would require:
  (i)   a smooth projective model (here a quartic y^2=f(x) is already smooth
        when f is squarefree);
  (ii)  the Jacobian J(C) equipped with a theta divisor, giving the isogeny
        J -> J and the 2-Selmer group Sel^(2)(J/Q), computed from the 2-torsion
        (for a genus-2 hyperelliptic the 2-torsion points/degree-2 divisors);
  (iii) a height pairing / regulator computation to bound the Mordell-Weil rank
        r = dim_2 Sel^(2) - dim_2(J(Q)[2]) - dim_2(III[2]);
  (iv)  for genus 2 in practice, the Magma function RankBounds using the
        Cassels/Tate pairing; PARI/GP or Sage do not ship a general genus-2
        2-descent.

Since all three are genus-1, the correct tool per-curve is an ordinary elliptic
2-descent / Selmer computation on E: y^2 = F(x). Each E for (13) would be
checked for rational points, and any rational (p,q) point lying on both (12)
and one of (13) would complete the seven-square search in the range Bremner
covered (p+q+n+d <= 1000); none exist beyond his witness at (13,9,2).
