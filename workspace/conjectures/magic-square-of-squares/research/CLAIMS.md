To add a claim, put a fenced `claim` block in the note that establishes it, with `id`, `statement`, `hypotheses`, `holds-here`, `status`, `bearing`, and `anchor` lines. A result this run *computed* belongs here as much as one it read: write the note beside the output in `code/out/` and mark it `status: checked`.

`holds-here` is whether the hypotheses hold for *this* problem: a true theorem whose hypotheses fail here is worse than no theorem, because it looks like progress.
