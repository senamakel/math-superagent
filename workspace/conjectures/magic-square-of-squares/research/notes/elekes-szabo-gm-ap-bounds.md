# Elekes–Szabó / sum-product for 𝔾_m vs. APs in Φ = f(ℚ), f(t) = sin(4 arctan t)

**Question asked (research specialist check, 2026-08):** does the Elekes–Szabó /
sum-product literature for the multiplicative group 𝔾_m (NOT elliptic curves) give any bound
on arithmetic progressions inside the image of a rational map f: 𝔾_m → 𝔾_a — specifically
Φ = f(ℚ∩(0,1)), f(t) = 4t(1−t²)/(1+t²)² = sin(4 arctan t), the y-coordinate map of the
doubling/square on the unit circle? The Φ-quadruple condition (q1, q2, q1+q2, q1−q2 ∈ Φ)
is an AP q1−q2, q1, q1+q2 of length 3 in f(ℚ).

**Short answer.** There **is** a theorem in this literature, verbatim on point:
Harrison–Mudgal–Schmidt (HMS), arXiv:2603.06483, **Corollary 2.2**, whose hypotheses are
satisfied by 𝒞 = graph(f), G = 𝔾_m, H = 𝔾_a, and which bounds the size of any proper
generalised AP inside f(Γ) by D(d)^{1+r} (d = degree of the correspondence = 5, r = rank of
the subgroup Γ ⊆ 𝔾_m(ℂ) generated by the preimages). **But the bound is completely
ineffective (D never computed, no size bound anywhere) and is structurally vacuous for the
length-3 case:** |P| = 3 ≤ D^{1+r} is trivially true for any D ≥ 1, and the theorem's
mechanism (uniform Mordell–Lang / S-unit counting) cannot produce a non-emptiness statement.
No ES result on 𝔾_m bounds APs in f(ℚ) in any usable way. The failure is structural, for
three reasons recorded below. And **HMS is NOT exclusively elliptic curves** — its 𝔾_m half
is real and explicit (see §4).

---

## 1. The exact applicable statement (HMS 2603.06483, Corollary 2.2)

> For all integers d ≥ 1 there exists a constant D = D(d) with the following property. Let G
> be either 𝔾_m or an elliptic curve E, and let 𝒞 be a correspondence of degree at most d
> between G and an algebraic group H of dimension 1, that is not the translate of an
> algebraic subgroup. Then for any subgroup Γ ⊆ G(ℂ) of rank r, a proper generalised
> arithmetic progression P of rank k in 𝒞(Γ) satisfies |P| ≤ D^{1+r}.

**Why it applies to Φ, term by term:**
- **G = 𝔾_m, H = 𝔾_a.** HMS §3.1: the only 1-dim connected algebraic groups over ℂ are
  𝔾_a, 𝔾_m, elliptic curves.
- **𝒞 = graph of f:** f: 𝔾_m → 𝔾_a is a non-constant rational map, degree 4 as a map
  ℙ¹→ℙ¹: f(t) = y has generic fibre the quartic y(1+t²)² = 4t(1−t²), i.e.
  y t⁴ + 4t³ + 2y t² − 4t + y = 0; numerator 4t−4t³ and denominator (1+t²)² are coprime
  (t = 0, ±1 give numerator 0, denominator ≠ 0), so deg f = max(3,4) = 4; and
  f(∞) = 0 (f(1/z) = (4z³−4z)/(z²+1)² → 0 as z→0).
- **Degree of the correspondence:** for a graph, π_𝒞→G is an isomorphism (d_X = 1) and
  π_𝒞→H has degree = deg f = 4 (d_Y = 4); HMS §3.2 formula
  deg_L(𝒞) = d_X·deg(X) + d_Y·deg(Y) = 1·1 + 4·1 = **5**. So d = 5 for Φ. (Cf. HMS
  Example 3.6: graph of a degree-d polynomial has correspondence degree d+1.)
- **Not a translate of an algebraic subgroup:** the only connected 1-dim algebraic subgroups
  of 𝔾_m×𝔾_a with dominant projection to 𝔾_m are translates of 𝔾_m×{0}, whose projection
  to 𝔾_a is a single point — not dominant. 𝒞(𝔾_m) = f(𝔾_m) is dominant in 𝔾_a
  (f non-constant). So the excluded case does not occur.
- **Γ of finite rank:** for a length-3 AP in f(ℚ) pick t₁, t₂, t₃ ∈ ℚ with f(tᵢ) =
  a+(i−1)d; the subgroup Γ = ⟨t₁, t₂, t₃⟩ ⊆ ℚ* ⊂ ℂ* has rank r ≤ 3 (in the worst case,
  five distinct preimages for q1−q2, q1, q1+q2 give r ≤ 6). P = {q1−q2, q1, q1+q2} is a
  proper GPAP of rank k = 1, size 3, inside 𝒞(Γ).

**What it gives.** 3 = |P| ≤ D(5)^{1+r}. This is the *whole* content for the Φ-quadruple.

## 2. Effective? No — and structurally vacuous at length 3

- **D is never computed or bounded anywhere in the paper.** HMS proves Cor 2.2 via
  Theorem 2.1 (c(d,g) ∈ (0,1), uncomputed) ⇐ Theorem 4.2 ⇐ Theorem 3.7, whose input is:
  elliptic half — David–Philippon uniform Mordell–Lang [11, Théorème 1.13]; 𝔾_m half —
  Laurent [29] + Evertse–Schlickewei–Schmidt S-unit bounds [18]. The paper states Theorem
  3.7's 𝔾_m proof explicitly (variety defined by Q_i; no-vanishing-subsum ⇒ ESS bound
  c(deg Q_i, g)^{1+r}). None of the constants is exhibited; the §1 Remark says only
  "effectively computable". This is the same ineffectiveness already recorded for Theorem
  1.1 in claim `hms-2026-bremner-effective-constant`.
- **Threshold for usefulness at |P| = 3:** to rule out the Φ-quadruple one would need
  D(5)^{1+r} < 3, i.e. D(5) < 3^{1/(1+r)}; with preimage-rank r ≤ 6, D(5) < 3^{1/7} ≈
  1.1699 (for r = 1: D < √3 ≈ 1.732). No source computes or bounds D(5) anywhere near
  this; the DP constants in the literature dwarf it (astronomically > 3). Hand computation:
  3^{1/5} ≈ 1.24573, 3^{1/7} ≈ 1.16993, √3 ≈ 1.73205, √2 ≈ 1.41421.
- **Why "vacuous in principle":** |P| is an integer ≥ 2 (proper GPAP, rank ≥ 1, L₁ ≥ 2).
  Any uniform bound of the shape C^{1+r} with C ≥ 1 reads "≤ something ≥ 1 ≥ 2", and for
  the bound to be non-vacuous at |P| = 2 one needs C ≥ 2^{1/(1+r)}. The number 3 sits at
  the *smallest* end of the spectrum; the machinery is built to forbid LONG APs (length
  ≫ max(C, 1)^{1+r}), never a single 3-term AP. The Mordell–Lang/ESS backbone (Thm 3.7)
  is a **counting** theorem (#(V^co ∩ Γ) ≤ C^{1+r}); a count bound says nothing about
  whether the count is ≥ 1. None of the ES/PFR/approximate-group circle proves
  non-existence of a fixed small configuration — only relative sparsity as the size/height
  of the input grows.

## 3. Structural reasons APs in 𝔾_m-coordinate-sets escape ES/PFR

1. **Small-doubling / finite-rank hypothesis fails for Φ as a set.** Every theorem in the
   circle (Elekes–Szabó 2012; Raz–Sharir–de Zeeuw 2016; Bays–Breuillard ASENS 2021 (1.2);
   Chernikov–Peterzil–Starchenko 2024 (δ = 1/21); Bays–Dobrowolski–Zou 2023; HMS Theorems
   1.5, 1.8, 2.3, 2.6) needs the *input* set A to have small group-doubling
   (|A○A| ≤ K|A|, K = K(ε) or O_K(1)) or to lie in a subgroup of bounded rank. Φ = f(ℚ∩(0,1))
   has neither: (a) multiplicatively, {f(1/p) : p prime} already generates an infinite-rank
   subgroup of ℚ* (each f(1/p) = 4p(p−1)(p+1)/(p²+1)² has the prime p as a factor, for all
   primes p, so the rank is unbounded); (b) additively, Φ is dense in (0,1] (f continuous,
   ℚ∩(0,1) dense, f((0,1)) ⊇ (0,1]) — the opposite of an approximate subgroup of 𝔾_a. So
   the input-set hypotheses cannot even be stated for A = Φ. For the *3-point* input
   A = {t₁,t₂,t₃}, small doubling holds trivially (|A·A| ≤ 9 = 3|A|) but the conclusions
   are expansion lower bounds |𝒞(A)+⋯+𝒞(A)| ≥ c^{1+r}|A|^g, which are true-but-uninformative
   at |A| = 3 (any absolute c < 1: c^{1+r}·3² < 9, no information).
2. **Counting ≠ non-existence.** The deepest inputs (Laurent; ESS; David–Philippon) all
   count points of a variety in a finite-rank group, with bounds C^{1+r}. For a *fixed*
   configuration (one AP of length 3), the count bound is a large finite number with no
   bearing on whether it is zero. No theorem in this area proves emptiness of a fixed
   small configuration; and indeed analogous configurations DO exist over extension fields
   (run claim `extension-field-mss-exist`), so an emptiness theorem would have to use
   ℚ-arithmetic essentially — none in this literature does (the counting theorems hold over
   ℂ).
3. **Expansion versus substructure.** ES-type theorems are *expansion* dichotomies:
   "if A is additively structured then the transported set is large". An AP *inside the
   image* is a *substructure* question about f(A) (a 1-dimensional additive pattern of
   fixed size). Lower bounds of order |A|^{1+δ} (or |A|^g/K^{O}) constrain asymptotic
   growth; they cannot forbid one 3-point subset, and the two complementary structures
   (A multiplicatively sparse vs f(A) additively sparse) are both satisfied trivially at
   |A| = 3.

## 4. Is arXiv:2603.06483 exclusively elliptic curves? No.

Elliptic-curve-only statements: **Theorem 1.1** (Bremner's conjecture: AP/GP/consecutive-
squares inside X = {x(P)} or Y = {y(P)} of E(ℚ)) and its §7 proof route. **Everything else
is stated for G = 𝔾_m as well as elliptic curves**, and for H = 𝔾_a or 𝔾_m:
- **Theorem 3.7** (the backbone): "G is an elliptic curve or 𝔾_m" — the 𝔾_m half is proved
  via Laurent + ESS S-unit bounds (§3.4, explicit in the paper).
- **Corollary 2.2**: quoted in §1 above — G = 𝔾_m *or* elliptic; AP/GP bounds in 𝒞(Γ) for
  any correspondence (graph of a polynomial or more generally a non-subgroup curve).
- **Theorems 2.1, 1.3, 1.5, 2.3, 2.6, Corollaries 1.4, 2.4, 2.7**: 1-dim algebraic groups
  G ⊄ 𝔾_a, with G = 𝔾_m explicitly the model case (Cor 1.4: polynomials φᵢ, A ⊆ ℂ,
  |A^(g)| vs |φ₁(A)+⋯+φ_g(A)|; Cor 2.4: |A·A| ≤ K|A| ⇒ |φ(A)+φ(A)| ≫ |A|²/K^D).
- The 𝔾_m cases of Cor 2.2 are described in §1 as the "geometric progressions / coordinate
  sets of 𝔾_m" half (Bremner–Ulas style), versus the analytic headline (elliptic APs).
- The paper's explicit examples of what the correspondence can be are the *graph of a
  polynomial* (Example 3.6, degree d ⇒ deg_L = d+1) and the elliptic x-map (Example 3.5).
  A rational map f: 𝔾_m → 𝔾_a (like Φ's f) is a perfectly good non-polynomial instance:
  same statement, d = deg_L(𝒞) = 5.

So: the paper **does** cover rational maps 𝔾_m → 𝔾_a and APs in their images — but only in
the ineffective counting form above. It says **nothing** about *rational curves* in the
conic sense (APs of points on conics; that is Ciss–Moody, downloaded alongside) — "rational
curve" is not a phrase in the paper; its objects are algebraic *groups* and correspondences
between them.

## 5. Bays–Dobrowolski–Zou (2023) — not an AP-bound paper

"Elekes–Szabó for groups, and approximate subgroups in weak general position", *Discrete
Analysis* 2023:6 (DOI 10.19086/da.77361; full download failed at the resolver, evidence =
published abstract + DML digest + HMS's citation of the Bays–Breuillard framework). Its
direction is the **inverse/classification** problem: if R ⊆ ℂ³ (or a group-shaped
replacement) has ~N^{2-o(1)} related triples from large sets A, B, C, then R is
(coordinate-finite-to-finite) the graph of multiplication of a 1-dim algebraic group; with
weak general position, approximate-subgroup structure forces the group **nilpotent** (for
1-dim groups: abelian), and nilpotent groups give the extremal examples. For 𝔾_m (abelian,
1-dim) the group-structure conclusion is trivial, and **no statement about arithmetic
progressions inside images of rational maps appears anywhere in the abstract or the
digest**. It is a theorem about the *shape of relations with many incidences*, not about
substructures of coordinate sets. Reject as a source of AP bounds; keep as the correct
citation for "ES says the relation must be a group operation" (which is exactly *why* one
does not expect an AP-in-f(ℚ) obstruction: f is not a group operation, so ES says nothing).

## 6. Sources examined and rejected

- HMS 2603.06483 full text (132 KB, on disk) — used (Cor 2.2, Thm 3.7, §§3–7). The only
  on-point source.
- Ciss–Moody "Arithmetic Progressions on Conics" (PMC5535277, downloaded) — APs of *points
  on* conics, different set-up; no bound on APs in a fixed rational map's image; provides
  the classical "3-term APs on the circle are abundant" context. Used only as context.
- Bays–Dobrowolski–Zou 2023 (Discrete Analysis da.77361) — inverse ES; no AP bounds. Used
  for classification context.
- Elekes–Szabó problem + Uniformity Conjecture (Springer 2022, Isr. J. Math; s ≤ 5,
  conditional over ℚ) — polynomial-families incidence bounds over ℚ; no AP-in-image;
  conditional on rank uniformity. Rejected.
- Elekes–Rónyai (2000) / Raz–Sharir–de Zeeuw (2016) / Raz–Sharir–Solymosi (2016) —
  expansion of polynomial images; asymptotic, |A| large; nothing at |A| = 3. Rejected.
- Solymosi–Zahl (2024), Cushman (2025), Chang (2009), Bourgain–Chang (2004),
  Pálvölgyi–Zhelezov (2021), Elekes (1997), Erdős–Szemerédi (1983) — sum-product
  exponents; asymptotic in |A|; rejected (no fixed-size content).
- "Growth in sumsets of higher convex functions" (Combinatorica 2023) — real-valued
  convex functions; no arithmetic structure; rejected.
- Exponential sums over multiplicative subgroups (Fnite Fields Appl. 2014) — finite
  fields; rejected.
- Ergodic {x+y, xy} theorem (ETDS 2017) — density/colouring results; no quantitative
  AP-in-image; rejected.
- Approximate groups (BGT; Breuillard–Green; residually nilpotent; closed approximate
  subgroups; Borel density for approximate lattices) — structure of approximate subgroups;
  no AP-in-coordinate-set; rejected.
