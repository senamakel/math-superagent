# "Robertson, Magic squares of squares" — DUPLICATE OF BREMNER 1999

[[robertson-magic-squares-of-squares-1996]]

**Provenance correction.** The file downloaded as `research/sources/robertson-magic-squares-of-squares-1996.full.md` is a byte-for-byte duplicate of **Bremner, "On squares of squares", Acta Arithmetica 88 (1999) 289–297** (its header comment even names the URL `http://multimagie.com/Bremner1.pdf`). It is NOT Robertson's own 1996 Mathematics Magazine article; it is Bremner 1999 quoting/crediting Robertson's observation. There is no secondary Robertson paper in this library.

## What this means for the run
- Do **not** cite this file as a separate source: every statement in it is already digested under `research/summaries/bremner-on-squares-of-squares-1999.md` (parametrisation, elliptic reduction `robertson-elliptic-reduction`, extension-field MSS, the two near-misses).
- The Robertson attribution ("the 2E(Q) reformulation is due to Robertson") is real but is *reported* by Bremner in this paper, not by Robertson's own paper. If the run ever needs Robertson's original (Mathematics Magazine 69(4) 1996, 289–293), it must be fetched separately.

## Not a separate source
Redundant with Bremner 1999; kept in the library only because the download landed under a misleading filename. No separate claim block is warranted — it would duplicate `robertson-elliptic-reduction` and `extension-field-mss-exist`.
