## The result this source is cited for (from secondary sources, NOT from this paper)

- Number of exceptions n ∈ [1, N] to ESC is ≤ N exp(−c (log N)^{2/3}) for
  some absolute c > 0. — stated identically in erdosproblems #242 [Va70] and
  in the Bloom–Elsholtz survey §2.2 (in library, full text, proof sketched:
  soluble classes mod 4t−1 are described by d₃(t), needs Bombieri–Vinogradov
  + Brun–Titchmarsh).

  classical worker set: Bernstein (1962), Obláth (1949 Mathesis), Rosati
  (1954), Yamamoto (1965).
