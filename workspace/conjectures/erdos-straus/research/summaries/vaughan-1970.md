# Vaughan, "On a problem of Erdős, Straus and Schinzel" — RELATED ONLY (bound not core)

The Vaughan 1970 result (Mathematika 17 (1970) 193–198, doi:10.1112/S0025579300002886)
is cited in the FRONTIER. It is an analytic-counting bound: the number of
exceptions in [1,x] is ≤ `x exp(-c (log x)^{2/3})` for some c>0 (also stated in
erdosproblems #242 and Wikipedia). This run's goal is a *construction*, not a
counting bound, so Vaughan is context, not machinery. The original text was not
downloaded; the statement is recorded from the two compendium sources above.
