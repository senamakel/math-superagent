# OEIS A075245 — least x in solutions to 4/n = 1/x + 1/y + 1/z

Source: https://oeis.org/A075245
Full text: `research/sources/oeis-a075245.full.md`

## What it establishes (sourced, cross-check material)

- `a(n)` = the smallest possible `x` in an (ordered, `x ≤ y ≤ z`) solution of
  `4/n = 1/x + 1/y + 1/z`. Offset 3; `a(3)=1, a(4)=2, a(5)=2, ...`.
- Related to A073101 (number of solutions). Comments:
  - Conjecture (M. F. Hasler, 2022): `a(n) = floor(n/4) + d`, with `d = 1`
    except for some `n = 8k+1` (k in 6, 9, 11, 14, 20, 21, 24, 29, 30, 35, 39,
    41, ...) where `d = 2`. Unproved.

## Consequence

Cross-check material: the interesting values are only at `n = 8k+1`, which is
consistent with `x ≈ ⌈n/4⌉ + k` (Bradford's parametrisation) — the `d=2`
spikes at `n ≡ 1 (mod 8)` are where a small-offset solution is not available.
Not load-bearing for the run's construction, but a useful oracle check
(least-x values for the open classes, where the residual behaviour lives).
