A075246

y-value of the solution (x,y,z) to 4/n = 1/x + 1/y + 1/z satisfying 0 < x < y < z and having the largest z-value. The x and z components are in [A075245][4] and [A075247][5].

EXAMPLE

For n=3, we have 4/n = 4/3 = 1/x + 1/y + 1/z. If x >= 2, 1/2 + 1/3 + 1/4 = 13/12 leaves us short of 4/3, so x must be 1 and therefore 1/y + 1/z = 1/3. The largest z will come from the smallest y, and the smallest possible is y=4, which gives a solution 1/1 + 1/4 + 1/12 = 4/3. So a(3) = y = 4. - [Michael B. Porter][19], Nov 26 2025
