# OEIS A073101 — number of ordered solutions 0<x<y<z to 4/n=1/x+1/y+1/z

Source: https://oeis.org/A073101
Full text: `research/sources/oeis-a073101.full.md`

## What it establishes (sourced, cross-check material)

- `a(n)` = number of solutions to `4/n = 1/x+1/y+1/z` with `0<x<y<z`.
- Terms from n=1: 0,0,1,1,2,5,5,6,4,9,7,15,4,14,33,22,4,21,9,30,25,22,19,45,...;
  a(1)=a(2)=0 (n>=3 has solutions; the conjecture is about existence, and
  these counts are distinct-solution counts).
- Related: A075245/A075246/A075247 (largest-z solutions), A075248
  (Sierpiński's 5/n conjecture), A287116.

## Implication

Provides an independent oracle cross-check for the existence checker and for
"smallest uncovered prime is 1009" style statements. Also the OEIS lookup
target if the run ever computes a solution-count sequence.
