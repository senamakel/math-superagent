A075245

x-value of the solution (x,y,z) to 4/n = 1/x + 1/y + 1/z satisfying 0 < x < y < z and having the largest z-value. The y and z components are in [A075246][4] and [A075247][5].

COMMENTS

See [A073101][13] for more details.

a(n) = floor(n/4) + 1, at least up to n = 2000, except for some n = 8k+1 (k = 6, 9, 11, 14, 20, 21, 24, 29, 30, 35, 39, 41, 44, 45, 50, ...), where a(n) is one larger than a(n-1) and a(n+1). - [M. F. Hasler][14], Jul 02 2022

FORMULA

Conjecture: a(n) = floor(n/4) + d, with d = 1 except for some n = 8k+1 (k = 6, 9, 11, 14, 20, 21, 24, 29, 30, 35, 39, ...) where d = 2 . - [M. F. Hasler][14], Jul 02 2022

EXAMPLE

For n = 3, we have a(3) = 1 = x in 4/3 = 1/x + 1/y + 1/z with y = 4 and z = 12 which is the largest possible z: Indeed, x < y < z gives 4/3 < 3/x, so only x = 1 and 2 are possible, and then with y < z, 2/y > 4/3 - 1/x is impossible for x = 2 < y < 12/5 and for x = 1 < y < 6 only y = 4 gives a solution.
