# Ansari 2025 — recursively sufficient sieves

[[ansari-2025-recursive-sufficiency.full]]

Source: https://nntdm.net/papers/nntdm-31/NNTDM-31-3-471-480.pdf

Ansari defines recursive sufficiency: every omitted `n>1` merges under the accelerated map with a strictly smaller `m`. Theorem 2.1 proves that checking the recursively sufficient set inside `[1,N]` is equivalent to checking all `[1,N]`; this strict-smaller condition is stronger than Monks' ordinary merge sufficiency. Nested residue sieves have elimination fraction `100(4*3^r-2^r)/(4*3^r)`, tending to 100%. Proposition 3.2 gives a structural extension: if `N=2*3^r+1` is verified then `(N,2N]` is verified. Combining `r=44` with Barina's finite verification below `2^71` yields the claimed finite frontier `4*3^44+2 ≈ 3.939e21 ≈ 2^71.74`, subject to the source theorem and exact arithmetic. This is not a proof beyond that finite interval.
