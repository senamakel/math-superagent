# Monks 2006 — arithmetic progressions are sufficient

Source URL: https://doi.org/10.1090/S0002-9939-06-08567-4
Author copy: https://monks.scranton.edu/files/pubs/SufficiencyRev4.pdf

For the accelerated map T(x)=(3x+1)/2 on odd x and x/2 on even x, Monks defines a set as sufficient when every positive orbit merges with the orbit of an element of that set. Theorem 1.1 states that every nonconstant arithmetic progression A+BN is sufficient. Corollaries state the analogous reduction for the divergent-orbits and nontrivial-cycles sub-conjectures. Thus proving convergence/cycle-freeness on one arithmetic progression would imply the corresponding global statement, but the theorem does not itself prove convergence on that progression.

Method: inverse/back-tracing functions and congruence-group actions.
