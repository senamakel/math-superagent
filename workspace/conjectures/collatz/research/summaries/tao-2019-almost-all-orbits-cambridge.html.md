# Tao 2019/2022 — almost all Collatz orbits

Source URL: https://www.cambridge.org/core/journals/forum-of-mathematics-pi/article/almost-all-orbits-of-the-collatz-map-attain-almost-bounded-values/1008CC2DF91AF87F66D190C5E01C907F
Preprint: https://arxiv.org/abs/1909.03562

Tao defines Col(N)=3N+1 for odd N and N/2 for even N, and Col_min(N) as the infimum of the forward orbit. Theorem 1.3 states: for every f(N)→∞, Col_min(N)≤f(N) for almost all N in logarithmic density. The paper also states the analogous Syracuse formulation. This is a density-one theorem about typical starting values; it does not rule out an exceptional individual divergent orbit or nontrivial cycle, so it does not resolve the Collatz conjecture.
