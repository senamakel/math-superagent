CHANGE REPORTED (the one deliberate adjustment):
  Case (b) was requested as "etp h j = r + 1 - h j".  That is off by one and is
  NOT what the definitions compute.  Since
      etp h j = |h j - (r+1)| - 1 = (r+1) - h j - 1 = r - h j
  (h j ≤ 1 ≤ r+1 makes the absolute value (r+1) - h j), the correct identity is
      etp h j = r - h j.
  Example: h j = 1, h(j+1) = 2 (so r = et h (j+1) = 1) gives
      etp = |1 - 2| - 1 = 0  =  r - h j = 0,
  whereas r + 1 - h j = 1 (wrong).  The statement in this file is the corrected one;
  the wall_right / wall_left pointwise halves also use the same arithmetic (they
  state inequalities, unaffected by the off-by-one in the equality form).

  The task's "(b) wall case: h(j) in {0,1} and h(j+1)=r+1 (r=t(j+1)>=1) then
  t'(j)=r+1-h(j)" appears in the workspace steer note as "Use t'(j) = t(j+1) - h(j)"
  -- i.e. the r - h j form.  This file follows that corrected reading.
