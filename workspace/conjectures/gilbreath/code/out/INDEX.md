# Index — code/out

What each file in this folder is for. Keep it current: describe a file when you
create it, and refresh this index after adding, renaming, or deleting files.
Captured (`*.captured.txt`) files are terminal outputs of the matching script,
recorded so later agents can read the computed numbers without re-running.

| File | Purpose |
| --- | --- |
| `README.md` | What the output folder generated by scripts contains. |
| `witnesses.json` | Oracle: row data and block profile for depth 600 (sieve to 400000, 33860 primes); `A_1..A_5` first 12, `block_profile_first_40`. Everything else is checked against it. |
| `blocks_depth1000.json` | The depth-1000 record analyzed here: `b` (block lengths, 1000), `s` (second entries), `intruder` (first value past block, `None` from k=162 = width exhaustion), D=1000, sieve 20M, 1270607 primes. |
| `blocks_deep.captured.txt` | Output of `pattern/blocks_deep.py` that produced blocks_depth1000.json: min/max b, 60 regen rows, longest erosion 838, s/intruder stats. |
| `erosion_dynamics.captured.txt` | Output of `pattern/erosion_dynamics.py`: erosion-step predictions 101/101 and the regen trigger (x,y)=(2,4) verified 60/60. |
| `check_reduction.captured.txt` | Output of `check_reduction.py`: reduction facts hold for k=1..599. |
| `check_reduction.py` | Per-row check of the reduction facts. |
| `oracle_depth600.captured.txt` | Trial of the depth-600 oracle. |
| `check-block-protection.py` | Boundary protection lemma verifier. |
| `boundary_check.captured.txt`, `boundary_check.json` | Boundary lemma check output and stored facts. |
| `brute.captured.txt` | Small brute-force oracle output. |
| `check_regenerate_lemma.captured.txt` | Output of the candidate regeneration-lemma refutation (iff fails; see notes). |
| `check_regenerate_lemma.notes.md` | Refutation of a candidate regeneration iff lemma with exact k-values; the lemma FAILED — do not weaken and re-assert. |
| `commands.log` | Full command log of the run. |
| `extract_witness.captured.txt` | Output of `pattern/extract_witness.py` (b, s, diffs for k=1..40). |
| `genuine_sequences.json` | Stored genuine (non-artifact) sequence data. |
| `regeneration_analysis.captured.txt` | Output of `pattern/regeneration_analysis.py`: the 60-event table, rate buckets, histograms, runs test, minima. |
| `regeneration_detail.captured.txt` | Output of `pattern/regeneration_detail.py`: s at events, gap histogram, big-jump ratios, long-run intruder traces. |
| `intruder_runs.captured.txt` | Output of `pattern/intruder_runs.py`: the 17 maximal y=4 runs, drain table, after-regen intruders. |
| `regeneration_successors.captured.txt` | Output of `pattern/regeneration_successors.py`: stall→regen verification, successors, drain staircases, histograms. |
| `regeneration_lastfacts.captured.txt` | Output of `pattern/regeneration_lastfacts.py`: run-start intruders, tall-intruder rows, min-b by window. |
| `blocks_deep_regen.captured.txt`, `regen_mechanism.captured.txt`, `regen_c4_check.captured.txt`, `_explore_indexing.captured.txt` | Earlier regeneracy experiments (superseded by the regeneration_* set). |
