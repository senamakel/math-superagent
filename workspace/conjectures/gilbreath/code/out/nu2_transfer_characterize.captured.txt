[4] Hypothesis assessment (which non-degeneracy restores nu2>=c*w?)
    h[j] = (gap_j/2) mod 2 over j in [2,n-1]; w = wt(h).
    Constant-gap/consecutive-odds case: h == all-ones, w = n-2.
  H    statement                          verdict on consecutive-odds / primes
  H_a  not all bits 1                     excludes all-ones (consec-odds); primes: h=(1,1,0,...) both values -> holds
  H_b  at least one 0 and one 1           excludes all-ones and all-zeros; primes -> holds
  H_c  w(n) -> infinity                   consec-odds w=n-2->inf: does NOT exclude degenerate case
  H_d  both values with positive lower density excludes all-ones; primes -> holds (0 density 0.4, 1 density 0.6)
  H_e  w(n) >= c*n for some c>0           consec-odds w=n-2 ~ n: does NOT exclude degenerate case

  Measured facts from [2] and [3]:
    consecutive-odds min nu2l/w = 0.001 (nu2=O(1), w~n -> transfer FAILS)
    all-gaps-4  min nu2w = inf (h all-zeros, w=0)
    primes      min nu2c/w = 0.705, min nu2l/w = 0.705 (transfer HOLDS)

  WEAKEST H that (i) excludes the constant-gap degenerate case and (ii) the primes satisfy: H_a
    (H_a 'not all bits 1' is implied by every stronger non-degeneracy that excludes all-ones, and is the minimal such; consecutive-odds violates it, all other families and primes satisfy it.)
    Under H_a, the primes give measured nu2 >= c*w with c = min nu2c/w = 0.7049 > 0.
    H_c and H_e are NOT sufficient: consecutive-odds satisfies both yet gives nu2/w -> 0.

[Distinction]
  The constant-gap example IS a successful 2-then-odds sequence (it collapses to all-1 rows: A_k(0)=1 for all k).
  So it refutes the UNIVERSAL transfer lemma nu2>=c*w, never the general-class theorem (which the example satisfies).
  A refuted transfer ROUTE is not a refuted theorem.
