# CORRECTION — this file is mislabeled (Green–Tao, not Rubinstein–Sarnak)

<!-- source: https://arxiv.org/pdf/math/0404188 | THIS IS GREEN-TAO -->

**Do not cite this file as Rubinstein–Sarnak.** The arXiv ID `math/0404188`
filed here is:

> **Ben Green, Terence Tao, "The primes contain arbitrarily long arithmetic
> progressions", arXiv:math/0404188** (2004; Ann. of Math. 167 (2008)).

That is a genuinely important paper (Szemerédi's theorem + a transference
principle applied to the primes, via Goldston–Yildirim) but it is **not** the
Chebyshev-bias paper the `chebyshev-bias-granville-nu2-supply` approach cites,
and it has nothing to do with the mod-4 distribution of consecutive primes that
feeds Granville's ν₂ supply. Quoting it as Rubinstein–Sarnak would be a
citation error.

The genuine Rubinstein–Sarnak 1994 paper (*Chebyshev's Bias*, Experimental
Mathematics 3.3, 173–197, DOI 10.1080/10586458.1994.10504289) is held in full at:

> `research/sources/rubinstein-sarnak-1994-chebyshev-bias-full.full.md` (full text)
> `research/summaries/rubinstein-sarnak-1994-chebyshev-bias-full.md` (summary)

This mislabeled Green–Tao file is retained only so nobody re-fetches
`math/0404188` expecting Rubinstein–Sarnak; its real content, if needed, is the
Green–Tao AP-of-primes theorem, a legitimate if unrelated member of the library.
