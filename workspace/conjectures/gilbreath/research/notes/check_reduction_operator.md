# Operator run of `code/out/check_reduction.py`

The two claims in `research/notes/reduction.md`
(`gilbreath-reduces-to-second-in-02`, `second-entry-4-kills`) were recorded
with evidence `proved` but `code/out/check_reduction.py`, which pins that
reduction against the actual generated rows rather than the stored
first-12-entries witness slices, had never been run — `code/out/commands.log`
had no entry for it. Ran it directly (operator, not the agent run):

```
$ cd code/out && timeout 540 python3 check_reduction.py
```

Full sieve to 400,000 (33,860 primes, matching `witnesses.json`
`primes_used`/`depth_verified`), one row held at a time (O(width) memory, no
triangle stored), depth 600. Both R1 (shape `(odd, even, even, ...)` for every
`k>=1`) and R2 (`A_{k+1}(0) == 1  <=>  A_k(1) in {0,2}`) held with no
counterexample over the full 599-row check — not just the 12-entry slices in
`witnesses.json`.

Note the stray `print("timeout placeholder")` in the script — leftover debug
line, harmless, but worth removing if the script is reused.
