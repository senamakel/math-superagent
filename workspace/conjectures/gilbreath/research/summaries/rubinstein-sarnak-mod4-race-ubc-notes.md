## What it establishes

A clean, readable **secondary transcript** of the Rubinstein–Sarnak 1994
mod-4 race result. The value of this file is that the primary (Project Euclid)
copy is the authoritative source, and this note gives the same number with the
hypotheses stated plainly:

- **Logarithmic density exists under GRH + LI (linear independence of the
  nontrivial Dirichlet-L zeros' imaginary parts), and**
  `δ(P_{4;3,1}) = 0.9959...` — the logarithmic density of the set of x where
  π(x;4,3) > π(x;4,1). **Strong bias toward primes ≡ 3 (mod 4).**
- **Oscillation / Littlewood-type:** even under these hypotheses the sign
  changes infinitely often; the first x with π(x;4,1) > π(x;4,3) is **26861**
  (Leech). So **no one-sided unconditional statement exists** — a specified
  unconditional bias cannot be asserted.
- Bias dissolves as q→∞.
