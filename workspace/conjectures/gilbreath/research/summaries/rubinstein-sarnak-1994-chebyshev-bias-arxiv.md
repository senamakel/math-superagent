# CORRECTION — this file is mislabeled

**This file is NOT Rubinstein–Sarnak's Chebyshev's bias paper.** The arXiv ID
`math/0404188` that was fetched here is Green–Tao, *The primes contain
arbitrarily long arithmetic progressions* (2004). That is a real paper but not
the one the `chebyshev-bias-granville-nu2-supply` approach cites, and it is not
relevant to the ν₂ mod-4 supply density. It must not be quoted as Rubinstein–
Sarnak.

The genuine Rubinstein–Sarnak 1994 paper (*Chebyshev's Bias*, Experimental
Mathematics 3(3), DOI 10.1080/10586458.1994.10504289) is the authoritative
treatment of the Chebyshev bias: the primes ≡ 3 (mod 4) seem to outnumber those
≡ 1 (mod 4), and — the load-bearing fact for this run — under GRH + Grand
Simplicity Hypothesis the set of x where the bias holds has a well-defined
**logarithmic density** δ, and the bias parameter oscillates (Littlewood-type),
so no one-sided bias is unconditional.
