idea: Riordan array / binomial Sheffer sequence classification — reframe the Gilbreath triangle as the absolute value of the Riordan array (difference table) of the prime gaps, then classify which Riordan arrays have left column bounded in {0,1} (or {0,2} after doubling).

mechanism: The forward-difference table of a sequence a = (a_0, a_1, a_2, ...) is the infinite matrix D with entries D_{n,k} = Σ_{j=0}^k (−1)^{k−j} C(k,j) a_{n+j}. This is a Riordan array: D = (1/(1+X), a(X)/(1+X)) in the notation of the Riordan group, where a(X) = Σ a_n X^n is the ordinary generating function of the sequence. Specifically, the bivariate generating function is Σ D_{n,k} X^n Y^k = a(XY/(1+Y)) / (1+Y). The Gilbreath triangle of a sequence starting with 2 followed by odds satisfies A_k(i) = |D_{i,k}| where the indices are shifted appropriately. The conjecture A_k(1) ∈ {0,2} for all k means |D_{1,k}| ∈ {0,1} for all k (after halving). This is a statement about the RIORDIAN ARRAY of the prime sequence: its first column (n=1) under the absolute-value-iterated map stays bounded. The Riordan group is well-studied combinatorially; it has a subgroup structure, an associated Sheffer sequence (the binomial transform), and connections to umbral calculus. The key move: instead of studying the absolute-difference dynamics row-by-row, study the GENERATING FUNCTION of the initial sequence and ask: which formal power series a(X) produce a Riordan array whose "absolute-value iterated left column" stays bounded? The Riordan framework separates the combinatorial structure (the binomial coefficients, which are the Sierpinski pattern mod 2) from the analytic structure (the growth of the a_n). Since the binomial coefficients mod 2 are exactly the Sierpinski gasket, the mod-2 Riordan array is well-understood: it is the action of (1+X) in GF(2)[[X]], which is Rule 90. The lift from mod 2 to Z involves the carries. The Riordan group over Z (or Z_2) provides algebraic tools — the composition law, the associated Sheffer sequence, the umbral operator — to track how the carries propagate. The specific conjecture: there is a SUBGROUP of the Riordan group (characterized by some growth condition on the coefficients a_n) for which the absolute-value iterated left column remains bounded. If the prime gap generating function lies in this subgroup, the conjecture follows.
