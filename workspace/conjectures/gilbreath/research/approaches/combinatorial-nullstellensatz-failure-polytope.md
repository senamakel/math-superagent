```approach
idea: Encode the first-failure event (A_k(1) ≥ 4 for the first time) as a finite union of rational polytopes in gap-space, then use the polynomial method — Alon's Combinatorial Nullstellensatz — to exhibit a *low-degree* certificate separating the failure set from the prime-gap region. Higher-degree certificates are strictly more powerful than the linear (Farkas) ones already proposed.
mechanism: On the even region, every branch of the iterated map |∂| is linear with integer coefficients, so "A_k(1) = 4 (or ≥ 4) for the first time" is a union of finitely many rational polytopes P in the variables g_1..g_{k+1} (the minimal-counterexample system). The Combinatorial Nullstellensatz (Alon 1999): a nonzero multilinear polynomial of degree ≤ d cannot vanish on a full grid of side > d. Contrapositive applied here: if the failure set contains the prime-gap prefix, then any low-degree multilinear polynomial that vanishes on P must also vanish on the whole box, which is impossible for a polynomial constructed from a prime-specific property (e.g. evenness g_i ≡ 0 mod 2, first gap g_1 = 2, and the mod-4 switch structure). The certificate is not a Farkas nonnegative combination of the linear constraints (degree 1); it is a degree-k multilinear polynomial whose vanishing set contains P and whose nonvanishing on the prime region is forced by a *degree/box* argument — the polynomial method proper. For small k the certificate is decidable by exact integer/GF(2) linear algebra, and the growth of its degree with k is the structural claim to bound. This attacks the *minimal counterexample* directly (the object FRONTIER.md demands), and it is the one route where "UNSAT over a polynomial ideal" is a theorem rather than a search.
status: refuted
precedent: Alon, "Combinatorial Nullstellensatz" (Combin. Probab. Comput. 8 (1999) 7–29, doi:10.1017/S0963548398003411); precise CNS-vs-ideal equivalence and its box-likeness hypothesis — Mészáros–Rónyai, "A note on Alon's combinatorial Nullstellensatz" (Acta Cybern. 2014, doi:10.71352/ac.42.249). The SAT-certificate method the candidate wants (Σβf = 1) is *Hilbert's* Nullstellensatz, whose successful uses are finite-bound conjectures: Konev–Lisitsa, "A SAT Attack on the Erdős Discrepancy Conjecture" (SAT 2014, doi:10.1007/978-3-319-09284-3_17); MATHCHECK (Zulkoski–Ganesh–Czarnecki, IJCAI 2016, doi:10.5555/3061053.3061252). Claim ids: valid-extension-backward-nonlocal-refuted, gatti-2020-valid-extension-global-formula (global whole-prefix criterion), colonna-deletion-left-edge-failure (first failure A₁(1)=4 inside the even-gap class), minimal-counterexample-geometry (grounding: no SAT/SAT+CAS attack reaches GC). Full grounding: research/notes/grounding-three-candidates.md.
killed-by: Three grounds. (1) Theorem misapplication: CNS is an existence statement on a *box* S₁×…×Sₙ; the failure set {A_k(1)≥4 first time} is a union of rational polytopes, not a box, and by Mészáros–Rónyai the CNS applies exactly to point sets whose vanishing ideal is box-like — a generic polytope union is not. The "UNSAT over a polynomial ideal" the candidate wants is Hilbert's Nullstellensatz (certificate Σβᵢfᵢ=1), whose degree is uncontrolled (no small-certificate bound for GC). (2) No finite bound: the certificate method terminates only when the conjecture has a finite extremal bound (EDP length 1161; Ramsey-type numbers). GC is an infinite-array conjecture with a global whole-prefix extension criterion (valid-extension-backward-nonlocal-refuted); a certificate at finite k proves nothing about k→∞, which is why no published SAT/SAT+CAS attack reaches GC (minimal-counterexample-geometry). (3) Class-level impossibility of a gap-only certificate: the named input properties (g₁=2, gaps even, mod-4 switch) hold for 2-then-odds sequences that FAIL — Colonna's delete-5 sequence (colonna-deletion-left-edge-failure) is an even-gap bounded sequence with A₁(1)=4, a first failure already at k=1. Any polynomial that nonvanishes on the primes and vanishes on the failure set must use a distinguishing property holding for the primes and not Colonna's sequence; the only candidate is CHT non-concentration, unproved for primes (= the open problem). A degree/box certificate separating the primes from the failure polytope is equivalent to the conjecture, not a route to it.
first-step: (closed by refutation) the CNS box hypothesis fails on a polytope union and the finite-certificate premise fails for an infinite-array conjecture; higher degree does not escape the global-extension obstruction.
```
