# Kernel method: the block boundary as a reflected walk in a wedge

```approach
idea: The block length b_k is a walk on the half-line N that is never allowed to go negative: deterministic left step (erosion b -> b-1), structural right jump (regeneration b -> b+j_i). Encode it in a bivariate generating function F(z,u) = sum_{k,i} a_{k,i} z^k u^i, where a_{k,i} is the (combinatorial) weight of reaching block length i in row k. The one-step transition law (erosion + jump, with the drain law fixing the event trigger) gives a linear functional equation F = F_0 + K(z,u) F with an explicit kernel K. The kernel method then determines the algebraic/algebraic-log nature of F, and singularity analysis of the dominant singularity gives an exact or lower-bound growth rate for b_k.
mechanism: This is the canonical "walk in a wedge / quadrant" setting of analytic combinatorics, and the recharge identity b_k = b_1 + sum_{events}(j_i+1) - (k-1) is exactly a renewal decomposition of this walk. The kernel method upgrades that decomposition from a formal identity to a solvable functional equation: the conjecture b_k >= 1 for all k becomes a sign condition on the kernel root that governs the dominant singularity, i.e. a statement about the local event rule (drain law + jump law) rather than about detailed prime-gap randomness. A lower bound survives even if the event process is not i.i.d., because the functional equation closes from the local rule alone. This differs from the proposed subadditive-growth (Kingman ergodic limits, needs stationarity) and transfer-operator (Banach-space quasi-compactness) routes, and from lattice-path-weighted-enumeration (which sums signed paths to A_k(1)) by tracking b_k itself.
status: proposed
first-step: (a) Write the exact one-step functional equation for the interface generating function from the step/drain/jump laws, treating the jump size j_i and the event indicator as structural variables. (b) Solve the homogeneous kernel equation in the degenerate case j_i = 0 identically (pure erosion) and confirm it reproduces the known linear death; this validates the kernel. (c) Isolate the kernel root whose location decides growth, and state the precise inequality on (event rate, jump size) whose strict positivity is equivalent to the conjecture.
side: general-class; targets regeneration (the open content).
risk: the jump size j_i is itself a random functional of the gap word, so the functional equation may not close without an extra hypothesis on j_i; the degenerate-case check in (b) is the cheap gate that decides whether the kernel actually closes.
