```approach
idea: Farkas-lemma infeasibility certificate — prove the Gilbreath conjecture for the general 2-then-odds class by formulating "the block ever dies" as a system of linear inequalities on the initial gap sequence, then showing the system is infeasible via LP duality.

mechanism: The recharge identity b_k = b_1 + Σ_{events i<k} (j_i+1) − (k−1) is an exact combinatorial identity. The conjecture fails iff there exists a k with b_k = 0, which is equivalent to Σ_{events i<k} (j_i+1) < k − 1 − b_1. Since j_i ≥ 0 always, the worst case is when there are FEW events with SMALL jumps. Now, each regeneration event (x=2, y=4) produces a jump j_i whose size is determined by the GAPS in the initial sequence A_0 at positions adjacent to the new block boundary. Specifically, after a (2,4)-event at row k, the new {0,2} block extends rightward by absorbing as many consecutive even entries from the tail as are in {0,2}. The number of absorbed entries j_i is exactly the length of the leading {0,2} run in the tail of A_{k+1} starting at position b_k+1. This is DETERMINED by the initial sequence A_0 through the forward-difference formulas. Crucially, the condition "A_0 produces a death at row k" can be encoded as: there exist integers (gap values at certain positions) satisfying a finite set of constraints (parity, positivity, and the step/drain laws leading to b_k = 0). The step law, drain law, and XOR-interior evolution are all expressible as CONGRUENCES and INEQUALITIES on the A_0 entries, which for a fixed k give a finite linear system. If this system is infeasible for ALL k, then no 2-then-odds sequence can die, and the conjecture is proved for the general class. Farkas' lemma (or Motzkin's transposition theorem for mixed integer/linear systems) then gives a POSITIVE CERTIFICATE: a non-negative linear combination of the constraints that yields 0 ≤ −1 — a combinatorial proof of impossibility. The certificate IS the proof.

status: proposed
first-step: For a small fixed k (e.g., k=3, k=4, k=5), write down the exact system of constraints on the initial gaps g_1, g_2, ..., g_m that would be necessary for the block to die at row k. Encode: (a) g_0 = 2 (first gap), (b) all g_i even and positive, (c) the step-by-step evolution of the block boundary according to the proved step/drain laws, (d) the condition b_k = 0. Solve this as a feasibility problem for each k using an ILP solver (or manually for small k). If infeasible for all k up to some bound, extract the Farkas certificate and inspect whether it generalises to arbitrary k.

speculative: The certificate for small k might reveal a simple invariant — e.g., that the sum of the first few gaps plus the block length can never fall below a threshold. If the certificate has a uniform structure across k, it yields a closed-form proof. The approach is on the GENERAL-CLASS side: it does not use any property of primes beyond "2 then odds with even gaps." If it succeeds, it proves the conjecture for all 2-then-odds sequences with even gaps — a stronger result than the original. The risk is that the system might be FEASIBLE for some gap assignment, i.e., there IS a 2-then-odds sequence that dies — which would refute the general-class version of the conjecture (this is exactly what Eppstein 2011 threatens). If so, the infeasibility would need an additional hypothesis (e.g., a gap-growth bound or non-concentration condition), and the Farkas certificate would make explicit exactly which hypothesis is needed.
```
