# Withdrawn (superseded)

This candidate was proposed and immediately withdrawn in the same proposing
round, before research grounding. The mechanism it named — reading the halved
row as a height function, using the exact identity "block of row k+1 = longest
1-Lipschitz prefix of h_k", and checking whether the excess energy
Σ max(0, |∂h| − 1) is monotone — is the same object and the same energy as the
still-open approach `lipschitz-excess-lyapunov`, and the "flat prefix" primitive
is shared with the refuted `discrete-curvature-flow-flat-prefix`. It was
therefore a re-proposal under a different name (limit-shape / frozen boundary
layer), not a new line. Replaced this round by
`filtered-complex-spectral-sequence.md`.
