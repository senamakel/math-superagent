# Support

## Where To Go

| Need | Where |
| --- | --- |
| Usage question or design discussion | GitHub Discussions |
| Reproducible bug | GitHub Issues |
| Feature or API proposal | GitHub Issues |
| Suspected vulnerability | [SECURITY.md](SECURITY.md), never a public issue |
| How to contribute a change | [CONTRIBUTING.md](CONTRIBUTING.md) |

## Before Opening An Issue

Search existing issues first, then check [`README.md`](README.md) and the API
documentation (`cargo doc --open`).

A good report includes the crate version or commit, the output of
`rustc --version`, a minimal reproduction, the expected and actual behavior, and
the commands you ran.

## Response Expectations

This project is maintained on a best-effort basis. Issues with a minimal
reproduction get looked at first. There is no service-level agreement for
non-security reports.
